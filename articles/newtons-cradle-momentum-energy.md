## 1個入れたら、なぜ1個だけ出るのか

デスクに置く金属球5個のおもちゃ——**ニュートンのゆりかご**。端の球を1個引いて離すと、反対側の球が**1個だけ**飛び出す。2個引けば2個出る。真ん中の3個はほとんど動かない。なぜこんなにきれいに「個数が保存」されるのでしょうか。

答えは2つの保存則を**同時に**満たす解が、それしか無いからです。この記事では、等質量の弾性衝突という単純なモデルからこの不思議を導き、JavaScript の振り子シミュレーションで数値的に確かめます。

## 2つの保存則が答えを1つに絞る

等しい質量 $m$ の球が一直線に並び、左から速さ $v$ の球が静止した球列に突っ込むとします。完全弾性衝突では、衝突の前後で次の2つが保存されます。

$$
\text{運動量: } \sum_i m v_i = \text{const}, \qquad
\text{運動エネルギー: } \sum_i \tfrac{1}{2} m v_i^2 = \text{const}
$$

「$n$ 個の球が速さ $v$ で入ってきて、反対側から $k$ 個の球が速さ $u$ で出ていく」と仮定すると、運動量保存は $n v = k u$、エネルギー保存は $n v^2 = k u^2$ になります。この2式を割り算すると $v = u$、したがって $k = n$。

つまり**「入ってきたのと同じ個数の球が、同じ速さで出ていく」解だけが2つの保存則を両立**します。もし「1個入れて2個が半分の速さで出る」とすると、運動量は $1\cdot v = 2\cdot \tfrac{v}{2}$ で合いますが、エネルギーは $1\cdot v^2 \ne 2\cdot(\tfrac{v}{2})^2 = \tfrac{v^2}{2}$ で合いません。だから自然はこの解を選びません。

## 衝突の正体は「速度の交換」

等質量・完全弾性（反発係数 $e=1$）の2球衝突を解くと、答えは驚くほど単純です。

$$
v_1' = v_2, \qquad v_2' = v_1
$$

**2つの球は速度をそっくり交換する**だけ。だから動いている球は止まり、止まっていた球が動き出す。これが球列を「ところてん式」に伝わっていき、最後の球だけが飛び出すのです。中間の球は「受け取ってすぐ隣に渡す」ので、ほぼ静止して見えます。

反発係数 $e$ が 1 より小さい非弾性衝突では、相対速度が $e$ 倍に縮みます。運動量は保存したまま、エネルギーだけが熱・音・変形に失われます。等質量なら衝突後の速度は

$$
v_1' = \frac{1-e}{2}v_1 + \frac{1+e}{2}v_2, \qquad
v_2' = \frac{1+e}{2}v_1 + \frac{1-e}{2}v_2
$$

で与えられ、$e=1$ を代入すると上の「速度交換」に戻ります。実際の鋼球は $e \approx 0.95\sim0.99$ で、振幅が少しずつ減衰します。

## エネルギーは KE と PE を行き来する

各球は弦長 $L$ の振り子でもあります。角度 $\theta$ のとき、速さは $v=\omega L$、位置エネルギーは基準点（最下点）から測って $mgL(1-\cos\theta)$。系全体のエネルギーは

$$
E = \underbrace{\sum_i \tfrac12 m (\omega_i L)^2}_{\text{運動エネルギー}}
  + \underbrace{\sum_i m g L (1-\cos\theta_i)}_{\text{位置エネルギー}}
$$

引き上げた瞬間は全部 PE、最下点では全部 KE。衝突を挟みながら、エネルギーは KE と PE のあいだを往復し続けます。

![KE と PE が交換し合い、合計は一定に保たれる](/images/newtons-cradle/charts-closeup.png)

左図のように左端の1球を $22.9°$（$0.40\,\mathrm{rad}$）引くと、$m=1\,\mathrm{kg}$、$L=1\,\mathrm{m}$ で初期位置エネルギーは $mgL(1-\cos\theta_0) = 0.774\,\mathrm{J}$。右図はこの系を数値積分したエネルギー時刻歴で、オレンジ（KE）と水色（PE）が山と谷を入れ替えながら、白破線の**合計エネルギーがほぼ水平**に保たれているのが見えます（後述の Verlet 積分での合計エネルギーのドリフトは約 0.5%）。

## JavaScript で振り子＋衝突を解く

実装は「各球を独立した振り子として積分」→「隣り合う球が接触したら速度を交換」の2段構えです。振り子は $\ddot\theta = -\frac{g}{L}\sin\theta$ を Verlet で進めます。

```javascript
const N = 5, L = 1.0, g = 9.81;
let theta = new Array(N).fill(0), omega = new Array(N).fill(0);
theta[0] = -0.40;                          // 左端を引いて離す

function step(dt) {
  for (let i = 0; i < N; i++) {            // 各球を振り子として積分
    omega[i] += -(g / L) * Math.sin(theta[i]) * dt;
    theta[i] += omega[i] * dt;
  }
  for (let i = 0; i < N - 1; i++) {        // 隣接衝突 = 速度交換 (e=1)
    if (contact(i, i + 1) && omega[i] * L - omega[i+1] * L > 0) {
      const t = omega[i]; omega[i] = omega[i+1]; omega[i+1] = t;
    }
  }
}
```

接触判定は隣り合う球の中心間距離が直径以下になったかで行います。この最小モデルだけで、「1個入れたら1個出る」挙動が自然に再現されます。

## ツールで遊ぶ

[ニュートンのゆりかご シミュレーター](https://novasolver.jp/tools/newtons-cradle.html)で試してほしい操作：

- **球を直接ドラッグ**して引き上げ、離す。引く角度を変えて飛び出す勢いの違いを見る
- **プリセット「1球」「2球」「3球」**で、引いた数と同じ数だけ反対側が飛ぶことを確認
- **反発係数 e スライダー**を 1.0 → 0.8 に下げ、振幅がだんだん減衰して最後に全球が静止する様子を観察
- **弦の長さ L スライダー**を変え、結果表示の**周期 $T$** が $T=2\pi\sqrt{L/g}$ に従って変わることを確認（$L=1.5\,\mathrm{m}$ で $T \approx 2.46\,\mathrm{s}$）
- **重力加速度 g スライダー**を下げて（月面想定）動きがゆっくりになるのを見る
- **「エネルギーグラフ」表示**で、運動エネルギー・位置エネルギー・合計の時刻歴を眺める
- **速度倍率**スライダーでスロー再生し、衝突が伝わる瞬間を細かく見る

## まとめ

- 「1個入れたら1個出る」のは、運動量とエネルギーの**両方**を満たす解が「同数・同速で出る」だけだから
- 等質量・弾性衝突（$e=1$）の正体は**速度の交換** $v_1'=v_2,\ v_2'=v_1$。中間の球は受け渡し役で動かない
- 振り子の周期は $T=2\pi\sqrt{L/g}$。質量によらず、弦長と重力だけで決まる
- 全エネルギーは KE ⇄ PE を往復しながら保存（数値積分では合計のドリフト約 0.5%）。$e<1$ では衝突のたびに少しずつ失われる

衝突安全設計（LS-DYNA などの陽解法解析）や、ボールミル・打撃加工の基礎にもなる「等質量弾性衝突」を、手元のおもちゃで確かめてみてください。
