## 火力・原子力発電を支える水と蒸気のサイクル

世界の電力の多くは、水を沸かして蒸気を作り、その蒸気でタービンを回して生まれます。この蒸気動力プラントを理想化したのが**ランキンサイクル**です。ガスタービン（ブレイトン）との決定的な違いは、作動流体が**液体⇄気体の相変化**をすること。その結果、**ポンプが消費する仕事がタービンの取り出す仕事に比べて極端に小さい**という、ランキンならではの特徴が生まれます。

この記事では、ランキンサイクルの効率と「ポンプ仕事の小ささ」を JavaScript で確かめます。

♨️ **動くデモ**: [ランキンサイクルシミュレーター（NovaSolver）](https://novasolver.jp/tools/rankine-cycle.html)

## 4つの装置と熱効率

ランキンサイクルは ①ポンプ（加圧） ②ボイラ（加熱・蒸発） ③タービン（膨張・発電） ④凝縮器（冷却・液化）の 4 装置を巡ります。熱効率はエンタルピー $h$ で次のように書けます。

$$
\eta_{th} = \frac{w_{net}}{q_{in}} = \frac{(h_3-h_4)-(h_2-h_1)}{h_3-h_2}
$$

ポンプ仕事は液体を加圧するだけなので、比体積 $v$ がほぼ一定として

$$
w_{pump} \approx v\,(P_{high}-P_{low})
$$

と近似できます。ここがポイント：水の比体積 $v \approx 0.001\,\mathrm{m^3/kg}$ は気体の千分の一なので、ポンプ仕事は極めて小さくなります。

ボイラ圧力 3 MPa、凝縮圧力 10 kPa の標準条件で計算すると、ポンプ仕事は $v\Delta P = 0.001 \times (3000-10) = 2.99\,\mathrm{kJ/kg}$。一方タービン仕事は約 **819 kJ/kg**。つまり**ポンプ仕事はタービン仕事のわずか 0.46%**。発電に使う仕事のほとんどが正味の出力として残ります（仕事比が小さい）。このサイクルでシミュレーターが算出する熱効率は約 **30%** です。

## JavaScript 実装

ポンプ仕事とタービン仕事の比較が核心です。

```javascript
function rankine(Phigh_MPa, Plow_MPa, h1, h3, h4) {
  const v1 = 0.001;                                  // 飽和水の比体積 m³/kg
  const wp = v1 * (Phigh_MPa - Plow_MPa) * 1000;     // ポンプ仕事 ≈ vΔP [kJ/kg]
  const h2 = h1 + wp;                                // ポンプ出口
  const wt = h3 - h4;                                // タービン仕事
  const wnet = wt - wp;                              // 正味仕事
  const qin = h3 - h2;                               // ボイラ投入熱
  const eta = wnet / qin;                            // 熱効率
  const workRatio = wp / wt;                         // 仕事比（≈0.5% と非常に小さい）
  return { wp, wt, wnet, qin, eta, workRatio };
}
```

ボイラ圧力を上げると平均加熱温度が上がり、効率は向上します（カルノー効率に近づく）。シミュレーターでボイラ圧力を上げると効率が 30% から 34% 程度へ伸びるのが確認できます。

> 注：このシミュレーターは蒸気の物性を簡易な近似式で計算する教育用モデルです。厳密な蒸気表（IAPWS）とは数値が多少ずれますが、「ポンプ仕事が小さい」「圧力を上げると効率が上がる」という定性的な傾向は正しく再現します。

## ツールで遊ぶ

[ランキンサイクルシミュレーター](https://novasolver.jp/tools/rankine-cycle.html)で試してほしい操作：

- **ボイラ圧力スライダー**を上げ、「熱効率 η_th」が向上するのを確認
- **凝縮圧力スライダー**を下げ、効率が上がる（背圧が低いほど有利）のを見る
- **「正味仕事」と「ボイラ熱量」**を比較し、**仕事比**が非常に小さいことを確認
- **タービン効率・ポンプ効率スライダー**で実機の非可逆損失の影響を見る
- **T-s 線図**で飽和ドームとサイクルの位置関係を読む
- **「冷凍サイクル」モード**に切り替えて、同じ装置を逆に使うヒートポンプ／冷凍機を見る

## まとめ

- ランキンサイクルの効率は $\eta = w_{net}/q_{in}$（エンタルピー差で計算）
- ポンプ仕事 $\approx v\Delta P$ は液体の小さい比体積ゆえ極めて小さい
- 標準条件でポンプ仕事はタービン仕事の約 0.46%、効率は約 30%
- ボイラ圧力を上げ、凝縮圧力を下げると効率が向上する

火力・原子力発電の基礎を、圧力やタービン効率を動かしながら体感してみてください。
