## なぜ自転車は坂道でギアを軽くするのか

自転車で坂を登るときギアを軽くすると、ペダルは速く回るけれど力は小さくて済みます。逆に平地で重いギアにすると、ゆっくり強く進む。これは**歯車比**によって**回転数とトルク（回す力）を交換**しているからです。エンジンの動力を車輪に、モーターの高速回転をロボットの関節の大トルクに——歯車は機械のいたるところで速度と力を変換しています。

この記事では歯車比の式を導き、JavaScript で回転数・トルクの変換を計算します。

## 歯車比と速度・トルクの変換

噛み合う2つの歯車では、歯数の比が**歯車比**になります。

$$
i = \frac{Z_2}{Z_1} = \frac{n_1}{n_2}
$$

$Z$ は歯数、$n$ は回転数。駆動歯車 $Z_1$ より従動歯車 $Z_2$ の歯が多ければ $i>1$ の**減速**で、出力は

$$
n_2 = \frac{n_1}{i}\quad(\text{回転数は}1/i),\qquad
T_2 = T_1\cdot i\cdot\eta\quad(\text{トルクは}i\,\text{倍})
$$

$\eta$ は伝達効率（摩擦損失）。**回転数が下がる分、トルクが上がる**——これが歯車の本質です。エネルギー（動力 $P=T\omega$）は保存されるので、速度を犠牲にして力を得る（またはその逆）というトレードオフになります。

ツールの既定例（$Z_1=20$、$Z_2=40$、入力 $n_1=1500\,\mathrm{rpm}$、$T_1=10\,\mathrm{N\cdot m}$、$\eta=0.98$）では歯車比 $i=2$、出力回転数 $n_2=750\,\mathrm{rpm}$（半分）、出力トルク $T_2=19.6\,\mathrm{N\cdot m}$（約2倍）。伝達動力は $P=T_1\cdot2\pi n_1/60\approx1571\,\mathrm{W}$ です。

![噛み合う歯車（左）と、回転数↓・トルク↑のトレードオフ（右）](/images/gear-ratio/charts-closeup.png)

噛み合う歯車は必ず**逆向き**に回ります。従動歯車は歯数比だけ遅く回転します（上図右で 1500→750 rpm、トルクは 10→19.6 N·m）。

## 複合歯車列と遊星歯車

大きな減速比が必要なときは、複数段を直列にした**複合歯車列**を使います。全体の歯車比は各段の積です。

$$
i_{\text{total}} = \prod_{k=1}^{n} \frac{Z_{2k}}{Z_{1k}}
$$

2段それぞれ $i=4$ なら全体で $4\times4=16$ の減速になります。さらにコンパクトに大減速を得るのが**遊星歯車**。リングギアを固定した場合の歯車比は

$$
i = 1 + \frac{Z_R}{Z_S}
$$

（$Z_S$ は太陽歯車、$Z_R$ はリングギアの歯数）。自動車の自動変速機やロボットの関節減速機（波動歯車）で多用される、同軸で大減速・高トルクを実現する方式です。

## JavaScript 実装

歯車比と出力の計算は素直です。

```javascript
// 単純・複合歯車列
let i_total = 1;
for (const [z1, z2] of teeth) i_total *= z2 / z1;   // 各段の比の積
const etaTot = Math.pow(eta, teeth.length);          // 段数ぶんの効率
const nOut = n1 / i_total;                           // 出力回転数
const tOut = t1 * i_total * etaTot;                  // 出力トルク
const power = t1 * 2*Math.PI*n1 / 60;                // 伝達動力 [W]
// 遊星（リング固定）
const i_planet = 1 + zr / zs;
```

- **歯数 Z₁・Z₂ スライダー**を変え、**歯車比 i** と出力回転数・トルクがどう変わるか見る
- **減速**（$Z_2>Z_1$）で回転数が下がりトルクが上がる、**増速**（$Z_2<Z_1$）でその逆になることを確認
- **入力回転数 n₁・トルク T₁ スライダー**を変え、出力と**伝達動力 P** の関係を読む
- **歯車タイプ**を「単純」「複合」「遊星」で切り替え、複合は段数の積、遊星は $1+Z_R/Z_S$ になることを確認
- **複合歯車**で段数を増やし、大きな減速比を作る
- **噛み合いアニメーション**で、隣り合う歯車が逆向きに回ることを観察
- **計算結果**（歯車比・出力回転数・出力トルク・伝達動力・ピッチ円直径）を確認

## まとめ

- 歯車比 $i=Z_2/Z_1$。減速で回転数は $1/i$、トルクは $i$ 倍（動力は保存）
- 既定例で $i=2$：1500→750 rpm、10→19.6 N·m
- 複合歯車列は各段の積 $i=\prod Z_{2k}/Z_{1k}$、遊星（リング固定）は $i=1+Z_R/Z_S$
- 噛み合う歯車は逆回転。速度と力のトレードオフが機械設計の要

自転車・自動車・ロボット・産業機械の動力伝達を支える歯車比を、歯数を変えながら体感してみてください。
