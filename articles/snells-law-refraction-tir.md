## ストローが水面で「折れて」見える理由

コップの水に挿したストローが水面で折れ曲がって見える、プールの底が実際より浅く見える——これらは光が異なる媒質の境界で進む向きを変える**屈折**のせいです。屈折を支配するのが**スネルの法則**。そしてこの法則の延長線上に、光ファイバーが光を閉じ込める鍵となる**全反射**があります。

この記事ではスネルの法則と臨界角を導き、JavaScript で光線図を描いて、全反射が起きる条件を確かめます。

## スネルの法則

屈折率 $n_1$ の媒質から $n_2$ の媒質へ光が入るとき、入射角 $\theta_1$ と屈折角 $\theta_2$（いずれも境界の法線から測る）の間には

$$
n_1\sin\theta_1 = n_2\sin\theta_2
$$

が成り立ちます。屈折率は「その媒質中で光がどれだけ遅くなるか」の指標で、空気 1.00、水 1.33、ガラス 1.50、ダイヤモンド 2.42。**屈折率の大きい（光学的に密な）媒質に入ると、光は法線に近づく**ように曲がります。

ツールの既定値（空気 $n_1=1.0$ →ガラス $n_2=1.5$、入射角 $\theta_1=40°$）で計算すると

$$
\sin\theta_2 = \frac{n_1}{n_2}\sin\theta_1 = \frac{1.0}{1.5}\sin40° = 0.429
\;\Rightarrow\; \theta_2 = 25.4°
$$

入射 40° の光が、ガラス中では 25.4° と法線寄りに曲がります。

## 全反射と臨界角

逆に**密な媒質から疎な媒質へ**（ガラス→空気のように $n_1>n_2$）進む場合、光は法線から**遠ざかる**ように曲がります。入射角を上げていくと、ある角度で屈折角が 90°（境界に沿う）に達し、それを超えると光は**まったく屈折できず、すべて反射**されます。これが**全反射（TIR）** です。

その境目の入射角を**臨界角**と呼び、$\theta_2=90°$ から

$$
\theta_c = \arcsin\!\left(\frac{n_2}{n_1}\right)
$$

ガラス→空気なら $\theta_c=\arcsin(1/1.5)=41.8°$。$\theta_1>41.8°$ では全反射が起きます（上図右の曲線が臨界角で途切れているのがそれ）。屈折率の高いダイヤモンドでは $\theta_c=24.4°$ と小さく、内部で何度も全反射を繰り返すため、あの強い輝き（ブリリアンス）が生まれます。

**光ファイバー**はこの全反射を使って、コア（高屈折率）に閉じ込めた光を損失なく遠くまで運びます。インターネットを支える光通信の根幹が、この単純な角度の法則なのです。

## JavaScript 実装

スネルの法則と全反射判定は数行です。

```javascript
function compute(n1, n2, theta1) {
  const sinTheta2 = (n1 / n2) * Math.sin(theta1 * Math.PI/180);
  const isTIR = sinTheta2 > 1.0;                              // 全反射判定
  const theta2 = isTIR ? null : Math.asin(sinTheta2) * 180/Math.PI;
  const critAngle = n1 > n2 ? Math.asin(n2/n1) * 180/Math.PI : null;  // 臨界角
  return { theta2, critAngle, isTIR };
}
```

$\sin\theta_2 > 1$（数学的に解が無い）が、そのまま「屈折できない＝全反射」を意味します。

## ツールで遊ぶ

[スネルの法則シミュレーター](https://novasolver.jp/tools/snells-law.html)で試してほしい操作：

- **入射角 θ₁ スライダー**を動かし、屈折光（オレンジ）が曲がる様子を見る
- **屈折率 n₁・n₂ スライダー**や**媒質プリセット**（空気・水・ガラス・ダイヤモンド）を切り替え、曲がり方の違いを比較
- **n₁ > n₂**（例：ガラス→空気）にして入射角を上げ、**臨界角を超えると全反射**になることを確認（**状態**表示が「全反射」に変わる）
- **計算結果**で「屈折角 θ₂」「臨界角 θc」「n₂/n₁」を読む
- **ダイヤモンド**（n=2.42）で臨界角が 24.4° と小さいことを確認（強い輝きの理由）
- **屈折角 vs 入射角グラフ**で、臨界角での曲線の途切れを観察

## まとめ

- スネルの法則 $n_1\sin\theta_1=n_2\sin\theta_2$。密な媒質に入ると光は法線に近づく
- 空気→ガラス（$\theta_1=40°$）で屈折角 $\theta_2=25.4°$
- 密→疎（$n_1>n_2$）で入射角が臨界角 $\theta_c=\arcsin(n_2/n_1)$ を超えると**全反射**
- ガラス→空気の臨界角は 41.8°。光ファイバー・プリズム・ダイヤの輝きの原理
