## サインの足し算で「角ばった波」を作る

なめらかな正弦波をたくさん足し合わせると、角ばった方形波やのこぎり波が作れる——これが**フーリエ級数**です。あらゆる周期信号は、基本波とその整数倍の高調波（サイン・コサイン）の重ね合わせで表せます。

ところが、不連続な角（ジャンプ）を持つ波を再現しようとすると、高調波をいくら足しても角の近くで波形が**約 9% 行き過ぎる**——この消えない行き過ぎが**ギブス現象**です。この記事ではフーリエ級数の係数を導き、JavaScript で方形波を合成し、ギブス現象を数値で確かめます。

## フーリエ級数と各波形の係数

周期 $T$ の信号 $f(t)$ は次の級数で表せます。

$$
f(t) = \frac{a_0}{2} + \sum_{n=1}^{N}\left(a_n\cos\frac{2\pi nt}{T} + b_n\sin\frac{2\pi nt}{T}\right)
$$

奇関数（原点対称）の代表的な波形では、サイン係数 $b_n$ だけで書けます。

- **方形波**：$b_n = \dfrac{4A}{n\pi}$（**奇数 $n$ のみ**）
- **三角波**：$b_n = \dfrac{8A}{n^2\pi^2}\sin\dfrac{n\pi}{2}$
- **のこぎり波**：$b_n = -\dfrac{2A}{n\pi}(-1)^n$

係数の減り方が波形の「滑らかさ」を決めます。方形波・のこぎり波は $1/n$ でゆっくり減るため高調波が長く尾を引き、角がシャープ。三角波は $1/n^2$ で速く減るので、少ない高調波でなめらかに収束します。

## ギブス現象：消えない約9%の行き過ぎ

方形波を有限項 $N$ で打ち切ると、不連続点（ジャンプ）の近くで部分和がオーバーシュートします。高調波を増やすと**行き過ぎの幅は狭く**なりますが、**高さは約 8.95% に収束して消えません**。これがギブス現象です。

オーバーシュートはジャンプの高さに対して約 8.95%。方形波（$-A$ から $+A$、ジャンプ $2A$）では、ピークが $A$ をどれだけ超えるかで測ると振幅 $A$ の**約 18%**に相当します。数値計算でも $N=12$ で部分和の最大値は約 $1.18A$（$A$ 比 +18%）。$N$ を 50 にしても 100 にしても、この値はほぼ変わりません——**項数を増やしても解決しない**のがギブス現象の厄介なところで、信号処理では窓関数などで緩和します。

なお三角波は連続なのでギブス現象が起きず、なめらかに収束します。

## JavaScript 実装

各波形の係数で部分和を組み立てるだけです。

```javascript
function evalPartialSum(type, A, N, t) {
  let s = 0;
  for (let n = 1; n <= N; n++) {
    let bn = 0;
    if (type === 'square')        bn = (n % 2 === 1) ? 4*A/(n*Math.PI) : 0;
    else if (type === 'triangle') bn = 8*A/(n*n*Math.PI*Math.PI) * Math.sin(n*Math.PI/2);
    else if (type === 'sawtooth') bn = -2*A/(n*Math.PI) * Math.pow(-1, n);
    s += bn * Math.sin(2*Math.PI*n*t);
  }
  return s;
}
// ギブス: 部分和の最大値を測ると、方形波で max ≈ 1.18A（A比+18% = ジャンプの約9%）
```

## ツールで遊ぶ

[フーリエ級数シミュレーター](https://novasolver.jp/tools/fourier-series.html)で試してほしい操作：

- **高調波次数 N スライダー**（1〜50）を上げ、部分和が目標波形に近づくのを見る
- **波形の種類**を「方形波」「三角波」「のこぎり波」「半波整流サイン」で切り替え
- 方形波で **N をいくら増やしても、角のオーバーシュート（ギブス）が消えない**ことを **Gibbs バッジ**で確認
- **三角波**に切り替えると、ギブス現象が起きずなめらかに収束する（係数が $1/n^2$ で速く減衰）ことを比較
- **スペクトル表示**で、方形波は奇数次のみ、係数が $4/(n\pi)$ で減衰することを確認
- **計算結果**の「最大振幅」「RMS 誤差」で収束の度合いを数値で追う

## まとめ

- フーリエ級数：周期信号は高調波（サイン・コサイン）の重ね合わせで表せる
- 係数の減衰が滑らかさを決める：方形波・のこぎり波は $1/n$、三角波は $1/n^2$
- **ギブス現象**：不連続点で約 9%（ジャンプ基準。振幅 $A$ 基準なら約 18%、ピーク $\approx1.18A$）の行き過ぎが、項数を増やしても消えない
- 三角波など連続な波形ではギブス現象は起きない
