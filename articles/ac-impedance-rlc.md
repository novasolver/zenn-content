## 直列RLC回路で何が起きるのか

抵抗 $R$、コイル $L$、コンデンサ $C$ を一直線につないで交流電源 $V(t)=V_0\sin(\omega t)$ を加える。たったこれだけの回路ですが、周波数 $f$ を変えると回路の「通りにくさ」（インピーダンス $|Z|$）が大きく上下し、ある特定の周波数でストンと最小値に落ちます。これが**直列共振**で、ラジオの選局やスピーカーのクロスオーバーといった身近な技術の土台になっています。

ポイントは、コイルとコンデンサが**周波数で抵抗値が変わる素子**だということです。コイルの誘導性リアクタンスは $X_L=\omega L$ で高周波ほど大きく、コンデンサの容量性リアクタンスは $X_C=1/(\omega C)$ で低周波ほど大きい。両者は符号が逆なので、ある周波数でちょうど打ち消し合い、残るのは $R$ だけになります。

この記事では：

1. 各素子のリアクタンスと、複素数（ベクトル）としての合成
2. 共振周波数 $f_0$ と品質係数 $Q$ の意味
3. JavaScript での実装と、周波数特性の V 字を数値で確かめる

## リアクタンスとインピーダンスの合成

角周波数 $\omega=2\pi f$ における各素子のリアクタンスは次の通りです：

$$
X_L = \omega L,\qquad X_C = \frac{1}{\omega C},\qquad X = X_L - X_C
$$

抵抗は周波数によらず実部 $R$、コイルは位相 $+90°$、コンデンサは位相 $-90°$ を持つため、直列接続のインピーダンスは複素数として加算されます：

$$
Z = R + j\left(\omega L - \frac{1}{\omega C}\right) = R + jX
$$

観測できる量は、その大きさと位相角です：

$$
|Z| = \sqrt{R^2 + X^2},\qquad \varphi = \arctan\!\left(\frac{X}{R}\right)
$$

$\varphi$ が正なら誘導性（電流が電圧より遅れる）、負なら容量性（電流が電圧より進む）。合成リアクタンス $X$ がゼロになる周波数では $|Z|$ が最小値 $R$ まで下がり、$\varphi=0$ で純抵抗的にふるまいます。

## 共振周波数と品質係数

$X_L=X_C$ となる周波数が共振周波数 $f_0$ です。$\omega_0 L = 1/(\omega_0 C)$ を解くと：

$$
f_0 = \frac{1}{2\pi\sqrt{LC}}
$$

共振の鋭さを表すのが品質係数 $Q$ で、直列RLCでは次のように書けます：

$$
Q = \frac{1}{R}\sqrt{\frac{L}{C}} = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 R C}
$$

$Q$ が大きいほど V 字の谷が深く鋭くなり、狙った周波数だけくっきり選べます。半値幅（帯域幅）は $\Delta f = f_0/Q$ で決まります。重要なのは、$f_0$ は $LC$ の**積**で決まるのに対し、$Q$ は $L/C$ の**比**で決まる点です。$L$ を2倍・$C$ を半分にすれば $f_0$ は同じまま $Q$ だけ変わるので、共振周波数と選択度を別々に設計できます。

## JavaScript での実装

ツールの計算ロジックはそのままシンプルな関数群になります（ツールの実装に準拠）：

```javascript
const L = 10e-3;   // 10 mH
const C = 1e-6;    // 1 μF

const omega = (f) => 2 * Math.PI * f;
const XL = (f) => omega(f) * L;
const XC = (f) => 1 / (omega(f) * C);

// インピーダンスの大きさ |Z| = √(R² + (X_L - X_C)²)
function Zmag(f, R) {
  const X = XL(f) - XC(f);
  return Math.sqrt(R * R + X * X);
}

// 位相角 φ = atan2(X, R)（度）
function phaseDeg(f, R) {
  const X = XL(f) - XC(f);
  return Math.atan2(X, R) * 180 / Math.PI;
}

// 共振周波数と品質係数
const f0 = 1 / (2 * Math.PI * Math.sqrt(L * C));   // 1591.5 Hz
const Q  = (1 / 100) * Math.sqrt(L / C);           // R=100 → 1.00
```

デフォルト値 $R=100\,\Omega,\ L=10\,\mathrm{mH},\ C=1\,\mathrm{\mu F}$ で計算すると、$f_0=1591.5\,\mathrm{Hz}$、$Q=1.00$ になります。ツールの初期周波数 $f=1592\,\mathrm{Hz}$ はこの共振点とほぼ一致しているので、起動直後から「共振真っ最中」の状態を観察できます。

## 周波数特性のV字を数値で確かめる

$R=100\,\Omega$ で固定し、いくつかの周波数で $|Z|$ と $\varphi$ を計算すると、共振点を底とする V 字がはっきり現れます：

| 周波数 $f$ | $X_L$ | $X_C$ | $\lvert Z\rvert$ | $\varphi$ |
|---|---|---|---|---|
| 100 Hz | 6.3 Ω | 1592 Ω | 1588 Ω | $-86.4°$ |
| 1000 Hz | 62.8 Ω | 159.2 Ω | 138.8 Ω | $-43.9°$ |
| **1591.5 Hz**（$f_0$） | 100.0 Ω | 100.0 Ω | **100.0 Ω** | $0.0°$ |
| 2500 Hz | 157.1 Ω | 63.7 Ω | 136.8 Ω | $+43.1°$ |
| 10000 Hz | 628.3 Ω | 15.9 Ω | 620.0 Ω | $+80.7°$ |

低周波では $X_C$ が支配的で容量性（$\varphi<0$、電流が進む）、高周波では $X_L$ が支配的で誘導性（$\varphi>0$、電流が遅れる）。共振点 $f_0$ でちょうど $X_L=X_C=100\,\Omega$ となって打ち消し合い、$|Z|=R=100\,\Omega$ に落ちます。

![直列RLCの周波数特性（|Z|と位相角）](/images/ac-impedance-rlc/charts-closeup.png)

両対数（log-log）でプロットするのは、$|Z|$ が周波数で数桁にわたって変化するからです。線形軸では低周波か高周波の片方しか見えませんが、log-log にすると全範囲が一枚に収まり、コンデンサの $-20\,\mathrm{dB/dec}$（$X_C\propto 1/f$）とコイルの $+20\,\mathrm{dB/dec}$（$X_L\propto f$）の傾きがどちらも直線として現れます。

## Q値で共振の鋭さがどう変わるか

$Q=(1/R)\sqrt{L/C}$ なので、$L$ と $C$ を固定して $R$ だけを変えると選択度が変わります。$L=10\,\mathrm{mH},\ C=1\,\mathrm{\mu F}$ では $\sqrt{L/C}=100$ なので：

| $R$ | $Q=(1/R)\sqrt{L/C}$ | 帯域幅 $\Delta f=f_0/Q$ | 共振点の谷 |
|---|---|---|---|
| 10 Ω | 10.0 | 159 Hz | 深く鋭い |
| 100 Ω | 1.00 | 1592 Hz | なだらか |
| 1000 Ω | 0.10 | 約 16 kHz | ほぼ V 字でない |

$R$ を小さくするほど $Q$ が上がり、谷が深く鋭くなって特定周波数だけを選べるようになります。ただし注意点があり、理想の L・C だけなら共振点で $|Z|=0$（電流無限大）になりますが、現実にはコイルの巻線抵抗・コンデンサの ESR・配線抵抗が必ず入るため、谷の底は $R$ で止まります。逆に $Q$ を上げすぎると共振点でコンデンサ両端に $Q\cdot V_{\text{in}}$ もの電圧がかかり、部品定格を超える危険もあります。

## まとめ

- 直列RLCのインピーダンスは $Z=R+j(\omega L - 1/(\omega C))$ という複素数（ベクトル）の和
- 大きさ $|Z|=\sqrt{R^2+X^2}$、位相 $\varphi=\arctan(X/R)$。共振点 $f_0=1/(2\pi\sqrt{LC})$ で $|Z|$ は最小値 $R$
- デフォルト値（$R=100,\ L=10\,\mathrm{mH},\ C=1\,\mathrm{\mu F}$）では $f_0=1591.5\,\mathrm{Hz},\ Q=1.00$
- $f_0$ は $LC$ の積、$Q=(1/R)\sqrt{L/C}$ は $L/C$ の比で決まり、共振周波数と選択度を別々に設計できる

「周波数で抵抗値が変わる素子を組み合わせると、特定周波数だけ通る／止める」という発想は、フィルタ・同調・力率改善まで電気電子の広い範囲を貫く考え方です。3素子のベクトル和でそれを体感できるのが直列RLC回路の面白さです。
