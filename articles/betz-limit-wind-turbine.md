## ベッツ限界とは

風車はどんなに頑張っても、流れてくる風の運動エネルギーの **59.3% 以上**を取り出せません。この上限を**ベッツ限界**と呼びます。1919 年にドイツの物理学者 Albert Betz が、風車を理想的な流管としてモデル化して導いた結果です。

直感的にはこうです。風車が風を完全に止めようとすると、後ろに空気の出口がなくなり、そもそも新しい風が流れてこなくなります。逆にまったく減速させなければ、エネルギーは取り出せません。**「適度に減速させて、適度に通過させる」**バランス点が存在し、そこで取り出せる動力が最大になります。

この記事では：

1. 軸方向誘導係数 $a$ とパワー係数 $C_P(a)$ の定義
2. 数行の JavaScript による $C_P$ 曲線の計算
3. 最適点 $a=1/3$ で $C_{P,\max}=16/27$ になることを数値で確認

## 軸方向誘導係数とパワー係数

風車を通過する空気を 1 次元の流管としてモデル化します。上流の風速を $V_\infty$、ローター位置での風速を $V=(1-a)V_\infty$、下流（後流）の風速を $V_w=(1-2a)V_\infty$ とします。ここで $a$ が**軸方向誘導係数**で、「ローター位置でどれだけ風が遅くなったか」の比率です。

質量保存と運動量保存だけから、取り出される動力は

$$
P = 2\rho A\,V_\infty^3\,a(1-a)^2
$$

となり、風がもともと持つ利用可能動力 $P_{wind}=\tfrac{1}{2}\rho A V_\infty^3$ で割ると、無次元のパワー係数

$$
C_P(a) = \frac{P}{P_{wind}} = 4a(1-a)^2
$$

が得られます。$\rho$ は空気密度、$A=\pi D^2/4$ はローター掃過面積です。

## 最大値はどこか — 微分して求める

$C_P(a)=4a(1-a)^2$ を $a$ で微分すると：

$$
\frac{dC_P}{da} = 4(1-a)(1-3a) = 0
$$

これを解くと $a=1$（自明解）と $a=1/3$。物理的に意味があるのは $a=1/3$ で、ここで最大値

$$
C_{P,\max} = 4\cdot\frac{1}{3}\cdot\left(\frac{2}{3}\right)^2 = \frac{16}{27} \approx 0.5926
$$

をとります。これがベッツの理論上限です。

## JavaScript で C_P 曲線を計算する

ツールの計算ロジックは驚くほど短く書けます：

```javascript
function cpOf(a) {
  return 4 * a * (1 - a) * (1 - a);   // C_P(a) = 4a(1-a)²
}

function power(V, D, a, rho) {
  const A     = Math.PI * D * D / 4;        // 掃過面積 [m²]
  const Pwind = 0.5 * rho * A * V ** 3;     // 利用可能動力 [W]
  const cp    = Math.max(0, cpOf(a));
  const Pcap  = cp * Pwind;                  // 取り出し動力 [W]
  const ratio = cp / (16 / 27);              // ベッツ限界比
  return { Pwind, Pcap, cp, ratio };
}

// デフォルト（V=12m/s, D=80m, a=1/3, ρ=1.225）
console.log(power(12, 80, 0.333, 1.225));
// cp ≈ 0.593, Pwind ≈ 5.32 MW, Pcap ≈ 3.15 MW, ratio ≈ 100%
```

$a=1/3$ ちょうどで $C_P$ がベッツ限界 $16/27\approx0.593$ に一致し、ベッツ限界比が 100% になります。

## C_P(a) 曲線と流管の収縮を見る

$C_P(a)$ は $a=1/3$ を頂点とする山型の曲線です。$a=0$（素通り）と $a=0.5$（後流速度ゼロ）で挟まれた範囲が物理的に意味をもちます。

![パワー係数 C_P(a) 曲線とベッツ限界](/images/betz-limit/charts-closeup.png)

ツールでは、この曲線に加えて風車の正面図と「上から見た流管」を描きます。風が風車を通過する際に減速し、連続の式（$\rho A V = $ 一定）から後流側で流管が拡がる様子が $a$ に応じて変化します。

## 最適点を数値で確かめる

$C_P(a)=4a(1-a)^2$ を計算した表です。$a=1/3$ が確かにピークで、$a$ を増やしすぎると逆に下がることが分かります：

| 軸方向誘導係数 $a$ | パワー係数 $C_P$ |
|---|---|
| 0.0 | 0.0000 |
| 0.1 | 0.3240 |
| 0.2 | 0.5120 |
| **1/3** | **0.5926** |
| 0.4 | 0.5760 |
| 0.5 | 0.5000 |

$a=0.5$ では後流速度 $V_w=(1-2a)V_\infty=0$、つまり風車のすぐ後ろで空気が止まる状態で、$C_P=0.5$ まで下がります。$a>0.5$ では計算上 $C_P$ が負になり、これは流管モデル自体が破綻していることを示します。実機では $a\approx0.4$ が現実的な上限です。

もう一つ重要なのが**動力が風速の 3 乗に比例する**点です。質量流量が $V$ に比例し、運動エネルギーが $V^2$ に比例するので合わせて $V^3$ になります。年平均風速 6m/s と 8m/s では、同じ風車で

$$
\left(\frac{8}{6}\right)^3 = 2.370
$$

と **2.37 倍**の発電量差が出ます。これが「風車は風の良いサイトに建てる」「洋上風力が有利」と言われる根拠です。

> なぜ実機はベッツ限界に届かないのか。ベッツの導出は軸対称・無摩擦・後流回転なしの理想モデルです。実機では翼の粘性抵抗、後流回転による損失（Glauert 補正）、翼端渦損失、発電機・ギアの変換効率が加わり、$C_P$ は 0.45〜0.50 程度に留まります。それでもベッツ比（$C_P/C_{P,\max}$）で 76〜84% に達しており、工学的には極めて高効率です。

## まとめ

- ベッツ限界は軸対称・無摩擦の風車が取り出せる動力の運動量理論上限
- パワー係数 $C_P(a)=4a(1-a)^2$ は $a=1/3$ で最大、$C_{P,\max}=16/27\approx0.593$
- $a$ を大きくしすぎると後流速度がゼロになり逆効果。実機の現実的上限は $a\approx0.4$
- 動力は風速の 3 乗に比例。年平均風速 6→8m/s で発電量は 2.37 倍

「効率を上げるより、まず風の良い場所に大きな風車を建てる」という風力発電の設計思想は、$P=C_P\cdot\tfrac{1}{2}\rho A V^3$ という一本の式から自然に導かれます。
