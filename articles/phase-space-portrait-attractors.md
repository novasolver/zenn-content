## 位相空間とは

「時間 vs 変位」のグラフは振動の波形を見せてくれますが、系の**定性的な構造**——周期運動なのか、減衰するのか、カオスなのか——は読み取りにくいものです。

そこで横軸に変位 $x$、縦軸に速度 $\dot{x}$ をとった平面＝**位相空間**で軌跡を描きます。すると運動の「型」が一目でわかります：

- 閉じた**楕円** → 周期運動（エネルギー保存）
- 原点へ巻き込む**螺旋** → 減衰（安定固定点）
- 孤立した閉曲線＝**リミットサイクル** → 自励振動
- 二度と閉じない**ストレンジアトラクタ** → カオス

この記事では：

1. 位相空間でベクトル場と軌跡を描く方法
2. 5 つの古典系（単振動・減衰・van der Pol・Duffing・Lorenz）の読み分け
3. リミットサイクルの「振幅が初期条件によらない」性質を数値で確認

## 2変数の1階系として書く

2 階の運動方程式 $\ddot{x} = a(x, \dot{x}, t)$ は、$y = \dot{x}$ とおけば 2 本の 1 階方程式になります：

$$
\dot{x} = y, \qquad \dot{y} = a(x, y, t)
$$

位相空間の各点 $(x, y)$ に**ベクトル $(\dot{x}, \dot{y})$** を割り当てたものが**ベクトル場**で、軌跡はこの矢印に沿って流れます。NovaSolver のツールは RK4（$dt=0.01$）で積分し、矢印と軌跡を重ねて描いています。

```javascript
function rk4(f, s, dt) {        // s = [x, y], f(s) = [ẋ, ẏ]
  const k1 = f(s);
  const k2 = f(s.map((v,i)=>v+k1[i]*dt/2));
  const k3 = f(s.map((v,i)=>v+k2[i]*dt/2));
  const k4 = f(s.map((v,i)=>v+k3[i]*dt));
  return s.map((v,i)=>v+(k1[i]+2*k2[i]+2*k3[i]+k4[i])*dt/6);
}
```

## 5 つの系を読み分ける

| 系 | 方程式 $(\dot{x}=y,\ \dot{y}=\dots)$ | 位相空間の姿 |
|---|---|---|
| 単純調和振動 | $-\omega^2 x$ | 閉じた楕円（保存） |
| 減衰振動 | $-2\gamma y - \omega^2 x$ | 原点への螺旋 |
| van der Pol | $\mu(1-x^2)y - x$ | リミットサイクル |
| Duffing（外力付き） | $-\delta y - x - \beta x^3 + \gamma\cos\omega t$ | ストレンジアトラクタ |
| Lorenz（x–z 投影） | （3 変数）| バタフライ型カオス |

**単振動**はエネルギー $E=\tfrac12 y^2 + \tfrac12\omega^2 x^2$ が保存するので軌跡は閉じた楕円。RK4 で 200 秒積分してもエネルギー変動は **0.0000%** で、楕円はきれいに閉じます。**減衰振動**ではエネルギーが散逸し、軌跡は原点（安定固定点＝アトラクタ）へ螺旋状に収束します（200 秒後の状態の大きさは $\sim10^{-13}$）。

## リミットサイクル：初期条件を忘れる振動

非線形系で最も面白いのが **van der Pol 振動子**：

$$
\dot{x} = y, \qquad \dot{y} = \mu(1 - x^2)\,y - x
$$

$|x|<1$ では負の減衰（エネルギーを注入）、$|x|>1$ では正の減衰（散逸）。この綱引きの結果、**どこから出発しても同じ 1 本の閉曲線（リミットサイクル）に吸い込まれます**。

![van der Pol のリミットサイクルとベクトル場](/images/phase-space-portrait/charts-closeup.png)

外側から来た軌跡も内側の小さな螺旋から来た軌跡も、同じサイクルに巻きつくのが見えます。数値的に確かめると、リミットサイクルの **x 方向振幅は初期条件にも $\mu$ にもほとんど依らず約 2.0**：

| $\mu$ | リミットサイクルの x 振幅 | 周期 |
|---|---|---|
| 0.5 | 2.00 | 6.38 |
| 1.0 | 2.01 | 6.66 |
| 2.0 | 2.02 | 7.63 |

$\mu$ を上げると振幅はほぼ一定のまま、波形が鋭くなり周期が伸びる（**緩和振動**）のが特徴です：

![μ を上げるとリミットサイクルが緩和振動に](/images/phase-space-portrait/slider-anim.gif)

この「初期条件を忘れて一定の振動に落ち着く」性質は、心臓の拍動・真空管発振器・概日リズムなど、**自励振動**のモデルとして使われます。線形のばね振動（楕円）が初期エネルギーをいつまでも覚えているのと対照的です。

## カオスへ

**Duffing 振動子**（非線形ばね＋周期外力）や **Lorenz 系**を選ぶと、軌跡はどの閉曲線にも収束せず、有限の領域を二度と同じ経路を通らずに埋めていきます——**ストレンジアトラクタ**です。最大リアプノフ指数 $\lambda>0$ がカオスの判定基準で、初期値鋭敏性（バタフライ効果）が現れます。

## ツールで遊ぶ

[位相空間ポートレート](https://novasolver.jp/tools/phase-space-portrait.html)で試してほしい操作：

- **系の選択**ドロップダウンで 5 つの系を切り替え、姿の違いを見比べる
- **キャンバスをクリック**して、その点から始まる軌跡を描く（複数同時に置ける）
- **「ランダム軌跡を追加」**で van der Pol に何本も流し込み、すべてが同じリミットサイクルへ吸い込まれるのを観察
- **ベクトル場の表示**をオン/オフして、矢印と軌跡の関係を確認
- 各系のパラメータ（$\mu,\ \gamma,\ \beta$ など）を変えて分岐を探す

## まとめ

- 位相空間 $(x, \dot{x})$ は運動の定性構造（周期・減衰・自励・カオス）を一目で見せる
- 2 階の式は $\dot{x}=y$ と組にして 1 階系にし、RK4 で積分する
- 楕円＝保存、螺旋＝減衰、リミットサイクル＝自励、ストレンジアトラクタ＝カオス
- van der Pol のリミットサイクルは振幅 ≈2.0 で初期条件に依らない（自励振動の本質）

「波形」ではなく「軌跡の形」で運動を捉えるのが、非線形力学の第一歩です。
