## ランベルト・ベールの法則とは

色のついた溶液に光を通すと、濃いほど・長く通すほど暗くなります。この「どれだけ光が吸われたか」を定量化するのが **ランベルト・ベールの法則** です：

$$
A = \varepsilon\, l\, c = -\log_{10} T
$$

- $A$：吸光度（無次元）
- $\varepsilon$：モル吸光係数 $[\mathrm{L\,mol^{-1}\,cm^{-1}}]$
- $l$：光路長 $[\mathrm{cm}]$
- $c$：濃度 $[\mathrm{mol/L}]$
- $T = I/I_0$：透過率（透過光 ÷ 入射光）

透過率と吸光度は対数で結ばれます：

$$
T = \frac{I}{I_0} = 10^{-A} = 10^{-\varepsilon l c}
$$

吸光度が濃度に比例するので、**未知試料の濃度を吸光度から逆算** できる——これが分光光度計による定量分析の原理です。

1. なぜ吸光度が「対数」で定義されるのか
2. 10 行の JavaScript で吸光度・透過率を計算する
3. なぜ実務では $A=0.1\sim1.5$ に収めるのか

## なぜ対数なのか — 光が指数的に減衰するから

光が溶液中を微小距離 $dx$ 進むたびに、一定割合だけ吸収されると仮定します。すると強度の減少は

$$
\frac{dI}{dx} = -k\,I \quad\Longrightarrow\quad I(x) = I_0\,10^{-\varepsilon c x}
$$

という指数関数になります。距離が 2 倍になれば通過する分子数も 2 倍、濃度が 2 倍になれば分子数も 2 倍——だから吸収は $\varepsilon l c$ の積に比例します。指数関数の肩に乗る量 $\varepsilon l c$ をそのまま指標にしたのが吸光度 $A$ で、対数で定義されるのは自然な帰結です。

「半分まで減衰する光路長」も計算できます。$T=1/2$ となる距離は

$$
l_{1/2} = \frac{\log_{10} 2}{\varepsilon c}
$$

で、ツールの「半減光路長」がこの値を出力します。

## 10 行の JavaScript 実装

代数式なので実装はごく単純です。ツールでは濃度を扱いやすい mmol/L で入力し、内部で mol/L に直しています：

```javascript
// 入力: ε[L/(mol·cm)], l[cm], c[mmol/L]
function beerLambert(eps, l, c_mmol) {
  const A = eps * l * (c_mmol * 1e-3);     // mmol/L → mol/L
  const T = Math.pow(10, -A);              // 透過率 (0〜1)
  const absorbed = (1 - T) * 100;          // 吸収された光の割合 [%]
  const halfLength = Math.log10(2) / (eps * c_mmol * 1e-3);  // 半減光路長 [cm]
  return { A, transmittance: T * 100, absorbed, halfLength };
}

// 既定値: ε=5000, l=1.0 cm, c=0.10 mmol/L
const r = beerLambert(5000, 1.0, 0.10);
console.log(`A = ${r.A.toFixed(3)}, T = ${r.transmittance.toFixed(1)}%`);
// A = 0.500, T = 31.6%
```

濃度の単位変換（`* 1e-3`）を忘れると吸光度が 1000 倍ずれます。単位は分析化学でいちばん事故りやすいポイントです。

## 吸光度と透過率の非線形な関係

吸光度は足し算的（線形）ですが、透過率は対数で結ばれるため急激に変化します。標準条件（$\varepsilon=5000$、$l=1$ cm）で濃度を上げていくと：

![A=εlc の検量線と A–T 非線形関係](/images/beer-lambert-law/charts-closeup.png)

| 濃度 $c$ [mmol/L] | 吸光度 $A$ | 透過率 $T$ | 吸収割合 |
|---|---|---|---|
| 0.10 | 0.500 | 31.6% | 68.4% |
| 0.20 | 1.000 | 10.0% | 90.0% |
| 0.30 | 1.500 | 3.2% | 96.8% |

吸光度が一定間隔（0.5 → 1.0 → 1.5）で増えても、透過率は 31.6% → 10.0% → 3.2% と急落します。$A=1$ で透過率はちょうど 10%、$A=2$ で 1% です。

## なぜ A = 0.1〜1.5 が「適正域」なのか

吸光度が高すぎても低すぎても、測定精度は落ちます。

- $A=0.1$ では $T=79.4\%$。入射光と透過光の差が小さすぎて、わずかな測定誤差が濃度推定に大きく響きます
- $A=2$ では $T=1\%$。透過光がほぼゼロで、検出器のノイズが支配的になります

このため実務では、吸光度がおおよそ $0.1\sim1.5$ に収まるように濃度や光路長を調整します。ヘモグロビンのように $\varepsilon$ が極端に大きい物質（$\varepsilon\approx120{,}000$）では、$c=0.01$ mmol/L という希薄濃度でも $A=1.2$ に達します。「濃すぎる試料は薄める」「光路長を変える」のはこの適正域に入れるためです。

なお、この比例関係が成り立つのは比較的低濃度の範囲に限られます。高濃度では分子間相互作用などで見かけの $\varepsilon$ が変化し、検量線が直線から外れることが知られています。

## まとめ

- ランベルト・ベールの法則 $A=\varepsilon l c=-\log_{10}T$ は、光が溶液中で指数的に減衰することから導かれる
- 既定条件（$\varepsilon=5000$、$l=1$、$c=0.10$ mM）で $A=0.500$、$T=31.6\%$
- 実装は単位変換に注意した 10 行。$A=1$ で $T=10\%$、$A=2$ で $T=1\%$
- 透過率は対数で結ばれるため、精度の出る適正域はおおよそ $A=0.1\sim1.5$

身近な「色の濃さ」が、分子 1 個あたりの光吸収という量子的な性質まで遡れる——シンプルな式の奥行きを感じられるテーマです。
