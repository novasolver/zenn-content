## 座屈とは「潰れる前に横にしなる」破壊

細長い棒を両端から押すと、材料が圧縮で潰れるより**ずっと小さい力**で、ある瞬間に横へ「ぱっ」としなって壊れます。これが**座屈（buckling）**です。プラスチック定規を両手で押し込むと、ある力を境に急に弓なりに曲がる——あの現象がまさに座屈です。

座屈は「材料が降伏したから壊れる」のではなく、「真っ直ぐな釣り合いが**不安定**になって別の曲がった形に飛び移る」という、剛性の問題です。だから材料強度（降伏応力）だけでなく、柱の**長さ・断面形状・端の固定のされ方**で臨界荷重が大きく変わります。

この記事では：

1. 細長い柱のための**オイラーの座屈荷重** $P_{cr}=\pi^2EI/(KL)^2$
2. 太短い柱で過大評価を防ぐ**ジョンソンの放物線式**
3. 両者を**細長比 $\lambda$** で自動的に切り替える境界の出し方

を、実際の計算値で確かめます。

## オイラーの座屈荷重

弾性座屈の臨界荷重は、Leonhard Euler が18世紀に導いた次式で与えられます：

$$
P_{cr} = \frac{\pi^2 EI}{(KL)^2}
$$

ここで $E$ はヤング率、$I$ は断面二次モーメント（最小主軸まわり）、$L$ は柱の長さ、$K$ は**有効長さ係数**です。$KL$ を「有効座屈長さ」と呼び、端の固定条件で決まります。

| 端末条件 | $K$ | 意味 |
|---|---|---|
| ピン—ピン | 1.0 | 両端が回転自由・移動拘束 |
| 固定—自由（片持ち） | 2.0 | 一端だけ完全固定 |
| 固定—ピン | 0.7 | 一端固定・他端ピン |
| 固定—固定 | 0.5 | 両端を回転拘束 |

注目すべきは $P_{cr}\propto 1/(KL)^2$ という形です。$K$ が半分になると有効長さが半分になり、臨界荷重は $2^2=4$ 倍になります。実際、同じ柱（鋼・円形 $d=50$ mm・$L=4$ m）で計算すると、ピン—ピン（$K=1.0$）の $P_{cr}=37.8$ kN に対し、固定—固定（$K=0.5$）は **151.4 kN とちょうど4倍**になります。「両端をしっかり固定すれば座屈に4倍強くなる」という設計上の指針が、この式から直接読み取れます。

## ジョンソン式 — 太短い柱の補正

オイラー式は「細長い柱」にしか当てはまりません。柱が太く短くなると、座屈する前に材料が降伏してしまうため、オイラー式は臨界荷重を**過大評価**します。極端な話、$L\to 0$ ではオイラー式の $P_{cr}$ は無限大に発散しますが、現実には断面の降伏荷重 $A\sigma_y$ で頭打ちになります。

そこで太短い柱には**ジョンソンの放物線式**を使います：

$$
P_{cr} = A\,\sigma_y\left[1 - \frac{\sigma_y}{4\pi^2 E}\left(\frac{KL}{r}\right)^2\right]
$$

$A$ は断面積、$\sigma_y$ は降伏応力、$r=\sqrt{I/A}$ は**断面二次半径**です。$KL/r$（細長比）が小さいとき、括弧内は1に近づき $P_{cr}\to A\sigma_y$（押し潰し荷重）になります。

## 細長比で式を切り替える

どこでオイラーとジョンソンを切り替えるか。その境界が**遷移細長比** $\lambda_c$ です。2本の曲線が滑らかに接する条件から導かれます：

$$
\lambda_c = \pi\sqrt{\frac{2E}{\sigma_y}}
$$

細長比 $\lambda=KL/r$ がこの値より**大きければオイラー式**（細長い長柱）、**小さければジョンソン式**（太短い短柱）です。鋼（$E=200$ GPa, $\sigma_y=250$ MPa）で計算すると：

$$
\lambda_c = \pi\sqrt{\frac{2\times 200\times10^9}{250\times10^6}} = 125.7
$$

材料を変えると境界も動きます。アルミ（$E=70$ GPa, $\sigma_y=270$ MPa）では $\lambda_c=71.5$、木材（$E=12$ GPa, $\sigma_y=30$ MPa）では $\lambda_c=88.9$。ヤング率が小さいほど早くオイラー領域に入る、というわけです。

この $\lambda_c$ では2式が一致します。オイラー応力 $\sigma_{cr}=\pi^2E/\lambda_c^2$ に $\lambda_c$ を代入すると、ちょうど $\sigma_y/2=125$ MPa になり、ジョンソン放物線の値とも一致します。曲線が折れずに連続するように $\lambda_c$ が定義されているのです。

## JavaScriptで実装する

切り替えロジックは20数行で書けます。ツールの計算もこの通りです：

```javascript
const E = 200e9, sy = 250e6;        // 鋼: ヤング率・降伏応力 [Pa]

// 円形断面 (直径 d[m])
function section(d) {
  const I = Math.PI * d**4 / 64;     // 断面二次モーメント
  const A = Math.PI * d**2 / 4;      // 断面積
  return { I, A };
}

function buckling(K, L, I, A) {
  const r    = Math.sqrt(I / A);         // 断面二次半径
  const lam  = K * L / r;                // 細長比 λ = KL/r
  const lamC = Math.PI * Math.sqrt(2 * E / sy);  // 遷移細長比
  if (lam > lamC) {                       // 細長い → オイラー
    return { Pcr: Math.PI**2 * E * I / (K * L)**2, mode: "Euler" };
  } else {                                // 太短い → ジョンソン
    const Pcr = A * sy * (1 - sy * lam**2 / (4 * Math.PI**2 * E));
    return { Pcr, mode: "Johnson" };
  }
}

const { I, A } = section(0.05);          // d = 50mm
console.log(buckling(1.0, 2.0, I, A));   // { Pcr: 151417…, mode: "Euler" }
```

デフォルト条件（鋼・円形 $d=50$ mm・ピン—ピン・$L=2$ m）では $\lambda=160>\lambda_c=125.7$ なのでオイラー式が選ばれ、$P_{cr}=151.4$ kN。設計荷重 $P=50$ kN に対する安全率は $FS=151.4/50=3.03$ になります。

## 断面の効きかた — 細長比の物理

座屈強さを支配するのは $I$ そのものより、$r=\sqrt{I/A}$ を通じた**細長比 $\lambda=KL/r$** です。$r$ が大きい（中身が外側に広がった）断面ほど $\lambda$ が小さくなり、座屈に強くなります。

同じ鋼・$L=2$ m・ピン—ピンで断面を変えて比べると：

| 断面 | $r$ (mm) | $\lambda$ | 適用式 | $P_{cr}$ (kN) |
|---|---|---|---|---|
| 円形 $d=50$ | 12.5 | 160 | オイラー | 151.4 |
| 短い円柱（$L=0.5$ m） | 12.5 | 40 | ジョンソン | 466.0 |
| I形鋼（$h$100/$b_f$80/$t_w$8/$t_f$12） | 39.9 | 50 | ジョンソン | 581.8 |

I形鋼は材料を外側のフランジに集めることで $r$ を約3倍に稼ぎ、同じ長さでも細長比が一気に下がってジョンソン領域（押し潰しに近い高い荷重）に入ります。「材料を断面の外周に配る」という構造設計の鉄則が、$r$ と $\lambda$ の関係に凝縮されています（なお短い円柱は押し潰し荷重 $A\sigma_y=490.9$ kN に近づきます）。

## まとめ

- 座屈は強度ではなく**剛性の不安定化**。細長い柱は降伏前に横へしなって壊れる
- 細長い柱は**オイラー式** $P_{cr}=\pi^2EI/(KL)^2$。$P_{cr}\propto1/(KL)^2$ で、固定—固定はピン—ピンの4倍強い
- 太短い柱は**ジョンソン式**で押し潰し荷重 $A\sigma_y$ 側に補正する
- 切り替え境界は**遷移細長比** $\lambda_c=\pi\sqrt{2E/\sigma_y}$（鋼で125.7）。ここで2式は $\sigma_y/2$ で連続する
- 断面は $r=\sqrt{I/A}$ を通じて効く。材料を外側に配ると $\lambda$ が下がり座屈に強い

「同じ材料・同じ重さでも、長さと固定方法と断面の配り方で座屈荷重は何倍も変わる」——これが圧縮部材設計の核心です。
