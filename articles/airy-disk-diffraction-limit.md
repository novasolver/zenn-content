## エアリーディスクとは

完璧なレンズで星のような点光源を結像しても、像は「点」になりません。波の性質を持つ光が、有限の直径 $D$ の円形開口を通る瞬間に必ず広がり、中央の明るい円＋同心円状の暗環・副環からなるパターンになります。この中央の円が **エアリーディスク** です。

円形開口のフラウンホーファー回折強度は、第 1 種ベッセル関数 $J_1$ で表されます：

$$
I(\theta) = I_0\left[\frac{2\,J_1(x)}{x}\right]^2,\qquad x = \frac{\pi D}{\lambda}\sin\theta
$$

$J_1(x)$ の最初のゼロ点 $x=3.8317$ が第 1 暗環で、これがエアリーディスクの縁を決めます。そこから導かれる回折限界角が：

$$
\theta_\text{Airy} = 1.22\,\frac{\lambda}{D}
$$

レンズをどれだけ磨いても、この限界より細かくは結像できません。

## 回折限界・分解能・F値の関係

ツールが計算する 3 つの量を整理します。まず角分解能（遠方の 2 点を見分ける能力）は開口直径 $D$ だけで決まります：

$$
\theta_\text{Airy} = 1.22\,\frac{\lambda}{D}
$$

次に、焦点距離 $f$ のレンズの焦点面では、エアリー半径が焦点比 $F\# = f/D$ で決まります。$r = \theta\cdot f = 1.22\lambda(f/D)$ なので：

$$
r_\text{focal} = 1.22\,\lambda\,F\#
$$

距離 $R$ にある面では半径 $r_R = \theta_\text{Airy}\cdot R$ に広がります。**レイリー基準** は「一方のディスク中心が他方の第 1 暗環に重なる」最小角度差を $\theta_\text{Airy}$ と定義し、これが回折限界そのものになります。

## ベッセル関数で強度を描く

`Math` にベッセル関数は無いので、多項式近似（Abramowitz & Stegun）で $J_1$ を実装します。強度プロファイルはそこから一発です：

```javascript
// J1(x) の多項式近似（|x| < 8 の領域）
function besselJ1(x) {
  const y = x * x;
  const num = x * (72362614232 + y*(-7895059235 + y*(242396853.1
    + y*(-2972611.439 + y*(15704.4826 + y*(-30.16036606))))));
  const den = 144725228442 + y*(2300535178 + y*(18583304.74
    + y*(99447.43394 + y*(376.9991397 + y))));
  return num / den;
}

// エアリー強度 [2 J1(x)/x]^2
function airyIntensity(x) {
  if (Math.abs(x) < 1e-9) return 1.0;     // 中心は極限値 1
  const v = 2 * besselJ1(x) / x;
  return v * v;
}

// 回折限界角・焦点面エアリー半径（λ[nm], D[mm], F#）
function airy(lambda_nm, D_mm, Fnum) {
  const lambda = lambda_nm * 1e-9, D = D_mm * 1e-3;
  const theta = 1.22 * lambda / D;        // rad
  const rFocal = 1.22 * lambda * Fnum;    // m
  return { thetaUrad: theta * 1e6, rFocalUm: rFocal * 1e6 };
}

const r = airy(550, 100, 8);
console.log(`θ = ${r.thetaUrad.toFixed(2)} μrad, r_focal = ${r.rFocalUm.toFixed(2)} μm`);
// θ = 6.71 μrad, r_focal = 5.37 μm
```

中心 $x\to0$ では $2J_1(x)/x\to1$ なので、強度を 1 に固定します（ゼロ割回避）。

## 開口を変えると分解能はどう動くか

波長 $\lambda=550$ nm（緑色光）に固定し、開口直径 $D$ を変えると角分解能は反比例で改善します。観測距離 $R=1000$ m での分離可能距離も合わせて見ると：

![エアリー強度プロファイルと開口径による分解能変化](/images/airy-disk/charts-closeup.png)

| 開口 $D$ | $\theta_\text{Airy}$ | 角度換算 | $R=1000$m での分解能 |
|---|---|---|---|
| 10 mm | 67.10 μrad | 13.84″ | 67.10 mm |
| 100 mm | 6.71 μrad | 1.38″ | 6.71 mm |
| 2400 mm（HST 相当） | 0.28 μrad | 0.058″ | 0.28 mm |

口径を 10 倍にすると分解能も 10 倍向上します。一方、波長を短くしても改善し、$\lambda$ を 550 nm から 200 nm（紫外）に下げると分解能は $550/200 = 2.75$ 倍鋭くなります。なお、中央ディスク内に集まる光エネルギーの割合は約 **83.8%**（ベッセル関数の積分で得られる形状定数）で、$\lambda$・$D$・$F\#$ をどう変えても不変です。

## 「絞り過ぎ」がボケる理由

焦点面のエアリー半径 $r_\text{focal} = 1.22\lambda F\#$ は、$F\#$ に比例して大きくなります。$\lambda=550$ nm では：

| $F\#$ | 焦点面エアリー半径 $r_\text{focal}$ |
|---|---|
| 2.8 | 1.88 μm |
| 8 | 5.37 μm |
| 11 | 7.38 μm |
| 22 | 14.8 μm |

フルサイズセンサーの画素ピッチが 6 μm 程度だとすると、$F\#=11$ ではエアリー半径 7.38 μm が画素を上回ります。これが「回折ボケ」で、絞り込むほど被写界深度は深くなる一方、ある $F\#$ を超えると解像度はかえって落ちます。カメラマンが「絞り過ぎは禁物」と言う物理的な根拠です。

逆に、角分解能 $\theta=1.22\lambda/D$ は $F\#$ には依存しません。$F\#=8$ で $D=10$ mm と $D=100$ mm のレンズは、焦点面ボケの大きさは同じでも、遠方を見分ける角分解能は後者が 10 倍優れています。焦点面の話と角度の話を混同しないのがポイントです。

## まとめ

- エアリーディスクは円形開口の回折パターンで、強度は $I=I_0[2J_1(x)/x]^2$（$J_1$ は第 1 種ベッセル関数）
- 回折限界角 $\theta_\text{Airy}=1.22\lambda/D$ は開口直径だけで決まり、$\lambda=550$nm・$D=100$mm で 6.71 μrad（1.38″）
- 焦点面エアリー半径 $r=1.22\lambda F\#$ は $F\#$ に比例し、絞り過ぎると回折ボケになる
- 中央ディスクのエネルギー比 83.8% は開口形状だけで決まる定数で、パラメータに依存しない

「レンズの良し悪し」ではなく「光が波だから」結像に限界がある——望遠鏡もカメラも顕微鏡も、この $1.22\lambda/D$ に縛られています。
