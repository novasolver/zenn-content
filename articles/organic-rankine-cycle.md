## 捨てるしかなかった熱を電気に変える

工場の排ガス、地熱、バイオマス燃焼。世の中には **80〜300°C の「中途半端に熱い」廃熱** が大量にあります。ところが、この温度帯では水を作動流体にした普通の蒸気タービン（スチームランキンサイクル）は効率が出ず、ほとんどが煙突から大気へ捨てられてきました。

そこで登場するのが **有機ランキンサイクル（ORC, Organic Rankine Cycle）** です。サイクルの構成（蒸発器 → タービン → 凝縮器 → ポンプ）は蒸気サイクルと同じですが、作動流体に水ではなく **低沸点の有機分子** を使います。R245fa や R134a といった冷媒、n-Pentane や Toluene といった炭化水素です。これらは水よりずっと低い温度で沸騰するので、100°C 程度の熱源からでも十分な蒸気圧を作ってタービンを回せます。

この記事では：

1. ORC の効率を決める $\eta_{\text{ORC}} = \eta_C \cdot f_{\text{fluid}} \cdot \eta_{\text{turb}}$ の意味
2. 正味出力 $W_{\text{net}}$ と熱入力 $Q_{\text{in}}$ を求める 20 行ちょっとの JavaScript
3. 再生器（IHE）が効率をきっちり 12% 押し上げることを数値で確認

を順に見ていきます。

## サイクル効率を決める3つの掛け算

ORC のサイクル効率は、3 つの係数の積で表せます：

$$
\eta_{\text{ORC}} = \eta_C \cdot f_{\text{fluid}} \cdot \eta_{\text{turb}}
$$

ここで $\eta_C$ は **カルノー効率**。熱力学が許す理論上限で、絶対温度（K）の蒸発温度 $T_{\text{evap}}$ と凝縮温度 $T_{\text{cond}}$ から決まります：

$$
\eta_C = \frac{T_{\text{evap}} - T_{\text{cond}}}{T_{\text{evap}}}
$$

$f_{\text{fluid}}$ は **作動流体の品質係数**で、実在の有機流体がカルノー上限のどこまで近づけるかを表します。蒸発潜熱の小ささや過熱の浅さから、有機流体では典型的に 0.5〜0.7、本ツールでは代表値 **0.55** を採用しています。$\eta_{\text{turb}}$ は **タービン（膨張機）の断熱効率**で、スクリュー式やラジアル式で 60〜90% 程度です。

| 記号 | 名前 | 物理的意味 |
|---|---|---|
| $\eta_C$ | カルノー効率 | 温度差で決まる理論上限 |
| $f_{\text{fluid}}$ | 流体品質係数 | 実流体のカルノー達成度（≈0.55） |
| $\eta_{\text{turb}}$ | タービン効率 | 膨張機の断熱効率 |

重要なのは、効率がほぼ **温度差だけ** で決まる点です。流体を変えても $\eta_C$・$f_{\text{fluid}}$・$\eta_{\text{turb}}$ が同じなら効率は変わりません。流体選びが効くのは「その温度で蒸発できるか（$T_{\text{max}}$, $T_{\text{crit}}$）」と「取り出せる熱量（潜熱 $h_{fg}$）」の方です。

## 熱入力と正味出力

効率が決まれば、あとは熱の出入りを掛け算するだけです。蒸発器に入る熱入力 $Q_{\text{in}}$ は、液を沸点まで温める **顕熱** と、沸騰させる **潜熱** の合計です：

$$
Q_{\text{in}} = \dot m \left( c_p\, \Delta T + h_{fg} \right), \qquad W_{\text{net}} = Q_{\text{in}} \cdot \eta_{\text{ORC}}
$$

$\dot m$ は質量流量 [kg/s]、$c_p$ は比熱 [kJ/(kg·K)]、$\Delta T = T_{\text{evap}} - T_{\text{cond}}$、$h_{fg}$ は蒸発潜熱 [kJ/kg] です。正味出力 $W_{\text{net}}$ はポンプ動力を差し引いた電気出力に相当します。

蒸発・凝縮温度は、熱源・冷却源から **ピンチ温度差** を取って決めます。本ツールでは蒸発温度を熱源より 10°C 低く（ただし流体の耐熱上限 $T_{\text{max}}$ でクランプ）、凝縮温度を冷却水より 10°C 高く設定します：

$$
T_{\text{evap}} = \min(T_{\text{max}},\ T_{\text{hot}} - 10), \qquad T_{\text{cond}} = T_{\text{cool}} + 10
$$

## 20行ちょっとのJavaScript実装

ORC の計算ロジックは、上の式をそのまま書き下すだけです。本ツールの中核はこうなっています：

```javascript
const fluid = { name: "R245fa", cp: 1.32, hfg: 200, Tmax: 140 };

function orc(Thot, Tcool, mdot, etaT, etaP, regen) {
  // 蒸発・凝縮温度（ピンチ10°C、耐熱上限でクランプ）
  const Tevap = Math.min(fluid.Tmax, Thot - 10);
  const Tcond = Tcool + 10;
  const TeK = Tevap + 273.15, TcK = Tcond + 273.15;

  // カルノー効率 → サイクル効率（流体品質0.55 × タービン効率）
  const carnot = (TeK - TcK) / TeK;
  let eta = carnot * 0.55 * (etaT / 100);
  if (regen) eta *= 1.12;                 // 再生器ブースト
  eta = Math.min(0.5, Math.max(0.01, eta));

  // 熱入力（顕熱＋潜熱）と正味出力
  const dT = Math.max(0, Tevap - Tcond);
  const Qin  = mdot * (fluid.cp * dT + fluid.hfg);
  const Wnet = Qin * eta;
  return { Tevap, Tcond, carnot, eta, Qin, Wnet };
}
```

デフォルト条件（熱源 150°C、冷却 25°C、流量 5.0 kg/s、タービン 80%、再生器 ON）で呼ぶと：

```javascript
orc(150, 25, 5.0, 80, 75, true);
// Tevap = 140°C, Tcond = 35°C
// carnot = 0.2541  (25.4%)
// eta    = 0.1252  (12.5%)
// Qin    = 1693 kW
// Wnet   = 212.0 kW
```

カルノー効率 25.4% に対し、実サイクルは 12.5%。比をとると **カルノー比 49.3%** で、これは $0.55 \times 0.80 \times 1.12 = 0.4928$ そのものです。流体品質とタービン効率と再生器の積が、そのままカルノー達成度になっているわけです。

## 再生器(IHE)は効率をきっちり12%上げる

ORC で効率を底上げする鍵が **再生器（IHE, Internal Heat Exchanger）** です。タービンを出た「まだ熱い過熱蒸気」で、ポンプ吐出側の「冷たい液」をあらかじめ温める熱交換器です。蒸発器の負担が減るぶん、同じ出力をより少ない外部熱入力で得られます。

本ツールでは再生器の効果を係数 **1.12（+12%）** で概算しています。再生器の ON / OFF を切り替えると、効率と正味出力がきれいに 12% 変化します：

| 再生器 | サイクル効率 | 正味出力 $W_{\text{net}}$ |
|---|---|---|
| OFF | 11.18% | 189.3 kW |
| ON | 12.52% | 212.0 kW |
| 比 | ×1.12 | ×1.12 |

熱入力 $Q_{\text{in}}=1693$ kW は再生器の有無で変わらず（流量と温度で決まるため）、効率だけが 1.12 倍になるので、出力も正確に 1.12 倍になります。実際の ORC でも再生器で 10〜15% 改善するのが一般的で、過熱気味になりやすい dry fluid（n-Pentane, Toluene 等）との相性が特に良いため、地熱・廃熱 ORC ではほぼ標準装備です。

## 温度差を上げると効率はどう伸びるか

効率がほぼ温度差で決まるなら、熱源温度を上げれば効率も上がるはずです。本ツールには「熱源温度に対するサイクル効率」のグラフがあり、$\eta_{\text{ORC}}$ とカルノー上限 $\eta_C$ が右肩上がりに伸びていく様子が見えます：

![T-s線図と効率カーブ](/images/organic-rankine-cycle/charts-closeup.png)

ただし作動流体には耐熱上限 $T_{\text{max}}$ があります。R245fa は $T_{\text{max}}=140$°C なので、熱源を 150°C より上げても蒸発温度は 140°C で頭打ちになり、効率は飽和します。高温熱源を活かすには、より高温向きの流体に替える必要があります。Toluene（$T_{\text{crit}}=319$°C）なら熱源 300°C で蒸発温度 290°C まで使え、効率は **22.3%**、出力は 1043 kW（流量 5 kg/s 換算）まで伸びます。「熱源温度を見て流体を選ぶ」のが ORC 設計の第一歩、というのはこの飽和の壁を避けるためです。

## まとめ

- ORC は水の代わりに低沸点の有機流体を使い、80〜300°C の低温廃熱から発電するサイクル
- 効率は $\eta_{\text{ORC}} = \eta_C \cdot f_{\text{fluid}} \cdot \eta_{\text{turb}}$ で、温度差（カルノー効率）が主役
- デフォルト条件で効率 12.5%、正味出力 212 kW、カルノー比 49.3%（$=0.55\times0.80\times1.12$）
- 再生器は効率を正確に 1.12 倍に押し上げる
- 流体には耐熱上限があり、高温熱源には高温向き流体（Toluene 等）が必要
