## 細い棒は「強度」より先に「座屈」で壊れる

長い定規を両手で押すと、ある力を超えた瞬間にフニャッと横に曲がります。材料が圧縮で潰れる（圧壊）前に、**横にたわんで安定を失う**——これが**座屈（buckling）** です。細長い柱では、材料の強度ではなく座屈が設計を支配します。1744 年にレオンハルト・オイラーが導いたこの臨界荷重の式は、今も柱・支柱・トラスの設計で使われています。

## オイラーの座屈荷重

柱が座屈する臨界荷重は次式で与えられます。

$$
P_{cr} = \frac{\pi^2 E I}{(KL)^2}
$$

$E$ はヤング率、$I$ は断面二次モーメント（曲げにくさ）、$L$ は柱の長さ、$K$ は**有効長さ係数**——両端の支持条件で決まる数です。注目すべきは $P_{cr}$ が長さの**2乗に反比例**すること。柱を 2 倍長くすると、座屈荷重は 1/4 に落ちます。

ツールの既定例（直径 50 mm の丸鋼、$E=200\,\mathrm{GPa}$、$L=2\,\mathrm{m}$、両端ピン $K=1.0$）では、断面二次モーメント $I=\pi d^4/64=3.07\times10^{-7}\,\mathrm{m^4}$ から

$$
P_{cr} = \frac{\pi^2\times200\times10^9\times3.07\times10^{-7}}{(1.0\times2)^2} = 151.4\,\mathrm{kN}
$$

## 端末条件 K がすべてを変える

両端をどう支えるかで $K$、ひいては座屈荷重が大きく変わります。

| 端末条件 | $K$ | 座屈荷重（両端ピン比） |
|---|---|---|
| 両端固定 | 0.5 | **4 倍** |
| 固定 - ピン | 0.7 | 約 2 倍 |
| 両端ピン | 1.0 | 1 倍（基準） |
| 一端固定・他端自由 | 2.0 | **1/4** |

上図のように、同じ柱でも**両端固定なら 4 倍の荷重に耐え、片持ち（一端自由）なら 1/4 しか耐えられない**。$P_{cr}\propto 1/K^2$ なので、支持を強めることは断面を太くするのと同じくらい効きます。座屈モードの形（半波の数）も条件で変わります。

## 細長比と座屈応力

柱が「細長い」かは**細長比** $\lambda = KL/r$（$r=\sqrt{I/A}$ は断面回転半径）で測ります。座屈応力は

$$
\sigma_{cr} = \frac{P_{cr}}{A} = \frac{\pi^2 E}{\lambda^2}
$$

$\lambda$ が大きい（細長い）ほど座屈応力は小さく、座屈が支配的になります。鋼では $\lambda_c=\pi\sqrt{E/\sigma_Y}\approx100$ 前後が境目で、これより細長ければオイラー座屈（弾性座屈）、太短ければ材料降伏や Johnson 式が支配します。既定例の細長比は $KL/r=160$ で、十分に細長くオイラー式が有効な領域です。

## JavaScript 実装

臨界荷重の計算は1行、断面二次モーメントは形状ごとに求めます。

```javascript
const Pcr = Math.PI*Math.PI * E * I / (K*L * K*L);   // オイラー座屈荷重
// 断面二次モーメント（丸棒なら）
const I = Math.PI * Math.pow(d, 4) / 64;
const A = Math.PI * d*d / 4;
const r = Math.sqrt(I / A);                           // 回転半径
const slenderness = K*L / r;                          // 細長比 λ
// K factors: 両端ピン1.0 / 一端自由2.0 / 両端固定0.5 / 固定-ピン0.7
```

## まとめ

- 細長い柱は強度より先に**座屈**で壊れる。臨界荷重は $P_{cr}=\pi^2EI/(KL)^2$
- $P_{cr}$ は長さの**2乗に反比例**（長さ2倍で1/4）、$EI$ に比例
- **端末条件 K** が決定的：両端固定で 4 倍、片持ちで 1/4
- 細長比 $\lambda=KL/r$ が大きいほど座屈支配。鋼では $\lambda\approx100$ が弾性座屈と降伏の境
