## クラウジウス・クラペイロンの式とは

純粋な液体は、温度ごとに「これだけの圧力までは自分の蒸気を押し戻せる」という**蒸気圧**をもっています。20°C の水なら約 2.3 kPa、100°C で約 101 kPa（1 気圧）。温度はわずか数倍しか変わっていないのに、蒸気圧は **40 倍以上**に跳ね上がります。

この劇的な増加を説明するのが**クラウジウス・クラペイロンの式**です。蒸気圧の対数 $\ln P$ が温度の逆数 $1/T$ に対してほぼ直線になる、というのがその核心です：

$$
\ln\frac{P_2}{P_1} = -\frac{\Delta H_{vap}}{R}\left(\frac{1}{T_2}-\frac{1}{T_1}\right)
$$

ここで $\Delta H_{vap}$ は蒸発潜熱、$R=8.314\,\mathrm{J/(mol\cdot K)}$ は気体定数、$T$ は絶対温度です。

2. 数行の JavaScript による任意温度の蒸気圧計算
3. 水の沸点が標高・圧力でどう変わるかを数値で確認

## なぜ「指数関数的」に増えるのか

$\ln P$ と $1/T$ が直線関係にあるということは、$P$ 自体は温度に対して**指数関数**で増えるということです。基準点 $(T_1, P_1)$ から任意温度 $T$ の蒸気圧は：

$$
P(T) = P_1\,\exp\!\left[-\frac{\Delta H_{vap}}{R}\left(\frac{1}{T}-\frac{1}{T_1}\right)\right]
$$

温度を少し上げると $1/T$ が少し下がり、指数の中身が増え、$P$ が爆発的に伸びます。直線の傾きの大きさは $\Delta H_{vap}/R$ で決まり、蒸発潜熱が大きい液体ほど傾きが急になります。水は $\Delta H_{vap}\approx40.7\,\mathrm{kJ/mol}$ と比較的大きいので沸点が高く、エタノール（38.6）やアセトン（29）はこれより低い沸点になります。

なお、この式には二つの簡略化が入っています。蒸気を理想気体として扱うことと、温度範囲内で $\Delta H_{vap}$ を一定とみなすことです。沸点近傍では数 % の精度で成立しますが、臨界点（水なら 374°C）に近づくと両仮定が崩れます。広い温度範囲では Antoine 式や Wagner 式が使われます。

## JavaScript で蒸気圧を計算する

ツールの計算ロジックは数行で書けます。蒸発潜熱は kJ/mol で入力し、内部で J/mol に変換するのがポイントです：

```javascript
const R = 8.314;   // J/(mol·K)

function vaporPressure(T1, P1, dH_kJ, T2) {
  const enthalpyOverR = dH_kJ * 1000 / R;     // ΔH/R [K]（kJ→J）
  const invDiff  = 1 / T2 - 1 / T1;           // 1/K
  const lnRatio  = -enthalpyOverR * invDiff;  // ln(P2/P1)
  const ratio    = Math.exp(lnRatio);         // P2/P1
  const P2       = P1 * ratio;                // kPa
  return { P2, ratio, lnRatio, HoverR: enthalpyOverR };
}

// 水の基準点（標準沸点）から 400K の蒸気圧
console.log(vaporPressure(373.15, 101.325, 40.7, 400));
// P2 ≈ 244.4 kPa, ratio ≈ 2.412, ln比 ≈ 0.881, ΔH/R ≈ 4895 K
```

温度を**必ず絶対温度 [K]** で渡すこと、$\Delta H_{vap}$ と $R$ の桁を合わせること（kJ/mol なら 1000 倍）が頻出のミスです。°C のまま $1/T$ に入れると桁違いの答えになります。

## 沸点と蒸気圧曲線を描く

蒸気圧は温度に対して指数的に立ち上がり、**蒸気圧が周囲の全圧に等しくなる温度が沸点**です。$\ln P$ を $1/T$ に対してプロットすると、傾き $-\Delta H_{vap}/R$ の直線になります。

![蒸気圧曲線 P(T) と ln P − 1/T 直線](/images/clausius-clapeyron-vapor/charts-closeup.png)

左の P-T 曲線（指数的立ち上がり）と、右の $\ln P$ − $1/T$ 直線（同じデータが直線に化ける）を見比べると、「指数 ↔ 直線」の対応が直感的に分かります。ツールではこの 2 つのグラフに加え、密閉フラスコ内で分子が蒸発・凝縮するアニメーションも表示されます。

## 水の蒸気圧を数値で確かめる

水（基準点 $T_1=373.15\,\mathrm{K}$、$P_1=101.325\,\mathrm{kPa}$、$\Delta H_{vap}=40.7\,\mathrm{kJ/mol}$）で温度を振った結果が次の表です：

| 温度 | $T$ [K] | 蒸気圧 $P_2$ [kPa] | $P_2/P_1$ |
|---|---|---|---|
| 20°C | 293.15 | 2.82 | 0.028 |
| 40°C | 313.15 | 8.20 | 0.081 |
| 60°C | 333.15 | 20.97 | 0.207 |
| 80°C | 353.15 | 48.20 | 0.476 |
| 100°C | 373.15 | 101.33 | 1.000 |
| 120°C | 393.15 | 197.49 | 1.949 |

20°C の 2.82 kPa から 120°C の 197 kPa まで、約 **70 倍**に膨らみます。20°C の計算値 2.82 kPa は実測値 2.3 kPa にやや高めですが、これは $\Delta H_{vap}$ を一定（40.7）とした近似によるもの。25°C では実際は 44.0 kJ/mol と大きく、その差が低温側のズレに現れます。

逆に「蒸気圧が周囲の全圧に等しくなる温度」を沸点として逆算すると、身近な現象が説明できます：

- **富士山頂（気圧 0.65 atm ≈ 66 kPa）**: 計算上の沸点は約 **88°C**（文献 ~87°C）
- **圧力鍋（内圧 2 atm ≈ 203 kPa）**: 計算上の沸点は約 **121°C**（文献 ~120°C）

標高が高いと沸点が下がって米やパスタの芯が残り、圧力鍋では沸点が上がって短時間で煮込めるのは、すべてこの一本の式の帰結です。

> 注意：クラウジウス・クラペイロンの式は**純物質**の式です。塩を溶かした海水は蒸気圧が下がり（Raoult の法則）、エタノール水溶液は共沸点をもつなど、混合物には直接適用できません。ツールの結果は「$\Delta H_{vap}$ が代表する純粋な液体」を仮定した参考値と理解してください。

試してほしい操作：

- **評価温度 T₂ スライダー**を動かして、「評価温度の蒸気圧 P₂」「圧力比 P₂/P₁」カードが指数的に変化するのを観察
- **蒸発潜熱 ΔH_vap スライダー**を 30 と 50 で比べて、右下の ln P − 1/T 直線の傾きがまるで変わるのを確認（水=40.7、エタノール=38.6、アセトン=29、ベンゼン=30.7）
- **基準温度 T₁・基準圧力 P₁** を変えて、別の液体や別の基準点に合わせる
- **P₁ を 101.325 kPa に固定**し、評価点を動かして「P₂ が 101.325 になる温度」を探せば、それがその液体の標準沸点
- 「密閉フラスコ」アニメーションで、温度を上げると上向きに飛ぶ分子（＝蒸気圧）が増える様子を観察

## まとめ

- クラウジウス・クラペイロンの式 $\ln(P_2/P_1) = -\frac{\Delta H_{vap}}{R}(1/T_2 - 1/T_1)$ で蒸気圧の温度依存を表す
- $\ln P$ と $1/T$ が直線、すなわち $P$ は温度に対して指数関数的に増大する
- 水は 20°C→120°C で蒸気圧が約 70 倍に。沸点は「蒸気圧＝全圧」の温度
- 富士山頂で約 88°C、圧力鍋で約 121°C という沸点も式から逆算できる（文献値と一致）

蒸留・乾燥・気象（露点・湿度）・凍結乾燥・半導体プロセスまで、温度が絡む蒸発現象はすべてこの一本の式の延長線上にあります。
