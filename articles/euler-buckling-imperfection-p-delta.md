## オイラー座屈とは

細長い柱を上から押すと、材料が潰れるより先に **横へ「グニャッ」としなって** 一気に耐えられなくなります。これが座屈（buckling）です。その限界荷重を与えるのが、1744 年にオイラーが導いた式です。

$$
P_{cr} = \frac{\pi^2 E I}{(K L)^2}
$$

$E$ はヤング率、$I$ は断面二次モーメント、$L$ は柱長さ、$K$ は端末条件係数（支持の仕方で決まる）です。**強度（降伏応力）が一切出てこない**のが座屈の本質——耐力を決めるのは「材料の硬さ × 断面の形 ÷ 長さの 2 乗」です。

この記事では：

1. $P_{cr}$ と細長比 $\lambda$ の意味
2. 端末条件 $K$ がどれだけ効くか
3. 初期不整（偏心）が引き起こす P-δ 曲線

## 細長比と座屈応力

座屈のしやすさは、長さと断面の「やせ具合」の比、**細長比 $\lambda$** で測ります。

$$
\lambda = \frac{KL}{r}, \qquad r = \sqrt{\frac{I}{A}}, \qquad \sigma_{cr} = \frac{P_{cr}}{A} = \frac{\pi^2 E}{\lambda^2}
$$

ここで $r$ は断面二次半径、$A$ は断面積です。$\lambda$ が大きい（細長い）ほど座屈応力 $\sigma_{cr}$ は小さくなり、おおむね $\lambda > 100$ で弾性座屈が支配的になります。逆に $\lambda$ が小さい短柱は、座屈より先に材料が降伏するため、オイラー式だけでは評価できません。

たとえば 100×100 mm の鋼の角柱（$E=200\,\mathrm{GPa}$）を長さ 3 m・両端ピンで使うと、Python で照合した値は次のとおりです：

```
I = 100^4 / 12 = 8.33 × 10^6 mm^4
r = sqrt(I/A) = 28.87 mm
λ = KL/r = 1.0 × 3000 / 28.87 = 103.9   → 弾性座屈域
Pcr = π² × 200000 × 8.33e6 / (3000)² / 1000 = 1827.7 kN
```

## 16 行で計算する

オイラー荷重と細長比は数式どおりに書けます。断面二次モーメントだけ、形状に応じて計算します。

```javascript
function sectionProps(b, h) {           // 矩形 b×h
  const I = b * h ** 3 / 12;
  const A = b * h;
  return { I, A, r: Math.sqrt(I / A) };
}

function buckling(E_GPa, b, h, K, L) {
  const E = E_GPa * 1e3;                 // GPa -> MPa
  const { I, A, r } = sectionProps(b, h);
  const Pcr = Math.PI ** 2 * E * I / (K * L) ** 2 / 1000;  // kN
  const lambda = K * L / r;
  const sigma_cr = Math.PI ** 2 * E / lambda ** 2;          // MPa
  return { I, A, Pcr, lambda, sigma_cr };
}

// 例: buckling(200, 100, 100, 1.0, 3000)
// -> Pcr = 1827.7 kN, lambda = 103.9
```

## 端末条件 K がすべてを変える

同じ柱でも、両端をどう支えるかで座屈荷重は劇的に変わります。$K$ は「等価な両端ピン柱の長さ」を表す係数で、$P_{cr}$ は $1/K^2$ に比例します。上の角柱（100×100、L=3m）で計算しました（Python 照合値）：

| 端末条件 | $K$ | $P_{cr}$ | 両端ピン比 |
|---|---|---|---|
| 両端ピン | 1.0 | 1828 kN | ×1.00 |
| 一端固定・他端ピン | 0.7 | 3730 kN | ×2.04 |
| 両端固定 | 0.5 | 7311 kN | ×4.00 |
| 一端固定・他端自由 | 2.0 | 457 kN | ×0.25 |

両端を固定するだけで耐力が **4 倍**、逆に片持ち（固定-自由）にすると **1/4** に落ちます。「柱の長さ」より「端の留め方」のほうが効く場面が多い、というのが設計の勘どころです。

## 初期不整と P-δ 曲線

ここからが「高度」座屈解析の核心です。現実の柱は完全にまっすぐではなく、荷重も中心から少しずれます（偏心 $e$）。すると、$P_{cr}$ に達するずっと手前から横たわみ $\delta$ が現れ、荷重とともに非線形に増大します。これを表すのが **割線公式（secant formula）** です。

$$
\delta = e\left(\frac{1}{\cos\left(\frac{\pi}{2}\sqrt{P/P_{cr}}\right)} - 1\right)
$$

偏心 $e=5\,\mathrm{mm}$ の柱で、荷重比ごとのたわみを計算しました（Python 照合値）：

| $P/P_{cr}$ | たわみ $\delta$ |
|---|---|
| 0.2 | 1.55 mm |
| 0.5 | 6.26 mm |
| 0.8 | 25.3 mm |
| 0.95 | 120.7 mm |

たわみは $0.5P_{cr}$ で 6 mm 程度なのに、$0.8P_{cr}$ で 25 mm、$0.95P_{cr}$ では 121 mm へと **加速度的に膨らみます**。$P \to P_{cr}$ で $\cos$ の中身が $\pi/2$ に近づき、$\delta$ が発散するためです。理想的な完全直柱なら $P_{cr}$ まで真っ直ぐ耐えますが、わずかな初期不整があるだけで「座屈荷重の手前で実質的に使えなくなる」——これが実務で安全率を取る理由です。

## まとめ

- オイラー座屈 $P_{cr}=\pi^2 EI/(KL)^2$ は、材料強度ではなく「剛性 × 形 ÷ 長さ²」で決まる
- 細長比 $\lambda=KL/r$ が大きい（$\lambda>100$ 程度）ほど弾性座屈が支配的
- 端末条件 $K$ の効果は $1/K^2$——両端固定で 4 倍、片持ちで 1/4
- 初期不整（偏心 $e$）があると、$P_{cr}$ の手前からたわみが加速的に増える（割線公式）

座屈は高層ビルの柱、橋脚、ロケットのストリンガー、油圧シリンダのロッドまで、細長い圧縮部材すべての設計支配要因です。$P_{cr}$ を求めるだけでなく、初期不整を見込んだ P-δ 挙動で「使える荷重」を判断する感覚を、ツールでつかんでみてください。
