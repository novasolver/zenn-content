## オペアンプとは

オペアンプ（演算増幅器）は、アナログ電子回路の主役です。たった 1 個の三角形の素子に抵抗とコンデンサを数本つなぐだけで、増幅・加算・積分・微分といった「演算」が実現できます。名前の「演算」はここから来ています。

不思議なのは、増幅率（利得）が**オペアンプ自身の性能ではなく、外付けの抵抗比だけで決まる**ことです。理想オペアンプの開ループ利得は数万〜数十万倍と巨大ですが、私たちが回路に組むときに気にするのは抵抗の比だけ。この「巨大な利得を負帰還で飼いならす」という発想を、2 つの公式で読み解いていきます。

この記事では：

1. すべての解析の出発点になる「仮想短絡」
2. 反転増幅回路の利得 $A_v = -R_f/R_{in}$ の導出と数値確認
3. 出力が電源電圧で頭打ちになる「クリッピング」を波形で確かめる

## 仮想短絡 — すべての出発点

理想オペアンプには 2 つの入力端子があります。非反転入力（$+$）と反転入力（$-$）です。出力はこの 2 端子の電位差を巨大な利得 $A$ で増幅します：

$$
V_{out} = A\,(V_+ - V_-)
$$

ここで **負帰還**（出力の一部を $-$ 端子に戻す配線）がかかっているとします。$A$ は非常に大きいので、$V_{out}$ が有限の値に落ち着くためには $(V_+ - V_-)$ がほぼ 0 でなければなりません：

$$
V_+ - V_- = \frac{V_{out}}{A} \xrightarrow{A \to \infty} 0
$$

つまり **$V_+ \approx V_-$**。2 端子の電圧が（電流は流れないのに）等しくなる——これを **仮想短絡（バーチャルショート）** と呼びます。$+$ 端子を接地している反転増幅回路では $V_+ = 0$ なので $V_- \approx 0$ となり、これは特に **仮想接地** と呼ばれます。

ポイントは、電圧だけが等しく、端子に電流は流れ込まない（入力インピーダンス無限大）という 2 点です。この 2 つを使うと、回路の利得が一気に求まります。

## 反転増幅回路の利得

最も基本的な反転増幅回路を考えます。入力 $V_{in}$ を抵抗 $R_{in}$ 経由で $-$ 端子へ、$-$ 端子と出力の間に帰還抵抗 $R_f$ をつなぎます。$+$ 端子は接地します。

仮想接地から $V_- = 0$。$-$ 端子に電流が流れ込まないので、$R_{in}$ を通る電流と $R_f$ を通る電流は等しくなります（キルヒホッフの電流則）：

$$
\frac{V_{in} - 0}{R_{in}} = \frac{0 - V_{out}}{R_f}
$$

これを $V_{out}/V_{in}$ について解くと、有名な利得の式が得られます：

$$
A_v = \frac{V_{out}}{V_{in}} = -\frac{R_f}{R_{in}}
$$

負号は、出力が入力と **逆極性（位相 180°反転）** であることを表します。注目すべきは、この式に周波数もオペアンプの性能も出てこないこと。**抵抗比だけ** で利得が決まります。

シミュレーターの初期値は $R_{in} = 10\,\mathrm{k\Omega}$、$R_f = 47\,\mathrm{k\Omega}$ なので：

$$
A_v = -\frac{47}{10} = -4.7 \quad (\,20\log_{10}4.7 = 13.44\ \mathrm{dB}\,)
$$

教科書でよく出る $R_{in} = 10\,\mathrm{k\Omega}$、$R_f = 100\,\mathrm{k\Omega}$ なら $A_v = -10$（ちょうど 10 倍の反転増幅器）です。

## JavaScript で利得と波形を計算する

ツールの計算ロジックは、入力波形の各サンプルに利得を掛け、電源電圧でクリップするだけです。中核は 25 行ほどで書けます：

```javascript
const Rin = 10, Rf = 47;   // kΩ
const Vcc = 15;            // 電源電圧 ±15V
const amp = 5, freq = 1000; // 入力 5Vp, 1kHz
const gain = -(Rf / Rin);  // = -4.7

// 反転増幅 + クリッピング（出力は ±Vcc を超えられない）
function opamp(vin) {
  const ideal = gain * vin;
  return Math.max(-Vcc, Math.min(Vcc, ideal));
}

// 1周期ぶんの入出力波形を生成
const N = 300, T = 1 / freq;
let clipped = 0;
for (let i = 0; i < N; i++) {
  const t = (i / N) * T;
  const vin = amp * Math.sin(2 * Math.PI * freq * t);
  const vout = opamp(vin);
  if (Math.abs(vout) >= Vcc - 0.01) clipped++;  // クリップ判定
}
console.log("理想ピーク =", Math.abs(gain) * amp, "V");  // 23.5
console.log("クリップ率 =", (clipped / N * 100).toFixed(1), "%"); // 54.0
```

利得 4.7 倍に振幅 5V を入れると、理想出力は $4.7 \times 5 = 23.5\,\mathrm{V}$。これは電源電圧 $\pm 15\,\mathrm{V}$ を超えるので、波形の頭が削られます。実際にサンプルの **54.0%** が $\pm 15\,\mathrm{V}$ に張り付く計算になります。

## 波形とクリッピングを見る

ツールでは入力 $V_{in}$（青）と出力 $V_{out}$（水色）を同じ時間軸に重ねて描画します。クリップした区間は赤く色分けされます：

![入出力波形とクリッピング](/images/op-amp-circuits/charts-closeup.png)

クリッピングは、出力が電源レール（$\pm V_{cc}$）にぶつかって平らになる現象です。発生条件はシンプルで、

$$
|A_v| \cdot V_{p} > V_{cc}
$$

を満たすと頭が削れます。初期値（$A_v = -4.7$、$V_{cc} = 15$）の場合、入力振幅が

$$
V_p > \frac{V_{cc}}{|A_v|} = \frac{15}{4.7} \approx 3.19\ \mathrm{V}
$$

を超えるとクリッピングが始まります。逆に言えば、歪みなく増幅できる入力振幅の上限が 3.19V ということです。実際の回路設計では、この「飽和しないレベルに信号を収める」ことが基本になります。

## 積分回路 — 抵抗をコンデンサに替える

帰還抵抗 $R_f$ をコンデンサ $C$ に置き換えると、回路は **積分器** になります。出力は入力の時間積分に比例します：

$$
V_{out} = -\frac{1}{R_{in}C}\int V_{in}\,dt
$$

正弦波を積分すると（マイナス）コサイン波になるので、出力は入力に対して位相が **90°遅れ** ます。正弦波 1 つに対する利得（振幅比）は、角周波数 $\omega = 2\pi f$ を使って

$$
|A_v| = \frac{1}{\omega R_{in} C}
$$

で表せます。これは周波数が高いほど利得が下がる、つまり積分器が **ローパスフィルタ** として働くことを意味します。ツールの設計例（$R_{in} = 100\,\mathrm{k\Omega}$、$C = 100\,\mathrm{nF}$）で時定数は

$$
\tau = R_{in}C = 100\times10^{3} \times 100\times10^{-9} = 10\ \mathrm{ms}
$$

となり、$1\,\mathrm{kHz}$ での利得は $1/(\omega\tau) = 0.0159$、すなわち **約 $-36\ \mathrm{dB}$** です。微分回路はこの逆で、$V_{out} = -R_f C\,(dV_{in}/dt)$ となり、ハイパスフィルタとして働きます。

> 注意：理想積分器を単純な数値積分（前進オイラー法）で 1 方向に回すと、入力の直流成分や初期位相のオフセットが積分されて出力がじわじわドリフトします。実回路でも入力オフセット電圧やバイアス電流が同じように蓄積し、放置すると出力が電源電圧まで飽和してしまうため、帰還抵抗を並列に入れて直流利得を抑えるのが定石です。

## まとめ

- 理想オペアンプ＋負帰還から **仮想短絡 $V_+ \approx V_-$** が導かれ、これが全解析の出発点
- 反転増幅の利得は抵抗比だけで決まる：$A_v = -R_f/R_{in}$（初期値で $-4.7$、$13.44\,\mathrm{dB}$）
- 出力は電源電圧で頭打ちになる：$|A_v|V_p > V_{cc}$ で **クリッピング**（初期値なら $V_p > 3.19\,\mathrm{V}$）
- 帰還素子をコンデンサに替えると積分器（$-36\,\mathrm{dB}$ @1kHz）、入力側に入れると微分器になる

「巨大な利得を負帰還で飼いならし、外付け部品で演算を作る」というオペアンプの考え方は、センサ信号の増幅からオーディオ、フィルタ、制御系まであらゆる場面で使われます。式と波形を並べて眺めると、その普遍性が見えてきます。
