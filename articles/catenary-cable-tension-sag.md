## カテナリー曲線とは

両端を固定したケーブルが**自重だけ**で垂れ下がったとき、その形は放物線ではなく **双曲線余弦（cosh）** になります。これがカテナリー（懸垂線）です。

$$
y = a\cosh\!\left(\frac{x}{a}\right) - a, \qquad a = \frac{H}{w}
$$

ここで $H$ は最低点での水平張力、$w$ は単位長さあたりの重量（N/m）、$a$ は曲線の「開き具合」を決めるカテナリーパラメータです。1691 年にホイヘンス・ライプニッツ・ベルヌーイがほぼ同時に解いた、解析力学の古典的な問題でもあります。

この記事では：

1. なぜ放物線ではなく cosh になるのか
2. 水平張力 $H$・最大張力 $T_{max}$・ケーブル長 $S$ の求め方
3. 「たわみが浅いときは放物線で十分」を数値で確かめる

## なぜ cosh になるのか

ケーブルの微小要素 $ds$ にかかる力は、両端の張力と自重 $w\,ds$ の 3 つだけです。水平方向の張力は全長で一定（$H$）、鉛直方向は自重を積み上げた分だけ増えていきます。最低点からの弧長を $s$ とすると、ある点での張力の鉛直成分は $V = w\,s$ になり、傾きは

$$
\frac{dy}{dx} = \frac{V}{H} = \frac{w\,s}{H}
$$

これを弧長の式 $ds = \sqrt{1+(dy/dx)^2}\,dx$ と組み合わせて解くと、答えが $\sinh$・$\cosh$ の形に落ち着きます。**「単位水平距離あたり」ではなく「単位弧長あたり」に自重がかかる**——この一点が放物線との分かれ目です。荷重が水平距離あたり一定（たとえば橋桁の重さが主）なら、形は放物線になります。

主要な出力は次の 3 つです。

$$
S = 2a\sinh\!\left(\frac{L}{2a}\right), \qquad T_{max} = H + w\,d
$$

$S$ はケーブル全長、$T_{max}$ は最も張力が大きくなる支点での値、$d$ は中央のたわみ（サグ）です。$a$ を求めるには、スパン $L$ とたわみ $d$ の関係式

$$
d = a\left(\cosh\frac{L}{2a} - 1\right)
$$

を $a$ について解く必要があります。閉じた式が無いので**数値的に解く**しかありません。

## 20 行で解く（二分法）

$a$ を求める式 $f(a) = a(\cosh(L/2a)-1) - d = 0$ は、$a$ について単調なので二分法で安全に解けます。

```javascript
function solveCatenaryA(L, d) {
  // f(a) = a*(cosh(L/2a) - 1) - d は a に対して単調減少
  const f = a => a * (Math.cosh(L / (2 * a)) - 1) - d;
  let lo = 1e-2, hi = L * 1e4;       // 根は必ずこの区間内
  for (let i = 0; i < 200; i++) {
    const mid = (lo + hi) / 2;
    if (f(mid) > 0) lo = mid;         // f は減少関数なので f>0 側を lo に寄せる
    else hi = mid;
    if (hi - lo < 1e-9) break;
  }
  return (lo + hi) / 2;
}

function catenary(L, d, w) {
  const a = solveCatenaryA(L, d);
  const H = w * a;
  const Tmax = H + w * d;
  const S = 2 * a * Math.sinh(L / (2 * a));
  return { a, H, Tmax, S };
}
```

`L=100m, d=10m, w=50N/m` で実行すると次の値が得られます（Python で照合済み）：

```
a    = 126.63 m
H    = 6.332 kN     最低点の水平張力
Tmax = 6.832 kN     支点での最大張力
S    = 102.62 m     ケーブル全長（スパン 100m より 2.6m 長い）
```

> 補足：$\cosh$ は引数が大きいと急激に発散します。$a$ が非常に小さい（＝たわみが極端に深い）と `Math.cosh(L/2a)` がオーバーフローして `Infinity` になるため、根の探索区間の取り方には注意が必要です。二分法では「区間の端で関数が発散しても、符号さえ判定できればよい」のが利点です。

## ケーブルの形と張力分布

NovaSolver のツールでは、この cosh 曲線を Canvas に描き、支点に向かって張力が増えていく様子を色とチャートで表示します。

![カテナリー曲線とケーブル張力分布](/images/catenary-cable/charts-closeup.png)

特徴的なのは：

- **最低点で張力が最小**（水平成分 $H$ のみ）
- **支点で張力が最大**（$T_{max} = H + w\,d$、鉛直成分が加わる）
- たわみ $d$ が浅いほど $H$ も $T_{max}$ も大きくなる——ピンと張った綱は内部張力が跳ね上がる

「たるませた方が楽」という直感は正しく、送電線をわざとたるませて張るのはこのためです。

## 放物線近似はいつ使える？

たわみがスパンに対して浅い（$d/L$ が小さい）とき、自重は「ほぼ水平距離あたり一定」とみなせ、形は放物線で近似できます。

$$
y = \frac{4d}{L^2}x(L-x), \qquad H = \frac{wL^2}{8d}
$$

この放物線の $H$ は、閉じた式で一発で求まるのが魅力です。では厳密なカテナリーとどれくらいズレるのか。$L=100m,\ w=50\,\mathrm{N/m}$ で水平張力を両方計算して比べました（Python 照合値）：

| たわみ $d$ | $d/L$ | $H$ カテナリー | $H$ 放物線 | 差 |
|---|---|---|---|---|
| 2 m | 2 % | 31.27 kN | 31.25 kN | +0.05 % |
| 5 m | 5 % | 12.54 kN | 12.50 kN | +0.33 % |
| 10 m | 10 % | 6.332 kN | 6.250 kN | +1.31 % |
| 20 m | 20 % | 3.279 kN | 3.125 kN | +4.94 % |
| 30 m | 30 % | 2.297 kN | 2.083 kN | +10.3 % |

$d/L$ が 5 % 以下なら誤差は 0.3 % 程度で、放物線で十分です。一方、$d/L$ が 20 % を超えると 5 % 以上ずれ始め、深く垂れた懸垂幕やアーチではカテナリーが必要になります。**「浅いケーブルは放物線、深いケーブルは cosh」**——この使い分けが実務の勘どころです。

## まとめ

- 自重だけで垂れたケーブルの形は放物線ではなく $y=a\cosh(x/a)-a$（カテナリー）
- 水平張力 $H=wa$、最大張力 $T_{max}=H+wd$、ケーブル長 $S=2a\sinh(L/2a)$
- $a$ は閉じた式で解けないので二分法で数値的に求める（20 行の JS）
- たわみ比 $d/L$ が 5 % 以下なら放物線近似で誤差 0.3 % 程度、20 % を超えると 5 % 以上ずれる

ケーブルの張力計算は、吊り橋の主ケーブルから架空送電線、膜構造のエッジケーブルまで幅広く使われます。「浅いか深いか」で式を選び分ける感覚を、ツールで手を動かしながらつかんでみてください。
