## 交流回路インピーダンスとは

直流回路ならオームの法則 $V = IR$ で電流が一発で出ます。ところが交流になると、コイル（インダクタ）やコンデンサ（キャパシタ）が入ったとたん、電圧と電流のあいだに「位相のずれ」が生まれて、単純な割り算では済まなくなります。

これを解決するのが**インピーダンス** $Z$ です。抵抗を複素数に拡張した量で、交流でも

$$
V = Z\,I
$$

という、オームの法則とまったく同じ形で書けます。ポイントは $Z$ が**複素数**だということ。実部が抵抗、虚部がリアクタンス（コイル・コンデンサの「交流的な抵抗」）に対応し、1 本の複素数のなかに**振幅の比と位相のずれの両方**が畳み込まれています。

この記事では、

1. インピーダンスがなぜ複素数になるのか
2. 直列 RLC の $|Z|$・位相・共振を 20 数行の JavaScript で計算する
3. 共振周波数 $f_0$ と Q 値を実数で確かめる

## 3 つの素子のリアクタンス

交流（角周波数 $\omega = 2\pi f$）に対する各素子の振る舞いは、複素数で次のように書けます。

| 素子 | インピーダンス | 性質 |
|---|---|---|
| 抵抗 $R$ | $R$（実数） | 周波数に依存しない |
| コイル $L$ | $j\omega L$ | 高周波ほど通しにくい（$X_L = \omega L$） |
| コンデンサ $C$ | $\dfrac{1}{j\omega C} = -\dfrac{j}{\omega C}$ | 低周波ほど通しにくい（$X_C = \dfrac{1}{\omega C}$） |

ここで $j$ は虚数単位（電気では $i$ は電流に使うので $j$ を使う慣習）。$j$ が掛かることが「電圧と電流が 90° ずれる」ことを意味します。コイルでは電圧が電流より進み、コンデンサでは遅れます。

これらを直列につなぐと、インピーダンスは単純な足し算になります：

$$
Z = R + j\!\left(\omega L - \frac{1}{\omega C}\right)
$$

虚部 $X = \omega L - \dfrac{1}{\omega C}$ をまとめて**リアクタンス**と呼びます。大きさと位相は

$$
|Z| = \sqrt{R^2 + X^2}, \qquad
\varphi = \arctan\frac{X}{R}
$$

で得られます。$\varphi$ が電圧と電流の位相差そのものです。

## 共振周波数と Q 値

式 $X = \omega L - \dfrac{1}{\omega C}$ を見ると、ある周波数で $\omega L$ と $\dfrac{1}{\omega C}$ がちょうど打ち消し合い、$X = 0$ になります。そのときの周波数が**共振周波数** $f_0$ です。$X=0$ を解くと

$$
f_0 = \frac{1}{2\pi\sqrt{LC}}
$$

このとき直列回路では虚部が消え、$|Z| = R$ という**最小値**になります。リアクタンスが消えるので回路は純抵抗のように振る舞い、同じ電圧なら電流が最大になります。ラジオの選局回路が「特定の周波数だけを拾う」のはこの性質を使っています。

共振の鋭さを表すのが**Q 値**です。直列 RLC では

$$
Q = \frac{\omega_0 L}{R}, \qquad \text{帯域幅}\ \mathrm{BW} = \frac{f_0}{Q}
$$

$Q$ が大きいほどピークが鋭く、選択性が高くなります。

シミュレーターのデフォルト値 $R=100\,\Omega,\ L=16\,\mathrm{mH},\ C=1.6\,\mu\mathrm{F}$ で実際に計算してみると：

$$
f_0 = \frac{1}{2\pi\sqrt{16\times10^{-3}\cdot 1.6\times10^{-6}}} = 994.7\ \mathrm{Hz}
$$

$$
Q = \frac{2\pi \cdot 994.7 \cdot 16\times10^{-3}}{100} = 1.0
$$

$Q=1$ なのでかなりなだらかな共振です。同じ $L,C$ のまま $R$ を $10\,\Omega$ に下げると $Q=10$、帯域幅は $\mathrm{BW}\approx 99\,\mathrm{Hz}$ まで狭まります。抵抗を下げるほど共振が鋭くなる、という関係が数値で確認できます。

## JavaScript で 20 数行

シミュレーターが内部で回している計算は、ほぼそのまま JavaScript の数行に落ちます。直列・並列の両方を扱います：

```javascript
function calcZ(R, L, C, f, type) {
  const w  = 2 * Math.PI * f;
  const XL = w * L;          // コイルのリアクタンス
  const XC = 1 / (w * C);    // コンデンサのリアクタンス
  let Zmag, phi;
  if (type === 'series') {
    const X = XL - XC;                       // 虚部
    Zmag = Math.hypot(R, X);                 // |Z| = √(R²+X²)
    phi  = Math.atan2(X, R) * 180 / Math.PI; // 位相 (度)
  } else {
    // 並列: アドミタンス Y = 1/R + j(ωC − 1/ωL) で計算
    const G = 1 / R;
    const B = w * C - 1 / XL;
    Zmag = 1 / Math.hypot(G, B);
    phi  = -Math.atan2(B, G) * 180 / Math.PI;
  }
  return { Zmag, phi };
}

const f0 = 1 / (2 * Math.PI * Math.sqrt(L * C)); // 共振周波数
```

デフォルト値で動作点 $f=1000\,\mathrm{Hz}$ を入れると、$|Z|\approx 100\,\Omega$、$\varphi\approx 0.6°$ が返ります。これは $f_0=994.7\,\mathrm{Hz}$ のすぐ上、ほぼ共振点なので、リアクタンスが消えて $|Z|$ が $R$ に張り付いているわけです。並列のときに**アドミタンス** $Y = 1/Z$ で計算しているのは、並列素子では「逆数の足し算」のほうが素直に書けるためです。

## ボード線図に描く

$f$ を対数軸で振って $|Z|$ をプロットすると、$f_0$ で底をうつ V 字（直列）が現れます。位相は $f_0$ を境に $-90°$（容量性）から $+90°$（誘導性）へ反転します：

![ボード線図と位相特性](/images/ac-circuit-impedance/charts-closeup.png)

読み取れること：

- **$f < f_0$**：$X_C$ が支配的で $X<0$。容量性で $\varphi<0$、電流が電圧より進む
- **$f = f_0$**：$X=0$。$|Z|$ 最小 $=R$、$\varphi=0$
- **$f > f_0$**：$X_L$ が支配的で $X>0$。誘導性で $\varphi>0$、電流が遅れる
- **$R$ が小さいほど** V 字が深く鋭くなる（高 Q）。$R=10\,\Omega$ で $Q=10$、$R=1000\,\Omega$ では $Q=0.1$ で谷がほとんど消える

横軸を対数にすると、$10^1$ から $10^6\,\mathrm{Hz}$ という 5 桁にわたる特性が 1 枚に収まります。これがボード線図の強みです。

## 動作点を動かす

シミュレーターの周波数スライダー（$\log_{10} f$）を動かすと、ボード線図上の赤い動作点が V 字を滑り、$|Z|$ と $\varphi$ がリアルタイムに更新されます：

![周波数を動かすと動作点がV字を滑る](/images/ac-circuit-impedance/slider-anim.gif)

試してほしい操作：

- **「🎯 共振周波数に合わせる」ボタン**で、現在の $L,C$ から計算した $f_0$ に周波数を一発でセット。$|Z|$ が最小に落ちる瞬間が見える
- **直列 RLC / 並列 RLC** をボタンで切り替え。並列ではインピーダンスが $f_0$ で**最大**になり、挙動が逆転する
- **プリセット**「AM ラジオ 540kHz」「オーディオ 1kHz」「タンク回路 5kHz」などをワンクリック。AM ラジオ設定（$R=10,\ L=0.3\,\mathrm{mH},\ C=300\,\mathrm{pF}$）では $Q\approx100$ の鋭い共振になる
- **ボード線図 / 位相特性 / フェーザー図**のタブを切り替えて、複素平面上で $R$・$jX_L$・$-jX_C$・$Z$ のベクトル合成を確認

## まとめ

- 交流回路は**インピーダンス $Z=R+j(\omega L - 1/\omega C)$** で、振幅 $|Z|$ と位相 $\varphi$ を同時に扱える
- 共振周波数は $f_0 = 1/(2\pi\sqrt{LC})$。直列では $|Z|$ 最小、並列では最大
- 共振の鋭さは $Q=\omega_0 L/R$。$R$ を下げるほど高 Q（デフォルトは $f_0=994.7\,\mathrm{Hz}$、$Q=1.0$）
- 計算ロジックは `Math.hypot` と `Math.atan2` を使えば 20 数行の JavaScript で書ける

「複素数 1 個に振幅と位相を畳み込む」というフェーザーの考え方は、フィルタ設計・電源の EMC 対策・制御系のボード線図まで広く効く道具です。まずはスライダーで $f$ を動かし、V 字の底をくぐる感覚を掴んでみてください。
