## ベジェ曲線とは

Illustrator のペンツール、フォントの文字の輪郭、CSS の `cubic-bezier()` ——これらすべての正体が **ベジェ曲線** です。数個の制御点でなめらかな曲線を「形づくる」パラメトリック曲線で、ベクターグラフィックスの共通言語になっています。

次数 $n$ のベジェ曲線は、制御点 $P_0, \dots, P_n$ をバーンスタイン基底関数で重み付けした和として定義されます：

$$
B(t) = \sum_{i=0}^{n} \binom{n}{i}(1-t)^{n-i}\,t^{i}\,P_i,\qquad t \in [0,1]
$$

実務で最もよく使う 3 次ベジェ（制御点 4 個）は、展開すると次のようになります：

$$
B(t) = (1-t)^3 P_0 + 3(1-t)^2 t\,P_1 + 3(1-t)t^2 P_2 + t^3 P_3
$$

重要な性質が 2 つあります。1 つは **端点補間**：$t=0$ では $(1-t)^3=1$ で他の重みが 0 になるため $B(0)=P_0$、同様に $B(1)=P_3$。曲線は両端の制御点を必ず通ります。もう 1 つは、内部の制御点 $P_1, P_2$ は曲線を **「引っ張る」だけで通らない** こと。重みの合計が常に 1 なので、曲線は全制御点の凸包の内側に収まります。

この記事では：

1. De Casteljau のアルゴリズム（線形補間の繰り返しで $B(t)$ を求める）
2. 20 行ほどの JavaScript による実装と検算
3. 曲率と接線方向を数値で確かめる

## De Casteljau のアルゴリズム

バーンスタイン多項式を直接計算する代わりに、**線形補間（lerp）を繰り返すだけ** で $B(t)$ を求められるのが De Casteljau のアルゴリズムです。隣り合う制御点を比 $t$ で内分し、新しい点列を作る——これを点が 1 つになるまで繰り返します。3 次ベジェなら 4 点 → 3 点 → 2 点 → 1 点と 3 段で収束し、最後の点が $B(t)$ です。

バーンスタイン形より数値的に安定で、曲線を $t$ で 2 分割するのにもそのまま使えるため、グラフィックスや CAD で標準的に使われています。

```javascript
const P0 = {x:0,  y:0};
const P3 = {x:100,y:0};   // 端点は固定
const lerp = (a, b, t) => ({x: a.x+(b.x-a.x)*t, y: a.y+(b.y-a.y)*t});

// De Casteljau: 制御点列を t で内分し続ける
function deCasteljau(pts, t){
  while(pts.length > 1){
    const next = [];
    for(let i=0; i<pts.length-1; i++) next.push(lerp(pts[i], pts[i+1], t));
    pts = next;
  }
  return pts[0];
}

// 例: P1=(20,80), P2=(80,80) の 3次ベジェを t=0.5 で評価
const P1 = {x:20,y:80}, P2 = {x:80,y:80};
console.log(deCasteljau([P0,P1,P2,P3], 0.5));  // {x:50, y:60}
```

この結果 $B(0.5)=(50, 60)$ は、バーンスタイン形に直接代入しても同じ値になります（検算済み）。左右対称な制御点配置なので、x 座標がちょうど中央の 50 になるのは自然な結果です。

## 接線方向と曲率

曲線の「向き」と「曲がり具合」は、微分から求まります。1 階微分 $B'(t)$ が接線ベクトルで、方向角は $\mathrm{atan2}(B'_y, B'_x)$。曲率 $\kappa$ は 1 階・2 階微分から：

$$
\kappa = \frac{|B'_x B''_y - B'_y B''_x|}{(B'^2_x + B'^2_y)^{3/2}}
$$

分母は速度の 3 乗で、接線がゼロベクトルになる「カスプ（尖点）」では発散します。数値計算ではこの分母を微小値でガードしないと NaN が出ます（ツールも同じガードを入れています）。

デフォルトの対称な 3 次ベジェ $P_1=(20,80)$, $P_2=(80,80)$ で各値を計算すると：

| 量 | $t=0.5$ での値 |
|---|---|
| $B(t)$ | $(50.00,\ 60.00)$ |
| 接線方向 | $0.0°$（水平） |
| 曲率 $\kappa$ | $0.03333$ |
| 曲線長（近似） | $167.33$ |
| 制御多角形の長さ | $224.92$ |

接線が水平（$0°$）になるのは、対称な配置では $t=0.5$ が曲線の頂点だからです。曲率も $t=0.5$ で最大（$\kappa=0.03333$）になり、両端に向かって小さくなります。曲線長 167.33 が制御多角形長 224.92 より短いのは、曲線が多角形の内側（凸包の中）をショートカットして通るためで、ベジェの凸包性質の数値的な裏付けになっています。

## まとめ

- ベジェ曲線はバーンスタイン基底の重み付き和。端点 $P_0, P_n$ を必ず通り、内部の制御点は引っ張るだけ
- De Casteljau 法は線形補間の繰り返しで $B(t)$ を安定に求める（3 次なら 3 段）
- 接線方向は $B'(t)$、曲率は 1 階・2 階微分から。カスプで発散するため分母ガードが必要
- 対称な 3 次ベジェでは $B(0.5)=(50,60)$、曲率は $t=0.5$ で最大、曲線長 < 制御多角形長（凸包性質）

実務では高次の 1 本ではなく、3 次ベジェを複数つないだ「ベジェスプライン」を使い、つなぎ目で接線（C1 連続）や曲率（C2 連続）をそろえることが、なめらかな見た目の鍵になります。
