## オームの法則とは

電気回路を学ぶとき、最初に出会う関係式がオームの法則です。導体に流れる電流 $I$ は、両端の電圧 $V$ に比例し、抵抗 $R$ に反比例します：

$$
V = I \times R
$$

1827 年にゲオルク・オームが発見したこの 1 本の式は、LED に直列抵抗を入れるといった日常の電子工作から、SPICE による回路シミュレーション、CAE の電気伝導解析まで、あらゆる場面で土台になっています。

この記事では、式の変形による使い分け、電力の計算、直列・並列回路での合成抵抗の振る舞いを整理し、実際に値を動かして確かめられるシミュレーターを紹介します。

⚡ **動くデモ**: [オームの法則シミュレーター（NovaSolver）](https://novasolver.jp/tools/ohms-law.html)

## 3 つの変形で「何を知りたいか」を切り替える

$V = IR$ は、知りたい量に応じて 3 通りに書き換えられます：

$$
I = \frac{V}{R}, \qquad R = \frac{V}{I}, \qquad V = I \times R
$$

| 知りたい量 | 使う式 | 典型的な場面 |
|---|---|---|
| 電流 $I$ | $I = V/R$ | 電源電圧と抵抗から流れる電流を求める |
| 抵抗 $R$ | $R = V/I$ | 必要な電流に絞り込む抵抗値を逆算する |
| 電圧 $V$ | $V = IR$ | 抵抗にかかる電圧降下を求める |

例えば 12V の電源に 100Ω の抵抗をつなぐと、流れる電流は

$$
I = \frac{12\,\text{V}}{100\,\Omega} = 0.12\,\text{A} = 120\,\text{mA}
$$

となります。この値は、後で紹介するシミュレーターのデフォルト表示（120.0 mA）とぴったり一致します。

## 電力は 3 通りに書ける

抵抗で消費される電力 $P$（熱として放出される量）は、オームの法則を代入することで 3 つの等価な式になります：

$$
P = VI = I^2 R = \frac{V^2}{R}
$$

どれも同じ値ですが、手元にある既知量で選ぶと計算が速くなります。先ほどの 12V・100Ω なら：

$$
P = \frac{V^2}{R} = \frac{12^2}{100} = 1.44\,\text{W}
$$

これもシミュレーターの表示（1.44 W）と一致します。1 時間あたりの消費エネルギーは $P \times 3600 \approx 5.18\,\text{kJ/h}$ で、ツールの「消費エネルギー/h」欄の値そのものです。

$P = I^2 R$ を見ると、**同じ抵抗でも電流が 2 倍になれば発熱は 4 倍**になることが一目でわかります。抵抗値を小さくして電流を増やしすぎると消費電力が跳ね上がり、部品から煙が出る——という失敗はここから来ます。

## JavaScript で 25 行の実装

オームの法則の計算は驚くほど単純で、ブラウザ上の Vanilla JS だけで完結します。シミュレーターの中身も、本質はこれだけです：

```javascript
// V[V], R[Ω] から I, P, 1時間あたりエネルギーを求める
function compute(V, R) {
  const I = V / R;          // 電流 [A]  (オームの法則)
  const P = V * I;          // 電力 [W]  (= V^2 / R)
  const Eh = P * 3600;      // 1時間の消費エネルギー [J]
  return { I, P, Eh };
}

// 電流を読みやすい単位に整形（A / mA / μA）
function fmtI(I) {
  if (Math.abs(I) >= 1)      return I.toFixed(3) + ' A';
  if (Math.abs(I) >= 1e-3)   return (I * 1e3).toFixed(1) + ' mA';
  return (I * 1e6).toFixed(0) + ' μA';
}

// デフォルト: V=12, R=100
const r = compute(12, 100);
console.log(fmtI(r.I));                 // "120.0 mA"
console.log(r.P.toFixed(2) + ' W');     // "1.44 W"
console.log((r.Eh / 1000).toFixed(2));  // "5.18" (kJ/h)
```

スライダーを動かすたびにこの `compute()` を呼び、結果を画面に反映するだけ。重い数値積分も外部ライブラリも不要なので、リアルタイムに電流アニメーションを描けます。

## 電流・電力のグラフで関係を掴む

数式だけだと比例・反比例の感覚がつかみにくいので、グラフにしてみます。$R$ を 100Ω に固定して $V$ を変えると $I = V/R$ は直線（比例）に、$V$ を 12V に固定して $R$ を変えると $P = V^2/R$ は反比例の曲線になります：

![I=V/R の直線と P=V²/R の反比例曲線](/images/ohms-law/charts-closeup.png)

- **左：回路図** — 12V・100Ω で 120mA が流れる様子。電流が大きいほど配線の色が明るく、流れる点（電子）の数が増えます
- **中央：$I$ vs $V$** — 抵抗一定なら電流は電圧に正比例（オームの法則そのもの）
- **右：$P$ vs $R$** — 電圧一定なら、抵抗を小さくするほど消費電力が急増する

右のグラフが、前述の「抵抗を下げすぎると発熱が暴走する」ことを視覚的に示しています。

## 直列と並列で合成抵抗はこう変わる

複数の抵抗をつなぐと、合成抵抗 $R_{eq}$ の求め方が接続方式で変わります：

$$
\text{直列}: R_{eq} = \sum_i R_i, \qquad
\text{並列}: \frac{1}{R_{eq}} = \sum_i \frac{1}{R_i}
$$

シミュレーターのデフォルト（$R_1{=}100,\ R_2{=}220,\ R_3{=}470\,\Omega$、電源 12V）で計算すると：

| 接続 | $R_{eq}$ | 電源からの電流 |
|---|---|---|
| 直列 | $100+220+470 = 790\,\Omega$ | $12/790 \approx 15.2\,\text{mA}$ |
| 並列 | $1/(1/100+1/220+1/470) \approx 59.98\,\Omega$ | $\approx 200\,\text{mA}$ |

直列では全抵抗が足し算で増え、電流は小さくなります。並列では合成抵抗が**どの抵抗よりも小さくなり**、電源から流れ出る総電流が増えます。並列の合成抵抗が必ず最小の抵抗より小さくなるのは、電流の通り道が増えるためです。

並列の落とし穴は値が大きく異なるとき。$10\,\Omega$ と $1000\,\Omega$ を並列にすると $R_{eq} \approx 9.9\,\Omega$ で、ほぼ小さい方に張り付きます。「電流は流れやすい経路に集中する」と覚えておくと直感が合います。

## まとめ

- オームの法則は $V = IR$ の 1 本。$I=V/R$、$R=V/I$ に変形して使い分ける
- 電力は $P = VI = I^2R = V^2/R$ の 3 通り。$I^2R$ から、電流増加で発熱が二乗で効くことがわかる
- 12V・100Ω のとき $I=120\,\text{mA}$、$P=1.44\,\text{W}$、$5.18\,\text{kJ/h}$（ツールのデフォルト表示と一致）
- 直列は $R_{eq}$ が足し算で増え、並列は最小抵抗より小さくなる
- 計算は JavaScript 25 行で書け、リアルタイム可視化に向く
