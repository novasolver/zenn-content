## 終端速度とは

高いところから落ちる物体は、最初は重力で加速しますが、やがて速度が一定になります。これが **終端速度（terminal velocity）** です。理由はシンプルで、速くなるほど空気抵抗が強くなり、ある速度で抵抗が重力とちょうど釣り合うから。それ以上は加速できません。

この記事では：

1. 空気抵抗を含む運動方程式と終端速度の式
2. 「速度の2乗」に比例する抵抗が生む非線形なダイナミクス
3. 数値積分で落下を解く JavaScript 実装と、解析解との照合

## 運動方程式と終端速度

落下する物体には、下向きの重力 $mg$ と上向きの空気抵抗が働きます。空気抵抗は速度の2乗に比例する **二次抗力** モデルを使います：

$$
m\frac{dv}{dt} = mg - \frac{1}{2}\rho C_D A\,v^2
$$

$\rho$ は空気密度、$C_D$ は抗力係数、$A$ は進行方向から見た断面積です。右辺が0になる（加速度ゼロ）速度が終端速度で、式を解くと：

$$
v_t = \sqrt{\frac{2mg}{\rho C_D A}}
$$

質量が大きいほど速く、断面積や抗力係数が大きいほど遅くなります。パラシュートが $A$ と $C_D$ を巨大にして $v_t$ を下げているのは、まさにこの式どおりです。落下中のレイノルズ数も併せて評価されます：

$$
Re = \frac{\rho\,v\,D}{\mu}
$$

$D$ は代表長さ（断面積から換算した直径）、$\mu$ は空気の粘度（$1.81\times10^{-5}\ \mathrm{Pa\cdot s}$）です。

## 速度の2乗が効くと、解析解が tanh になる

抵抗が $v^2$ に比例するため運動方程式は非線形ですが、初速0の落下なら閉じた解があります：

$$
v(t) = v_t \tanh\!\left(\frac{g\,t}{v_t}\right)
$$

$\tanh$ は最初ほぼ線形（自由落下 $v \approx gt$）で立ち上がり、やがて $v_t$ に漸近します。終端速度の90%に達する時刻は $\tanh(x)=0.9 \Rightarrow x=\operatorname{artanh}(0.9)\approx 1.472$ から $t_{90} = 1.472\,v_t/g$ と求まります。

## 数値積分で落下を解く

ツールは解析解ではなく、運動方程式をそのまま **前進オイラー法** で時間積分しています（刻み $dt \approx 0.02\ \mathrm{s}$）。20行ほどで書けます：

```javascript
const g = 9.81;

function terminalVelocity(m, A, Cd, rho = 1.2) {
  return Math.sqrt(2 * m * g / (rho * Cd * A));
}

// 90%vt 到達時間を前進オイラー法で求める
function time90(m, A, Cd, rho = 1.2) {
  const dt = 0.05, vt = terminalVelocity(m, A, Cd, rho), tgt = 0.9 * vt;
  let v = 0, t = 0;
  for (let i = 0; i < 20000; i++) {
    const a = (m * g - 0.5 * rho * Cd * A * v * v) / m; // 運動方程式
    v += a * dt;
    t += dt;
    if (v >= tgt) return t;
  }
  return t;
}

// スカイダイバー: m=75kg, A=0.70m², Cd=1.0
const vt = terminalVelocity(75, 0.70, 1.0);
console.log(vt.toFixed(1));        // 41.9 m/s
console.log(time90(75, 0.70, 1.0)); // 約 6.2 s
```

オイラー積分の $t_{90}=6.2\ \mathrm{s}$ は、前述の解析解 $t_{90}=1.472\,v_t/g=6.28\ \mathrm{s}$ とほぼ一致します。刻みが十分小さければ、単純なオイラー法でも実用精度が出る好例です。

## 速度・加速度カーブを見る

ツールは落下アニメーション、速度 $v(t)$、加速度 $a(t)$ を同時に描きます。速度が $v_t$ へ漸近するにつれ、加速度は $g$ から0へ滑らかに減っていきます：

![プリセットごとの終端速度比較](/images/drag-terminal-velocity/charts-closeup.png)

プリセット6種を上記モデル（$\rho=1.2$）で計算すると、終端速度の桁違いの差が見えます：

| プリセット | 質量 | 断面積 | $C_D$ | 終端速度 $v_t$ | 90%到達時間 |
|---|---|---|---|---|---|
| スカイダイバー | 75 kg | 0.70 m² | 1.00 | 41.9 m/s | 6.2 s |
| パラシュート | 90 kg | 28.0 m² | 1.30 | 6.4 m/s | 1.0 s |
| 野球ボール | 0.145 kg | 0.0043 m² | 0.47 | 34.4 m/s | 5.1 s |
| 雨滴 | 5×10⁻⁵ kg | 7.9×10⁻⁵ m² | 0.47 | 4.7 m/s | 0.7 s |
| 雹（ひょう） | 0.01 kg | 7.1×10⁻⁴ m² | 0.47 | 22.2 m/s | 3.3 s |

パラシュートは断面積が桁違いに大きいため、同じ人の体重でも終端速度が $42\to 6.4\ \mathrm{m/s}$ まで落ちます。雨滴がゆっくり降ってくるのも、質量に対して断面積が相対的に大きいからです。なお、ここでのスカイダイバーは断面積0.70 m²・$C_D=1.0$ という設定値での結果で、姿勢（断面積）次第で実際の終端速度はもっと変わります。

## まとめ

- 終端速度は重力と二次抗力が釣り合う速度で、$v_t = \sqrt{2mg/(\rho C_D A)}$
- $v^2$ 比例の抵抗により $v(t) = v_t\tanh(gt/v_t)$ という非線形な立ち上がりになる
- 前進オイラー法（$dt\approx0.02$）で運動方程式を積分すれば、解析解とほぼ一致する精度が出る
- 質量・断面積・抗力係数で終端速度は桁違いに変わる（パラシュートは断面積で $v_t$ を1桁下げる）

二次抗力モデルは、自動車・航空機の空力（CFD の入力確認）から、雨滴の落下速度、スカイダイビングまで幅広く現れます。パラメータを動かして、終端速度の変わり方を確かめてみてください。
