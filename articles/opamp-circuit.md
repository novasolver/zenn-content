## オペアンプ基本回路とは

**オペアンプ（演算増幅器）** は、2 つの入力端子の電圧差をきわめて大きく（理想では無限大に）増幅する差動増幅器です。外側に抵抗やコンデンサを数個つけて「基本回路」に仕立てると、抵抗の比だけでゲインが決まり、温度や個体差にほとんど依存しなくなります——これがフィードバック（負帰還）の威力です。

この記事では、6 つの基本回路のうち特に **反転増幅回路** を軸に、

1. ゲインがなぜ抵抗比だけで決まるのか（理想オペアンプの 2 つの仮定）
2. 出力が電源電圧で頭打ちになる **クリッピング**
3. ゲインを上げると帯域が狭くなる **利得帯域幅積（GBW）** のトレードオフ

を、数式と JavaScript と波形で確かめていきます。

## 理想オペアンプの 2 つの仮定

解析の出発点は、理想オペアンプの 2 つの性質です。

- **仮想短絡（バーチャルショート）**：負帰還がかかっていれば 2 入力間の電圧差はほぼ 0。$V_+ = V_-$ とみなせる。
- **入力電流ゼロ**：入力インピーダンスが無限大なので、入力端子に電流は流れ込まない。

反転増幅回路では非反転入力 $V_+$ を接地するので $V_+ = 0$、したがって反転入力も $V_- = 0$（仮想接地）。入力電流が流れないので、$R_1$ を流れる電流はそのまま $R_f$ を流れます：

$$
\frac{V_{in} - 0}{R_1} = \frac{0 - V_{out}}{R_f}
$$

これを解くと、反転増幅のゲインが得られます：

$$
A_v = \frac{V_{out}}{V_{in}} = -\frac{R_f}{R_1}
$$

マイナス符号は **位相が 180° 反転** することを意味します。同じ論法で、非反転増幅は $A_v = 1 + R_f/R_1$、電圧フォロワは $A_v = 1$ となります。

## ゲインを数値で確かめる

シミュレーターのデフォルト（$R_1 = 10\,\mathrm{k\Omega},\ R_f = 100\,\mathrm{k\Omega}$）で計算してみます：

$$
A_v = -\frac{100\,\mathrm{k\Omega}}{10\,\mathrm{k\Omega}} = -10
$$

dB に直すと $20\log_{10}|A_v| = 20\log_{10}(10) = 20.0\ \mathrm{dB}$。入力インピーダンスは反転増幅では $R_1$ そのものなので $10\,\mathrm{k\Omega}$ です。ツールのロジックを JavaScript でそのまま書くとこうなります：

```javascript
function calcGain(type, R1, Rf) {
  switch (type) {
    case 'inverting':    return -(Rf / R1);   // -10
    case 'noninverting': return 1 + Rf / R1;  // 11
    case 'follower':     return 1;
  }
}
const av = calcGain('inverting', 10e3, 100e3);  // -10
const dB = 20 * Math.log10(Math.abs(av));        // 20.0 dB
```

非反転にすると $A_v = 1 + 100/10 = 11$（$20.8\ \mathrm{dB}$）で、必ず 1 以上になります。反転で $A_v = -100$ がほしければ $R_1 = 1\,\mathrm{k\Omega},\ R_f = 100\,\mathrm{k\Omega}$——比だけで決まるのが扱いやすい点です。

## クリッピング：出力は電源電圧を超えられない

ゲインがいくら大きくても、出力電圧は **電源電圧 $\pm V_{cc}$ を超えられません**。増幅後の理論値が $V_{cc}$ を超えると、波形の頂部が水平に切り取られます。これが **クリッピング（飽和）** です。ツールの波形計算は、各時刻でゲインを掛けたあと電源電圧で頭打ちにするだけのシンプルな実装です：

```javascript
function waveform(av, amp, vcc, freq, t) {
  const vin  = amp * Math.sin(2 * Math.PI * freq * t);
  let   vout = av * vin;                 // 反転なら av<0 で位相反転
  if (vout >  vcc) vout =  vcc;          // 上側クリップ
  if (vout < -vcc) vout = -vcc;          // 下側クリップ
  return { vin, vout };
}
```

歪みなく増幅できる条件は単純です：

$$
|A_v| \cdot V_{in,\text{peak}} < V_{cc}
$$

たとえば $A_v = -10$、入力振幅 $1\,\mathrm{V}$ なら理論出力は $10\,\mathrm{V}$。電源が $\pm 12\,\mathrm{V}$ あれば余裕ですが、$\pm 8\,\mathrm{V}$ だと $\pm 8\,\mathrm{V}$ で頭打ちになります。入力換算では $V_{cc}/|A_v| = 8/10 = 0.8\,\mathrm{V}$ を超えた部分が潰れる計算です。下のグラフ（左）はまさにこの状態——青の正弦波入力に対し、オレンジの出力が $\pm 8\,\mathrm{V}$ で平らに切られています。

## 利得帯域幅積（GBW）というトレードオフ

「ゲインを大きくすれば万事解決」ではありません。実オペアンプには **利得帯域幅積（Gain-Bandwidth Product, GBW）** という固有の定数があり、ゲインと帯域幅の積が一定に保たれます：

$$
\mathrm{BW} = \frac{\mathrm{GBW}}{|A_v|}
$$

このシミュレーターは $\mathrm{GBW} = 1\,\mathrm{MHz}$ を仮定しています。すると：

| ゲイン $\lvert A_v\rvert$ | dB | −3dB 帯域幅 BW |
|---|---|---|
| 1 | 0 dB | 1 MHz |
| 10 | 20 dB | 100 kHz |
| 100 | 40 dB | 10 kHz |
| 200 | 46 dB | 5 kHz |

ゲインを 10 倍から 100 倍に上げると、帯域幅は $100\,\mathrm{kHz}$ から $10\,\mathrm{kHz}$ へ 1 桁狭くなります。上のグラフ（右）の両対数プロットでは、これが傾き $-1$ の直線として現れます。音声回路で高ゲインにしすぎると高音域が削れるのはこのため。広帯域がほしければ、低ゲインの段を複数つなぐか、GBW の大きいオペアンプを選びます。

## スライダーでゲインを動かす

ツールで回路タイプを選び、$R_1 / R_f$ や入力振幅・電源電圧・周波数のスライダーを動かすと、入出力波形・伝達曲線・統計（ゲイン、dB、入力インピーダンス、帯域幅）がリアルタイムに更新されます。下の GIF は反転増幅で $R_f$ を増やしていく様子——出力（オレンジ）の振幅が大きくなり、やがて電源電圧でクリップします。入力（青）と位相が反転しているのも見て取れます。

![Rf を動かすと出力が成長しクリップする](/images/opamp-circuit/slider-anim.gif)

試してほしい操作：

- **回路タイプ**を反転増幅・非反転増幅・電圧フォロワ・加算増幅・微分回路・積分回路の 6 種類から選ぶ
- **$R_1 / R_f$ スライダー**を動かして、ゲイン（dB）と帯域幅の表示が連動して変わるのを見る
- **入力振幅 $V_{in}$ または電源電圧 $\pm V_{cc}$** を変え、クリッピング警告が出る境界を探す
- **入力周波数**（1 Hz〜100 kHz、対数）を変える
- **伝達曲線 $V_{out}$ vs $V_{in}$** で、飽和領域が水平になる様子を確認する

> なお、このツールの波形は各時刻に $V_{out} = A_v \cdot V_{in}$ を掛けてクリップする簡易モデルです。そのため微分回路・積分回路を選んでも、出力は入力と同位相のまま振幅だけが変わる正弦波として描かれ、本来の「微分なら 90° 進む／積分なら 90° 遅れる」位相関係や三角波⇄矩形波の波形変換までは再現されません。微分・積分の挙動はゲイン（振幅）の周波数依存として捉えてください。

## まとめ

- 反転増幅のゲインは仮想短絡＋入力電流ゼロから $A_v = -R_f/R_1$ と導ける（位相は 180° 反転）
- $R_1=10\mathrm{k},\ R_f=100\mathrm{k}$ で $A_v=-10$（20 dB）、入力インピーダンス $10\,\mathrm{k\Omega}$
- 出力は $\pm V_{cc}$ を超えられず、$|A_v|\cdot V_{in,\text{peak}} > V_{cc}$ でクリッピングが起きる
- 利得帯域幅積により $\mathrm{BW} = \mathrm{GBW}/|A_v|$。ゲインを上げるほど帯域は狭くなる（GBW=1MHz 仮定）

抵抗 2 本でゲインを設計し、電源電圧と GBW という 2 つの限界を意識する——これがアナログ回路設計の出発点です。センサ信号の増幅やフィルタ、計測インターフェースなど、オペアンプは実務のいたるところで使われています。
