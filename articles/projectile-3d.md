## 高校物理の放物線では足りない

「初速 $v_0$、仰角 $\theta$ で投げたボールの射程は $R = v_0^2 \sin 2\theta / g$」。高校で習うこの式は、**空気抵抗もスピンも風もない真空**を前提にしています。ところが実際の野球・ゴルフ・サッカーでは、空気の力が軌道を大きく曲げます。野球プリセット（初速 42 m/s、仰角 15°）を真空で計算すると射程は **89.7 m** ですが、空気抵抗を入れると **71.9 m** まで縮みます。約 2 割も短くなるのです。

さらに、回転するボールには横向きの力（**マグナス効果**）が働き、軌道が左右に曲がります。これがカーブやスライダーの正体です。

この記事では：

1. 抗力・マグナス力・重力を含む 3 次元の運動方程式
2. RK4（4 次ルンゲ・クッタ）による数値積分（実コード約 25 行）
3. 「真空 vs 空気抵抗」「スピンによる横偏向」を数値で確認

## 3つの力と運動方程式

質量 $m$ のボールに働く力は **重力・抗力・マグナス力** の 3 つです。位置 $\mathbf{r}=(x,y,z)$ の運動方程式は：

$$
m\ddot{\mathbf{r}} = m\mathbf{g} + \vec{F}_D + \vec{F}_M
$$

**抗力（空気抵抗）** は、相対速度 $\mathbf{v}_{\mathrm{rel}}=\mathbf{v}-\mathbf{v}_{\text{wind}}$ の逆向きに、速さの 2 乗で効きます：

$$
\vec{F}_D = -\frac{1}{2}C_D\,\rho\,A\,|\mathbf{v}_{\mathrm{rel}}|\,\mathbf{v}_{\mathrm{rel}}
$$

ここで $C_D$ は抗力係数、$\rho=1.225~\mathrm{kg/m^3}$ は空気密度、$A$ は断面積です。$|\mathbf{v}_{\mathrm{rel}}|\,\mathbf{v}_{\mathrm{rel}}$ という形なので、向きを保ったまま大きさが $v^2$ に比例します。

**マグナス力** は、スピンによって生じる横向きの揚力です。相対速度の水平成分に垂直な向きに働きます：

$$
\vec{F}_M = \frac{1}{2}C_L\,\rho\,A\,|\mathbf{v}_{\mathrm{rel}}|^2\,\hat{n}
$$

このツールでは揚力係数を $C_L = \min(0.5\,\omega d / v,\ 0.5)$ という簡易式で与えています。$\omega=2\pi\cdot(\text{RPM})/60$ は角速度、$d=2\sqrt{A/\pi}$ は断面積から逆算した直径です。低速ほど $\omega d/v$ が大きくなり横力が増える——ただし 0.5 で頭打ち（飽和）させてある、という点が実装のポイントです。

| 記号 | 意味 | 野球プリセットの値 |
|---|---|---|
| $v_0$ | 初速度 | 42 m/s |
| $\theta$ | 仰角 | 15° |
| $C_D$ | 抗力係数 | 0.35 |
| $A$ | 断面積 | 29 cm² |
| $m$ | 質量 | 0.145 kg |
| スピン | 回転数 | 2000 rpm |

## RK4 で 25 行の実装

抗力もマグナス力も速度の非線形関数なので、解析解はありません。そこで **RK4** で数値積分します。状態は位置 $(x,y,z)$ と速度 $(v_x,v_y,v_z)$ の 6 成分。加速度を返す `deriv` を 4 回評価して 1 ステップ進めます（時間刻み $dt=0.005$ s）：

```javascript
const rho = 1.225, g = 9.81, dt = 0.005;
const area = 29e-4, mass = 0.145, cd = 0.35;       // 野球プリセット
const omega = 2000 * 2 * Math.PI / 60;             // スピン[rad/s]
const d = 2 * Math.sqrt(area / Math.PI);           // 直径
const wx = 0, wy = 0;                              // 風(無風)

function deriv(vx, vy, vz) {
  const rx = vx - wx, ry = vy - wy, rz = vz;        // 相対速度
  const v = Math.hypot(rx, ry, rz) || 1e-9;
  const Fd = 0.5 * cd * rho * area * v * v;          // 抗力の大きさ
  const ax = -Fd * rx / (v * mass);
  const ay = -Fd * ry / (v * mass);
  const az = -Fd * rz / (v * mass) - g;             // 重力を加算
  const CL = Math.min(0.5 * omega * d / v, 0.5);     // 揚力係数(飽和)
  const Fm = 0.5 * CL * rho * area * v * v;          // マグナス力
  const vh = Math.hypot(rx, ry) || 1e-9;             // 水平速度に垂直
  return { ax: ax + Fm * (-ry / vh) / mass,
           ay: ay + Fm * ( rx / vh) / mass, az };
}
```

メインループは標準的な RK4 です：

```javascript
let x=0, y=0, z=0;
let vx=42*Math.cos(0.2618), vy=0, vz=42*Math.sin(0.2618);  // θ=15°
while (z >= 0) {
  const k1 = deriv(vx, vy, vz);
  const k2 = deriv(vx+0.5*dt*k1.ax, vy+0.5*dt*k1.ay, vz+0.5*dt*k1.az);
  const k3 = deriv(vx+0.5*dt*k2.ax, vy+0.5*dt*k2.ay, vz+0.5*dt*k2.az);
  const k4 = deriv(vx+dt*k3.ax, vy+dt*k3.ay, vz+dt*k3.az);
  vx += dt*(k1.ax+2*k2.ax+2*k3.ax+k4.ax)/6;
  vy += dt*(k1.ay+2*k2.ay+2*k3.ay+k4.ay)/6;
  vz += dt*(k1.az+2*k2.az+2*k3.az+k4.az)/6;
  x += vx*dt; y += vy*dt; z += vz*dt;
}
```

なぜ RK4 か。オイラー法（1 次）だと同じ $dt$ でも誤差が蓄積して射程がずれますが、RK4 は局所誤差が $O(dt^5)$ と小さく、安定して弾道を再現できます。これは自動車の衝突解析や構造物の地震応答といった CAE の時間積分でも標準的に使われる手法です。

## 真空 vs 空気抵抗を数値で確かめる

野球プリセット（$v_0=42$ m/s、$\theta=15°$、$C_D=0.35$、$A=29$ cm²、$m=0.145$ kg、スピン 2000 rpm）で計算すると、各出力は次のようになります：

| 出力 | 真空 | 空気抵抗あり |
|---|---|---|
| 最大射程 $R$ | 89.7 m | **71.9 m** |
| 最高点 $H$ | — | 5.3 m |
| 飛行時間 $T$ | — | 2.09 s |
| 着地速度 | — | 31.2 m/s |

![側面図とマグナス偏向](/images/projectile-3d/charts-closeup.png)

左の側面図（X-Z 面）では、破線の真空軌道が放物線（前後対称）なのに対し、空気抵抗ありの軌道（実線）は**後半が急に落ちる非対称な形**になっています。落下側で速度が減衰し、揚程が伸びないためです。真空の射程公式 $R=v_0^2\sin2\theta/g$ に代入すると $42^2\sin30°/9.81=89.9$ m となり、ツールの真空射程 89.7 m とほぼ一致します（差は着地点の離散補間によるもの）。

抗力の効きは断面積と速度に強く依存します。試しにゴルフプリセット（$v_0=70$ m/s）で計算すると、真空射程 202.8 m に対し空気抵抗ありは **128.5 m**——高速ほど $v^2$ の抗力が効いて、真空との差はさらに開きます。

## マグナス効果で軌道が曲がる

右の上面図（X-Y 面）は、真上から見た軌道です。スピン 0 なら横偏向はゼロ（まっすぐ）ですが、スピン 2000 rpm では着地時に **5.6 m** も横にそれます。これがカーブボールやバナナシュートの物理です。

スピンを 0 → 4000 rpm と動かすと、横偏向がほぼ線形に増えていく様子が見えます：

![スピンを動かすと横偏向が増える](/images/projectile-3d/slider-anim.gif)

ここで揚力係数の飽和が効いてきます。$C_L=\min(0.5\,\omega d/v,\ 0.5)$ の中身を野球（$d=6.08$ cm、$\omega=209$ rad/s）で見ると、$v=42$ m/s では $C_L=0.152$ ですが、ボールが減速して $v=20$ m/s になると $C_L=0.318$ まで上がります。**低速になるほど曲がりが急になる**——打者の手元で変化球が「キレる」感覚は、この速度依存性とも対応しています。ただし上限 0.5 で頭打ちにすることで、非現実的な急旋回を防いでいます。

## 風の影響

風は相対速度 $\mathbf{v}_{\mathrm{rel}}=\mathbf{v}-\mathbf{v}_{\text{wind}}$ を通じて抗力とマグナス力の両方に入ります。野球プリセットに 10 m/s の風を加えると：

| 風 | 射程 $R$ |
|---|---|
| 無風 | 71.9 m |
| 追い風 10 m/s | 77.8 m |
| 向かい風 10 m/s | 65.2 m |

向かい風では相対速度が増えて抗力が強まり射程が縮み、追い風では逆に伸びます。横風（風向を 90° に設定）にすればマグナス効果と複合した複雑な軌跡も再現できます。

## まとめ

- 3 次元弾道は重力・抗力 $\frac{1}{2}C_D\rho A v\,\mathbf{v}$・マグナス力 $\frac{1}{2}C_L\rho A v^2$ の合力で決まる
- 解析解はなく、RK4 + $dt=0.005$ で約 25 行の JavaScript として実装できる（CAE の時間積分と同じ手法）
- 野球プリセットでは真空 89.7 m → 空気抵抗あり 71.9 m と約 2 割短縮
- スピン 2000 rpm で横偏向 5.6 m。$C_L$ は低速ほど大きく、変化球の「キレ」に対応する
- 風は相対速度を通じて働き、追い風 +5.9 m／向かい風 −6.7 m の差を生む

「高校物理の放物線」と「実際のボールの軌道」のギャップを、数式と数値で埋められるのがこのツールの面白さです。
