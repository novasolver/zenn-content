## フリスの伝達公式とは

スマホ、Wi-Fi、テレビ放送、そして火星探査機まで、あらゆる無線リンクは同じ「電力の会計問題」を抱えています。送信機から出した電力のうち、受信機に届くのはほんの一部。その「一部」を、障害物も反射も大気吸収もない理想空間（自由空間）について予測するのが、1946 年に Harald Friis が発表した **フリスの伝達公式**です。

実務ではすべてをデシベルで計算します。デシベルにすると利得は足し算、損失は引き算になり、リンクバジェットがただの加減算の表になるからです：

$$
P_{rx} = P_{tx} + G_{tx} + G_{rx} - \text{FSPL}
$$

ここで $P_{rx}$ は受信電力 [dBm]、$P_{tx}$ は送信電力 [dBm]、$G_{tx}, G_{rx}$ は送受信アンテナ利得 [dBi]、FSPL は自由空間伝搬損失 [dB] です。

この記事では：

1. なぜ何もない空間でも電波が距離で弱るのか（FSPL の正体）
2. 距離 2 倍で受信電力が **きっかり −6 dB** になる理由
3. リンクマージンで「回線が成立するか」を判定する方法

を、実際に数値を計算しながら確かめます。

## 自由空間伝搬損失（FSPL）

最も直感に反するのが、障害物が何もなくても電波が弱ること。送信アンテナの電力は風船のように球面状に広がり、受信アンテナが捉えられるのはその球面のごく一部だけです。球の表面積は距離の 2 乗で増えるので、受信側の取り分は距離の 2 乗に反比例して減ります。

さらに、利得一定のアンテナの実効開口面積は波長の 2 乗に比例するため、周波数が高いほど受信アンテナは「小さなバケツ」になります。両方を合わせると、距離 $d$ [km]・周波数 $f$ [MHz] の標準的なデシベル形は：

$$
\text{FSPL} = 20\log_{10} d + 20\log_{10} f + 32.44\quad[\text{dB}]
$$

距離も周波数も、係数が同じ $20\log_{10}$。つまり **距離が 2 倍 = 周波数が 2 倍 = どちらも +6 dB** の損失増。これがフリスの公式の最も美しい対称性です。

## 20行で書くリンクバジェット計算

ツールの中核はこれだけです。送信電力をワットで受け取り、すべてデシベルに変換してから加減算します：

```javascript
const C_LIGHT = 3e8;   // 光速 m/s
const RX_SENS = -90;   // 代表的な受信感度 dBm

// Ptx[W], Gtx/Grx[dBi], f[MHz], d[km]
function friis(Ptx, Gtx, Grx, fMHz, dKm) {
  const wavelength = C_LIGHT / (fMHz * 1e6);                 // 波長 m
  const fspl = 20*Math.log10(dKm) + 20*Math.log10(fMHz) + 32.44; // dB
  const txDbm = 10 * Math.log10(Ptx * 1000);                 // W -> dBm
  const rxDbm = txDbm + Gtx + Grx - fspl;                    // 受信電力 dBm
  const rxW = Math.pow(10, (rxDbm - 30) / 10);               // dBm -> W
  const margin = rxDbm - RX_SENS;                            // リンクマージン dB
  return { wavelength, fspl, txDbm, rxDbm, rxW, margin };
}
```

既定値 $P_{tx}=10$ W、$G_{tx}=G_{rx}=12$ dBi、$f=2400$ MHz、$d=10$ km を入れると：

```javascript
friis(10, 12, 12, 2400, 10);
// wavelength: 0.125  (m)
// fspl:       120.04 (dB)
// txDbm:      40.0   (dBm)  ← 10W = 40dBm
// rxDbm:      -56.04 (dBm)
// rxW:        2.49e-9 (W)
// margin:     34.0   (dB)   ← 受信感度 -90dBm に対し余裕34dB
```

受信電力 $-56$ dBm。受信感度 $-90$ dBm を 34 dB 上回り、回線は十分成立します。

## 距離・周波数を倍にすると −6 dB

20log の構造を数値で確かめます。既定条件から距離だけ、あるいは周波数だけを 2 倍にすると：

| 変更 | FSPL [dB] | $P_{rx}$ [dBm] | 差分 |
|---|---|---|---|
| 基準（10 km, 2400 MHz） | 120.04 | $-56.04$ | — |
| 距離 2 倍（20 km） | 126.06 | $-62.06$ | $-6.02$ dB |
| 周波数 2 倍（4800 MHz） | 126.06 | $-62.06$ | $-6.02$ dB |

きっかり $-6.02$ dB（$=20\log_{10}2$）。距離でも周波数でも、倍にすれば受信電力は 1/4 になります。距離を 10 倍ずつ振ると受信電力は 20 dB ずつ落ちていきます：

| 距離 $d$ | $P_{rx}$ [dBm] | マージン [dB] |
|---|---|---|
| 1 km | $-36.0$ | $+54.0$ |
| 10 km | $-56.0$ | $+34.0$ |
| 100 km | $-76.0$ | $+14.0$ |
| 1000 km | $-96.0$ | $-6.0$（不成立） |

静止衛星（約 36,000 km）まで届かせるなら、2400 MHz で FSPL は約 191 dB。だから地上局は直径数 m の高利得パラボラで、この桁外れの損失を利得で取り返します。

## リンクマージンで回線を判定する

リンクマージンは「受信電力が受信機の最低必要感度をどれだけ上回っているか」の余裕です。本ツールは代表的な感度 $-90$ dBm を基準に $M = P_{rx} - (-90)$ で計算します。

実例として 2.4 GHz の LoRa リンク（$P_{tx}=20$ dBm $=0.1$ W、$G_{tx}=2$ dBi、$G_{rx}=5$ dBi、$d=1$ km、受信感度 $-100$ dBm）を計算すると、FSPL $\approx 100$ dB、$P_{rx}\approx -73$ dBm、マージン $\approx 27$ dB。十分な余裕です。

ただしマージンがちょうど 0 だと危険です。実際の電波は雨で減衰し、フェージングで揺れ、アンテナの向きが少しずれます。だから実務では 10 dB 以上、衛星リンクのような重要回線では 20 dB 以上を目標にします。健全なマージンこそが、悪天候や微妙なズレに対する保険です。

## まとめ

- フリスの公式は $P_{rx} = P_{tx} + G_{tx} + G_{rx} - \text{FSPL}$、すべてデシベルで会計
- 自由空間でも電力は球面に広がり、距離の 2 乗で薄まる
- FSPL $= 20\log_{10}d + 20\log_{10}f + 32.44$。距離 2 倍も周波数 2 倍も $-6$ dB
- 既定条件で $P_{rx}=-56$ dBm、マージン 34 dB。実務は 10 dB 以上の余裕を確保

「送り出した電力を、利得で稼ぎ、損失で失う」という単純な足し算引き算が、Wi-Fi から深宇宙探査まで貫く設計の出発点です。なお本ツールは自由空間の理想値であり、壁・雨・マルチパスによる追加損失は含まない「これより悪くなることはあっても良くはならない」上限の目安として使ってください。
