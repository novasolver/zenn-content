## 複利とは

100 万円を年利 5% で 30 年運用する。単利なら $100 + 100\times0.05\times30 = 250$ 万円。ところが複利だと **約 432 万円**。差は 182 万円にもなります。利息がさらに利息を生む——この指数的な成長が複利の本質です。

元金 $P$、年利率 $r$、年複利、$n$ 年後の資産 $A$ は次のように書けます：

$$
A = P\,(1+r)^n
$$

年に $m$ 回複利すると（月次なら $m=12$）、各期の利率は $r/m$、期数は $mn$ になるので：

$$
A = P\left(1+\frac{r}{m}\right)^{mn}
$$

$m\to\infty$ の極限が **連続複利** $A = Pe^{rn}$ です。さらに毎年末に $C$ ずつ積み立てると、第 2 項に **年金の将来価値（FV of annuity）** が加わります：

$$
A = P\,(1+r)^n + C\,\frac{(1+r)^n - 1}{r}
$$

1. 単利と複利の差がなぜ指数的に開くか
2. 20 行の JavaScript での資産推移計算
3. 積立・複利頻度・インフレを入れたときの数値

を実際に計算して確かめます。

## 72 の法則 — 資産が 2 倍になる年数

「年利 $r\%$ なら $72/r$ 年で 2 倍」という暗算ルールが **72 の法則** です。正確な倍増年数は $\ln 2 / \ln(1+r)$ で、両者を比べると：

| 年利 | 72 の法則 | 正確値 $\ln2/\ln(1+r)$ |
|---|---|---|
| 4% | 18.0 年 | 17.67 年 |
| 5% | 14.4 年 | 14.21 年 |
| 6% | 12.0 年 | 11.90 年 |
| 10% | 7.2 年 | 7.27 年 |

実用的な利率（4〜10%）では誤差は 0.1〜0.3 年程度。72 は 2,3,4,6,8,9,12 で割り切れて暗算しやすいため、$\ln 2 \approx 0.693$ をあえて 0.72 に丸めた絶妙な近似になっています。

## 20 行で資産推移を計算する

NovaSolver のツールが内部で回しているのと同じ計算を書き出します。複利頻度 $m$ と積立 $C$ の両方に対応します：

```javascript
// P:元金, r:年利(小数), n:年数, C:毎年積立, m:複利回数/年
function growth(P, r, n, C, m) {
  const out = [];
  const rp = r / m;                       // 1期あたりの利率
  const annualR = Math.pow(1 + rp, m) - 1; // 実効年利（EAR）
  for (let yr = 0; yr <= n; yr++) {
    let A = P * Math.pow(1 + rp, m * yr);  // 元金部分の複利成長
    if (C > 0 && yr > 0) {
      // 毎年末積立の将来価値（年金の将来価値）
      A += C * (Math.pow(1 + annualR, yr) - 1) / annualR;
    }
    out.push(Math.round(A * 10) / 10);
  }
  return out;
}

const a = growth(100, 0.05, 30, 0, 1);
console.log(a[30].toFixed(0)); // 432  （100万 → 432万）
```

複利頻度を上げると実効年利が少し上がります。名目年利 6% の場合、

$$
\text{EAR} = \left(1+\frac{r}{m}\right)^m - 1
$$

| 複利頻度 | 実効年利 EAR |
|---|---|
| 年次（m=1） | 6.000% |
| 月次（m=12） | 6.168% |
| 日次（m=365） | 6.183% |
| 連続（$e^{0.06}-1$） | 6.184% |

頻度を上げても連続複利が上限。差はわずかですが、長期では効いてきます。

## 積立の威力 — 月1.5万円が1200万円に

ツールの「iDeCo」プリセットは、元金 0・毎年積立 18 万円（月 1.5 万円）・年利 5%・月次複利・30 年です。計算すると：

- 元本投入額：$18\times30 = 540$ 万円
- 最終資産額：**約 1220 万円**
- 複利による増益分：約 680 万円

投入した 540 万円が 30 年で 1220 万円に。増益分が元本を上回ります。これが「積立 + 複利」の組み合わせの威力で、年金の将来価値の式そのものです。「新NISA」プリセット（月 3 万円・年利 7%・20 年）でも投入 720 万円 → 約 1513 万円、増益 793 万円になります。

## インフレを引くと実質はどうなるか

名目で増えても、物価が上がれば購買力は目減りします。実質資産は $A/(1+i)^n$ で、名目リターン $r$ とインフレ率 $i$ の関係はフィッシャー方程式で表されます：

$$
1 + r_{\text{real}} = \frac{1+r}{1+i}
$$

![名目資産と実質購買力の成長曲線](/images/compound-interest-sim/charts-closeup.png)

ツールの「インフレ侵食」プリセット（元金 100 万・年利 1%・インフレ 3%・30 年）で計算すると、名目では 134.8 万円に増えるのに、実質購買力は **55.5 万円** まで下がります。

$$
r_{\text{real}} = \frac{1.01}{1.03} - 1 \approx -1.94\%
$$

実質リターンがマイナス——つまり「増えているのに、買えるものは減っている」状態です。年利をインフレ率より高く保てるかどうかが、資産形成の分かれ目になります。

## まとめ

- 複利 $A=P(1+r/m)^{mn}$ は単利を指数的に引き離す（100万・5%・30年で 432万 vs 250万）
- 72 の法則は $\ln2/\ln(1+r)$ の優れた近似（年利 6% で約 12 年で 2 倍）
- 積立込みの式は年金の将来価値が加わり、月1.5万円・5%・30年で投入 540万 → 約 1220万
- 複利頻度を上げると実効年利が上がるが、連続複利が上限（6% なら 6.184%）
- インフレ率がリターンを上回ると実質購買力は減る（フィッシャー方程式）

複利は短期では地味でも、時間を味方につけると指数的に効きます。数式とグラフで「時間が最大の資産」という言葉の意味を体感できるのが、このシミュレーターの狙いです。
