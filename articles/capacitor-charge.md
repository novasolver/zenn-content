## コンデンサの充放電とは

抵抗 $R$ とコンデンサ $C$ を直列につないだ **RC 回路** にスイッチを入れると、コンデンサの電圧は一瞬で電源電圧にはなりません。**じわじわと指数関数的に**立ち上がり、スイッチを切ると今度はじわじわと落ちていきます。この「立ち上がり／立ち下がりの速さ」を一手に決めているのが **時定数 $\tau = RC$** です。

充電と放電の電圧は、それぞれ次の式で表されます：

$$
V_\text{charge}(t) = V_0\left(1 - e^{-t/\tau}\right)
$$
$$
V_\text{discharge}(t) = V_0\, e^{-t/\tau}
$$

回路に流れる電流は充電・放電のどちらでも同じ形で、最初に最大、その後は指数的に減衰します：

$$
I(t) = \frac{V_0}{R}\, e^{-t/\tau}, \qquad \tau = RC
$$

この記事では、

1. なぜ電圧が「直線」ではなく「指数曲線」になるのか
2. $\tau = RC$ が持つ「63.2%」という意味
3. 20 行ほどの JavaScript で充放電曲線を再現する

を順に見ていきます。

## なぜ指数関数になるのか

コンデンサが蓄える電荷は $Q = CV$ で、電流は電荷の時間変化 $I = dQ/dt = C\,dV/dt$ です。一方、電源電圧 $V_0$ は抵抗の電圧降下とコンデンサの電圧に分かれます（キルヒホッフの電圧則）：

$$
V_0 = R\,I + V = RC\frac{dV}{dt} + V
$$

これは 1 階の線形微分方程式で、$\tau = RC$ とおいて解くと充電解 $V(t) = V_0(1 - e^{-t/\tau})$ が出てきます。

直感的には、**$V$ が上がるほど抵抗にかかる電圧 $V_0 - V$ が減り、流れ込む電流が細くなる**。だから最初は勢いよく、満タンに近づくほどゆっくりになる——これが直線ではなく指数曲線になる理由です。放電はその逆です。

## τ=RC が意味する「63.2%」

時定数 $\tau$ は単なる時間スケールではなく、はっきりした物理的意味を持ちます。充電開始から $t = \tau$ 経過すると：

$$
V(\tau) = V_0\left(1 - e^{-1}\right) = V_0 \times 0.632
$$

つまり **最終値のちょうど 63.2%** に達します。$t = k\tau$ における充電率は $1 - e^{-k}$ で、Python で並べると次の通りです：

| 経過時間 | 充電率 $1-e^{-k}$ | 放電率 $e^{-k}$ |
|---|---|---|
| $t=\tau$ | 63.2% | 36.8% |
| $t=2\tau$ | 86.5% | 13.5% |
| $t=3\tau$ | 95.0% | 5.0% |
| $t=4\tau$ | 98.2% | 1.8% |
| $t=5\tau$ | 99.3% | 0.7% |

実務では **$t = 5\tau$ でほぼ完了（99.3%）** とみなすのが定番です。「99% に達する時間」を厳密に求めるなら $t = \tau\ln 100 \approx 4.61\,\tau$ になります。

具体例として $R = 1\,\text{k}\Omega$、$C = 1000\,\mu\text{F}$ を取ると、

$$
\tau = RC = 10^3 \times 10^{-3} = 1.0\ \text{秒}
$$

となり、電源 $V_0 = 9\,\text{V}$ なら 1 秒後にちょうど $5.69\,\text{V}$（63.2%）、5 秒後に 99.3% まで充電されます。初期電流は $I_0 = V_0/R = 9\,\text{mA}$ です。

## 20 行の JavaScript で再現する

RC 回路には解析解があるので、数値積分すら不要です。式をそのまま評価するだけで曲線が描けます：

```javascript
const R = 1000;        // 抵抗 [Ω]
const C = 1000e-6;     // 容量 [F]
const V0 = 9;          // 電源電圧 [V]
const tau = R * C;     // 時定数 τ = RC [s]

// 充電: V(t)=V0(1-e^{-t/τ})  放電: V(t)=V0 e^{-t/τ}
function voltage(t, mode) {
  return mode === "charge"
    ? V0 * (1 - Math.exp(-t / tau))
    : V0 * Math.exp(-t / tau);
}
// 電流は充放電とも I(t)=(V0/R)e^{-t/τ}
function current(t) {
  return (V0 / R) * Math.exp(-t / tau);
}

// 0 〜 6τ を等間隔にサンプリングして曲線データを作る
const tMax = 6 * tau, N = 200, pts = [];
for (let i = 0; i <= N; i++) {
  const t = (i / N) * tMax;
  pts.push({ t, v: voltage(t, "charge"), i: current(t) });
}
```

出力の要点を抜き出すとこうなります：

```javascript
console.log(voltage(tau,   "charge").toFixed(2));  // 5.69  (= 63.2%)
console.log(voltage(5*tau, "charge").toFixed(2));  // 8.94  (= 99.3%)
console.log((current(0) * 1000).toFixed(1));       // 9.0   [mA] 初期電流
```

## 時定数を変えると曲線はどう動くか

$\tau = RC$ なので、$R$ か $C$ を大きくすれば曲線はなだらかに、小さくすれば急峻になります。下のアニメーションは $C = 1000\,\mu\text{F}$ を固定して $R$ を $0.3\,\text{k}\Omega \to 3\,\text{k}\Omega$ と動かしたもので、$\tau$ が $0.3\,\text{s}$ から $3\,\text{s}$ まで伸び縮みします（橙の破線が $t=\tau$ の位置、点線が 63.2% ライン）：

![R を動かすと時定数 τ が伸び縮みする](/images/capacitor-charge/slider-anim.gif)

$\tau$ が大きいほど 63.2% ラインに到達するのが遅くなる——これが「$R$ や $C$ を増やすと応答が鈍る」ということの正体です。

## 実世界での応用

RC の充放電は身近な機器の中で何度も使われています。

- **カメラのフラッシュ**: 電池は瞬間的な大電流を出せないため、コンデンサに電荷をためておき発光時に一気に放電します。$E = \tfrac12 C V_0^2$ のエネルギーが一瞬で解放されます。
- **電源回路の平滑化**: 整流後の脈動（リップル）に大容量コンデンサを並列に入れ、出力をならします。
- **タイマー・発振回路**: $\tau = RC$ で決まる遅延を作り、マルチバイブレータなどの発振周期を決めます。

## よくある誤解と注意点

- **τ は「充電完了までの時間」ではない**。$\tau$ の時点ではまだ 63.2%。実務では 5τ（99.3%）を「ほぼ完了」とみなします。
- **コンデンサは「電圧」ではなく「電荷」をためる**。$Q = CV$ の結果として両端に電圧が現れます。充電中は電流が流れているので、$V_0 = V_C + V_R$ のうち抵抗側の降下 $V_R$ を見落とすと電流の減衰が理解しにくくなります。
- **理想モデルである点に注意**。実部品には等価直列抵抗（ESR）や漏れ電流があり、特に大電流を流すフラッシュ用途では ESR が発熱・効率低下の原因になります。本記事とツールの値は「理想的な挙動の基本形」として捉えてください。

## まとめ

- RC 回路の電圧は $V_0(1-e^{-t/\tau})$（充電）／ $V_0 e^{-t/\tau}$（放電）の指数曲線
- 時定数 $\tau = RC$ は「63.2% に達する時間」。$5\tau$ で 99.3%、ほぼ完了
- 解析解があるので数値積分は不要、20 行ほどの JavaScript で曲線を再現できる
- カメラフラッシュ・電源平滑化・タイマーなど、身近な機器の中核に RC 充放電がある

「単純な 1 階の微分方程式が、指数曲線という普遍的な形を生む」——それを手で動かして体感できるのが RC 回路の面白さです。
