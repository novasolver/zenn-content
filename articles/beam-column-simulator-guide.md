## 梁柱（beam-column）とは

「柱」は軸力だけ、「梁」は曲げだけを受ける——教科書ではそう習います。ところが実構造の柱は、上階の重さ（軸圧縮力 $N$）と、地震・風・偏心荷重による曲げモーメント $M$ を**同時に**受けます。この「軸力と曲げを同時に受ける部材」を**梁柱（beam-column）** と呼びます。

やっかいなのは、$N$ と $M$ の効果が単純な足し算にならない点です。軸力がかかっていると曲げに対する余力が減り、さらに軸力は柱を**座屈**させる方向にも働くため、細長い部材ほど不利になります。この連成を 1 枚のグラフにまとめたのが **P-M 相関図（軸力-曲げ相互作用図）** です。この記事では、欧州規格 EN 1993-1-1 の相互作用式と座屈低減係数 $\chi$ を整理し、約 25 行の JavaScript で照査ロジックを実装して、利用率 $\eta$ が 1.0 を境に PASS/FAIL を分ける様子を数値で確認します。

## オイラー座屈と無次元細長比

まず座屈です。軸力が大きくなると、細長い柱はある荷重で横へ折れます。その臨界荷重が**オイラー座屈荷重**：

$$
N_{cr} = \frac{\pi^2 E I_y}{(KL)^2}
$$

$E$ はヤング率、$I_y$ は断面二次モーメント、$L$ は部材長、$K$ は端末条件係数（両端ピン $=1.0$、固定-ピン $=0.7$、両端固定 $=0.5$、片持ち $=2.0$）です。$N_{cr}$ は $L^2$ に反比例するので、長い柱ほど急激に弱くなります。

座屈耐力の目安になるのが**無次元細長比**：

$$
\bar{\lambda} = \sqrt{\frac{A f_y}{N_{cr}}}
$$

$\bar{\lambda}$ が小さければ材料の降伏が先、大きければ座屈が先に効きます。EN 1993 ではこの $\bar{\lambda}$ から**座屈低減係数** $\chi$（$0\sim1$）を決めます。座屈曲線 b（$\alpha=0.34$）の場合：

$$
\Phi = 0.5\bigl[1 + \alpha(\bar{\lambda}-0.2) + \bar{\lambda}^2\bigr],\qquad
\chi = \frac{1}{\Phi + \sqrt{\Phi^2 - \bar{\lambda}^2}}\ (\le 1)
$$

座屈を考慮した圧縮耐力は $N_{b,Rd} = \chi A f_y$ となり、$\chi$ のぶんだけ削られます。

## EN 1993-1-1 の相互作用式

軸力と曲げを同時に受ける照査は、利用率の和で表します。本ツールは 2 軸曲げ（$M_y, M_z$）まで含めた簡易版を採用しています：

$$
\eta = \frac{N_{Ed}}{N_{b,Rd}} + k_{yy}\frac{M_{y,Ed}}{M_{b,Rd}} + k_{yz}\frac{M_{z,Ed}}{M_{bz,Rd}} \le 1.0
$$

$M_{b,Rd} = W_y f_y$ は曲げ耐力、$k_{yy}$ は軸力と曲げの連成係数で、ツールでは $k_{yy} = 1 + \min(0.8,\bar{\lambda})\cdot(N_{Ed}/N_{b,Rd})$、$k_{yz} = 0.6\,k_{yy}$ と簡略化しています。$\eta \le 1.0$ なら **PASS**、超えれば **FAIL** です。

> 注：本ツールの $M_{b,Rd}$ は断面係数 $W_y$ に降伏応力を掛けた値で、横ねじれ座屈の低減係数 $\chi_{LT}$ は含みません。$k_{yy}$ も EN1993 付録 B/C の厳密式ではなく教育用の簡易式です。傾向の理解には十分ですが、実設計では規格の完全な手順が必要です。

## 25 行で書く照査ロジック

デフォルト断面 HEA300・材料 S235（$f_y=235$ MPa, $E=210$ GPa）で、相互作用式を JavaScript に落とすとこうなります：

```javascript
const sec = { A: 112.5, Iy: 18260, Wy: 1260, Wz: 631 }; // cm系
const E = 210000, fy = 235;                              // MPa
const alpha = 0.34;                                      // 座屈曲線 b

function check(L, K, N, My, Mz) {
  const A = sec.A*1e-4, Iy = sec.Iy*1e-8;                // m², m⁴
  const Wy = sec.Wy*1e-6, Wz = sec.Wz*1e-6;             // m³
  const Ncr = Math.PI**2 * (E*1e6) * Iy / (K*L)**2 / 1e3;        // kN
  const lam = Math.sqrt(A*(fy*1e6) / (Ncr*1e3));                  // λ̄
  const Phi = 0.5*(1 + alpha*(lam-0.2) + lam**2);
  const chi = Math.min(1, 1/(Phi + Math.sqrt(Phi**2 - lam**2)));
  const NbRd = chi*A*(fy*1e6)/1e3;                                // kN
  const MbRd = Wy*(fy*1e6)/1e3, MbzRd = Wz*(fy*1e6)/1e3;          // kN·m
  const kyy = 1 + Math.min(0.8, lam)*(N/NbRd), kyz = 0.6*kyy;
  const eta = N/NbRd + kyy*My/MbRd + kyz*Mz/MbzRd;
  return { Ncr, lam, chi, NbRd, eta, pass: eta <= 1.0 };
}

console.log(check(5.0, 1.0, 800, 120, 30));
// { Ncr:15138, lam:0.418, chi:0.919, NbRd:2429, eta:0.928, pass:true }
```

デフォルト入力（$L=5$ m, $K=1.0$, $N=800$ kN, $M_y=120$ kN·m, $M_z=30$ kN·m）で $\eta = 0.928$。1.0 にあと少しの **PASS** です。Python で同じ式を独立に計算しても $N_{cr}=15138$ kN, $\bar{\lambda}=0.418$, $\chi=0.919$, $\eta=0.928$ と一致しました。

## P-M 相関図を描く

利用率 $\eta=1.0$ を境界として、$N$ を $0$ から $N_{b,Rd}$ まで動かし、各 $N$ で許容できる最大の $M_y$ を逆算すると、P-M 包絡線が描けます。設計点 $(M_{y,Ed}, N_{Ed})$ がこの曲線の**内側**にあれば安全です。

![P-M相関図と細長比による耐力低下](/images/beam-column/charts-closeup.png)

左図がデフォルト断面の P-M 相関図。緑の設計点（$N=800$）は包絡線の内側で PASS、赤い × 印（$N=1500$ に増やした場合）は外側に飛び出して $\eta=1.28$ の **FAIL** です。右図は $\bar{\lambda}$ と $\chi$ の関係で、$L$ を伸ばすほど $\bar{\lambda}$ が増えて $\chi$ が下がり、座屈耐力が削られていく様子がわかります。

## 利用率が 1.0 を越える瞬間

このツールの面白さは、入力をわずかに変えると PASS と FAIL が切り替わる点です。**部材長 $L$ だけ**を変えて他をデフォルトに固定すると：

| 部材長 $L$ | $N_{cr}$ (kN) | $\bar{\lambda}$ | $\chi$ | $\eta$ | 判定 |
|---|---|---|---|---|---|
| 2 m | 94,615 | 0.167 | 1.000 | 0.856 | PASS |
| 3 m | 42,051 | 0.251 | 0.982 | 0.876 | PASS |
| 5 m | 15,138 | 0.418 | 0.919 | 0.928 | PASS |
| 8 m | 5,913 | 0.669 | 0.801 | **1.037** | **FAIL** |
| 10 m | 3,785 | 0.836 | 0.702 | **1.139** | **FAIL** |

同じ断面・同じ荷重でも、$L=5$ m から $8$ m に伸ばしただけで $\eta$ が $0.928 \to 1.037$ と 1.0 を越え、FAIL に転じます。$N_{cr}$ が $L^2$ で効くため、長さは耐力にとても敏感です。端末条件 $K$ も同様で、$L=5$ m のまま片持ち（$K=2.0$）にすると有効座屈長が倍になり $\eta=1.139$ で FAIL、逆に両端固定（$K=0.5$）なら $\eta=0.864$ まで下がります。「断面を強くする」より「支持条件を見直して有効長を縮める」方が効く場面が多い、という勘どころが数値で確認できます。

## ツールで遊ぶ

NovaSolver のツールでは、スライダーを動かすたびに $\eta$ と P-M 相関図がリアルタイムで再計算され、PASS/FAIL のバーが緑↔赤に切り替わります：

![軸力Nを上げると設計点が包絡線を突き抜ける](/images/beam-column/slider-anim.gif)

試してほしい操作：

- **軸力 N スライダー**（0〜5000 kN）を上げて、設計点が包絡線をいつ突き抜けるか観察
- **柱長さ L スライダー**（1〜10 m）を伸ばし、$N_{cr}$ と $\bar{\lambda}$ の変化を「計算結果」カードで確認
- **断面形状**（HEA200 / HEA300 / IPE300 / W8×31 / W12×50）を切り替えて包絡線の大きさを比較
- **端末条件**（両端ピン / 固定-ピン / 両端固定 / 片持ち）で有効座屈長の効果を体感
- **「細長比」タブ**に切り替えて、現在の $\bar{\lambda}$ が $\chi$ 曲線のどこに乗っているかを確認

「計算結果」カードには $N_{cr}$、$\bar{\lambda}$、軸力利用率 $N/N_{b,Rd}$、曲げ利用率 $M/M_{b,Rd}$ が表示されます。

## まとめ

- 梁柱は軸力 $N$ と曲げ $M$ を同時に受ける部材で、両者は単純な足し算にならず連成する
- EN 1993-1-1 の相互作用式 $\eta = N/N_{b,Rd} + k_{yy}M_y/M_{b,Rd} + k_{yz}M_z/M_{bz,Rd} \le 1.0$ で照査する
- 座屈低減係数 $\chi$ は無次元細長比 $\bar{\lambda}$ から決まり、細長い柱ほど耐力が削られる
- デフォルト条件で $\eta=0.928$（PASS）。$L$ を 8 m に伸ばすと $\eta=1.037$ で FAIL に転じる
- 約 25 行の JavaScript で実装でき、長さ・端末条件・断面の影響をその場で確認できる

P-M 相関図は、鉄骨造の柱・橋脚・プラントのパイプラック・タワークレーンのマストなど、軸力と曲げが同時に効くあらゆる柱の設計で使われる実務直結のツールです。
