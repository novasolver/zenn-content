## 決定木の不純度とは

決定木は「データをどう分割すればクラスがきれいに分かれるか」を毎ステップ選びます。その「分かれ具合」を測るのが**不純度**です。ノードに集まったサンプルがクラスごとに混ざっているほど不純度は高く、ひとつのクラスに偏るほど低くなります。

2クラス分類（クラス1の比率 $p_1$、$p_2 = 1-p_1$）でよく使われる3指標は次の通りです。

$$
G = 2 p_1 p_2 = 2 p_1 (1 - p_1) \quad(\text{Gini}), \qquad
H = -p_1 \log_2 p_1 - p_2 \log_2 p_2 \quad(\text{エントロピー})
$$

$$
ME = \min(p_1, p_2) \quad(\text{誤分類率})
$$

いずれも $p_1=0.5$ で最大、$p_1=0$ または $1$ で $0$ になります。最大値は **Gini = 0.5、エントロピー = 1.0（bit）、誤分類率 = 0.5**。この記事では、なぜ CART が Gini を、ID3/C4.5 がエントロピーを使い、誤分類率が分割基準に向かないのかを数値で確かめます。

## 情報利得：分割の良し悪しを測る

分割の価値は**情報利得**（Information Gain）で測ります。親ノードの不純度から、子ノードの加重平均不純度を引いた値です。

$$
IG = I(\text{parent}) - \sum_k \frac{|S_k|}{|S|}\,I(S_k)
$$

$|S_k|/|S|$ は各子ノードのサンプル比率。$IG$ が大きいほど、その分割で不純度が大きく減る＝クラスがよく分かれることを意味します。決定木は各ノードでこの $IG$ を最大化する分割を貪欲法で選んで成長します。

## 20 行の JavaScript 実装

3指標と情報利得は、そのまま素直に書けます。

```javascript
const gini    = p => 2 * p * (1 - p);
const entropy = p => (p <= 0 || p >= 1) ? 0
                   : -(p * Math.log2(p) + (1-p) * Math.log2(1-p));
const misclass = p => Math.min(p, 1 - p);

// 親 → 左子・右子の分割の情報利得
function infoGain(impurity, pParent, leftN, leftP, rightN, rightP) {
  const total = leftN + rightN;
  const weighted = (leftN/total) * impurity(leftP)
                 + (rightN/total) * impurity(rightP);
  return impurity(pParent) - weighted;
}

// デフォルト: 親 p1=0.5, 左 50個(p1=0.8), 右 100個(p1=0.2)
const igGini    = infoGain(gini,    0.5, 50, 0.8, 100, 0.2);
const igEntropy = infoGain(entropy, 0.5, 50, 0.8, 100, 0.2);
// igGini    ≈ 0.180
// igEntropy ≈ 0.278
```

![不純度カーブと分割の樹形図](/images/decision-tree-impurity/charts-closeup.png)

Giniとエントロピーはなめらかなドーム（**凹関数**）、誤分類率は $p_1=0.5$ に角を持つ**折れ線**です。この形の違いが、分割基準としての適性を分けます。

## デフォルト分割を数値で追う

ツールのデフォルト（親 $p_1=0.5$、左子 50 個で $p_1=0.8$、右子 100 個で $p_1=0.2$）を計算すると、

| 量 | 値 |
|---|---|
| 親 Gini | 0.500 |
| 親エントロピー | 1.000 |
| 左子 Gini（$p_1=0.8$） | 0.320 |
| 右子 Gini（$p_1=0.2$） | 0.320 |
| 加重平均 Gini | $\tfrac{1}{3}(0.32)+\tfrac{2}{3}(0.32)=0.320$ |
| **Gini 情報利得** | $0.500 - 0.320 = \mathbf{0.180}$ |
| **Entropy 情報利得** | $1.000 - 0.722 = \mathbf{0.278}$ |

左右どちらも片方のクラスに偏った（$0.8$ と $0.2$）ので純度が上がり、$IG$ が正に出ています。左右の $p_1$ を両方 $0.5$ にすると、子の不純度が親と同じになり $IG=0$——「分けても情報が増えていない」状態です。

## なぜ誤分類率は分割基準に向かないか

誤分類率が折れ線であることの帰結を、Hastie らの教科書（ESL）の有名な例で確かめます。親が 400/400（$p_1=0.5$）の 800 サンプルを、2 通りに分割します。

| 分割 | 子ノード | $IG_{ME}$ | $IG_{Gini}$ |
|---|---|---|---|
| A | (300,100) と (100,300) | 0.250 | 0.125 |
| B | (200,400) と (200,0) | 0.250 | 0.167 |

誤分類率は両方を **0.250 で同点**と判定します。しかし分割 B は片方が (200,0) という**完全に純粋な葉**を作っており、明らかに優れています。Gini はこれを正しく $0.167 > 0.125$ と区別できます。折れ線の誤分類率は「純粋な葉を作る価値」に鈍感なのです。だから CART も ID3 も、分割基準には凹関数（Gini・エントロピー）を使い、誤分類率は剪定（pruning）の評価に回します。

> 補足：Giniとエントロピーはどちらもなめらかなドームでカーブが酷似しており、実用上の分割結果は数%しか変わりません。scikit-learn の公式ドキュメントも「どちらが優れているかの明確な実証的証拠はない」としています。Gini は $\log$ 不要で掛け算 2 回だけなので、CART は計算が速い Gini を標準採用しています。

## まとめ

- 2クラスの不純度は Gini $=2p_1p_2$、エントロピー $=-\sum p\log_2 p$、誤分類率 $=\min(p_1,p_2)$
- 最大値は Gini 0.5・エントロピー 1.0・誤分類率 0.5（いずれも $p_1=0.5$）
- 情報利得 ＝ 親の不純度 − 子の加重平均不純度。デフォルト分割で IG_Gini = 0.180
- 誤分類率は折れ線ゆえ「純粋な葉を作る価値」に鈍感で、分割基準には不適（ESL の例で同点判定）

不純度の減少は、医療診断の絞り込みや製造業の不良品分離など「ルールでクラスを分ける」あらゆる場面の土台です。
