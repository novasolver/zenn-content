## FFTは「波の成分表」をつくる

エンジンの振動、心電図、音声——時間とともに変化する複雑な信号の中には、いくつもの周波数の波が混ざっています。**FFT（高速フーリエ変換）** は、その混ざった波を「どの周波数の成分がどれだけ含まれているか」という成分表に分解する計算です。

出発点は離散フーリエ変換（DFT）です。$N$ 点の時間信号 $x[n]$ を、周波数成分 $X[k]$ に変換します：

$$
X[k] = \sum_{n=0}^{N-1} x[n]\, e^{-j 2\pi k n / N}
$$

DFT を素朴に計算すると $O(N^2)$ ですが、$N$ が 2 のべき乗のとき、偶数番目と奇数番目を再帰的に分割（クーリー・テューキー法）すると $O(N \log N)$ に落ちます。これが FFT です。$N=1024$ なら計算量は約 100 万回から約 1 万回へ——おおよそ 100 倍速くなります。

この記事では、信号処理の実務でつまずきやすい 3 つの落とし穴——**周波数分解能・エイリアシング・スペクトルリーク**——を数値とコードで確かめます。

## 周波数ビンと分解能 Δf

FFT の出力 $X[k]$ の各インデックス $k$（ビン）は、特定の周波数に対応します。サンプリング周波数を $f_s$、サンプル数を $N$ とすると：

$$
f_k = \frac{k \cdot f_s}{N}, \qquad \Delta f = \frac{f_s}{N}
$$

$\Delta f$ が **周波数分解能**——隣り合うビンの間隔であり、これより細かい周波数差は原理的に区別できません。

| $f_s$ | $N$ | $\Delta f = f_s/N$ | ナイキスト $f_s/2$ |
|---|---|---|---|
| 512 Hz | 1024 | 0.5 Hz | 256 Hz |
| 1024 Hz | 1024 | 1.0 Hz | 512 Hz |
| 2048 Hz | 1024 | 2.0 Hz | 1024 Hz |

ここで重要なのは、**$N$ を固定したまま $f_s$ を上げると分解能 $\Delta f$ は悪化する**という点です。高い周波数まで見たい（ナイキストを上げたい）ほど、同じ点数では周波数の見分けが粗くなる——測定時間とのトレードオフです。分解能を上げるには $N$ を増やす（＝より長く測る）必要があります。

## 合成波形を作って FFT する

ツールは 2 成分の正弦波にノイズを足した信号を生成し、窓関数をかけてから FFT します。計算の核心は次の 25 行ほどです：

```javascript
const N = 1024;

// ハニング窓（端をなめらかにゼロへ落とす）
const hann = (n, N) => 0.5 * (1 - Math.cos(2 * Math.PI * n / (N - 1)));

// 合成信号: a1·sin(2πf1 t) + a2·sin(2πf2 t) + ノイズ
function makeSignal(f1, a1, f2, a2, noise, fs) {
  const x = new Float64Array(N);
  for (let i = 0; i < N; i++) {
    const t = i / fs;
    x[i] = a1 * Math.sin(2 * Math.PI * f1 * t)
         + a2 * Math.sin(2 * Math.PI * f2 * t)
         + noise * (Math.random() * 2 - 1);
  }
  return x;
}

// 振幅スペクトル: 窓 → FFT → |X[k]| / N * 2
function amplitudeSpectrum(x, fs) {
  const w = x.map((v, n) => v * hann(n, N));   // 窓関数を適用
  const { re, im } = fft(w);                    // クーリー・テューキー FFT
  const mag = [];
  for (let k = 0; k < N / 2; k++) {
    mag.push(Math.sqrt(re[k] ** 2 + im[k] ** 2) / N * 2);
  }
  return mag;                                   // 片側スペクトル、振幅に正規化
}
```

デフォルトの設定（$f_1=50$ Hz・$A_1=1.0$、$f_2=120$ Hz・$A_2=0.6$、ノイズ 0.1、$f_s=1024$ Hz）でこれを回すと、スペクトルは 50 Hz と 120 Hz にきれいなピークを示します：

![時系列波形とFFTスペクトル](/images/fft-analyzer/charts-closeup.png)

上の時系列を眺めても「50 Hz と 120 Hz が混ざっている」とは読み取れませんが、FFT を通すと一目瞭然です。これが周波数領域で見ることの威力です。

## ノイズの中の信号 — SNR

ツールは信号対雑音比（SNR）も概算します。振幅 $A_1, A_2$ の正弦波の平均パワーは $A^2/2$、振幅 $L$ の一様乱数ノイズ（$[-L, L]$）の分散は $L^2/3$ なので：

$$
\mathrm{SNR} = 10 \log_{10} \frac{(A_1^2 + A_2^2)/2}{L^2/3}\ [\mathrm{dB}]
$$

デフォルト（$A_1=1.0,\ A_2=0.6,\ L=0.1$）では

$$
10 \log_{10} \frac{(1.0^2 + 0.6^2)/2}{0.1^2/3} = 10 \log_{10}\frac{0.68}{0.00333} \approx 23.1\ \mathrm{dB}
$$

プリセット「高ノイズ」（$A_2=0.3,\ L=0.5$）に切り替えると SNR は約 8.2 dB まで落ち、スペクトル上でも雑音の底上げがはっきり見えます。SNR は信号がどれだけノイズに埋もれているかの目安で、計測系の設計指標になります。

## エイリアシング — 折り返し歪み

FFT で正しく観測できる上限は **ナイキスト周波数** $f_s/2$ です。これを超える周波数成分は、低い周波数に「折り返って」偽のピークを作ります。これがエイリアシングです。

$f_s = 1024$ Hz（ナイキスト 512 Hz）で 600 Hz の成分を入れると、

$$
f_{\text{alias}} = f_s - f_{\text{in}} = 1024 - 600 = 424\ \mathrm{Hz}
$$

として現れます。本来 600 Hz の成分が 424 Hz に見える——存在しない周波数にピークが立つわけです。実際の計測では、A/D 変換の前にローパス（アンチエイリアシング）フィルタで $f_s/2$ 以上を除去するのが鉄則です。プリセット「ナイキスト境界」で $f_2=200$ Hz と $f_s$ の組み合わせを変えると、折り返しの起きる条件を確認できます。

## スペクトルリークと窓関数

FFT は「切り出した $N$ 点が無限に周期的に繰り返す」と暗黙に仮定します。信号の周波数がビンにぴったり乗らない（$f_k = k f_s/N$ に一致しない）と、信号の端が不連続になり、エネルギーが周囲のビンに漏れ出します。これが **スペクトルリーク** です。

たとえば 50.5 Hz の純音（$f_s=1024,\ N=1024$ なのでビン 50 と 51 のちょうど中間）を **矩形窓（窓なし）** で FFT すると、ピークから遠い 100 Hz のビンにも振幅 $\approx 0.0044$ の偽成分が残ります。同じ信号を **ハニング窓** に通すと、100 Hz のビンは $\approx 1\times10^{-6}$——リークが約 3500 分の 1 に抑えられます。

窓関数は端をなめらかにゼロへ落とすことで不連続をなくします。ただし副作用として主ピークが少し太く・低くなります（ハニング窓では主ピーク振幅が約 0.64 → 0.42 に低下）。**ピークの鋭さ（分解能）と、リークの少なさ（ダイナミックレンジ）のトレードオフ**で窓を選ぶ、というのが実務の判断です。ツールでは矩形・ハニング・ハミング・ブラックマンの 4 種を切り替えて、この差を見比べられます。

> 注意：リークは窓関数で「低減」できますが完全には消えません。非整数周期で切り出した信号では、どの窓を使っても隣接ビンへの漏れが残り、振幅の正確な読み取りには窓のコヒーレントゲイン補正が必要です。

## まとめ

- FFT は時間信号 $x[n]$ を周波数成分 $X[k]$ に $O(N\log N)$ で分解する
- 周波数分解能は $\Delta f = f_s/N$。$N$ 固定で $f_s$ を上げると分解能は悪化する（トレードオフ）
- ナイキスト $f_s/2$ を超える成分はエイリアシングで折り返す（600 Hz が 424 Hz に化ける）
- 非整数周期の切り出しはスペクトルリークを生み、窓関数で大幅に低減できる（矩形 → ハニングで約 3500 分の 1）

時間で見ると複雑きわまりない信号も、周波数で見ると驚くほど単純になる——その変換の威力と落とし穴を、自分の手で動かして確かめてみてください。
