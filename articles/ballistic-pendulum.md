## 弾道振り子とは

弾丸を、ひもで吊るした重い木のブロックに撃ち込む。弾丸はブロックに食い込み、一体になったブロックがゆっくり振り上がる。その**振り上がった高さ**から、撃ち込んだ弾丸の初速を逆算する——これが**弾道振り子**です。

電子式の弾速計（クロノグラフ）が無かった時代、弾丸の速度を測る標準装置でした。1742 年にイギリスの数学者 Benjamin Robins が考案したとされ、「直接測るには速すぎる量（弾丸の速度）を、ものさしで測れる量（振り上がり高さ）に変換する」という発想が画期的でした。

この記事では：

1. なぜ「運動量保存」と「エネルギー保存」を**段階ごとに使い分ける**のか
2. 共通速度・振り上がり高さ・振れ角を計算する 20 行ほどの JavaScript
3. 「運動エネルギーの 99.8% が衝突で消える」という事実を数値で確かめる

## 2 つの段階に分けて考える

弾道振り子の最大のポイントは、現象を **性質の違う 2 つの段階**にきっちり分けることです。ここを混ぜると答えが大きくずれます。

### 第 1 段階：完全非弾性衝突（運動量保存）

弾丸（質量 $m$、初速 $v_b$）が静止したブロック（質量 $M$）に食い込み、一体になる瞬間。衝突は一瞬で、外力（重力・張力）の力積が無視できるため **運動量が保存**されます。衝突直後の共通速度 $v$ は：

$$
m\,v_b = (m + M)\,v
\quad\Longrightarrow\quad
v = \frac{m\,v_b}{m + M}
$$

ただし完全非弾性衝突なので、**運動エネルギーは保存されません**。大部分は熱とブロックの変形に変わります。

### 第 2 段階：振り上げ（力学的エネルギー保存）

一体になったブロックは、あとは重力に引かれて振り上がるだけ。衝突のような急激な相互作用が無いので、今度は **力学的エネルギーが保存**されます。衝突直後の運動エネルギーがすべて位置エネルギーに変わるとして：

$$
\tfrac{1}{2}(m+M)\,v^2 = (m+M)\,g\,h
\quad\Longrightarrow\quad
h = \frac{v^2}{2g}
$$

振れ角 $\theta$ は、ひもの長さ $L$ と高さ $h$ から $h = L(1-\cos\theta)$ の関係を逆に解いて：

$$
\theta = \arccos\!\left(1 - \frac{h}{L}\right)
$$

実測では逆向きにたどります。$\theta$（または $h$）を測る → エネルギー保存で $v$ を求める → 運動量保存で $v_b$ を求める。**この順番が肝心**です。

## JavaScript で実装する

4 つの入力（弾丸質量 $m$ [g]、ブロック質量 $M$ [kg]、弾丸初速 $v_b$ [m/s]、ひも長 $L$ [m]）から全出力を計算します。ツールの `compute()` と同じロジックです：

```javascript
const G = 9.81;  // m/s^2

function ballistic(mGram, M, vb, L) {
  const m = mGram / 1000;                 // g -> kg

  // 第1段階: 完全非弾性衝突（運動量保存）
  const v = (m * vb) / (m + M);           // 共通速度 [m/s]

  // 第2段階: 振り上げ（エネルギー保存）
  let h = v * v / (2 * G);                // 振り上がり高さ [m]
  const hClamped = Math.min(h, L);        // h は L を超えられない
  const theta = Math.acos(1 - hClamped / L); // 振れ角 [rad]

  // 衝突のエネルギー収支
  const keBefore = 0.5 * m * vb * vb;             // 衝突前KE [J]
  const keAfter  = 0.5 * (m + M) * v * v;         // 衝突後KE [J]
  const lost     = keBefore - keAfter;            // 失われたKE [J]
  const lostFrac = lost / keBefore * 100;         // 損失率 [%]

  return { v, h, theta, keBefore, lost, lostFrac };
}
```

デフォルト値 $m=10\,\text{g},\ M=5\,\text{kg},\ v_b=300\,\text{m/s},\ L=1.0\,\text{m}$ を入れると：

```javascript
const r = ballistic(10, 5.0, 300, 1.0);
// v        = 0.599 m/s
// h        = 18.3 mm
// theta    = 10.97 deg
// keBefore = 450.0 J
// lost     = 449.1 J
// lostFrac = 99.80 %
```

300 m/s で飛んできた弾丸が、最終的にブロックを **わずか 18 mm** しか持ち上げられないことが分かります。

## 山場：運動エネルギーはどこへ消えたか

弾道振り子で最も直感に反するのが、**運動エネルギーがほとんど残らない**ことです。完全非弾性衝突で失われる運動エネルギーの割合は、初速 $v_b$ に一切よらず、質量比だけで決まります：

$$
\frac{\Delta E}{E_b} = \frac{M}{m + M}
$$

弾丸 $10\,\text{g}$・ブロック $5\,\text{kg}$ なら $\dfrac{5.0}{5.01} = 99.80\%$。実際に初速を変えて損失率を計算しても、見事に一定です：

| 弾丸初速 $v_b$ | 衝突前 KE | 損失率 |
|---|---|---|
| 50 m/s | 12.5 J | 99.800 % |
| 300 m/s | 450.0 J | 99.800 % |
| 1000 m/s | 5000 J | 99.800 % |

ブロックを重くするほど損失率は 1 に近づきます（$M=20\,\text{kg}$ なら 99.95%）。「重いブロックほど弾丸のエネルギーをよく食う」わけです。

ここで効いてくるのが「運動量は保存されるのに、エネルギーは保存されない」という非対称性です。運動量 $m v_b$ はそっくり共通速度 $v$ に引き継がれますが、エネルギーは $v^2$ に比例するため、速度が $1/501$ 倍に落ちると運動エネルギーは $(1/501)^2$ 倍まで激減し、質量が増えた分（$501$ 倍）を掛け戻しても元の $1/501$ しか残らない——これが 99.8% 損失の正体です。

逆算もきれいに閉じます。振れ角 $\theta=10.97°$ から $h = L(1-\cos\theta) = 18.28\,\text{mm}$、エネルギー保存で $v = \sqrt{2gh} = 0.599\,\text{m/s}$、運動量保存で $v_b = v\,(m+M)/m = 300.0\,\text{m/s}$。最初の初速がぴたりと戻ってきました。これが実験で角度から初速を求める手順そのものです。

## まとめ

- 弾道振り子は **第 1 段階＝運動量保存（非弾性衝突）／第 2 段階＝エネルギー保存（振り上げ）** に分けて解く
- 共通速度 $v=mv_b/(m+M)$、振り上がり高さ $h=v^2/2g$、振れ角 $\theta=\arccos(1-h/L)$ で全量が決まる
- デフォルト条件では振り上がりは 18 mm・振れ角 11°、そして衝突で **運動エネルギーの 99.8% が失われる**
- 損失率は初速によらず質量比 $M/(m+M)$ だけで決まる——「運動量は保存、エネルギーは非保存」の非対称性が核心

自動車の衝突試験や防弾装備の評価も、根っこは弾道振り子と同じ「完全非弾性衝突＋エネルギー吸収」。エネルギーをどれだけ食えるかが安全性能の指標であり、弾道振り子はその最小モデルです。
