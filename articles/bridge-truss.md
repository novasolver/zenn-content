## トラス橋の「力の地図」を計算する

橋桁を三角形の骨組みで支えるトラス橋。荷重をかけたとき、どの部材が引っ張られ（引張）、どの部材が押し潰される（圧縮）のか——その「力の地図」は、**有限要素法（FEM）** で1本の連立方程式に落とし込めます。

考え方はシンプルです。各部材を「軸力（伸び縮みの方向の力）だけを伝えるバネ」とみなし、全部材のバネをつなぎ合わせた**全体剛性マトリクス $K$** を作る。あとは荷重ベクトル $F$ に対して

$$
K \cdot u = F
$$

を解けば、全節点の変位 $u$ が一気に求まります。これは自動車ボディや航空機構造の静解析でも使われる、商用CAEの心臓部とまったく同じ手続きです。

この記事では：

1. バー要素の剛性マトリクスと、座標変換による全体行列の組み立て
2. ガウス消去で $K \cdot u = F$ を解く 25 行の JavaScript
3. 引張・圧縮の分布を実数値で確かめ、断面積・荷重を変えたときのスケーリングを検証

## バー要素の剛性マトリクス

長さ $L$、断面積 $A$、ヤング率 $E$ の1本の部材を考えます。その両端を軸方向に $u_1, u_2$ だけ動かしたとき、生じる軸力は $F_{bar} = \frac{EA}{L}(u_2 - u_1)$。これを行列でまとめると、**局所座標系**での要素剛性マトリクスは

$$
k_{local} = \frac{EA}{L}\begin{bmatrix} 1 & -1 \\ -1 & 1 \end{bmatrix}
$$

になります。$\frac{EA}{L}$ がバネ定数そのもので、太く（$A$大）短く（$L$小）硬い（$E$大）部材ほど大きくなります。

ただし橋の部材は水平・垂直・斜めとさまざまな向きを持つので、各部材の傾き $\theta$（方向余弦 $c=\cos\theta,\ s=\sin\theta$）で**全体座標系（x, y）に回転**してやる必要があります。1 部材あたり 2 節点 × 2 自由度 = 4×4 の行列になり：

$$
k_{global} = \frac{EA}{L}
\begin{bmatrix}
c^2 & cs & -c^2 & -cs \\
cs & s^2 & -cs & -s^2 \\
-c^2 & -cs & c^2 & cs \\
-cs & -s^2 & cs & s^2
\end{bmatrix}
$$

これを全部材ぶん、対応する自由度の位置へ足し込む（アセンブリ）と、全体剛性マトリクス $K$ が完成します。

## 25 行で書く FEM ソルバー

要素マトリクスのアセンブリと、境界条件（支点）の処理が実装の山場です。NovaSolver のツールは**ペナルティ法**——支点で固定したい自由度の対角成分に巨大な値 $10^{20}$ を足して「動けなくする」手法を使っています：

```javascript
const E = 200e9, A = 50e-4; // 200GPa, 50cm²
const ndof = 2 * nodes.length;
const K = Array.from({length: ndof}, () => new Array(ndof).fill(0));

// 各部材の剛性を全体行列へ足し込む（アセンブリ）
for (const [i, j] of elements) {
  const dx = nodes[j][0] - nodes[i][0];
  const dy = nodes[j][1] - nodes[i][1];
  const L = Math.hypot(dx, dy);
  const c = dx / L, s = dy / L;      // 方向余弦
  const k = E * A / L;
  const dofs = [2*i, 2*i+1, 2*j, 2*j+1];
  const T = [ c*c, c*s,-c*c,-c*s,
             c*s, s*s,-c*s,-s*s,
            -c*c,-c*s, c*c, c*s,
            -c*s,-s*s, c*s, s*s ];
  for (let a = 0; a < 4; a++)
    for (let b = 0; b < 4; b++)
      K[dofs[a]][dofs[b]] += k * T[a*4 + b];
}

// 境界条件（ペナルティ法）：ピン支点=x,y固定 / ローラー=y固定
const BIG = 1e20;
K[2*0+0][2*0+0] += BIG;  K[2*0+1][2*0+1] += BIG;  // 左端ピン
K[2*5+1][2*5+1] += BIG;                            // 右端ローラー
```

あとは $K \cdot u = F$ をガウス消去（部分ピボット選択つき）で解き、各部材の軸力を $F_{bar} = \frac{EA}{L}\big[(u_{2x}-u_{1x})c + (u_{2y}-u_{1y})s\big]$ で逆算するだけです。正なら引張（赤）、負なら圧縮（青）。

## 引張・圧縮の地図を読む

ツールの初期設定（5パネルのトラス、集中荷重 $F=100\,\text{kN}$ を中央節点に、$E=200\,\text{GPa}$、$A=50\,\text{cm}^2$）で解くと、各部材の軸力は次のように分かれます：

| 部材グループ | 軸力 [kN] | 符号 |
|---|---|---|
| 下弦材（5本） | +30, +90, **+100**, +60, +20 | すべて引張 |
| 上弦材（4本） | −60, **−120**, −80, −40 | すべて圧縮 |
| 斜材・垂直材 | ±67.08, ±44.72 | 引張と圧縮が交互 |

きれいなパターンが読み取れます。**下弦材は一様に引張、上弦材は一様に圧縮**。これは橋が下に凸にたわむことで、上側の繊維が縮み下側が伸びる、という梁の曲げと同じ理屈です。

![部材力の棒グラフと変形図](/images/bridge-truss/charts-closeup.png)

最大軸力は中央の上弦材で $-120\,\text{kN}$（圧縮）。これは支点反力からも裏付けられます。荷重 $100\,\text{kN}$ が左から $2/5$ の位置にかかるので、左支点反力は $60\,\text{kN}$、右支点反力は $40\,\text{kN}$。この反力が斜材を通じて上弦材へ流れ込みます。最大応力は

$$
\sigma_{max} = \frac{F_{bar}}{A} = \frac{120 \times 10^3\,\text{N}}{50 \times 10^{-4}\,\text{m}^2} = 24\,\text{MPa}
$$

最大変位は $0.834\,\text{mm}$。鋼材の降伏応力（約 $235\,\text{MPa}$）に対しては十分余裕がありますが、これはあくまで線形静解析の理想値です。

## スケーリングを数値で確かめる

線形FEMの嬉しい性質は、結果が入力に対してきれいに比例することです。ツールのスライダーを動かして確かめてみましょう（中央荷重・Pratt配置の場合）：

| 操作 | 最大変位 | 最大軸力 |
|---|---|---|
| 基準（$F$=100, $A$=50, $E$=200） | 0.834 mm | 120 kN |
| 断面積 $A$ を2倍（→100 cm²） | 0.417 mm（**1/2**） | 120 kN（不変） |
| ヤング率 $E$ を半分（→100 GPa） | 1.668 mm（**2倍**） | 120 kN（不変） |
| 荷重 $F$ を2倍（→200 kN） | 1.668 mm（2倍） | 240 kN（2倍） |

ここに構造設計の本質が見えます。**変位は軸剛性 $EA$ に反比例**するので、たわみを抑えたいなら $A$ や $E$ を上げればよい。ところが**部材力（と力の分布パターン）は $E,A$ を変えても一切変わりません**。なぜなら、この問題は静定に近く、力の流れは形状と荷重だけで決まるからです。応力 $\sigma = F_{bar}/A$ を下げたいなら、剛性ではなく**断面積 $A$ を増やす**のが正攻法、というわけです。

## ツールで遊ぶ

NovaSolver のツールでは、スライダーを動かすと変形図と部材力の棒グラフがリアルタイムで更新されます。引張は赤、圧縮は青で色分けされ、力が大きい部材ほど線が太く描かれます：

![荷重を上げると部材が赤・青に染まり変形が拡大する](/images/bridge-truss/slider-anim.gif)

試してほしい操作：

- **集中荷重 F**（10〜500 kN）を上げて、変位・最大軸力・最大応力が比例して増えるのを確認
- **断面積 A**（5〜200 cm²）を変えて、変位だけが変わり部材力は不変なことを体感
- **弾性係数 E**（70〜210 GPa、アルミ〜鋼）を切り替えて剛性の効きを比較
- **荷重位置**を「中央 / 1/4スパン / 等分布」に変えて、力の地図が組み替わる様子を観察
- **変形拡大率**を上げて、ミリ単位の微小なたわみを目に見える形に誇張表示

> 注意：このツールの3つの形式ボタン（Pratt / Warren / Howe）は、現状どれを選んでも同じ骨組みトポロジー（垂直材＋斜材の組み合わせ）で計算されます。本来は斜材の向きが形式ごとに異なるはずなので、解析結果は「1種類の代表的なトラス」のものとして読んでください。

## まとめ

- トラスのFEMは、バー要素 $k=\frac{EA}{L}\bigl[\begin{smallmatrix}1&-1\\-1&1\end{smallmatrix}\bigr]$ を座標変換して足し込み、$K \cdot u = F$ を解くだけ
- ペナルティ法で支点を固定し、ガウス消去で解く実装は 25 行に収まる
- 初期設定では下弦材が引張（最大 +100 kN）、上弦材が圧縮（最大 −120 kN）、最大応力 24 MPa、最大変位 0.834 mm
- 変位は軸剛性 $EA$ に反比例、部材力は荷重 $F$ に比例し $E,A$ に依存しない——応力を下げるには断面積 $A$ を増やす

「橋のどこに力が集中するか」が1枚の色分け図で読めるのが、トラスFEMのおもしろさ。3 本の式から蝶が生まれるカオスとは対極の、**設計の確かな見通し**を与えてくれる手法です。
