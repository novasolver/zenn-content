## ビリヤードの球と、ぶつかって止まる粘土

ビリヤードの球同士はカチンとはね返り、粘土の塊はぶつかってベチャッとくっつく。同じ「衝突」でも振る舞いはまるで違います。この違いを1つの数で表すのが**反発係数 $e$**。そして、衝突の種類によらず**必ず成り立つ**のが運動量保存則です。

この記事では一般の反発係数を含む衝突の式を導き、JavaScript で衝突後の速度・運動量・エネルギーを計算します。

🎱 **動くデモ**: [1次元衝突シミュレーター（NovaSolver）](https://novasolver.jp/tools/collision-1d.html)

## 運動量保存と反発係数

2 物体（質量 $m_1, m_2$、速度 $v_1, v_2$）が衝突するとき、外力がなければ**全運動量は保存**します。

$$
m_1 v_1 + m_2 v_2 = m_1 v_1' + m_2 v_2'
$$

これに反発係数 $e$（衝突後の相対速度 ÷ 衝突前の相対速度）の定義 $v_2'-v_1' = -e(v_2-v_1)$ を組み合わせると、衝突後の速度が一意に決まります。

$$
v_1' = \frac{(m_1 - e\,m_2)v_1 + (1+e)m_2 v_2}{m_1 + m_2},\qquad
v_2' = \frac{(m_2 - e\,m_1)v_2 + (1+e)m_1 v_1}{m_1 + m_2}
$$

この式は、$e$ がいくつでも**運動量を保存**します（代入すると $m_1v_1'+m_2v_2' = m_1v_1+m_2v_2$ がきれいに成り立つ）。一方、運動エネルギーは $e$ によって保存されたり失われたりします。

## 2つの極端：完全弾性と完全非弾性

**$e=1$（完全弾性衝突）** では運動エネルギーも保存されます。とくに**等質量**なら式は簡単になり、$v_1'=v_2$、$v_2'=v_1$——**速度をそっくり交換**します。ツールの既定値（$m_1=m_2=5\,\mathrm{kg}$、$v_1=+5$、$v_2=-3\,\mathrm{m/s}$）では衝突後 $v_1'=-3$、$v_2'=+5$ と入れ替わり、運動量（$10\to10$）も運動エネルギー（$85\,\mathrm{J}\to85\,\mathrm{J}$）も保存されます。

**$e=0$（完全非弾性衝突）** では2物体が**くっついて一体**になります。同じ初期条件なら衝突後はどちらも $1\,\mathrm{m/s}$ で一緒に動き、運動量は保存（$10\to10$）されますが、運動エネルギーは $85\,\mathrm{J}\to5\,\mathrm{J}$ と **80 J も失われます**（熱・変形へ）。実際の衝突は $0<e<1$ の間にあります。

## JavaScript 実装

一般の反発係数の式をそのまま実装します。

```javascript
const v1p = ((m1 - e*m2)*v1 + (1+e)*m2*v2) / (m1 + m2);
const v2p = ((m2 - e*m1)*v2 + (1+e)*m1*v1) / (m1 + m2);
// 検算：運動量とエネルギー
const pBefore = m1*v1 + m2*v2,  pAfter = m1*v1p + m2*v2p;   // 常に等しい
const keBefore = 0.5*m1*v1*v1 + 0.5*m2*v2*v2;
const keAfter  = 0.5*m1*v1p*v1p + 0.5*m2*v2p*v2p;          // e<1 で減る
const energyLoss = keBefore - keAfter;
```

## ツールで遊ぶ

[1次元衝突シミュレーター](https://novasolver.jp/tools/collision-1d.html)で試してほしい操作：

- **プリセット**「等質量弾性衝突」「大→小追突」「正面衝突」「完全非弾性」で典型例を再現
- **はね返り係数 e スライダー**を 1 → 0 に下げ、**エネルギー損失**が増えて最後はくっつく（一体化）のを見る
- **質量 m₁・m₂ スライダー**を変え、重い物体が軽い物体に与える影響を観察（大→小では小が大きく弾かれる）
- **計算結果**で「v₁'・v₂' 後」「Δp₁」「エネルギー損失」「KE 保存率」を読む
- **結果テーブル**で、運動量が衝突前後で**常に等しい**（どんな e でも）ことを確認
- **衝突アニメーション**で、速度ベクトルが衝突前後でどう変わるかを見る

## まとめ

- 1次元衝突では**運動量がいつも保存**：$m_1v_1+m_2v_2=m_1v_1'+m_2v_2'$
- 衝突後の速度は反発係数 $e$ で決まる一般式で求まる（運動量を常に保存）
- $e=1$（弾性）：運動エネルギーも保存、等質量なら速度交換
- $e=0$（完全非弾性）：くっついて一体化、運動エネルギー最大損失（既定で 80 J）

衝突安全設計・スポーツ・粒子物理の基礎となる衝突の法則を、質量や反発係数を変えながら体感してみてください。
