## ベベルギアの歯面荷重とは

平歯車（スパーギア）は、歯面に **接線力 $F_t$** と **半径方向力 $F_r$** の 2 つしか生みません。ところがベベルギア（かさ歯車）になると、ここに **軸方向力 $F_a$** が必ず加わって 3 力になります。この $F_a$ こそが「ベベルギア軸にはスラスト軸受が要る」という設計上の鉄則を生む張本人です。

理由は単純で、ベベルギアの歯は **円錐（コーン）の斜面** に並んでいるからです。平歯車は円筒なので歯面の法線が半径方向にしか倒れませんが、ベベルではコーンの母線が軸に対して傾いているぶん、法線が軸方向にも成分を持ちます。その軸方向成分が $F_a$ です。

この記事では：

1. 接線力・軸方向力・半径方向力を決める 3 本の式
2. ピッチ角 $\gamma$ を上げると $F_a$ がどこまで増えるか（数値で確認）
3. 「スラスト軸受が必須になる境目」をどう判定するか

## 3 力を決める式

直歯ベベルギアの歯面 3 力は、平均半径 $r_m$・トルク $T$・圧力角 $\alpha$・ピッチ角 $\gamma$ から次のように決まります：

$$
F_t = \frac{T}{r_m}, \quad F_a = F_t \tan\alpha \sin\gamma, \quad F_r = F_t \tan\alpha \cos\gamma
$$

| 記号 | 名前 | 役割 |
|---|---|---|
| $F_t$ | 接線力 | トルクを伝える主役。$T/r_m$ そのもの |
| $F_a$ | 軸方向力 | 軸を押し出す力。スラスト軸受で受ける |
| $F_r$ | 半径方向力 | 軸を曲げる力。ラジアル軸受で受ける |
| $\gamma$ | ピッチ角 | ピッチコーンの半角。45° でマイタギア |
| $\alpha$ | 圧力角 | 標準 20°、高負荷用 25° |

ポイントは $F_a$ と $F_r$ がともに $\tan\alpha$ に比例し、$\sin\gamma$ と $\cos\gamma$ で配分が決まることです。つまり **「軸方向に逃げる力」と「半径方向に逃げる力」の合計の大きさ $F_t\tan\alpha$ は $\gamma$ によらず一定**で、$\gamma$ はその力を軸方向と半径方向にどう振り分けるかだけを決めます。

歯そのものの強度（曲げ・面圧）を見るときは 3 力の合力を使います：

$$
F = \sqrt{F_t^2 + F_a^2 + F_r^2}
$$

## 標準パラメータで実測する

ツールのデフォルト（$r_m=50\,\mathrm{mm},\ \gamma=30°,\ T=100\,\mathrm{N\cdot m},\ \alpha=20°$）で 3 力を計算してみます。$r_m$ は m に直すので $0.05\,\mathrm{m}$：

$$
F_t = \frac{100}{0.05} = 2000\,\mathrm{N}
$$
$$
F_a = 2000 \times \tan 20° \times \sin 30° = 364\,\mathrm{N}
$$
$$
F_r = 2000 \times \tan 20° \times \cos 30° = 630\,\mathrm{N}
$$

合力は $F = \sqrt{2000^2 + 364^2 + 630^2} = 2128\,\mathrm{N}$、軸方向力比は $F_a/F_t = 18.2\%$ です。たった 30° のピッチ角でも、接線力の約 2 割が軸方向に逃げています。平歯車ならゼロだった成分です。

## ピッチ角を上げると何が起きるか

$F_a$ の大きさを左右する最大の因子はピッチ角 $\gamma$ です。$F_a/F_t = \tan\alpha\sin\gamma$ なので、$\alpha=20°$ 固定で $\gamma$ を振ると軸方向力比は次のように増えていきます：

| ピッチ角 $\gamma$ | $F_a/F_t$ 比 | 軸受の目安 |
|---|---|---|
| 20° | 12.4% | スラスト能力を検討 |
| 30° | 18.2% | スラスト軸受推奨 |
| 45°（マイタ） | 25.7% | スラスト軸受必須 |
| 60° | 31.5% | スラスト容量を増強 |
| 75° | 35.2% | ほぼ $\tan 20°$ に飽和 |

$\gamma$ が 90° に近づくと $\sin\gamma \to 1$ なので、$F_a/F_t$ は理論上限の $\tan\alpha = \tan 20° = 36.4\%$ に漸近します。逆に $\cos\gamma \to 0$ なので $F_r$ は小さくなり、荷重の大部分が軸方向へ逃げていきます。**減速比を大きくしたい（=大歯車の $\gamma$ を立てたい）ほど、自動的にスラスト軸受の容量も増やさなければならない**——これがベベルギア設計のジレンマです。

## JavaScript で再現する

ツールの計算ロジックはごく短いコードで再現できます。ラジアン変換と 3 本の式、それに合力と軸方向力比を出すだけです：

```javascript
// 入力: 平均半径[mm], ピッチ角[deg], トルク[N·m], 圧力角[deg]
function bevelForces(rmMm, gammaDeg, torque, alphaDeg) {
  const rm    = rmMm / 1000;                 // mm -> m
  const gamma = gammaDeg * Math.PI / 180;
  const alpha = alphaDeg * Math.PI / 180;

  const Ft = torque / rm;                     // 接線力 F_t = T / r_m
  const Fa = Ft * Math.tan(alpha) * Math.sin(gamma);  // 軸方向力
  const Fr = Ft * Math.tan(alpha) * Math.cos(gamma);  // 半径方向力
  const F  = Math.hypot(Ft, Fa, Fr);          // 合力 √(Ft²+Fa²+Fr²)
  const ratio = Ft > 0 ? Fa / Ft * 100 : 0;   // 軸方向力比 [%]

  return { Ft, Fa, Fr, F, ratio };
}

// デフォルト条件で確認
const r = bevelForces(50, 30, 100, 20);
console.log(r.Ft.toFixed(0), r.Fa.toFixed(0), r.Fr.toFixed(0),
            r.F.toFixed(0), r.ratio.toFixed(1));
// 2000 364 630 2128 18.2
```

最後の出力 `2000 364 630 2128 18.2` は、前章で手計算した値と完全に一致します。単位換算（mm→m、deg→rad）さえ間違えなければ、ベベルギアの歯面荷重はこのわずか数行で見積もれます。

棒グラフで見ると、デフォルト条件では接線力 $F_t$ が圧倒的に大きく（2000 N）、軸方向力 $F_a$（364 N）と半径方向力 $F_r$（630 N）はその一部です。しかし右の感度曲線が示すように、ピッチ角を立てると $F_a$ は単調に増えていき、$F_r$ と立場が逆転していきます。

## スラスト軸受が必須になる境目

実務では「軸方向力比 $F_a/F_t$ が 10% を超えたらスラスト能力をもつ軸受に変える」というのが現場の目安です。普通の深溝玉軸受もアキシアル荷重を少しは受けられますが、せいぜい動定格の 25% 程度。これを超えると内輪と玉の接触面がフレッチングを起こし、異音 → ガタ → 焼付きという典型的な早期破損パターンに入ります。

前の表を見ると、$\alpha=20°$ では $\gamma=20°$ ですでに 12.4% に達しており、**実用域のベベルギアはほとんどがスラスト軸受を必要とする**ことが分かります。だからこそ、ベベルギア軸の定番は円すいころ軸受（テーパーローラーベアリング）の背面組み合わせや、複列アンギュラ玉軸受なのです。

> 注意：ツールの「合力 $F$」は歯 1 枚に作用する総力で、歯の曲げ強度・面圧の検討用です。軸受選定では、これを軸座標系のラジアル成分（$F_t$ と $F_r$ の合成）とアキシアル成分（$F_a$）に分けて、軸受メーカーの計算式に入れます。合力をそのまま軸受の等価荷重に使うと過大評価になります。

## まとめ

- ベベルギアの歯面 3 力は $F_t=T/r_m$、$F_a=F_t\tan\alpha\sin\gamma$、$F_r=F_t\tan\alpha\cos\gamma$
- 平歯車と違い軸方向力 $F_a$ が必ず生じ、これがスラスト軸受を必須にする
- デフォルト（$\gamma=30°,\alpha=20°$）で $F_t=2000\,\mathrm{N},\ F_a=364\,\mathrm{N},\ F_a/F_t=18.2\%$
- $\gamma$ を立てるほど $F_a$ は増え、$\gamma\to90°$ で $F_a/F_t$ は $\tan\alpha=36.4\%$ に飽和する
- $F_a/F_t$ が 10% を超えたらスラスト能力をもつ軸受へ——実用域はほぼ該当する

「歯がコーン上に並ぶ」という一点から、軸方向力という新しい力と、それに耐える軸受という設計要求が芋づる式に出てくる。ベベルギアは、幾何形状が機械要素の選定を支配する好例です。
