## キャプスタン方程式とは

ロープを柱に数回巻きつけるだけで、人ひとりの力で何トンもの船を留められる——その正体が **キャプスタン方程式（オイラー・アイテルヴァインの式）** です。円柱に巻かれたロープの両端張力の比は、巻きつけた角度に対して **指数関数的** に増えます。

$$
\frac{T_\text{load}}{T_\text{hold}} = e^{\mu\beta}
$$

ここで $\mu$ は接触面の摩擦係数、$\beta$ は巻付角（ラジアン）、$T_\text{load}$ は荷重側、$T_\text{hold}$ は保持側の張力です。注目すべきは、この比に**ドラムの半径が一切現れない**こと。効くのは「摩擦係数」と「巻いた角度」だけです。

この記事では：

1. なぜ指数関数になるのか（微小要素のつり合い）
2. 半径が消える理由
3. 「巻けば巻くほど跳ね上がる」を数値で確かめる

## なぜ指数関数になるのか

ロープの微小な一片（角度 $d\phi$ ぶん）を取り出して力のつり合いを考えます。両端の張力差 $dT$ が、その一片に働く摩擦力とちょうど釣り合う、というのが滑り出す直前の条件です。

ロープが円柱を押す垂直抗力 $dN$ は、張力 $T$ と角度 $d\phi$ から $dN = T\,d\phi$。摩擦力はその $\mu$ 倍なので、

$$
dT = \mu\,dN = \mu\,T\,d\phi \quad\Longrightarrow\quad \frac{dT}{T} = \mu\,d\phi
$$

両辺を $0$ から $\beta$ まで積分すると、左辺は $\ln T$、右辺は $\mu\beta$ になり、

$$
\ln\frac{T_\text{load}}{T_\text{hold}} = \mu\beta \quad\Longrightarrow\quad \frac{T_\text{load}}{T_\text{hold}} = e^{\mu\beta}
$$

ポイントは **「張力が大きいほど、押し付ける力も摩擦も大きくなる」** という正のフィードバックです。これが線形ではなく指数関数を生みます。保持側から角度 $\phi$ の点での張力は

$$
T(\phi) = T_\text{hold}\,e^{\mu\phi}
$$

で、接触区間の途中も同じ指数カーブで増えていきます。

## なぜ半径が消えるのか

「太い柱の方がよく効きそう」という直感は外れます。式に半径 $R$ が無いのは、2 つの効果がちょうど打ち消し合うからです。

- 巻付角が同じなら、接触している**ロープの長さは半径に比例して増える**（$L = R\beta$）
- 一方、単位長さあたりの垂直抗力は **半径に反比例して減る**（$T/R$）

掛け合わせると $R$ が消え、結局「巻いた角度 $\beta$」だけが残ります。だから細い軸でも太いドラムでも、同じ巻付角・同じ摩擦係数なら保持力は同じ。ベルト摩擦シミュレーターに直径スライダーが無いのは、結果に影響しない「死んだパラメータ」になるからです。

## 12 行で計算する

キャプスタン方程式はそのまま数式どおりに書けます。

```javascript
const DEG = Math.PI / 180;

function capstan(mu, wrapDeg, Tload) {
  const beta  = wrapDeg * DEG;          // 巻付角をラジアンに
  const ratio = Math.exp(mu * beta);    // 倍力比 T_load/T_hold
  const Thold = Tload / ratio;          // 保持に必要な力
  return { beta, ratio, Thold };
}

// 保持側から角度 phi(rad) の点の張力
function tensionAt(mu, Thold, phi) {
  return Thold * Math.exp(mu * phi);
}
```

`mu=0.30, wrapDeg=180, Tload=1000N`（ツールの初期値）で実行すると、Python で照合した次の値になります：

```
ratio  = exp(0.30 × π) = 2.566   倍力比
Thold  = 1000 / 2.566  = 389.7 N  保持に必要な力
Tobs   = 624.2 N                  接触区間の中点(φ=90°)の張力
低減率 = 1 − Thold/Tload = 61.0 %
```

半回転（180°）巻くだけで、必要な保持力が荷重の **約 39 % まで** 下がります。

## 巻くほど跳ね上がる

巻付角を増やしたときの倍力比 $e^{\mu\beta}$ を、$\mu=0.30$ で計算しました（Python 照合値）。

| 巻数 | 巻付角 $\beta$ | 倍力比 $e^{\mu\beta}$ | 1000N を保持する力 |
|---|---|---|---|
| 0.5 回転 | 180° | 2.57 倍 | 389.7 N |
| 1 回転 | 360° | 6.59 倍 | 151.8 N |
| 1.5 回転 | 540° | 16.9 倍 | 59.2 N |
| 2 回転 | 720° | 43.4 倍 | 23.1 N |
| 3 回転 | 1080° | 285.7 倍 | 3.5 N |

巻付角を 2 倍（360°→720°）にすると、倍力比は 2 倍ではなく **約 6.6 倍** になります。指数関数なので、後半ほど跳ね上がるのが特徴です。3 回転も巻けば 1000N の荷重を **わずか 3.5N**——指 1 本で支えられる計算になります。係船柱にロープを 2〜3 回巻くだけで巨大な船を留められるのは、この指数的増幅のおかげです。

## まとめ

- キャプスタン方程式 $T_\text{load}/T_\text{hold}=e^{\mu\beta}$ は、巻付角に対して張力比が指数的に増える
- 微小要素のつり合い $dT/T=\mu\,d\phi$ を積分すると導ける
- 倍力比にドラム半径は現れない（接触長さ↑と単位垂直抗力↓が打ち消す）
- $\mu=0.3$ なら 1 回転で約 6.6 倍、3 回転で約 286 倍——後半ほど跳ね上がる

この式は係船・ウインチ・ベルト伝動・バンドブレーキ・登山のビレイまで、摩擦で力を「肩代わり」させるあらゆる場面の基礎です。なお実際の限界比は「滑り出す直前」の値なので、実務では摩擦係数のばらつきを見込んで安全率を上乗せして使います。
