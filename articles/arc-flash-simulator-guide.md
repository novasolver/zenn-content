## アークフラッシュとは何か

配電盤のメンテナンス中に工具を落として端子を短絡させる——その瞬間、空気が絶縁破壊を起こして数千℃のプラズマ（アーク）が発生し、爆発的な熱と圧力が作業者を襲います。これが**アークフラッシュ**です。設計者の仕事は、この事故が起きたとき作業者の皮膚に届く熱量を見積もり、適切な防護具（PPE）のレベルを決めること。その定量化の枠組みが **IEEE 1584** と **NFPA 70E** です。

この記事では、アークフラッシュ解析の中核である **入射エネルギー** $E$ が、どのパラメータにどう依存するかを 4 つの法則に分解して整理します。NovaSolver のシミュレーターでスライダーを動かすと、この依存関係がそのまま見えてきます。

## 入射エネルギーの簡易式

IEEE 1584-2018 の本式は電圧域ごとに係数が異なる経験式の塊ですが、教育・概算用には次の**簡易式**がよく使われます。

$$
E = 0.0093 \cdot \frac{I_a^{\,2}\, t}{D^{2}}
$$

ここで $E$ は入射エネルギー（cal/cm²）、$I_a$ はアーク電流（kA）、$t$ は保護装置の動作時間（s）、$D$ は作業距離です。そしてアーク電流 $I_a$ は、系統のボルテッド事故電流（短絡電流）$I_{bf}$ から次のように推定します。

$$
I_a \approx 0.6 \cdot I_{bf}
$$

短絡電流より小さくなるのは、アーク自身のインピーダンスが電流を制限するためです。$I_{bf} = 20\,\text{kA}$ なら $I_a \approx 12\,\text{kA}$。これは IEEE 1584 の低圧域で広く使われる安全側の近似です。

最後に、危険でなくなる距離——**アークフラッシュ境界（AFB）**——は、$E$ が 2 度熱傷の限界 $1.2\ \text{cal/cm}^2$ になる距離として求めます。

$$
D_{\text{AFB}} = \sqrt{\frac{0.0093\, I_a^{\,2}\, t}{1.2}}
$$

## 法則を支配する4つの依存性

この式から、$E$ を動かす要素は 4 つに分解できます。NovaSolver のツールが内部で計算している係数も含めて整理します。

| パラメータ | $E$ への効き方 | 物理的な意味 |
|---|---|---|
| アーク電流 $I_a$ | $E \propto I_a^{\,2}$ | 電流が 2 倍でエネルギーは 4 倍 |
| 動作時間 $t$ | $E \propto t$ | 遮断が遅れた分だけ線形に増える |
| 作業距離 $D$ | $E \propto 1/D^{2}$ | 離れるほど急速に減衰する |
| 電極ギャップ $G$ | $E \propto (G/32)^{0.18}$ | 弱い補正。広いほどわずかに増える |

さらにエンクロージャ種別（箱型 / 開放型）が補正係数 $k$ として効きます。箱型は $k=1.0$、開放型は $k=0.85$。箱の中ではエネルギーが反射・集中するため、開放より危険側になります。$k$ は $I_a$ に掛かるので、$E$ には $k^2$ で効きます。

## JavaScriptで再現する

ツールの計算ロジックは、上の式をそのまま素直に実装したものです。中核は 25 行ほどで書けます。

```javascript
function arcFlash(Ibf_kA, t_s, D_cm, G_mm, enc) {
  const k = enc === "box" ? 1.0 : 0.85;       // エンクロージャ補正
  const gapFactor = Math.pow(Math.max(10, G_mm) / 32, 0.18);
  const Ia = 0.6 * Ibf_kA * k;                // アーク電流 (kA)
  const E  = 0.0093 * Ia * Ia * t_s / (D_cm * D_cm) * gapFactor;
  const AFB_cm = Math.sqrt(0.0093 * Ia * Ia * t_s * gapFactor / 1.2);
  return { Ia, E, AFB_mm: AFB_cm * 10 };
}

// 入射エネルギーから PPE カテゴリを判定 (NFPA 70E)
function ppeCategory(E) {
  if (E < 4)  return 1;   // 難燃性作業着
  if (E < 8)  return 2;   // 耐炎素材
  if (E < 25) return 3;
  return 4;               // フルアークフラッシュスーツ
}

// 距離スイープ：E ∝ 1/D² を確かめる
for (let d = 30; d <= 90; d += 30) {
  console.log(d, arcFlash(20, 0.2, d, 32, "box").E.toFixed(4));
}
```

PPE カテゴリの 4 段階しきい値（4 / 8 / 25 cal/cm²）は NFPA 70E に基づくもので、ツールはこの境界を自動判定して防護服レベルを提示します。

## 距離の二乗則を数値で確かめる

4 つの依存性のうち、現場で最も効くのが距離です。NovaSolver のツールで作業距離 $D$ のスライダーを動かしながら入射エネルギーの相対値を追うと、きれいな逆二乗則が現れます（基準を $D=300\,\text{mm}$ の値 $1.00$ とした相対比）。

| 作業距離 $D$ | $E$ の相対比 | 逆二乗の理論値 |
|---|---|---|
| 300 mm | 1.000 | 1.000 |
| 600 mm | 0.250 | 0.250 |
| 900 mm | 0.111 | 0.111 |
| 1200 mm | 0.063 | 0.063 |

距離を 2 倍にするとエネルギーは $1/4$、3 倍で $1/9$。「あと一歩下がる」だけで危険度が桁で変わるのが、立ち入り禁止ラインを引く理由です。同様に動作時間 $t$ を $0.1\to0.4\,\text{s}$ にすると $E$ は厳密に 4 倍、$I_{bf}$ を $10\to40\,\text{kA}$ にすると $I_a^2$ を通じて 16 倍になります。これらの比はツール上でも理論どおりに再現されます。

試してほしい操作：

- **作業距離 $D$ スライダー**（100〜3000 mm）を動かし、入射エネルギー vs 距離グラフが逆二乗で落ちるのを確認
- **ボルテッド事故電流 $I_{bf}$**（1〜65 kA）を上げて、$I_a = 0.6\,I_{bf}$ と $E \propto I_a^2$ で結果が急騰するのを見る
- **保護装置動作時間 $t$**（0.01〜2.0 s）で、遮断を速くするとエネルギーが線形に下がることを確かめる
- **エンクロージャ種別**を箱型／開放型で切り替え、$k$ 補正の差を比較
- **PPEカテゴリ**バッジと **AFB 距離**、危険ゾーンの同心円図がリアルタイムに更新される

入射エネルギーが 4 / 8 / 25 cal/cm² の境界をまたぐ瞬間に、PPE カテゴリのバッジが切り替わります。「どのパラメータを動かせばカテゴリを下げられるか」を探すと、保護協調や離隔設計の勘所がつかめます。

## まとめ

- 入射エネルギーは $E = 0.0093\, I_a^2 t / D^2$、アーク電流は $I_a \approx 0.6\, I_{bf}$ で見積もる
- $E$ を支配するのは電流（2 乗）・時間（線形）・距離（逆 2 乗）・ギャップ（弱い補正）の 4 つ
- 距離は最強のレバー：2 倍離れると $1/4$、3 倍で $1/9$
- PPE カテゴリは 4 / 8 / 25 cal/cm² のしきい値（NFPA 70E）で自動判定される

アークフラッシュ解析は「危険を数値化して、設計と運用で下げる」ための定量ツールです。式の各項がどう効くかを手で動かして体に入れておくと、保護装置の時限設定や作業手順の安全マージンを判断するときに効いてきます。
