## 管を絞ると、なぜ圧力が下がるのか

ホースの先をつまむと水の勢いが増す——これは誰でも体験したことがあるはずです。この「速くなる」の裏側で起きているのが、**流速が増すぶん静圧が下がる**という現象です。流体力学ではこれを **ベルヌーイの定理** で記述します。

$$
P + \frac{1}{2}\rho v^2 + \rho g h = \text{const}
$$

ここで $P$ は静圧 [Pa]、$\rho$ は流体密度 [kg/m³]、$v$ は流速 [m/s]、$h$ は高さ [m] です。水平な管（$h$ 一定）では $P + \frac{1}{2}\rho v^2$ が一定になり、$v$ が増えれば $P$ が減るという「速さと圧力のトレードオフ」が成立します。

この記事では、ベルヌーイの定理の代表的な工業応用である **ベンチュリ管（差圧式流量計）** を題材に、

1. 連続の式とベルヌーイの定理を連立させて絞り部流速 $v_2$ を求める
2. 圧力降下 $\Delta P$ が径比の **4 乗** で効く理由
3. ベンチュリ・ノズル・オリフィスの流量係数 $C_d$ の違い

を、実際に数値を計算しながら確かめていきます。

## 連続の式とベルヌーイの定理を連立する

非圧縮流体では、管のどこを切っても体積流量 $Q = A v$ が同じです。これが **連続の式** です：

$$
A_1 v_1 = A_2 v_2
$$

円管なら断面積 $A = \pi (D/2)^2$ なので、絞り部流速は径比の **2 乗** で増えます：

$$
v_2 = v_1 \frac{A_1}{A_2} = v_1 \left(\frac{D_1}{D_2}\right)^2
$$

水平管でベルヌーイの定理を上流（添字 1）と絞り部（添字 2）に適用すると、圧力降下は

$$
\Delta P = P_1 - P_2 = \frac{1}{2}\rho\left(v_2^2 - v_1^2\right)
$$

となります。$v_2$ が径比の 2 乗で増え、$\Delta P$ は $v_2^2$ に比例するため、**$\Delta P$ は実質的に $(D_1/D_2)^4$ で効く**——これが後で効いてくるポイントです。

## JavaScript で 20 行の実装

ツールの計算ロジック（`calcVenturi`）はそのままブラウザで動く純粋な関数です。連続の式とベルヌーイの定理を素直にコード化しただけです：

```javascript
function calcVenturi(v1, D1, D2, rho) {
  const A1 = Math.PI * (D1 / 2) ** 2;          // 上流断面積 [m^2]
  const A2 = Math.PI * (D2 / 2) ** 2;          // 絞り部断面積 [m^2]
  const v2 = v1 * A1 / A2;                      // 連続の式: A1 v1 = A2 v2
  const dP = 0.5 * rho * (v2 ** 2 - v1 ** 2);   // ベルヌーイの定理
  const Q  = A1 * v1;                           // 体積流量 [m^3/s]
  return { v2, dP, Q, AR: A1 / A2 };
}

// 差圧 dP から流量 Q を逆算する実用式（流量係数 Cd 付き）
function flowFromDP(dP, A1, A2, rho, Cd) {
  const ratio2 = (A2 / A1) ** 2;
  const v2 = Math.sqrt(2 * dP / (rho * (1 - ratio2)));
  return Cd * A2 * v2;                          // [m^3/s]
}

// デフォルト: v1=10 m/s, D1=0.10 m, D2=0.05 m, 水 rho=1000
const r = calcVenturi(10, 0.10, 0.05, 1000);
console.log(r.v2.toFixed(2));         // 40.00   (m/s)
console.log((r.dP / 1000).toFixed(3)); // 750.000 (kPa)
console.log((r.Q * 1000).toFixed(2));  // 78.54   (L/s)
console.log(r.AR.toFixed(2));         // 4.00
```

径比 $D_1/D_2 = 100/50 = 2$ なので面積比 $A_1/A_2 = 4$、絞り部流速 $v_2 = 10 \times 4 = 40$ m/s。圧力降下は $\frac{1}{2}\times1000\times(40^2 - 10^2) = 750{,}000$ Pa = **750 kPa** になります。デフォルト設定はかなり過激な絞りで、これは後述の「設計上の注意」につながります。

![管内 流速・静圧プロファイルと径比感度](/images/bernoulli-applications/charts-closeup.png)

左図がデフォルト設定（$v_1=10$, $D_1/D_2=2$）のプロファイルです。入口で $v=10$ m/s・$P=200$ kPa だったものが、絞り部では $v=40$ m/s・$P=200-750=-550$ kPa まで落ち込みます。**静圧が負になっている**点に注目してください——これは現実には液体が気化（キャビテーション）するので起こり得ません。理想流体モデルの限界が数字に出ています。

## 圧力降下は径比の 4 乗で効く

上の右図は、径比 $D_1/D_2$ を 2 / 3 / 4 に固定したときの $\Delta P$–$v_1$ 曲線です。$v_1=10$ m/s で比べると、径比ごとに圧力降下が劇的に変わります：

| 径比 $D_1/D_2$ | $(D_1/D_2)^4$ | 絞り部流速 $v_2$ | 圧力降下 $\Delta P$ |
|---|---|---|---|
| 2.0 | 16 | 40 m/s | 750 kPa |
| 3.0 | 81 | 90 m/s | 4,000 kPa |
| 4.0 | 256 | 160 m/s | 12,750 kPa |

径比を 2 倍（2.0 → 4.0）にしただけで $\Delta P$ は 750 → 12,750 kPa、**実に 17 倍**です。理論式 $\Delta P = \frac{1}{2}\rho v_1^2\big[(D_1/D_2)^4 - 1\big]$ から、比は $(256-1)/(16-1) = 17$ と一致します。

これは流量計の感度設計のキモです。細く絞るほど差圧が大きく取れて測定が楽になりますが、絞りすぎると絞り部の圧力が飽和蒸気圧を割り込み、**キャビテーション**（気泡発生→崩壊による壊食・騒音）を招きます。感度とキャビテーション余裕のトレードオフが設計の本質です。

## 差圧から流量を逆算する

実務で本当に使うのは逆問題です。配管に取り付けたベンチュリ管の上流と絞り部の圧力差 $\Delta P$ を測り、そこから流量 $Q$ を求めます。連続の式とベルヌーイの定理を連立して整理すると、実用式が得られます：

$$
Q = C_d\, A_2 \sqrt{\dfrac{2\,\Delta P}{\rho\left[1 - (A_2/A_1)^2\right]}}
$$

$C_d$ は **流量係数**で、理想式からの実測ズレ（粘性・剥離など）を吸収する補正係数です。ベンチュリ管では $C_d \approx 0.98$ と 1 に近く、ほとんど理論どおりに測れます。

簡単な検算をしてみましょう。水 $\rho=1000$ kg/m³ が $D_1=50$ mm の管に $v_1=2$ m/s で流入し、$D_2=25$ mm に絞られる場合：径比 2 倍なので $v_2 = 2 \times 4 = 8$ m/s、$\Delta P = \frac{1}{2}\times1000\times(8^2-2^2) = 30{,}000$ Pa = **0.3 気圧**。手計算とツールの「絞り部流速 $v_2$」「圧力降下 $\Delta P$」カードの値が一致することを確認できます。

## デバイス比較：ベンチュリ・ノズル・オリフィス

3 つ目のタブは差圧式流量計の代表 3 種を比較します。同じ理想差圧でも、流量係数 $C_d$ が違うため必要差圧（測定差圧）と永久圧力損失が大きく変わります：

| デバイス | 流量係数 $C_d$ | 圧力回復 | 特徴 |
|---|---|---|---|
| ベンチュリ管 | 0.98 | 高い | 緩やかな絞り・拡大で損失最小、長尺で高価 |
| フローノズル | 0.95 | 中程度 | スラリーに強い、中間的 |
| オリフィス | 0.61 | 低い | 薄い穴板で安価だが急拡大で損失大 |

オリフィスは $C_d \approx 0.61$ と小さいため、同じ流量を測るのに大きな永久圧力損失（＝ポンプ電力の浪費）が発生します。一方ベンチュリは絞った後にゆっくり拡大する形状なので、絞り部でいったん下がった圧力のほとんどが下流で回復します。急拡大するオリフィスでは、絞りを抜けた流れが壁から剥離して乱流の渦を作り、その運動エネルギーが熱に変わって永久に失われます。これが永久圧力損失の正体です。

結果として、「初期投資は高いが運転コストが安い」のがベンチュリ、「安価で多点設置向き」がオリフィス、という使い分けになります。大口径・長期運用の基幹配管ではベンチュリの低損失が効いてポンプ電力を節約でき、工場内の数十か所をざっくり監視したい用途では安価なオリフィスが選ばれます。CAE の現場では、こうしたデバイス選定の一次スクリーニングを本ツールのような簡易計算で済ませ、有望な構成だけを詳細な 3 次元 CFD 解析に回す、という二段構えが定石です。

## まとめ

- ベンチュリ管は連続の式 $A_1 v_1 = A_2 v_2$ とベルヌーイの定理 $\Delta P = \frac{1}{2}\rho(v_2^2 - v_1^2)$ の連立で解ける
- 圧力降下 $\Delta P$ は径比の **4 乗**で効く（径比 2 倍で 17 倍）。デフォルト設定では $v_2=40$ m/s・$\Delta P=750$ kPa
- 差圧から流量は $Q = C_d A_2\sqrt{2\Delta P/(\rho[1-(A_2/A_1)^2])}$ で逆算でき、$C_d$ がデバイスの実力を表す
- 絞りすぎは静圧を負（＝キャビテーション）に追い込むため、感度と余裕のトレードオフで設計する

「速さと圧力のトレードオフ」というたった 1 つの原理から、流量計・ピトー管・翼の揚力まで説明できるのがベルヌーイの定理の強みです。
