## カメラも虫眼鏡も、式は1本

カメラのレンズは被写体を小さく倒立させてセンサーに結び、虫眼鏡は文字を拡大して見せる。一見正反対のこの2つは、**たった1本の式**——薄肉レンズの公式で完全に説明できます。違いは「物体がレンズの焦点より外か内か」だけ。

この記事ではレンズの公式と倍率を導き、JavaScript で**主光線3本**を追跡して、実像・虚像がどこに、どんな向き・大きさでできるかを作図します。

## レンズの公式と倍率

焦点距離 $f$、物体距離 $d_o$、像距離 $d_i$ の間には、**薄肉レンズの公式**が成り立ちます。

$$
\frac{1}{f} = \frac{1}{d_o} + \frac{1}{d_i}
$$

これを $d_i$ について解き、倍率 $m$ は次式です。

$$
d_i = \frac{f\,d_o}{d_o - f},\qquad m = -\frac{d_i}{d_o}
$$

符号がすべてを語ります。

- $d_i > 0$：**実像**（レンズの反対側にできる、スクリーンに映る像）
- $d_i < 0$：**虚像**（物体と同じ側にできる、覗き込んで見える像）
- $m < 0$：倒立、$m > 0$：正立。$|m|>1$：拡大、$|m|<1$：縮小

## 物体距離で像が一変する

ツールの既定値（凸レンズ $f=100\,\mathrm{mm}$、$d_o=200\,\mathrm{mm}$）で計算すると

$$
d_i = \frac{100\times200}{200-100} = 200\,\mathrm{mm},\qquad m = -\frac{200}{200} = -1
$$

像距離 200 mm の位置に、等倍・倒立の**実像**ができます（カメラの原理）。ところが物体を焦点の内側に入れると——「虫眼鏡」プリセット（$f=50$、$d_o=40$）では

$$
d_i = \frac{50\times40}{40-50} = -200\,\mathrm{mm},\qquad m = -\frac{-200}{40} = +5
$$

像距離が**負**＝虚像、倍率 +5 の**正立・拡大像**。これが虫眼鏡です。同じレンズでも物体の位置だけで像の性質が反転します。

## 主光線3本の作図ルール

像の位置は、たどり方の決まった**3本の光線**を引くだけで作図できます。

1. **光軸に平行な光線**（赤）：レンズで曲がり、後側焦点 $F'$ を通る
2. **レンズ中心を通る光線**（黄）：曲がらず直進する
3. **前側焦点 $F$ を通る光線**（緑）：レンズで曲がり、光軸に平行に進む

実像では、この3本が**実際に交わる点**に像ができます（上図左）。虚像では出射光が発散し、その**後方への延長線**（破線）が交わる点に像ができます（上図右）。

## JavaScript 実装

公式は数行、作図は3本のレイを引くだけです。

```javascript
function thinLens(f, do_) {
  if (Math.abs(do_ - f) < 0.5) return { di: 1e6, m: 1e6 };  // do=f は像が無限遠
  const di = f * do_ / (do_ - f);
  return { di, m: -di / do_ };
}
// 主光線: (1)平行→F', (2)中心→直進, (3)F→平行 の3本を描き交点を求める
```

凹レンズ（$f<0$）も同じ式で扱えます。「凹レンズ」プリセット（$f=-100$、$d_o=150$）なら $d_i=-60\,\mathrm{mm}$、$m=+0.4$ の正立・縮小の虚像になります。

## まとめ

- 薄肉レンズの公式 $1/f = 1/d_o + 1/d_i$ ひとつで、カメラも虫眼鏡も記述できる
- $d_i>0$ は実像（倒立・スクリーンに映る）、$d_i<0$ は虚像（正立・覗いて見る）。倍率 $m=-d_i/d_o$
- 物体が焦点の外なら実像、内なら拡大虚像。位置だけで像が一変する
- **主光線3本**（平行→F'、中心直進、F→平行）の交点で像が作図できる

幾何光学の基礎であり、カメラ・顕微鏡・望遠鏡の設計に直結する作図法を、レイを追いながら体感してみてください。
