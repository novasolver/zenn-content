## チョーク流れとは

圧縮空気の配管で「チョークしているからこれ以上流量は増えない」と言われることがあります。背圧（下流の圧力）をどれだけ下げても質量流量が頭打ちになる——直感に反するこの現象が **チョーク流れ（choked flow）** です。

正体は単純で、**収束ノズルの一番細い断面（喉部）で流れが局所音速に達した状態**です。音速に達すると、下流の圧力情報が音波として上流へ伝わらなくなり、喉部より下流で何が起きてもノズル入口の流れは変わらなくなります。

この記事では、

1. 臨界圧力比 $P^*/P_0$ がなぜ $\gamma$ だけで決まるのか
2. 最大質量流量 $\dot{m}_{\max}$ の計算と、20 行ほどの JavaScript 実装
3. 背圧を下げても流量が増えない様子を数値で確かめる

を扱います。

## 臨界圧力比 — γ だけで決まる境界

完全気体・等エントロピー・準1次元定常流れを仮定すると、収束ノズルが喉部で $M=1$ に達する臨界圧力比は、比熱比 $\gamma$ だけで決まります。

$$
\frac{P^*}{P_0} = \left(\frac{2}{\gamma+1}\right)^{\gamma/(\gamma-1)}
$$

空気（$\gamma = 1.4$）では $(2/2.4)^{3.5} \approx 0.528$。つまり背圧比 $P_b/P_0$ が **0.528 を下回るとチョーク**します。なぜ喉部で $M=1$ が上限になるかは、準1次元の連続式

$$
\frac{dA}{A} = (M^2 - 1)\,\frac{dV}{V}
$$

から説明できます。$M<1$ では断面を絞ると流速が上がりますが、$M=1$ では $dA=0$ でなければならず、収束のみのノズルでは喉部の音速が物理的な上限になります。さらに加速するにはラバール（収束-拡大）ノズルが必要です。

## 最大質量流量

チョーク時の質量流量は最大値で頭打ちになり、次式で与えられます。

$$
\dot{m}_{\max} = A^{*}\,P_0\,\sqrt{\frac{\gamma}{R\,T_0}}\left(\frac{2}{\gamma+1}\right)^{(\gamma+1)/(2(\gamma-1))}
$$

注目すべきは、右辺に現れるのが上流の $P_0,\ T_0$ と喉部面積 $A^{*}$、それに気体定数だけだという点です。背圧 $P_b$ は一切登場しません。喉部温度と音速も等エントロピー関係から得られます。

$$
T^{*} = T_0\,\frac{2}{\gamma+1}, \qquad a^{*} = \sqrt{\gamma R T^{*}}
$$

## JavaScript で書くと

ツールの計算ロジックはそのまま素直に書けます。

```javascript
const GAMMA = 1.4, R = 287; // 空気

function criticalRatio(g) {
  return Math.pow(2 / (g + 1), g / (g - 1));
}

function massFlowMax(P0, T0, A, g) {
  return A * P0 * Math.sqrt(g / (R * T0)) *
         Math.pow(2 / (g + 1), (g + 1) / (2 * (g - 1)));
}

function massFlowSubsonic(P0, T0, A, Pb, g) {
  const pr = Pb / P0;
  if (pr >= 1) return 0;
  const term = Math.pow(pr, 2 / g) - Math.pow(pr, (g + 1) / g);
  const coef = Math.sqrt(2 * g / ((g - 1) * R * T0));
  return A * P0 * coef * Math.sqrt(term);
}

function solve(P0, T0, A, Pb) {
  const rcr = criticalRatio(GAMMA);          // ≈ 0.528
  const choked = (Pb / P0) <= rcr;
  const mdot = choked
    ? massFlowMax(P0, T0, A, GAMMA)
    : massFlowSubsonic(P0, T0, A, Pb, GAMMA);
  return { rcr, choked, mdot };
}
```

デフォルト値 $P_0 = 500\,\mathrm{kPa},\ T_0 = 300\,\mathrm{K},\ A^{*} = 100\,\mathrm{mm}^2,\ P_b = 200\,\mathrm{kPa}$ を入れると、$P_b/P_0 = 0.4 < 0.528$ なのでチョーク、$\dot{m}_{\max} = 0.117\ \mathrm{kg/s}$ となります。

## ṁ vs 背圧比のグラフ

質量流量を背圧比 $P_b/P_0$ の関数として描くと、特徴的な形になります。

![質量流量と背圧比の関係](/images/choked-flow/charts-closeup.png)

- $P_b/P_0 \le 0.528$（チョーク領域）：$\dot{m}$ は一定（$\dot{m}_{\max}$）
- $0.528 < P_b/P_0 < 1$（亜音速領域）：背圧が上がるほど $\dot{m}$ が減少
- $P_b/P_0 = 1$：流れが止まり $\dot{m} = 0$

左半分が水平な「頭打ち」になっているのがチョークの視覚的な証拠です。

## 背圧を下げても増えない——数値で確認

「真空に引けば流量が増える」という直感が誤りであることを数値で確かめます。$P_0 = 500\,\mathrm{kPa}$ 固定で背圧を下げていきます。

| 背圧 $P_b$ | $P_b/P_0$ | 状態 | $\dot{m}$ [kg/s] |
|---|---|---|---|
| 270 kPa | 0.540 | 亜音速 | 0.1166 |
| 264 kPa | 0.528 | 臨界 | 0.1167 |
| 200 kPa | 0.400 | チョーク | 0.1167 |
| 50 kPa | 0.100 | チョーク | 0.1167 |
| 10 kPa | 0.020 | チョーク | 0.1167 |

臨界点 $P_b/P_0 = 0.528$ を割った瞬間から、背圧をいくら下げても $\dot{m}_{\max} = 0.117\ \mathrm{kg/s}$ から動きません。流量を増やしたいなら、上流全圧 $P_0$ を上げる・喉部面積 $A^{*}$ を広げる・上流温度 $T_0$ を下げる（密度を上げる）のいずれかで、$P_b$ を触っても無駄、ということになります。

> 補足：喉部音速は $T_0 = 300\,\mathrm{K}$ のとき $T^{*} = 250\,\mathrm{K}$ で $a^{*} \approx 317\ \mathrm{m/s}$ と、地上常温の音速 343 m/s より少し低くなります。断熱膨張で喉部の温度が下がっているためです。$T_0 = 600\,\mathrm{K}$ では $a^{*} \approx 448\ \mathrm{m/s}$ に上がります。

## まとめ

- 収束ノズルの臨界圧力比は $P^{*}/P_0 = (2/(\gamma+1))^{\gamma/(\gamma-1)}$、空気なら約 0.528
- 背圧比がこれを下回るとチョークし、$\dot{m}_{\max}$ は上流条件 $P_0,\ T_0,\ A^{*}$ だけで決まる
- 背圧を下げても流量は増えない（情報が音速の壁で遮られるため）
- デフォルト条件では $\dot{m}_{\max} = 0.117\ \mathrm{kg/s}$、喉部音速 $a^{*} \approx 317\ \mathrm{m/s}$

安全弁・破裂板・クリティカルフローノズル・ロケットエンジンなど、チョークを前提に「流量を上流条件だけで決める」設計は実務で広く使われています。なお実機では流出係数 $C_d$（おおむね 0.6〜0.95）を掛けるのが一般的で、本ツールは理想（等エントロピー）値を示している点に留意してください。
