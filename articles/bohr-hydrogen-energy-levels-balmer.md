## ボーア水素原子モデルとは

水素原子のスペクトルは、太陽光をプリズムに通したときに現れる「とびとびの輝線」として古くから知られていました。なぜ連続ではなく、特定の波長だけが光るのか。1913 年に Niels Bohr が出した答えが **ボーア水素原子モデル**です。

電子は原子核のまわりを「とびとびの円軌道」だけを回り、各軌道はエネルギーが量子化されている——という半古典的なモデルです。電子が高い軌道から低い軌道へ「飛び移る」とき、その差分のエネルギーが光子として放出されます。これが輝線の正体です。

## エネルギー準位と軌道半径の量子化

ボーアモデルの核心は、電子の角運動量が $\hbar = h/2\pi$ の整数倍に制限される（$mvr = n\hbar$）という量子条件です。ここから、軌道半径とエネルギーが主量子数 $n$ で決まります：

$$
E_n = -\frac{13.6}{n^2}\ \text{[eV]},\qquad r_n = n^2 a_0
$$

$a_0 = 0.0529$ nm（= 0.529 Å）は **ボーア半径**と呼ばれる、$n=1$ 軌道の半径です。エネルギーが負なのは、電子が無限遠（自由）にある状態を 0 と定義しているため。$n=1$ の $-13.6$ eV は「電子を完全に引き剥がす（電離させる）のに 13.6 eV 必要」という意味になります。

注意したいのは $n$ への依存の仕方です。半径は $n^2$ で**急激に広がる**一方、エネルギー準位の間隔は $n$ が大きくなるほど**狭まり**、$n\to\infty$ で連続（電離極限）に収束します。

## 遷移と放出波長：リュードベリの式

電子が準位 $n_1$ から $n_2$（$n_1 > n_2$）へ遷移すると、エネルギー差が光子として放出されます：

$$
\Delta E = |E_{n_1} - E_{n_2}|,\qquad \lambda = \frac{hc}{\Delta E} \approx \frac{1240}{\Delta E\,[\text{eV}]}\ \text{[nm]}
$$

これは波数で書くと、有名な **リュードベリの式**になります：

$$
\frac{1}{\lambda} = R_H\!\left(\frac{1}{n_2^2} - \frac{1}{n_1^2}\right)
$$

終状態 $n_2$ によって系列の名前が決まります。$n_2=1$ がライマン系列（紫外）、$n_2=2$ がバルマー系列（可視光）、$n_2=3$ がパッシェン系列（赤外）です。

## JavaScript で実装する

ツールが内部で行っている計算は、わずか数行の関数に収まります：

```javascript
const a0 = 0.0529;                 // ボーア半径 [nm]

// 準位 n のエネルギー [eV] と軌道半径 [nm]
function energy(n) { return -13.6 / (n * n); }
function radius(n) { return n * n * a0; }

// n1 -> n2 遷移で放出される光の波長 [nm]
function wavelength(n1, n2) {
  const dE = Math.abs(energy(n1) - energy(n2));  // [eV]
  return 1240 / dE;                              // λ = hc/ΔE
}

// バルマー系列（n2 = 2 への遷移）を列挙
for (let n1 = 3; n1 <= 6; n1++) {
  const dE = Math.abs(energy(n1) - energy(2));
  console.log(`${n1}→2 : ΔE=${dE.toFixed(3)} eV, λ=${wavelength(n1, 2).toFixed(1)} nm`);
}
// 3→2 : ΔE=1.889 eV, λ=656.5 nm   (Hα 赤)
// 4→2 : ΔE=2.550 eV, λ=486.3 nm   (Hβ 青緑)
// 5→2 : ΔE=2.856 eV, λ=434.2 nm   (Hγ 紫)
// 6→2 : ΔE=3.022 eV, λ=410.3 nm   (Hδ 紫)
```

$hc \approx 1240$ eV·nm という覚えやすい定数を使うのがポイントです。エネルギーを eV、波長を nm で扱う限り、この一行で光子の波長が出ます。

## 可視化：軌道とスペクトル

ツールでは主量子数を変えると、軌道半径が $n^2$ で広がる様子と、遷移で放出される光の色がリアルタイムに描かれます。

![ボーアモデルの軌道とバルマー系列スペクトル](/images/bohr-hydrogen-model/charts-closeup.png)

特徴的なのは、バルマー系列の 4 本が「赤 → 青緑 → 紫」と可視光域に綺麗に並ぶことです。星雲が赤く輝く HII 領域の色は、この Hα 線（656 nm）によるものとされています。

## バルマー系列を数値で確かめる

上のコードで計算したバルマー系列の波長を、独立に**リュードベリの式**（$R_H = 1.097\times10^7\ \text{m}^{-1}$）で計算し直すと、ほぼ完全に一致します：

| 遷移 | 名称 | $\Delta E$ [eV] | $\lambda$ (ツール) | $\lambda$ (リュードベリ) |
|---|---|---|---|---|
| $3\to2$ | Hα（赤） | 1.889 | 656.5 nm | 656.47 nm |
| $4\to2$ | Hβ（青緑） | 2.550 | 486.3 nm | 486.27 nm |
| $5\to2$ | Hγ（紫） | 2.856 | 434.2 nm | 434.17 nm |
| $6\to2$ | Hδ（紫） | 3.022 | 410.3 nm | 410.29 nm |

差はわずか 0.1 nm 以下で、これは $hc \approx 1240$ という丸めの範囲です。$-13.6/n^2$ という単純な式が、実験で観測される輝線波長をここまで正確に再現するのが、ボーアモデルが歴史的に衝撃を与えた理由でした。

なお基底状態 $n=1$ では $E_1 = -13.6$ eV、軌道半径は $r_1 = a_0 = 0.0529$ nm。「水素の電離エネルギー 13.6 eV」と「原子サイズ 約 0.1 nm」という基本スケールが、ここから直接出てきます。

## まとめ

- エネルギー準位は $E_n = -13.6/n^2$ eV、軌道半径は $r_n = n^2 a_0$（$a_0 = 0.0529$ nm）
- 遷移波長は $\lambda = 1240/\Delta E$、波数で書けばリュードベリの式
- バルマー系列（$n_2=2$）の Hα〜Hδ は 656・486・434・410 nm で、可視光域に並ぶ
- 計算は十数行の JavaScript で再現でき、リュードベリの式とも 0.1 nm 以内で一致する

ボーアモデルは多電子原子やスピンを説明できず、現在は量子力学（シュレーディンガー方程式）に置き換わっています。それでも「エネルギーが量子化され、その差が光になる」という直感は、いまも分光学の出発点として有効です。
