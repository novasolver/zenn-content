Xで「北海道で急激な冷え込み、ストーブ点火の声相次ぐ」という話題が上がっていました。では、外が冷えると暖房はどれだけ多く必要になるのでしょうか。

小さな家(壁80m²・窓15m²・室内20℃)で計算すると、外気が5℃から−2℃に下がっただけで、家から逃げる熱は2,404 Wから3,526 Wへ、47%増えます。1 kWの電気ストーブなら約3.5台分です。

*室内20℃のとき、外気温ごとに家から逃げる熱(部位別の積み上げ)*

## 逃げる熱は「温度差」に比例する

壁・屋根・窓から逃げる熱は、面積と熱の通しやすさ(U値)と内外の温度差の積です。すき間風や換気で入れ替わる空気も、温めた分だけ熱を持ち出します。

$$
Q = \sum_i U_i A_i \,\Delta T + 0.33\, n V \,\Delta T
$$

どの項も温度差 ΔT に比例するので、グラフは一直線になります。室内20℃のまま外が5℃から−2℃になると、温度差は15℃から22℃に、つまり1.47倍になります。「急に寒くなった」と感じる差が、そのまま暖房の負荷になるわけです。

```python
def heat_loss(t_out, t_in=20.0, glazing=2.3, ach=0.5):
    dT = t_in - t_out
    wall_U = 1 / (0.13 + 0.20 / 0.14 + 0.04)   # 木材0.2m + 内外表面の熱抵抗
    return (wall_U * 80 * dT           # 壁
            + 0.33 * ach * 300 * dT    # 換気・すき間風 (n=0.5回/h, 300m3)
            + glazing * 15 * dT        # 窓(複層ガラス U=2.3)
            + 0.25 * 50 * dT           # 屋根
            + 0.35 * 50 * dT * 0.5     # 床
            + 2.5 * 2.0 * dT)          # ドア

print(heat_loss(5), heat_loss(-2))  # 2404.4, 3526.5 [W]
```

## どこから逃げている？

外気−2℃のときの内訳です。壁・換気・窓の3つで84%を占めます。

![外気マイナス2度のときの部位別熱損失の棒グラフ](/images/trend/20261024-zenn-hokkaido-heat-loss/fig2_breakdown.png)
*部位別の熱損失(外気−2℃、室内20℃)*

- 窓は外皮面積のわずか8%なのに、熱損失の22%
- 換気・すき間風だけで31%(壁全体と同じくらい)
- 屋根は断熱が効いていて8%

## 手を入れるならどこから

同じ−2℃の条件で、窓をLow-E複層ガラス(U=1.1)にすると3,130 W、換気の熱損失を半分にすると2,982 W。両方で2,586 Wとなり、必要な暖房は27%減ります。
