## 点火プラグなしで燃やすエンジンの熱力学

ディーゼルエンジンは点火プラグを持ちません。空気だけを高圧縮して高温にし、そこへ燃料を噴射して**自己着火**させます。理想化した**ディーゼルサイクル**は、燃焼を「定積（オットー）」ではなく「**定圧**」加熱で表すのが特徴。この違いが効率の式に**締切り比（cutoff ratio）**という新しいパラメータを持ち込みます。

この記事では、ディーゼルサイクルの効率をオットーと比較しながら JavaScript で計算します。

🚛 **動くデモ**: [ディーゼルサイクルシミュレーター（NovaSolver）](https://novasolver.jp/tools/diesel-cycle.html)

## 締切り比が効率を下げる

ディーゼルサイクルの熱効率は次式です。

$$
\eta_{\text{Diesel}} = 1 - \frac{1}{r^{\gamma-1}}\cdot\frac{r_c^{\gamma}-1}{\gamma(r_c-1)}
$$

$r$ は圧縮比、$r_c = V_3/V_2$ は締切り比（定圧加熱で体積が膨らむ比）。第2項のカッコ部分（締切り係数）は $r_c > 1$ で必ず 1 より大きくなるため、**同じ圧縮比なら締切り比が大きいほど効率が下がります**。$r_c \to 1$ の極限ではオットーサイクルに一致します。

既定値 $r=18$、$r_c=2$、$\gamma=1.4$ で計算すると、締切り係数 $= (2^{1.4}-1)/(1.4\times1) = 1.171$、**熱効率 $\eta = 63.2\%$**。同じ圧縮比のオットーサイクル（$\eta = 1 - 1/18^{0.4} = 68.5\%$）より **5.4 ポイント低い**結果です。

ではなぜディーゼルが実用上有利なのか？ それは**圧縮比そのものを高くできる**から（点火プラグがなくノッキングの制約が緩い）。ガソリンの $r \approx 10$ に対しディーゼルは $r \approx 15$–$22$。高い $r$ が締切り比による損失を補って余りある、というわけです。

## JavaScript 実装

```javascript
function dieselEta(r, rc, g) {
  // rc→1 でオットーに帰着（0/0 を回避）
  const cutoff = Math.abs(rc - 1) < 1e-6 ? 1
               : (Math.pow(rc, g) - 1) / (g * (rc - 1));
  return 1 - (1 / Math.pow(r, g - 1)) * cutoff;
}
const ottoEta = (r, g) => 1 - 1 / Math.pow(r, g - 1);
// 状態点の温度
const T2 = T1 * Math.pow(r, g - 1);   // 断熱圧縮後
const T3 = T2 * rc;                    // 定圧加熱後（V3/V2 = rc）
const T4 = T1 * Math.pow(rc, g);       // 断熱膨張後
const P2 = P1 * Math.pow(r, g);        // 最高圧力 = P3
```

既定値では $T_3 = 1907\,\mathrm{K}$（最高温度）、最高圧力 $P_2 = 5720\,\mathrm{kPa}$。締切り比を $r_c = 1.5 \to 3 \to 4$ と増やすと効率は $65.6\% \to 58.9\% \to 55.3\%$ と下がります。締切り比が大きい＝より多くの燃料を定圧で燃やす＝より大出力だが効率は犠牲、というトレードオフです。

## ツールで遊ぶ

[ディーゼルサイクルシミュレーター](https://novasolver.jp/tools/diesel-cycle.html)で試してほしい操作：

- **締切り比 r_c スライダー**を上げ、「熱効率」が下がり「最高温度 T₃」が上がるのを確認
- **圧縮比 r スライダー**を上げて効率が向上するのを見る（ディーゼルが高圧縮で勝負する理由）
- **「オットー比較」表示**で同じ圧縮比のオットーとの効率差を読む
- **比熱比 γ スライダー**で効率の変化を確認
- **P-V 線図**で 2→3 の**定圧加熱（赤の水平区間）**がオットー（定積）と違うことを見る
- **効率カーブ**でディーゼル（実線）とオットー（破線）を比較

## まとめ

- ディーゼルの効率は $\eta = 1 - \frac{1}{r^{\gamma-1}}\cdot\frac{r_c^{\gamma}-1}{\gamma(r_c-1)}$
- 同じ圧縮比ならオットーより低い（既定で 63.2% vs 68.5%、差 5.4pt）
- 締切り比が大きいほど効率は下がる（出力とのトレードオフ）
- 実機は高い圧縮比でこの損失を補い、高効率を実現する

オットーとの違いを、締切り比と圧縮比を動かしながら体感してみてください。
