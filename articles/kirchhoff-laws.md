## 抵抗が混じった回路はどう解くのか

電池に抵抗を 1 本つなぐだけなら、オームの法則 $V=IR$ で電流は一発で出ます。ところが直列と並列が混ざった回路になると、「どこにどれだけ電流が流れるのか」が途端に見えなくなります。これを系統的に解くための土台が **キルヒホッフの法則** です。法則は 2 つだけ:

- **電圧則（KVL）**: 任意の閉ループを 1 周したとき、電圧の総和は 0
- **電流則（KCL）**: 任意の節点で、流入する電流の総和は流出する電流の総和に等しい

この記事では、電圧源 $V$ に直列抵抗 $R_1$ をつなぎ、その先に $R_2$ と $R_3$ を並列接続した「直並列回路」を題材に、KVL と KCL から全電流・各分岐電流・並列部の電圧をすべて手で導き、JavaScript で 25 行のソルバーに落とし込みます。

## 回路の構造と KVL・KCL

扱う回路は次の通りです。電圧源 $V$ から出た電流は、まず直列抵抗 $R_1$ を通って節点 a に達し、そこで $R_2$ 側と $R_3$ 側の 2 本に分かれて、再び合流して電源へ戻ります。

![直並列回路図と KCL バーチャート](/images/kirchhoff-laws/charts-closeup.png)

節点 a に KCL を適用すると、流入する全電流 $I_{total}$ が 2 本の分岐に分かれるので

$$
I_{total} = I_2 + I_3
$$

が成り立ちます。一方、電源 → $R_1$ → $R_2$（または $R_3$）→ 電源、という閉ループに KVL を適用すると

$$
V = I_{total}\,R_1 + V_{par}
$$

となります。ここで $V_{par}$ は並列部（$R_2$ と $R_3$ の両端）にかかる電圧です。並列接続では両端の電圧が共通なので、$V_{par}$ は 1 つの値で表せます。

## 並列部をまとめて 1 本の直列回路にする

直並列回路を解くコツは、**並列部を 1 個の等価抵抗にまとめてしまう**ことです。並列の合成抵抗 $R_{par}$ は、両端電圧 $V_{par}$ が共通で各分岐の電流が $V_{par}/R_k$ になることから、

$$
\frac{1}{R_{par}} = \frac{1}{R_2} + \frac{1}{R_3}
\quad\Longrightarrow\quad
R_{par} = \frac{R_2\,R_3}{R_2 + R_3}
$$

と「積を和で割る」式になります。3 本以上なら逆数の和を使いますが、2 本ならこの形が便利です。重要な性質として、**$R_{par}$ は必ず個別の抵抗のどれよりも小さくなります**。並列にすると電流の通り道が増えるので、全体としては「流れやすく＝抵抗が小さく」なるからです。

並列部をまとめてしまえば、回路は $R_1$ と $R_{par}$ が直列につながっただけの単純な回路です。全抵抗は

$$
R_{total} = R_1 + R_{par}
$$

であり、KVL から全電流が直ちに求まります:

$$
I_{total} = \frac{V}{R_{total}}, \qquad
V_{par} = V - I_{total}\,R_1, \qquad
I_2 = \frac{V_{par}}{R_2}, \quad I_3 = \frac{V_{par}}{R_3}
$$

## JavaScript で 25 行のソルバー

上の式をそのままコードにすると、入力 4 つ（$V, R_1, R_2, R_3$）から全変数が一意に決まります。シミュレーターの計算ロジックも実質これと同じです:

```javascript
function solveCircuit(V, R1, R2, R3) {
  // 並列部の合成抵抗（積を和で割る）
  const Rpar = (R2 * R3) / (R2 + R3);
  // 全抵抗 = 直列 + 並列まとめ
  const Rtot = R1 + Rpar;
  // KVL: 全電流
  const Itot = V / Rtot;
  // R1 での電圧降下と並列部の電圧
  const Vr1  = Itot * R1;
  const Vpar = V - Vr1;
  // 各分岐の電流（オームの法則）
  const I2 = Vpar / R2;
  const I3 = Vpar / R3;
  return { Rpar, Rtot, Itot, Vpar, I2, I3 };
}

// 既定値で実行
const s = solveCircuit(12, 100, 200, 300);
console.log("Itot =", (s.Itot * 1000).toFixed(1), "mA");
console.log("I2   =", (s.I2   * 1000).toFixed(1), "mA");
console.log("I3   =", (s.I3   * 1000).toFixed(1), "mA");
console.log("KCL  :", ((s.I2 + s.I3) * 1000).toFixed(1), "mA");
// Itot = 54.5 mA
// I2   = 32.7 mA
// I3   = 21.8 mA
// KCL  : 54.5 mA
```

非線形素子が無い純抵抗回路なので、反復計算（Newton-Raphson など）は不要で、閉じた式で一発で解けます。これが「線形回路は手で解ける」と言われる理由です。

## 既定値で数値を確かめる

既定値 $V=12$ V, $R_1=100$ Ω, $R_2=200$ Ω, $R_3=300$ Ω を入れて、一つずつ追ってみます。

まず並列部:

$$
R_{par} = \frac{200 \times 300}{200 + 300} = \frac{60000}{500} = 120\ \Omega
$$

全抵抗は $R_{total} = 100 + 120 = 220$ Ω。よって全電流は

$$
I_{total} = \frac{12}{220} = 0.05455\ \text{A} = 54.5\ \text{mA}
$$

$R_1$ での電圧降下は $I_{total}R_1 = 0.05455 \times 100 = 5.45$ V なので、並列部の電圧は

$$
V_{par} = 12 - 5.45 = 6.55\ \text{V}
$$

これを各分岐に分配すると:

| 量 | 値 |
|---|---|
| $R_{par}$ | $120\ \Omega$ |
| $I_{total}$ | $54.5\ \text{mA}$ |
| $V_{par}$ | $6.55\ \text{V}$ |
| $I_2 = V_{par}/R_2$ | $32.7\ \text{mA}$ |
| $I_3 = V_{par}/R_3$ | $21.8\ \text{mA}$ |
| $I_2 + I_3$ | $54.5\ \text{mA}$ |

最後の行が KCL の検証です。$I_2 + I_3 = 32.7 + 21.8 = 54.5$ mA となり、全電流 $I_{total}$ とぴたり一致します。これらの値は Python でも独立に再計算して、上記とすべて一致することを確認しています。

## 電流は「抵抗が小さい側」に多く流れる

ここで直感が試されます。並列分岐では両端の電圧 $V_{par}$ が共通なので、各分岐の電流は抵抗に**反比例**します:

$$
\frac{I_2}{I_3} = \frac{V_{par}/R_2}{V_{par}/R_3} = \frac{R_3}{R_2}
$$

既定値では $I_2 : I_3 = R_3 : R_2 = 300 : 200 = 3 : 2$ となり、確かに $32.7 : 21.8 \approx 3 : 2$ です。**抵抗が小さい $R_2$ 側により多くの電流が流れる**わけで、「並列だから半分ずつ」という思い込みは誤りです。

この性質が極端に出るのが、片方を極小にしたときです。たとえば $R_3$ を 1 Ω まで下げると、$R_{par} \approx 0.995$ Ω、$R_{total} \approx 101$ Ω なので $I_{total} \approx 118.8$ mA まで増え、並列部の電圧は $V_{par} \approx 0.118$ V まで下がります。すると $I_3 = 0.118/1 \approx 118.2$ mA、$I_2 = 0.118/200 \approx 0.59$ mA。ほぼ全電流が $R_3$ を通り、$R_2$ 側はほとんど素通りされます。これがいわゆる「低抵抗側への電流集中」で、ヒューズ・分流器・保護回路の設計で必ず考慮される現象です。

## まとめ

- 直並列回路は、**並列部を $R_{par}=R_2R_3/(R_2+R_3)$ にまとめて**単純な直列に化けさせると解ける
- KVL から $I_{total}=V/(R_1+R_{par})$、KCL から $I_{total}=I_2+I_3$ が得られる
- 既定値では $I_{total}=54.5$ mA、$I_2=32.7$ mA、$I_3=21.8$ mA で、$I_2+I_3$ が全電流と一致する
- 並列分岐の電流は抵抗に反比例し、**小さい抵抗側に多く流れる**
- 純抵抗回路は非線形項が無いので、25 行ほどの閉じた式でそのまま解ける

オームの法則が「素子 1 個」のルールなら、キルヒホッフの法則は「回路全体」をつなぐルールです。分流器・LED の並列駆動・配電の電圧降下など、実務の回路設計はこの 2 法則の上に成り立っています。
