## 磁気振り子とは

3 つの磁石の上に、鉄の振り子をぶら下げて揺らす。空気抵抗でいつかは止まりますが、**どの磁石の上で止まるか**は——出発点をほんの少しずらすだけで——まったく変わってしまいます。

出発点を色で塗り分けると（磁石 1 に落ちる点は赤、2 は緑、3 は青…）、境界が無限に入り組んだ**フラクタル吸引盆（basin of attraction）**が現れます。決定論的なのに事実上予測不能——散逸系（エネルギーが減る系）に現れるカオスの代表例です。

この記事では：

1. 減衰＋3 磁石の運動方程式と RK4 実装
2. 吸引盆をピクセルごとに塗る方法
3. 境界がなぜフラクタルになるのか（初期値鋭敏性）

## 運動方程式

振り子のおもり（平面座標 $(x,y)$）には 3 つの力が働きます：**中心に戻す復元力**、**速度に比例する減衰**、そして各磁石への**引力**。磁石は平面より高さ $h$ だけ下にあるので、距離に $h$ が効きます：

$$
\ddot{x} = -\frac{g}{L}x - b\,\dot{x} + \sum_{k=1}^{3} m_s\frac{x_k - x}{\left((x-x_k)^2 + (y-y_k)^2 + h^2\right)^{3/2}}
$$

$y$ についても同様。NovaSolver のツールは $g=1$、減衰 $b$・磁力 $m_s$・長さ $L$・磁石高さ $h$ をスライダーで調整できます。3 つの磁石は中心から半径 $0.8$ の正三角形に置くのが自然です：

$$
(0,\ 0.8),\quad (-0.693,\ -0.4),\quad (0.693,\ -0.4)
$$

（角度 $90°,210°,330°$。対称に置くと 3 つの吸引盆がほぼ均等になります。）

## JavaScript 実装（RK4）

加速度を返す関数を書き、RK4（$dt=0.05$）で時間を進めます：

```javascript
const g = 1, L = 1;
const mag = [ {x: 0, y: 0.8}, {x: -0.693, y: -0.4}, {x: 0.693, y: -0.4} ];

function accel(x, y, vx, vy, b, ms, h) {
  let ax = -(g/L)*x - b*vx;
  let ay = -(g/L)*y - b*vy;
  for (const m of mag) {
    const dx = m.x - x, dy = m.y - y;
    const r3 = Math.pow(dx*dx + dy*dy + h*h, 1.5);
    ax += ms * dx / r3;
    ay += ms * dy / r3;
  }
  return [ax, ay];
}
```

おもりを十分長く積分すると、減衰で速度が落ち、最後はどれか 1 つの磁石の真上で静止します。「最後に一番近い磁石の番号」がその出発点の**行き先**です。

## 吸引盆を塗る

画面の各ピクセルを「振り子の初期位置」とみなし、行き先の磁石の色で塗ると吸引盆ができます：

```javascript
function basinColor(x0, y0) {
  let x = x0, y = y0, vx = 0, vy = 0;
  for (let i = 0; i < 2500; i++) {
    // RK4 で1ステップ（accel を4回評価）...
    [x, y, vx, vy] = rk4Step(x, y, vx, vy);
    if (vx*vx + vy*vy < 1e-4 && i > 200) break;  // 静止
  }
  // 一番近い磁石のインデックスを返す → 色に対応
  return nearestMagnet(x, y);
}
```

対称配置で塗ると、3 色がほぼ均等（実測で約 **32% / 34% / 34%**）に分かれます。問題はその**境界**です。

## 境界はフラクタル

磁石の近くは「素直にその磁石へ落ちる」安定した領域ですが、3 つの磁石の中間あたりでは、おもりが磁石の間を何度も行き来した末に行き先が決まります。このため、**隣り合うピクセルでも行き先が違う**——境界が無限に細かく入り組みます。

実際、中心を通る水平線（$y=0$）に沿って 150 点をサンプリングすると、行き先の色が **39 回も切り替わり**ました。これがフラクタル境界の指紋です。境界上では初期位置の任意の精度の差が結果を変えうるので、**実質的に予測不可能**になります。

![パラメータを変えると吸引盆が変形する](/images/magnetic-pendulum/slider-anim.gif)

ローレンツや二重振り子の「軌道が指数的に発散する」カオスとは少し違い、こちらは**複数の安定状態（アトラクタ）＋フラクタルな境界**という、散逸系特有のカオスです。同じ構造は、化学反応の最終状態、ニューラルネットの収束先、最適化の局所解など「最終的にどこへ落ち着くか」が問題になる場面に広く現れます。

## まとめ

- 磁気振り子は「復元力＋減衰＋3 磁石の引力」で記述し、RK4 で積分する
- 出発点ごとの行き先を塗ると**フラクタル吸引盆**になる（対称配置で約 1/3 ずつ）
- 境界は無限に入り組み（$y=0$ 線で 39 回の色変化）、初期値鋭敏性により予測不能
- 「軌道の発散」型とは別の、**多安定＋フラクタル境界**型のカオス

決定論的な法則から「予測できなさ」が生まれる——その最も美しい絵がフラクタル吸引盆です。
