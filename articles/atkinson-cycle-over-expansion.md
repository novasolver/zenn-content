## アトキンソンサイクルとは

ガソリンエンジンの理想サイクルといえばオットーサイクルですが、ハイブリッド車のエンジンの多くは**アトキンソンサイクル**で動いています。その核心は一言でいうと、**膨張行程（仕事を取り出す行程）を圧縮行程より長くする**こと。

オットーサイクルでは圧縮と膨張でピストンの動く距離が同じなので、排気弁が開く瞬間の燃焼ガスはまだ大気圧よりかなり高い圧力をもったまま捨てられます。アトキンソンサイクルは、このガスを**吸気圧力 $P_1$ まで完全に膨張させ切る**ことで、その「まだ押せる力」をピストン仕事として回収します。だから「完全膨張サイクル」「過膨張サイクル」とも呼ばれます。

この記事では：

1. 理想アトキンソンサイクルの 4 行程と熱効率の式
2. 20 行ほどの JavaScript による各状態点の計算
3. 同じ圧縮比でオットーサイクルより効率が高くなることを数値で確認

## 4 つの行程と状態点

理想アトキンソンサイクルは、空気を作動流体とする以下の 4 行程でモデル化します（空気標準サイクル）：

| 行程 | 内容 | 変化 |
|---|---|---|
| 1→2 | 断熱（等エントロピー）圧縮 | $T_2 = T_1 r^{\gamma-1}$ |
| 2→3 | 定容加熱（燃焼） | $T_3 = T_2 + q_{in}/c_v$ |
| 3→4 | 断熱膨張（吸気圧力 $P_1$ まで） | $T_4 = T_3\left(P_1/P_3\right)^{(\gamma-1)/\gamma}$ |
| 4→1 | 定圧放熱 | $q_{out}=c_p(T_4-T_1)$ |

ここで $r$ は圧縮比、$\gamma$ は比熱比、$c_v,\,c_p$ はそれぞれ定容・定圧比熱です。オットーサイクルとの決定的な違いは**放熱が定圧（4→1）で起こる**点で、放熱量に $c_p$ を使うところにあります。これが効率を押し上げます。

## 熱効率の式

熱効率は「投入した熱のうち仕事になった割合」なので：

$$
\eta = 1 - \frac{q_{out}}{q_{in}}, \qquad q_{out} = c_p\,(T_4 - T_1)
$$

膨張比は、ガスが吸気圧力まで膨張する終点 $V_4$ と圧縮終点 $V_2$ の比で、

$$
r_{exp} = \frac{V_4}{V_2} = \left(\frac{P_3}{P_1}\right)^{1/\gamma}
$$

と書けます。$P_3$ は燃焼後の最高圧力です。**この $r_{exp}$ が圧縮比 $r$ より必ず大きくなる**こと（＝過膨張）が、アトキンソンサイクルの効率の源です。

## JavaScript で各状態点を計算する

ツールの計算ロジックはそのまま JavaScript で再現できます。空気の気体定数 $R=287\,\mathrm{J/(kg\cdot K)}$ から $c_v,\,c_p$ を作り、状態点を順番にたどるだけです：

```javascript
const R_AIR = 287;            // J/(kg·K)

function atkinson(r, g, T1, P1, qIn) {  // qIn は kJ/kg
  const cv = R_AIR / (g - 1);
  const cp = g * cv;

  // 1→2 断熱圧縮
  const T2 = T1 * Math.pow(r, g - 1);
  const P2 = P1 * Math.pow(r, g);

  // 2→3 定容加熱
  const T3 = T2 + (qIn * 1000) / cv;
  const P3 = P2 * T3 / T2;

  // 3→4 吸気圧力 P1 まで断熱膨張
  const T4 = T3 * Math.pow(P1 / P3, (g - 1) / g);

  // 熱効率と膨張比
  const qOut = cp * (T4 - T1);
  const eta  = 1 - qOut / (qIn * 1000);
  const rExp = Math.pow(P3 / P1, 1 / g);

  // 同じ圧縮比のオットーサイクル
  const etaOtto = 1 - 1 / Math.pow(r, g - 1);

  return { T2, T3, P3, T4, eta, rExp, etaOtto };
}

// デフォルト条件（r=10, γ=1.4, T1=300K, P1=100kPa, qIn=1800kJ/kg）
console.log(atkinson(10, 1.4, 300, 100, 1800));
// eta ≈ 0.691, etaOtto ≈ 0.602, rExp ≈ 28.5
```

デフォルト条件で計算すると、最高温度 $T_3\approx3262\,\mathrm{K}$、最高圧力 $P_3\approx10{,}874\,\mathrm{kPa}$、膨張比 $r_{exp}\approx28.5$ となり、圧縮比 10 の **約 2.85 倍**まで膨張していることが分かります。

## P-V 線図で「回収する仕事」を見る

各状態点を P-V 平面にプロットすると、3→4 の膨張カーブが圧縮始点 $V_1$ をはるかに超えて右へ伸びます。この長く伸びた部分が、オットーサイクルなら捨てていた仕事を回収している領域です。

![アトキンソンサイクルの P-V 線図と効率カーブ](/images/atkinson-cycle/charts-closeup.png)

ツールのアニメーションでは、サイクルが囲む面積（青の網掛け）が**正味仕事**に対応し、緑のマーカーが 1→2→3→4 の各行程を巡回します。膨張行程（3→4）が特に強調表示され、過膨張の様子が一目で分かります。

## オットーサイクルとの差を数値で確かめる

同じ圧縮比で比べると、アトキンソンは常にオットーより高効率です。比熱比 $\gamma=1.4$、$T_1=300\,\mathrm{K}$、$P_1=100\,\mathrm{kPa}$、$q_{in}=1800\,\mathrm{kJ/kg}$ 固定で、圧縮比 $r$ を振った結果が次の表です：

| 圧縮比 $r$ | $\eta_{\text{Atkinson}}$ | $\eta_{\text{Otto}}$ | 差 | $r_{exp}/r$ |
|---|---|---|---|---|
| 8 | 66.6% | 56.5% | +10.2pt | 2.99 |
| 10 | 69.1% | 60.2% | +8.9pt | 2.85 |
| 12 | 70.9% | 63.0% | +7.9pt | 2.74 |
| 14 | 72.4% | 65.2% | +7.2pt | 2.65 |
| 16 | 73.6% | 67.0% | +6.6pt | 2.57 |

デフォルトの圧縮比 10 では、アトキンソンが約 69%、オットーが約 60% で、**9 ポイント近い差**があります。これが捨てていた排気の圧力エネルギーを仕事に変えた分です。

ただし、これらは**理想化された空気標準サイクルの値**である点に注意してください。実際のエンジンでは燃焼の有限速度・壁面への熱損失・吸排気の絞り損失・摩擦損失などで正味の熱効率は大きく下がります。表の値は「パラメータが効率に効く向き」を見る教材としての上限の目安と考えるのが安全です。

> なぜ効率が良いのに普及が遅れたのか。膨張を長くするぶん実効的な吸気量が減り、同じエンジンサイズあたりの出力（パワー）が下がるからです。ハイブリッド車では足りない出力を電気モーターが補えるため、エンジンを効率最優先のアトキンソンサイクルで運転できるようになりました。実機の多くは可変バルブタイミングで吸気弁を遅閉じする「ミラーサイクル」方式で実装されています。

## ツールで遊ぶ

NovaSolver のツールでは、**圧縮比 r スライダー**を動かすと、熱効率 η と膨張比/圧縮比がその場で変化します：

![圧縮比を動かすと効率と膨張比が変わる](/images/atkinson-cycle/slider-anim.gif)

試してほしい操作：

- **圧縮比 r スライダー**（8〜16）を上げて、「熱効率 η」カードと「オットー比較」カードが伸びるのを観察
- **比熱比 γ スライダー**（1.2〜1.5）を変えて、効率カーブ全体がどう動くかを見る
- **加熱量 q_in スライダー**（500〜3000 kJ/kg）で最高温度 T₃・最高圧力 P₃ がどこまで上がるか確認
- **吸気温度 T₁・吸気圧力 P₁** を変えて、膨張の終点（完全膨張の位置）がどう動くかを見る
- 右側の **「熱効率 vs 圧縮比」グラフ**で、青のアトキンソン線がオレンジのオットー線の上にあることを確認

## まとめ

- アトキンソンサイクルは膨張行程を圧縮行程より長くし、放熱を定圧で行う過膨張サイクル
- 熱効率は $\eta = 1 - c_p(T_4-T_1)/q_{in}$、膨張比 $r_{exp}=(P_3/P_1)^{1/\gamma}$ は常に圧縮比より大きい
- デフォルト条件（圧縮比 10）で η≈69%、同条件のオットー（≈60%）より約 9 ポイント高い（理想値）
- 効率と出力はトレードオフで、その出力低下をモーターが補えるハイブリッド車で主流になった

「捨てている熱をどこまで回収できるか」という熱力学の基本問題を、4 行程と数本の式で体感できるのがアトキンソンサイクルの面白さです。
