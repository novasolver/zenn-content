## アルキメデスの原理とは

「物体を水に沈めると、押しのけた水の重さと同じだけ軽くなる」。紀元前 3 世紀のアルキメデスが見つけたこの法則は、船・潜水艦・気球・氷山——浮き沈みのすべてを支配します。

流体中の物体には、**押しのけた（排除した）流体の重さに等しい浮力** が上向きに働きます：

$$
F_b = \rho_{\text{fluid}} \cdot g \cdot V_{\text{submerged}}
$$

一方、物体に働く重力は

$$
W = \rho_{\text{obj}} \cdot g \cdot V_{\text{obj}}
$$

合力（完全水没時）は

$$
F_{\text{net}} = F_b - W = g\,V(\rho_{\text{fluid}} - \rho_{\text{obj}})
$$

符号がすべてを決めます。$F_{\text{net}}>0$ なら浮上、$<0$ なら沈降、$=0$ なら中性浮力。ポイントは、**浮力は流体と物体の密度差だけで決まり、水深には依存しない** ことです。この記事では、

1. 浮く／沈むを分ける密度の比較
2. 浮体が「何割沈むか」を決める式
3. 20 行の JavaScript での浮力計算

を実際の数値で確かめます。

## 浮体は何割沈むか

水に浮く物体は、ちょうど自重とつり合うところまで沈みます。平衡時（浮遊）には

$$
\rho_{\text{obj}}\,V_{\text{total}}\,g = \rho_{\text{fluid}}\,V_{\text{sub}}\,g
$$

が成り立ち、これを整理すると **水没割合** は密度比そのものになります：

$$
\frac{V_{\text{sub}}}{V_{\text{total}}} = \frac{\rho_{\text{obj}}}{\rho_{\text{fluid}}}
$$

氷の密度は約 917 kg/m³、海水は約 1025 kg/m³。だから氷山は

$$
\frac{917}{1025} \approx 0.895
$$

つまり **89.5% が海面下**、水面上に出るのはわずか 10.5%。「氷山の一角」という言葉はここから来ています。淡水（1000 kg/m³）だと $917/1000 = 91.7\%$ が沈み、海水よりわずかに深く沈みます。

## 20 行で浮力を計算する

NovaSolver のツールが内部で回しているのと同じ計算を書き出します。重力加速度は $g=9.81\,\text{m/s}^2$ です：

```javascript
const G = 9.81;

// robj:物体密度, V:体積, rfluid:流体密度, subPct:水没率(0-1)
function buoyancy(robj, V, rfluid, subPct) {
  const Vsub = V * subPct;          // 排除した流体の体積
  const Fb = rfluid * G * Vsub;     // 浮力（押しのけた流体の重さ）
  const W  = robj  * G * V;         // 重力
  const Fnet = Fb - W;              // 合力（+なら浮上）
  const ratio = Fb / W;             // 浮力/重力 比
  return { Fb, W, Fnet, ratio };
}

// 鋼鉄球: 7800 kg/m³, 0.001 m³(1L), 海水, 完全水没
const s = buoyancy(7800, 0.001, 1025, 1.0);
console.log(s.Fb.toFixed(2), s.W.toFixed(2), s.Fnet.toFixed(2));
// 10.06  76.52  -66.46  → 沈降（重力が浮力の約7.6倍）
```

鋼鉄球は浮力比 0.131、つまり浮力は重力の 13% しかなく、勢いよく沈みます。鉄そのものは水の 7.8 倍重いのですから当然です。では鋼鉄の船がなぜ浮くのか——船体は内部が空洞で、**空気を含めた平均密度** が水より小さいからです。同じ材料でも形状で排除する水の体積を増やせば浮きます（浮力は形状ではなく排除体積で決まる）。

## 流体を変えると浮く／沈むが反転する

浮き沈みは物体と流体の **密度比** で決まるので、流体を変えると結果が逆転します。代表的な組み合わせを計算すると：

| 物体 | 流体 | 密度比 | 結果 | 水没割合 |
|---|---|---|---|---|
| 鉄/鋼（7800） | 海水（1025） | 7.61 | 沈む | 全没 |
| 鉄/鋼（7800） | 水銀（13600） | 0.574 | **浮く** | 57.4% |
| 鉛（11340） | 水銀（13600） | 0.834 | 浮く | 83.4% |
| 氷（917） | 海水（1025） | 0.895 | 浮く | 89.5% |
| 木材（600） | 海水（1025） | 0.585 | 浮く | 58.5% |

鉄は水には沈みますが、水銀（13600 kg/m³）の中では 57.4% を沈めて浮きます。鉛さえも水銀には浮く——密度比がすべてを決めるという、アルキメデスの原理の本質がここに表れています。

## まとめ

- 浮力 $F_b=\rho_{\text{fluid}}\,g\,V_{\text{sub}}$ は押しのけた流体の重さに等しく、水深に依存しない
- 浮く／沈むは密度比 $\rho_{\text{obj}}/\rho_{\text{fluid}}$ で決まる
- 浮体の水没割合は密度比そのもの：氷/海水は 89.5%（氷山の一角）
- 鋼鉄球は浮力比 0.131 で沈むが、船は空気を含む平均密度で浮く
- 流体を水銀にすれば鉄（57.4% 沈）も鉛（83.4% 沈）も浮く

密度という一つの量で、船・氷山・潜水艦・気球の挙動がすべて説明できる——アルキメデスの原理は、流体力学の出発点でありながら最も応用範囲の広い法則の一つです。
