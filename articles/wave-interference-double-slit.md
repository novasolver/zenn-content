## 2つの波が出会うと何が起きるか

水面の波紋が交わる場所、ノイズキャンセリングヘッドホン、ギターのチューニングで聞こえる「ワンワン」という揺れ——これらはすべて**波の重ね合わせ（干渉）** の現れです。2つの波が同じ場所に来ると、変位は単純に足し算されます（重ね合わせの原理）。たったこれだけのルールから、強め合い・弱め合い・うなり・定在波という多彩な現象が生まれます。

この記事では重ね合わせの原理を出発点に、位相差・周波数差が作るパターンを JavaScript で再現し、数値で確かめます。

## 重ね合わせの原理

2つの正弦波を

$$
y_1 = A_1\sin(k_1 x - \omega_1 t + \phi_1),\qquad
y_2 = A_2\sin(k_2 x - \omega_2 t + \phi_2)
$$

とすると（波数 $k_i = 2\pi f_i / v$、角周波数 $\omega_i = 2\pi f_i$）、合成波は単純な和です。

$$
y = y_1 + y_2
$$

この足し算だけで、パラメータの組み合わせ次第で全く違う表情が現れます。

![成分波と合成波：強め合いと弱め合い](/images/wave-interference/charts-closeup.png)

## 4つの代表パターン

**① 強め合い（同位相）** 同じ振幅・周波数で位相差 $\Delta\phi=0$ なら、合成振幅は $A_1+A_2$。$A_1=A_2=1$ なら **2 倍**になります（上図右上）。

**② 弱め合い（逆位相）** 位相差 $\Delta\phi=180°$ では山と谷が打ち消し合い、合成振幅は **ほぼ 0**（上図右下）。ノイズキャンセリングはこれを能動的に作ります。

**③ うなり（ビート）** わずかに周波数の違う 2 波を重ねると、振幅がゆっくり脈打ちます。**うなり周波数**は周波数差そのものです。

$$
f_{\text{beat}} = |f_1 - f_2|
$$

ツール既定値（$f_1=5\,\mathrm{Hz}$、$f_2=6\,\mathrm{Hz}$）なら $f_{\text{beat}}=1\,\mathrm{Hz}$、つまり 1 秒に 1 回振幅が膨らみます。楽器のチューニングで 440 Hz と 443 Hz を鳴らすと毎秒 3 回のうなりが聞こえる、というのもこの式です。

**④ 定在波** 同じ波が逆向きに進むと、節と腹が固定された**定在波**になります。

$$
y = 2A\cos(kx)\sin(\omega t)
$$

波形が左右に進まず、その場で振動するのが特徴です。

## 波長とパラメータの関係

波長は速度と周波数から $\lambda = v/f$。既定値（$v=5\,\mathrm{m/s}$）では

$$
\lambda_1 = \frac{5}{5} = 1.00\,\mathrm{m},\qquad
\lambda_2 = \frac{5}{6} = 0.833\,\mathrm{m}
$$

この $\lambda_1\ne\lambda_2$ がうなりの空間パターンを生みます。

## JavaScript 実装

実装は重ね合わせの原理をそのままコードにするだけです。

```javascript
const w1 = 2*Math.PI*f1, w2 = 2*Math.PI*f2;
const k1 = w1/vw, k2 = w2/vw;
const y1 = x => a1 * Math.sin(k1*x - w1*t + phi1);
const y2 = x => a2 * Math.sin(k2*x - w2*t + phi2);
const ys = x => y1(x) + y2(x);            // 合成 = 単純な和

// 統計
const beat = Math.abs(f1 - f2);            // うなり周波数
const lambda1 = vw / f1, lambda2 = vw / f2; // 波長
```

合成波の振幅・うなり・定在波はすべてこの 1 行 `y1(x)+y2(x)` から自動的に立ち上がります。

## まとめ

- 波の干渉は**重ね合わせの原理** $y=y_1+y_2$ だけで説明できる
- 同位相で強め合い（振幅 $A_1+A_2$）、逆位相で弱め合い（≈0）
- 周波数差は**うなり** $f_{\text{beat}}=|f_1-f_2|$（既定 1 Hz）を生む
- 逆向きの波は**定在波** $y=2A\cos(kx)\sin(\omega t)$ を作る

光の干渉、音響設計、量子力学の波動関数まで、あらゆる波動現象の土台となる「重ね合わせ」を、スライダーで体感してみてください。
