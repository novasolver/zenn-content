## ベンチュリ流量計とは

配管の途中をなだらかに絞り、その「くびれ」の前後にできる**圧力差（差圧）**から流量を測る——それがベンチュリ流量計です。可動部がいっさいなく、原理はベルヌーイの定理と連続の式だけ。それでいて上下水道の送水管から発電所のボイラ給水まで、世界中の現場で使われています。

仕組みのカギは 2 つの古典法則です。管が細くなると流れが**速く**なり（連続の式）、流れが速くなると圧力が**下がる**（ベルヌーイの定理）。だから細いスロート部の圧力は太い上流部より低くなり、その差を測れば流量を逆算できます。

この記事では：

1. ベルヌーイ＋連続の式から流量 $Q$ の公式を導く
2. 「流量は差圧の**平方根**に比例する」という非線形性を数値で確かめる
3. 約 25 行の JavaScript で実装し、なぜベンチュリ管は損失が小さいのかを見る

## 流量の式を導く

非圧縮・定常の流れを考えます。上流（断面 1）とスロート（断面 2）でベルヌーイの定理を書くと：

$$
p_1 + \frac{1}{2}\rho V_1^2 = p_2 + \frac{1}{2}\rho V_2^2
$$

連続の式 $A_1 V_1 = A_2 V_2$ より $V_1 = (A_2/A_1)V_2$。ここで**絞り比** $\beta = D_2/D_1$ を導入すると、断面積比は $A_2/A_1 = \beta^2$ なので $V_1 = \beta^2 V_2$。これを代入して差圧 $\Delta p = p_1 - p_2$ について解くと：

$$
\Delta p = \frac{1}{2}\rho V_2^2\,(1 - \beta^4)
$$

$V_2$ について解き、実流量との差を補正する**流量係数** $C_d$ を掛けると、体積流量 $Q = C_d A_2 V_2$ は：

$$
Q = C_d\,A_2\sqrt{\dfrac{2\,\Delta p}{\rho\,(1-\beta^4)}},\qquad
A_2 = \frac{\pi D_2^2}{4}
$$

これがツールの中核式です。$C_d$ は理想式の予測流量に対する実流量の比で、粘性による境界層などのため $C_d < 1$。ベンチュリ管は流れが滑らかなので $C_d \approx 0.95\text{–}0.99$ と 1 に近く、これが高精度の理由です（鋭いエッジのオリフィス板は $C_d \approx 0.6$）。

## デフォルト値で計算してみる

ツールの初期値 $D_1=100\,\text{mm}$、$D_2=50\,\text{mm}$、$\Delta p=20\,\text{kPa}$、$\rho=998\,\text{kg/m}^3$、$C_d=0.980$ を入れてみます。

まず絞り比は $\beta = 50/100 = 0.5$、補正項は $1-\beta^4 = 1 - 0.0625 = 0.9375$。スロート断面積は $A_2 = \pi(0.05)^2/4 = 1.963\times10^{-3}\,\text{m}^2$。

理想スロート流速：

$$
V_2^{\text{ideal}} = \sqrt{\frac{2\times 20000}{998\times 0.9375}} = 6.539\ \text{m/s}
$$

体積流量：

$$
Q = 0.980 \times 1.963\times10^{-3} \times 6.539 = 1.258\times10^{-2}\ \text{m}^3/\text{s} = 45.3\ \text{m}^3/\text{h}
$$

| 出力 | 値 |
|---|---|
| 体積流量 $Q$ | $45.3\ \text{m}^3/\text{h}$ |
| スロート流速 $V_2$ | $6.41\ \text{m/s}$ |
| 上流流速 $V_1$ | $1.60\ \text{m/s}$ |
| 絞り比 $\beta$ | $0.500$ |
| レイノルズ数（スロート） | $3.20\times10^{5}$ |
| 永久圧力損失 | $2.50\ \text{kPa}$ |

ツールの計算結果カードと同じ値です。$V_2/V_1 = 4 = 1/\beta^2$ は連続の式そのもの。スロートで流れが 4 倍速くなり、その運動エネルギーの増加分が圧力降下として現れます。

## 25 行で実装する

ツールの `compute()` の核心はこれだけです：

```javascript
function venturi(D1, D2, dp_kPa, rho, Cd) {
  // D1,D2: mm  dp: kPa  rho: kg/m^3
  const A1 = Math.PI * Math.pow(D1 / 1000, 2) / 4;   // m^2
  const A2 = Math.PI * Math.pow(D2 / 1000, 2) / 4;   // m^2
  const beta  = D2 / D1;
  const beta4 = Math.pow(beta, 4);

  // ベルヌーイ＋連続の式による理想スロート流速
  const V2ideal = Math.sqrt(2 * (dp_kPa * 1000) / (rho * (1 - beta4)));

  const Q  = Cd * A2 * V2ideal;   // m^3/s
  const Qh = Q * 3600;            // m^3/h
  const V2 = Q / A2;              // スロート流速 m/s
  const V1 = Q / A1;              // 上流流速 m/s

  // 永久圧力損失（差圧の約10〜15%だけ失う）
  const loss = (0.10 + 0.05 * beta) * dp_kPa;  // kPa
  return { Qh, V2, V1, beta, loss };
}

const r = venturi(100, 50, 20, 998, 0.980);
console.log(r.Qh.toFixed(1), r.V2.toFixed(2), r.loss.toFixed(2));
// 45.3 6.41 2.50
```

ループも数値積分も不要で、閉じた式を 1 回評価するだけ。スライダーを動かすたびにこの関数を呼び、6 つの統計カードと 2 本のグラフを即時更新しています。

## 差圧の平方根に比例する

この流量計のいちばん面白い性質は、$Q \propto \sqrt{\Delta p}$ という**非線形性**です。式の $\sqrt{\cdot}$ から明らかですが、数値で見ると直感に反します。デフォルト形状（$\beta=0.5$）で差圧を振ると：

| 差圧 $\Delta p$ | 体積流量 $Q$ | $Q/Q(20)$ |
|---|---|---|
| $5\ \text{kPa}$ | $22.6\ \text{m}^3/\text{h}$ | $0.50$ |
| $20\ \text{kPa}$ | $45.3\ \text{m}^3/\text{h}$ | $1.00$ |
| $80\ \text{kPa}$ | $90.6\ \text{m}^3/\text{h}$ | $2.00$ |
| $180\ \text{kPa}$ | $135.9\ \text{m}^3/\text{h}$ | $3.00$ |

差圧を**4 倍**にして、ようやく流量が**2 倍**。グラフは原点近くで急に立ち上がり、その後ゆるやかになる平方根カーブを描きます。弱点は低流量域で、差圧がうんと小さくなるため計測精度が落ちます。だからベンチュリ管は「ある程度しっかり流れているとき」が得意です。

## なぜ損失が小さいのか

差圧 $\Delta p$ と**永久圧力損失**は別物です。圧力タップで測る $\Delta p$ は上流とスロートの瞬間的な差にすぎず、スロートで下がった圧力は後段の長く緩やかな末広がり（ディフューザ）で大部分が回復します。ツールは永久損失を経験式

$$
\Delta p_{\text{loss}} = (0.10 + 0.05\,\beta)\,\Delta p
$$

でモデル化しています。$\beta=0.5$、$\Delta p=20\,\text{kPa}$ なら $\Delta p_{\text{loss}} = 2.5\,\text{kPa}$、つまり**差圧の 12.5% だけ**を永久に失い、回復率は 87.5% です。

これがベンチュリ管の真価です。鋭いエッジのオリフィス板は流れが急に剥離し、差圧の 50〜80% を永久損失として捨てます。24 時間連続運転する送水ラインでは、この差がそのままポンプ電力に跳ね返るため、初期コストが高くてもベンチュリ管が選ばれます。

> 注意：永久損失の式は設計概算用の経験近似です。実際の損失はディフューザの拡がり角・表面粗さ・レイノルズ数に依存します。スロート部の $Re$ が $10^5$ を下回ると $C_d$ が低下するため、ツールも警告を出します。

試してほしい操作：

- **差圧 $\Delta p$ スライダー**を動かして、「流量 vs 差圧 Δp」グラフの平方根カーブをなぞる。差圧 4 倍で流量 2 倍を体感
- **スロート径 $D_2$** を変えて絞り比 $\beta$ を 0.4〜0.75 で振り、「流量 vs 絞り比 β」グラフで計測のしやすさと損失の綱引きを見る
- **アニメーション**：流体が収縮コーン→スロートで加速→ディフューザで減速する様子と、管軸方向の**圧力プロファイル** $p(x)$（スロートで急降下→回復）を観察
- $D_2 \ge D_1$ にすると「絞りになっていない」警告が、$Re < 10^5$ で低レイノルズ数の精度警告が出る

## まとめ

- ベンチュリ流量計は $Q = C_d A_2\sqrt{2\Delta p/(\rho(1-\beta^4))}$ で差圧から流量を測る
- 流量は差圧の**平方根**に比例：$\Delta p$ を 4 倍にして $Q$ は 2 倍（デフォルトで $20\,\text{kPa}\to45.3\,\text{m}^3/\text{h}$、$80\,\text{kPa}\to90.6\,\text{m}^3/\text{h}$）
- 閉じた式 1 本なので約 25 行の JavaScript で実装でき、ループ不要
- ディフューザが圧力を回復するため永久損失は差圧の約 10〜15%（$\beta=0.5$ で 12.5%）。これがオリフィス板（50〜80%）に対する省エネ上の強み

「くびれを作って圧力差を読むだけ」という単純な原理が、ベルヌーイと連続の式で精密な流量計になる——古典流体力学が今も現役で働いている好例です。
