## レイノルズ輸送定理とは

ホースの先を細くすると水が勢いよく飛ぶ。配管の曲がり角はブラケットでがっちり固定されている。これらに共通する「流体が及ぼす力」を、流れの中身を一切追わずに **入口と出口の条件だけ** から計算できる——それがレイノルズ輸送定理（Reynolds Transport Theorem, RTT）です。

粒子を1つずつ追いかけるラグランジュ描像の保存則を、空間に固定した **コントロールボリューム（検査体積, CV）** の上の式に翻訳します。任意の保存量 $B$（質量・運動量・エネルギー）について、その総量の時間変化は次の形で書けます：

$$
\frac{dB_{sys}}{dt} = \frac{\partial}{\partial t}\!\int_{CV}\!\rho b\,dV + \int_{CS}\!\rho b\,(\vec{V}\!\cdot\!\hat{n})\,dA
$$

ここで $b = B/m$ は単位質量あたりの量、$CS$ は CV の境界面（コントロールサーフェス）です。右辺第1項は箱の中に溜まる分（非定常項）、第2項は境界を通って出入りするフラックスを表します。

この記事では、定常流（第1項=0）を仮定し、

2. ノズル・90°曲がり管・拡大管の力を求める JavaScript 実装
3. 数値を実際に再現して、どこに「効く」のかを確かめる

を見ていきます。

## 3本の派生式

定常・非圧縮（$\rho$ 一定）を仮定すると、RTT は実用的な3本の式に落ちます。

**連続の式（質量保存）** — $b=1$ を代入すると、入口と出口の質量流量が等しくなります：

$$
\dot{m} = \rho A_1 V_1 = \rho A_2 V_2
$$

円管なら断面積 $A = \pi D^2/4$ なので、出口速度は径比の2乗で決まります：

$$
V_2 = V_1\left(\frac{A_1}{A_2}\right) = V_1\left(\frac{D_1}{D_2}\right)^2
$$

径を半分にすると速度は **4倍**。ノズルで水が加速するのはこのためです。

**運動量方程式** — $b=\vec{V}$ を代入すると、CV に働く力の総和が運動量フラックスの差に等しくなります：

$$
\sum \vec{F} = \dot{m}\,(\vec{V}_2 - \vec{V}_1)
$$

**ベルヌーイ式（エネルギー方程式の特殊解）** — 非粘性・定常・水平・単一流線という条件を課すと、圧力が求まります：

$$
P_1 + \tfrac{1}{2}\rho V_1^2 = P_2 + \tfrac{1}{2}\rho V_2^2
$$

ベルヌーイ式は RTT の一般形の特殊ケースで、粘性損失があれば損失項 $h_L$ を足すだけで一般化できます。

## JavaScript 実装

シミュレーターの計算ロジックはこの3本をそのまま連立しているだけです。要点を約25行に抜き出します：

```javascript
// 入力: 径[mm], 速度[m/s], 圧力[kPa], 密度[kg/m^3]
function solve(type, D1mm, D2mm, V1, P1kPa, rho) {
  const D1 = D1mm / 1000, D2 = D2mm / 1000, P1 = P1kPa * 1000;
  const A1 = Math.PI * D1 * D1 / 4;
  const A2 = Math.PI * D2 * D2 / 4;
  const mdot = rho * A1 * V1;        // 連続の式
  const V2 = mdot / (rho * A2);      // V2 = V1 (D1/D2)^2
  const P2 = P1 + 0.5 * rho * (V1*V1 - V2*V2);  // ベルヌーイ
  let Fx, Fy;
  if (type === "bend") {             // 90°曲がり管: x→y へ方向転換
    Fx = mdot * V1 + P1 * A1;        // x方向の運動量を打ち消す力
    Fy = mdot * V2 + P2 * A2;        // y方向の運動量を生む力
  } else {                           // ノズル / 拡大管: 直進
    Fx = mdot * (V2 - V1) + P2 * A2 - P1 * A1;
    Fy = 0;
  }
  return { mdot, V2, P2: P2/1000, Ftot: Math.hypot(Fx, Fy) };
}

console.log(solve("nozzle", 100, 50, 5.0, 200, 1000));
// { mdot: 39.27, V2: 20, P2: 12.5, Ftot: 957.2 }
```

ポイントは曲がり管の符号です。直進するノズルでは「運動量の増分 + 圧力差」が素直に足し算になりますが、90°曲がり管では入口の x 方向運動量を **ゼロに落とす** 力と、出口の y 方向運動量を **新たに生む** 力が直交2成分として現れ、合力 $|F|=\sqrt{F_x^2+F_y^2}$ になります。

## 数値を実際に確かめる

デフォルト設定（縮小ノズル、$D_1=100\,\text{mm}$, $D_2=50\,\text{mm}$, $V_1=5\,\text{m/s}$, $P_1=200\,\text{kPa}$, $\rho=1000\,\text{kg/m}^3$）を上の式で手計算と突き合わせます。

径比 $D_1/D_2 = 2$ なので $V_2 = 5\times 2^2 = 20\,\text{m/s}$。質量流量は $\dot{m} = 1000\times(\pi\cdot 0.1^2/4)\times 5 = 39.27\,\text{kg/s}$。ベルヌーイから

$$
P_2 = 200 + \tfrac{1}{2}\cdot 1000\cdot(5^2 - 20^2)/1000 = 12.5\,\text{kPa}
$$

速度が4倍になった代償に、圧力は 200 → 12.5 kPa まで落ちます。ツール出力と完全一致します。

| 形状 | $V_2$ | $P_2$ | 合計反力 $\lvert F\rvert$ |
|---|---|---|---|
| 縮小ノズル（既定） | 20.0 m/s | 12.5 kPa | 957.2 N |
| 90°曲がり管（既定） | 20.0 m/s | 12.5 kPa | 1943.9 N |
| 拡大管（$D_1{=}50,D_2{=}100$） | 1.25 m/s | 211.7 kPa | — |

90°曲がり管では $F_x=1767\,\text{N}$, $F_y=810\,\text{N}$ から $|F|=\sqrt{1767^2+810^2}=1944\,\text{N}$。同じ流れでも、方向転換を伴うだけで反力がノズルの約2倍になるのが分かります。配管の曲がり部を頑丈に固定する理由がここにあります。

拡大管（ディフューザー）では逆に速度が $5\to1.25\,\text{m/s}$ に落ち、ベルヌーイにより圧力が $200\to211.7\,\text{kPa}$ へ **回復** します。運動エネルギーが圧力エネルギーに変換される、ターボ機械や換気ダクトの出口で使われる原理です。

![圧力・速度分布と力成分の内訳](/images/reynolds-transport/charts-closeup.png)

左の棒グラフは縮小ノズルの入口・出口での圧力（青）と速度（緑）の対比、右は90°曲がり管の力成分の内訳です。右図で「運動量変化 $\dot{m}\,\Delta V$」と「圧力項 $P A$」が逆符号で打ち消し合いながら合力を作っている様子が読み取れます。

## まとめ

- レイノルズ輸送定理は、固定した検査体積の入口・出口だけから流体の力を計算する枠組み
- 定常・非圧縮なら、連続の式・運動量方程式・ベルヌーイ式の3本に落ちる
- 縮小ノズルでは $V_2=V_1(D_1/D_2)^2$ で加速し、圧力が落ちる（既定で 200→12.5 kPa）
- 90°曲がり管は方向転換のぶん反力が大きい（既定で約1944 N、ノズルの約2倍）
- わずか25行の JavaScript で再現でき、結果は手計算と一致する

「流れの中身を解かずに、境界の収支だけで力が分かる」——これが詳細 CFD の前に設計の当たりをつける、コントロールボリューム解析の威力です。
