## モンテカルロ法とは何か

**モンテカルロ法**は、決定的に解けない問題を **「乱数で点を打って統計を取る」** という乱暴な方法で近似するアプローチです。

定番の例題が **π の推定**：

1. 単位正方形 $[0, 1]^2$ 上に乱数で点をばらまく
2. 半径 1 の四分円（中心 0、第一象限）内に入った点の数を数える
3. 内側の点の数 / 全点数 ≈ 四分円の面積 / 正方形の面積 = $\pi / 4$
4. これを 4 倍すれば $\pi$ の推定値

シンプルすぎて拍子抜けしますが、**「乱数で積分する」** という発想は計算物理・金融工学・機械学習で実際に多用されます。

## 数式とアルゴリズム

理屈は単純です。一様乱数 $(X, Y) \sim U[0,1]^2$ に対し、確率

$$
P(X^2 + Y^2 \leq 1) = \frac{\pi/4}{1} = \frac{\pi}{4}
$$

なので、$N$ 個サンプリングして内側の点数を $K$ とすれば：

$$
\hat{\pi} = 4 \cdot \frac{K}{N}
$$

これが π の **不偏推定量** になります。

## 20 行の JavaScript

```javascript
function estimatePi(N) {
  let inside = 0;
  for (let i = 0; i < N; i++) {
    const x = Math.random();
    const y = Math.random();
    if (x * x + y * y <= 1) inside++;
  }
  return 4 * inside / N;
}

console.log(estimatePi(1000));      // ≈ 3.16
console.log(estimatePi(100000));    // ≈ 3.141
console.log(estimatePi(10000000));  // ≈ 3.1416
```

これだけで π が出ます。

## 誤差の理論

**ここが本当に面白いところ。** モンテカルロ法の誤差は理論的に：

$$
\text{標準誤差} \propto \frac{1}{\sqrt{N}}
$$

つまり、**精度を 10 倍にしたければ点を 100 倍打つ必要がある**。

- $N = 100$ → 誤差 ≈ ±0.2
- $N = 10000$ → 誤差 ≈ ±0.02
- $N = 1000000$ → 誤差 ≈ ±0.002

これは「めちゃくちゃ遅い」収束です。π を 6 桁求めるには **$10^{12}$ 個の点**が必要になります。

それでも使われる理由は：

- **次元の呪いに強い**：高次元積分でも収束速度は変わらない（決定的求積は $O(N^{-1/d})$ で死ぬ）
- **並列化が自明**：点の生成が独立
- **コードが激短い**：上の 6 行で終わる

## ピーク誤差は何で決まるか

統計的に、誤差の上限はざっくり：

$$
|\hat{\pi} - \pi| \lesssim \frac{2}{\sqrt{N}}
$$

これは **チェルノフ境界 / Hoeffding の不等式** の応用です。実用上は「点数を 4 倍にすれば誤差が半分になる」と覚えておくと感覚が合います。

## まとめ

- モンテカルロ法は「乱数 × 統計」で積分を近似する手法
- π の推定は 6 行で書ける
- 誤差は $O(1/\sqrt{N})$ で遅い、が次元の呪いに強い
- 高次元積分・物理シミュレーション・金融工学で実用

「正確に求められないなら、確率で殴る」という発想は強力です。
