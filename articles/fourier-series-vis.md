## サインの足し算を「回る円の鎖」で見る

フーリエ級数は「どんな周期波もサイン波の重ね合わせで作れる」という定理です。式だけ見ると抽象的ですが、各サイン波を**複素平面上で回転するベクトル（フェーザー）**として描くと、級数が一気に直感的になります。

半径の異なる円を、前の円の縁から次の円を生やすように**先端から先端へとつなげていく**。それぞれの円が違う速さで回ると、鎖の一番先の点が上下し、その高さの時間変化がちょうど合成波形になる——これがフェーザー可視化のアイデアです。この記事では、各波形のフーリエ係数を「円の半径と回転数」として読み替え、JavaScript で鎖を組み立て、なぜ先端の軌跡が方形波や鋸波になるのかを数値で確かめます。

🎡 **動くデモ**: [フーリエ級数可視化ツール（NovaSolver）](https://novasolver.jp/tools/fourier-series-vis.html)

## フェーザーとは何か

1 本のサイン波 $b_n \sin(2\pi n t)$ は、複素平面上を角速度 $2\pi n$ で回る半径 $|b_n|$ のベクトルの**虚部（y 成分）**として表せます。

$$
b_n \sin(2\pi n t) = \operatorname{Im}\!\left[\,|b_n|\,e^{\,i(2\pi n t + \phi_n)}\right]
$$

ここで $n$ は高調波の次数（回転の速さ）、$|b_n|$ は振幅（円の半径）、$\phi_n$ は位相です。係数 $b_n$ が負なら位相を $\pi$ ずらして半径を正に保ちます。NovaSolver のツールも内部でまさにこの形を使い、各項を `{freq: n, amp: b_n, phase: 0}` として保持しています。

級数全体は、これらのフェーザーを**先端から先端へ足し合わせたもの**です。

$$
f(t) = \sum_{n} b_n \sin(2\pi n t)
= \operatorname{Im}\!\left[\sum_n |b_n|\,e^{\,i(2\pi n t + \phi_n)}\right]
$$

つまり「ベクトルの足し算」を幾何的にやっているだけ。鎖の終端の y 座標が、その瞬間の波形の値になります。

## 波形ごとの「円の設計図」

どの円をいくつ、どんな半径で回すか——それを決めるのがフーリエ係数です。代表的な 3 波形（いずれも奇関数なのでサイン係数だけ）は次の通りです。

| 波形 | 係数 $b_n$ | 含む高調波 | 減衰 |
|---|---|---|---|
| 方形波 | $\dfrac{4}{n\pi}$ | 奇数 $n$ のみ | $1/n$（遅い） |
| 鋸波 | $-\dfrac{2}{n\pi}(-1)^{n}$ | 全 $n$ | $1/n$（遅い） |
| 三角波 | $\dfrac{8}{n^2\pi^2}\sin\dfrac{n\pi}{2}$ | 奇数 $n$ のみ | $1/n^2$（速い） |

基本波（$n=1$）の半径を計算すると、方形波は $4/\pi \approx 1.273$、鋸波は $2/\pi \approx 0.637$、三角波は $8/\pi^2 \approx 0.811$。一番大きな円が基本波で、次数が上がるほど円は小さくなり、回転は速くなります。

減衰の速さがそのまま「何個の円で十分か」を決めます。方形波・鋸波は半径が $1/n$ でしか縮まないので小さな円が長く尾を引き、角がシャープ。三角波は $1/n^2$ で一気に縮むので、$|b_3|/|b_1| = 1/9$ とすぐ無視できる大きさになり、わずかな円数でなめらかに収束します。

## JavaScript で鎖を組み立てる

ツールの係数定義をそのまま使い、各フェーザーの先端座標を順に足していくだけで鎖が作れます。

```javascript
function harmonics(wave, N) {        // 円の設計図（半径=amp, 回転数=freq）
  const terms = [];
  for (let k = 1; k <= N; k++) {
    if (wave === 'square')   { const n = 2*k-1; terms.push({freq:n, amp:(4/Math.PI)/n}); }
    if (wave === 'sawtooth') { const s=(k%2?1:-1); terms.push({freq:k, amp:(2/Math.PI)*s/k}); }
    if (wave === 'triangle') { const n=2*k-1, s=(k%2?1:-1);
                               terms.push({freq:n, amp:(8/(Math.PI*Math.PI))*s/(n*n)}); }
  }
  return terms;
}

function chainTipY(wave, N, t) {     // 先端の高さ = その瞬間の波形値
  let x = 0, y = 0;
  for (const {freq, amp} of harmonics(wave, N)) {
    const ang = freq * t * 2*Math.PI + (amp < 0 ? Math.PI : 0);
    x += Math.abs(amp) * Math.cos(ang);
    y += Math.abs(amp) * Math.sin(ang);   // y成分の和が合成波形
  }
  return y;
}
```

`t` を 0 から 1 まで動かすと `chainTipY` が描く軌跡が合成波形です。負の係数を $\pi$ の位相回転で吸収しているので、$|amp|\sin(\theta+\pi) = -|amp|\sin\theta = amp\cdot\sin\theta$ となり、結局ふつうの部分和 $\sum b_n\sin(2\pi n t)$ と一致します。

## なぜ先端の軌跡が波形になるのか

左の図は方形波 $N=7$ の鎖を位相 $t=0$ で止めたもの。$t=0$ では全フェーザーのサイン成分がゼロなので、腕は一直線に伸びて先端は中心線上にあります。時間が進むと各円が自分の次数の速さで回り、先端が上下します。

右の図はその先端の高さを横軸 $t$ に並べたもの。基本波（破線）だけだと滑らかな 1 つの山ですが、奇数次の小さな円を 7 個重ねると、平らな天井と急な立ち上がりを持つ方形波らしい形になります。同時に角の近くに**さざ波（オーバーシュート）**が見えます。

## ギブス現象：円を増やしても消えない行き過ぎ

方形波で円の数 $N$ を増やすと、波形は理想形に近づきますが、角（不連続点）のすぐ脇の行き過ぎは**消えません**。ツールの係数で部分和の最大値を計算すると、

| 円の数 $N$ | 部分和のピーク | 振幅 1 からの行き過ぎ |
|---|---|---|
| 7 | 1.181 | +18.1% |
| 15 | 1.179 | +17.9% |
| 30 | 1.179 | +17.9% |
| 50 | 1.179 | +17.9% |

$N$ をいくら増やしても、ピークは約 $1.179$（振幅 1 に対して約 **+18%**）に張り付きます。ジャンプの高さ（$-1$ から $+1$ の $2$）を基準にすると約 **8.95%**——これが有名なギブス現象で、極限は解析的に $\frac{2}{\pi}\!\int_0^{\pi}\frac{\sin x}{x}\,dx - 1 \approx 0.1790$ と求まります。円を足すと行き過ぎの**幅**は狭くなりますが、**高さ**は約 9%（ジャンプ基準）に収束して残ります。

一方、三角波は連続なのでギブス現象が起きません。係数が $1/n^2$ で速く減るため、$N=3$ で厳密形との RMS 誤差は約 0.016、$N=7$ で約 0.004 と、少ない円数でなめらかに収束します。

> 補足：ツールの「最大振幅」カードは厳密なピーク値ではなく、各円の半径の単純な総和 $\sum|b_n|$ を表示します。方形波 $N=7$ では $\sum|b_n| \approx 2.489$ で、これは全フェーザーが同時に真上を向いた仮想的な上限であり、実際の波形ピーク（約 1.18）とは別物です。鎖の腕が一斉に揃うことはないため、波形のピークは常にこの総和より小さくなります。

## まとめ

- 各サイン波は複素平面上の回転フェーザーで、半径＝振幅 $|b_n|$、回転数＝高調波次数 $n$
- フェーザーを先端から先端へつなぐと、鎖の終端の y 座標がそのまま合成波形になる
- 係数の減衰が円数の必要量を決める：方形波・鋸波は $1/n$（多くの円が必要）、三角波は $1/n^2$（少数で収束）
- 方形波では円を増やしても角の行き過ぎ（ギブス現象）が約 9%（ジャンプ基準）残る

「サインの足し算」を回る円の鎖として眺めると、フーリエ級数が幾何の問題に変わります。円を 1 つずつ足しながら、波形が立ち上がる瞬間を体感してみてください。
