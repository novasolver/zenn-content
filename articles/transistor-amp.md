## トランジスタ増幅回路の「動作点」とは

エミッタ接地（コモンエミッタ）増幅回路は、微弱な信号を大きくするアナログ電子回路の基本中の基本です。マイクの数 mV を扱える大きさまで持ち上げる、あの増幅です。

ところがこの回路、ただトランジスタに信号を入れれば増幅されるわけではありません。**信号が来る前に、トランジスタをちょうどいい「待機状態」に置いておく**必要があります。この待機状態が **Qポイント（動作点）** で、入力信号がゼロのときのコレクタ電流 $I_C$ とコレクタ-エミッタ間電圧 $V_{CE}$ の組で決まります。

この記事では、電圧分割バイアス回路を例に：

1. Qポイント（$I_C$, $V_{CE}$）が回路定数からどう決まるか
2. 電圧利得 $A_v$ と相互コンダクタンス $g_m$ の関係
3. JavaScript で Qポイントを計算する実装と、数値の検証

を順に見ていきます。

## 電圧分割バイアスでQポイントを決める

エミッタ接地回路では、ベースに **R1・R2 の分圧** で直流電圧を与えます。ベース電圧 $V_B$ は、ベース電流が小さいと仮定すれば単純な分圧で近似できます：

$$
V_B = V_{CC}\cdot\frac{R_2}{R_1+R_2}
$$

ベース-エミッタ間は順方向で約 0.7 V 落ちるので、エミッタ電圧とエミッタ電流（≒コレクタ電流）は：

$$
V_E = V_B - 0.7,\qquad I_C \approx \frac{V_E}{R_E}
$$

コレクタ側は $R_C$ による電圧降下を引いて、$V_{CE}$ が決まります：

$$
V_{CE} = V_{CC} - I_C R_C - V_E
$$

| 記号 | 意味 | 既定値 |
|---|---|---|
| $V_{CC}$ | 電源電圧 | 12 V |
| $R_1,\ R_2$ | バイアス分圧抵抗 | 47 kΩ / 10 kΩ |
| $R_C$ | コレクタ抵抗 | 4.7 kΩ |
| $R_E$ | エミッタ抵抗 | 1.0 kΩ |
| $\beta$ | 電流増幅率 | 150 |

このバイアス方式が好まれるのは、$\beta$ のばらつきに強いからです。$I_C$ は $V_B$ と $R_E$ でほぼ決まり、$\beta$ をほとんど含みません。トランジスタの個体差や温度変化で $\beta$ が動いても、Qポイントが大きくずれにくいわけです。

## 既定値でQポイントをPythonで実測する

ツールと同じ式を Python で再現し、既定値での数値を確かめます：

```python
VCC, R1, R2, RC, RE = 12, 47e3, 10e3, 4.7e3, 1.0e3
VB  = VCC * R2 / (R1 + R2)      # 2.105 V
VE  = VB - 0.7                  # 1.405 V
IC  = VE / RE                   # 1.405 mA
VCE = VCC - IC * RC - VE        # 3.99 V
print(VB, VE, IC*1e3, VCE)
# 2.105  1.405  1.405  3.99
```

得られた Qポイントは **$I_C = 1.41\ \mathrm{mA}$、$V_{CE} = 3.99\ \mathrm{V}$**。$V_{CE}$ が電源 12 V の 1/3 ほどに収まっており、飽和（$V_{CE}<0.2$ V）にも遮断（$V_{CE}>V_{CC}$）にも余裕がある「能動域」の良好な動作点です。

## 直流負荷線とQポイントの交点

Qポイントは、グラフ上では **トランジスタの IC-VCE 特性曲線** と **直流負荷線** の交点として現れます。負荷線はキルヒホッフの電圧則から、$R_C$ と $R_E$ を通る直流経路で決まります：

$$
I_C = \frac{V_{CC} - V_{CE}}{R_C + R_E}
$$

両端は、$V_{CE}=0$ で $I_C = V_{CC}/(R_C+R_E) = 12/5.7 = 2.11\ \mathrm{mA}$、$I_C=0$ で $V_{CE}=V_{CC}=12\ \mathrm{V}$。この 2 点を結ぶ直線上に Qポイントが乗ります。

![IC-VCE特性・負荷線・Qポイントと、REによる利得変化](/images/transistor-amp/charts-closeup.png)

左図がその交点。緑の点（Qポイント）が負荷線のちょうど中ほどにあるのが、歪みの少ない設計の目印です。Qポイントが負荷線の端（飽和側・遮断側）に寄っていると、大きな信号を入れたときに波形の片側がクリップしてしまいます。

## 電圧利得は gm で決まる

小信号（交流）の電圧利得は、相互コンダクタンス $g_m$ と負荷抵抗で決まります。エミッタが交流的に接地されている（バイパスされている）場合：

$$
A_v = -g_m (R_C \parallel R_L),\qquad g_m = \frac{I_C}{V_T}
$$

ここで $V_T$ は熱電圧で、室温では約 26 mV。マイナス符号は出力が入力と逆位相になることを表します。既定の Qポイント $I_C=1.41\ \mathrm{mA}$ を入れると：

$$
g_m = \frac{1.41\ \mathrm{mA}}{26\ \mathrm{mV}} = 54\ \mathrm{mS},\qquad
R_C \parallel R_L = \frac{4.7\cdot 10}{4.7+10} = 3.20\ \mathrm{k\Omega}
$$

$$
|A_v| = 54\ \mathrm{mS}\times 3.20\ \mathrm{k\Omega} \approx 173
$$

約 173 倍、デシベルにすると $20\log_{10}173 \approx 44.7\ \mathrm{dB}$。ツールの計算結果カードにもこの値が表示されます。利得が $I_C$ に比例する（$g_m \propto I_C$）点が重要で、Qポイントを動かすと利得も一緒に動きます。

この「動作点が利得を決める」関係は、実務でそのまま設計の勘所になります。たとえばオーディオアンプの初段では、大きな利得を稼ぎたい一方で、Qポイントを負荷線の中央に置いて出力スイングを最大限確保したい。両者は $I_C$ を介して引っ張り合うため、$R_C$ と $R_E$ のバランスで折り合いをつけます。センサ信号の前置増幅でも事情は同じで、微弱な変化を歪みなく増幅するには、まず安定したQポイントを置くことが出発点になります。スライダーで $I_C$ を動かしながら $|A_v|$ と $V_{CE}$ の余裕がどう変わるかを眺めると、この綱引きが目で見えてきます。

## JavaScript で 25 行の実装

ツールの計算ロジックはそのまま JavaScript で書けます。スライダーの値を読み、Qポイントと利得を返すだけです：

```javascript
const VT = 0.026; // 熱電圧 [V] @室温

function solve(VCC, beta, R1, R2, RC, RE, RL) {
  // 電圧分割バイアス → Qポイント
  const VB  = VCC * R2 / (R1 + R2);
  const VE  = Math.max(0, VB - 0.7);
  const IC  = RE > 0 ? VE / RE : 0;
  const VCE = VCC - IC * RC - VE;

  // 小信号利得（エミッタは交流接地と仮定）
  const gm    = IC > 0 ? IC / VT : 0;
  const RCpar = (RC * RL) / (RC + RL);
  const Av    = gm * RCpar;

  // 動作状態の判定
  const state = VCE < 0.2 ? "飽和"
              : VCE > VCC - 0.2 ? "カットオフ" : "能動域";
  return { IC, VCE, Av, state };
}

// 既定値（抵抗はΩに換算して渡す）
const q = solve(12, 150, 47e3, 10e3, 4.7e3, 1e3, 10e3);
console.log(q.IC * 1e3, q.VCE, q.Av, q.state);
// 1.405  3.99  172.8  能動域
```

出力は Python での実測値と一致します（$I_C=1.41$ mA、$V_{CE}=3.99$ V、$|A_v|=172.8$、能動域）。

## R2 を動かすとQポイントが負荷線上を滑る

このツールのいちばん直感的な遊び方は、**R2 スライダーで分圧比を変える**ことです。$R_2$ を大きくすると $V_B$ が上がって $I_C$ が増え、Qポイントは負荷線に沿って左上（飽和側）へ動きます。逆に小さくすると右下（遮断側）へ。

![R2を動かすとQポイントが負荷線上を移動する](/images/transistor-amp/slider-anim.gif)

試してほしい操作：

- **R2 スライダー**を動かして、Qポイントが負荷線上を滑り、状態カードが「能動域 → 飽和」「能動域 → カットオフ」と切り替わる境目を探す
- **RE スライダー**を上げると $I_C$ が下がり、$g_m$ も下がって**電圧利得 $|A_v|$ が減る**（右図の曲線の通り）
- **RC スライダー**で負荷線の傾きを変え、出力スイングと利得のトレードオフを見る
- **「ボード線図」タブ**に切り替えて、結合コンデンサによる低域カットオフと帯域の様子を確認する

## ツールを使うときの注意点

このシミュレーターは設計の感覚をつかむための**近似モデル**である点は押さえておきましょう。

- **$V_{BE}=0.7$ V 固定・ベース電流は無視**：実機ではベース電流が分圧を乱すため、$R_1,R_2$ が大きいと誤差が出ます。
- **利得式に $R_E$ が現れない**：表示される $|A_v|=g_m(R_C\parallel R_L)$ は「$R_E$ が交流的にバイパスされている」前提の値です。$R_E$ をそのまま残す（バイパスしない）設計では、実際の利得はおよそ $R_C\parallel R_L$ を $R_E$ で割った値（数倍〜十数倍）まで下がります。$R_E$ は Qポイントには効きますが、表示利得には直接効かない、という二面性に注意してください。
- **帯域幅は代表値の仮定**：高域カットオフは接合容量を 5 pF と仮定した目安で、実トランジスタの $f_T$ とは別物です。

これらは「ざっくり当たりをつける」用途では十分実用的で、Qポイントと利得のトレードオフを体で覚えるには最適です。

## まとめ

- Qポイントは $V_B=V_{CC}\,R_2/(R_1+R_2)$ → $I_C=(V_B-0.7)/R_E$ → $V_{CE}=V_{CC}-I_CR_C-V_E$ で決まる
- 既定値では $I_C=1.41$ mA、$V_{CE}=3.99$ V の良好な能動域（電源 12 V の約 1/3）
- 電圧利得は $|A_v|=g_m(R_C\parallel R_L)$、$g_m=I_C/V_T$。既定で約 173 倍（44.7 dB）
- Qポイントは IC-VCE 特性と直流負荷線の交点。負荷線の中ほどに置くと歪みが少ない

「バイアスで動作点を決め、その点まわりの小信号で増幅する」という二段構えは、アナログ回路設計に共通する考え方です。スライダーを動かして、動作点と利得が連動する感覚をつかんでみてください。
