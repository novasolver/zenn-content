## 変化球を曲げる「マグヌス力」とは

カーブが落ち、スライダーが横へ滑る——その正体は **マグヌス力（Magnus force）** という流体力です。回転しながら空気中を進む球は、表面が空気を引きずる向きと進行方向が合う側で気流が速く、逆側で遅くなります。ベルヌーイの関係から速い側は圧力が下がり、遅い側は上がる。この圧力差が、進行方向と回転軸の両方に垂直な力として球を押し曲げます。

この記事では：

1. マグヌス力と空気抵抗の式、そして変化量を決める要素
2. 一定加速度近似で投球軌道を出す JavaScript 実装
3. 球種ごとの変化量を数値で比較

⚾ **動くデモ**: [野球変化球・マグヌス力シミュレーター（NovaSolver）](https://novasolver.jp/tools/baseball-pitch-magnus.html)

## マグヌス力と空気抵抗の式

マグヌス力の大きさは、揚力係数 $C_L$ を使って次のように書けます：

$$
F_{\text{Magnus}} = \frac{1}{2}\,\rho\,C_L\,A\,v^2
$$

ここで $\rho$ は空気密度（約 $1.225\ \mathrm{kg/m^3}$）、$A$ は球の断面積、$v$ は球速です。揚力係数 $C_L$ は無次元の **スピンパラメータ** $S$ で決まります：

$$
S = \frac{r\,\omega}{v}
$$

$r$ は球の半径、$\omega$ は回転角速度です。$S$ は「ボール表面の周速度 ÷ 並進速度」を表し、回転が速い・球速が遅いほど大きくなります。同時に空気抵抗（ドラッグ）も働きます：

$$
F_{\text{drag}} = \frac{1}{2}\,\rho\,C_D\,A\,v^2
$$

NovaSolver のツールは野球ボールの値（$r=0.037\ \mathrm{m}$、質量 $m=0.145\ \mathrm{kg}$、$C_D=0.35$）を使い、揚力係数を $C_L = 0.1 + 0.4\min(S, 0.5)$ という単純な増加モデルで与えています。スピンが増えるほど $C_L$ が上がり、変化量が大きくなる、という傾向を捉えた近似です。

## 20行で書く投球軌道

軌道は、重力とマグヌス力による一定加速度として近似計算できます。回転軸の角度で、マグヌス力を縦成分（落下を増減）と横成分（横変化）に振り分けます：

```javascript
const RHO = 1.225, M = 0.145, R = 0.037;
const A = Math.PI * R * R, CD = 0.35, G = 9.81;

function pitch(speedKmh, rpm, axisDeg, dist = 18.4) {
  const v0 = speedKmh / 3.6;             // km/h -> m/s
  const omega = rpm * 2 * Math.PI / 60;  // rpm -> rad/s
  const axis = axisDeg * Math.PI / 180;

  const S  = R * omega / v0;             // スピンパラメータ
  const CL = 0.1 + 0.4 * Math.min(S, 0.5);
  const Fmag  = 0.5 * RHO * CL * A * v0 * v0;
  const Fdrag = 0.5 * RHO * CD * A * v0 * v0;

  const ay = -G + Fmag * Math.cos(axis) / M;  // 縦加速度
  const ax = Fmag * Math.sin(axis) / M;       // 横加速度
  const t  = dist / v0;                       // 滞空時間（等速近似）

  return {
    Fmag, Fdrag,
    drop:  Math.abs(0.5 * ay * t * t) * 100,  // cm
    break: Math.abs(0.5 * ax * t * t) * 100,  // cm
  };
}
```

スライダーのプリセット（球速 135 km/h・2400 rpm・軸 50°）を入れると、マグヌス力 $\approx 0.74\ \mathrm{N}$、空気抵抗 $\approx 1.30\ \mathrm{N}$、滞空時間 $0.49\ \mathrm{s}$ といった値が得られます。

## 軌道を描く

ツールでは、この計算で得た軌道を Chart.js で「側面（縦断面）」「真上（俯瞰）」「球種比較」の3タブに描き分けます：

![球種ごとの落下量・横変化量の比較](/images/baseball-pitch-magnus/charts-closeup.png)

ポイントは、変化量が **滞空時間の2乗** に効くこと。$\Delta \approx \frac{1}{2}\,a\,t^2$ なので、同じ力でも遅い球ほど（$t$ が長く）大きく曲がります。一方、速い球は力 $F \propto v^2$ そのものが大きい。「球速 vs 滞空時間」のせめぎ合いが、球種ごとの変化量を決めます。

## 球種ごとの変化量を数値で見る

ツールの6プリセットを上記モデルで計算すると、次のようになります（投球距離 18.4 m）：

| 球種 | 球速 | 回転数 | $S$ | $C_L$ | マグヌス力 | 滞空時間 |
|---|---|---|---|---|---|---|
| ストレート | 145 km/h | 2200 rpm | 0.212 | 0.185 | 0.79 N | 0.457 s |
| カーブ | 120 km/h | 2800 rpm | 0.325 | 0.230 | 0.67 N | 0.552 s |
| スライダー | 135 km/h | 2400 rpm | 0.248 | 0.199 | 0.74 N | 0.491 s |
| フォーク | 130 km/h | 200 rpm | 0.021 | 0.109 | 0.37 N | 0.510 s |
| ナックル | 105 km/h | 50 rpm | 0.007 | 0.103 | 0.23 N | 0.631 s |

回転数の少ないフォーク・ナックルは $S$ がほぼ0で、$C_L$ も下限（0.1付近）に張りつきます。マグヌス力が小さいため、これらは「揚力で支えられない＝重力で素直に落ちる」球になります。逆にカーブは $S=0.325$ と最も高く、揚力係数も 0.23 まで上がります。

ナックルの横変化が0になるのは、回転軸を0°（完全に横向き）に設定しているためで、マグヌス力が縦成分に振られる計算になっています。実際のナックルは回転がほぼ無いことで縫い目周りの気流が不規則に剥離し、予測しにくい揺れを生むとされますが、本モデルはその非対称剥離までは扱っていません。

## まとめ

- 変化球はマグヌス力 $F = \frac{1}{2}\rho C_L A v^2$ で曲がり、$C_L$ はスピンパラメータ $S = r\omega/v$ で増える
- 変化量は加速度 × 滞空時間² で決まり、「球速」と「滞空時間」のバランスで球種差が生まれる
- 回転の少ないフォーク・ナックルはマグヌス力が小さく、重力主体で落ちる
- 重力＋流体力を一定加速度で積分する近似は、20行ほどの JavaScript で書ける

「単純な圧力差が球の軌道を曲げる」というマグヌス効果は、サッカーのバナナシュートや卓球のドライブ、ゴルフのフックにも共通する普遍的な現象です。回転と球速を変えて、その手応えを確かめてみてください。
