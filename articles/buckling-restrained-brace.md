## 座屈拘束ブレースとは

建物の壁に斜めに入った「筋かい（ブレース）」は、地震の横揺れに抵抗する代表的な部材です。ところが普通の鋼製ブレースには弱点があります。**引張には強いのに、押されると簡単に座屈してしまう**のです。細長い棒を両側から押せばグニャッと曲がる——あれと同じで、一度座屈すると圧縮側の踏ん張りが一気に失われます。地震は建物を行ったり来たり揺らすので、引張と圧縮が交互に来ます。普通のブレースは「片側だけ弱い不公平な部材」になってしまうわけです。

**座屈拘束ブレース（Buckling-Restrained Brace, BRB）** は、この問題を「仕事の分担」で解決します。軸力を負担して降伏する細い**芯材**を中心に置き、その周りを鋼管にモルタルを詰めた**拘束材**で包んで、横にふくらもうとするのを物理的に押さえ込む。しかも拘束材は芯材と意図的に縁切り（アンボンド）してあり、軸力そのものは負担しません。横から支える役に徹するのです。

座屈しなくなった芯材は、圧縮側でも引張側とまったく同じように降伏できます。その結果、力-変形のグラフ（履歴ループ）が**太く左右対称**な、理想的な弾塑性ダンパーのような形になります。

## 基本となる4つの量

BRBの設計で押さえるべき量は、すべて芯材の寸法と材料から決まります。

| 量 | 式 | 意味 |
|---|---|---|
| 降伏耐力 $P_y$ | $A_{core}\,F_y$ | 芯材が降伏する軸力 |
| 軸剛性 $k$ | $A_{core}\,E / L$ | 弾性域でのばね定数 |
| 降伏変位 $\delta_y$ | $F_y\,L / E$ | 降伏が始まる軸変形 |
| 延性率（要求）$\mu$ | $\delta_{design} / \delta_y$ | 設計時にどれだけ塑性化するか |

降伏耐力は芯材の断面積と降伏応力の積だけで決まります：

$$
P_y = A_{core}\,F_y
$$

ここで重要なのは、**BRBは座屈しないので $P_y$ が引張側でも圧縮側でもほぼ同じ**という点です。普通のブレースなら圧縮側の耐力は座屈荷重で頭打ちになりますが、BRBにはそれがありません。だから設計が単純で見通しよくなります。拘束材を太くしても $P_y$ は上がらない——上げたいなら芯材を見直す、というのが設計の勘所です。

## 数値で確かめる

デフォルト設定（芯材断面積 $A_{core}=2500\,\mathrm{mm^2}$、降伏応力 $F_y=235\,\mathrm{MPa}$、有効長さ $L=3500\,\mathrm{mm}$、ヤング率 $E=205\,\mathrm{GPa}$、設計層間変形 $\delta_{design}=40\,\mathrm{mm}$）で各量を計算してみます。

まず降伏耐力：

$$
P_y = 2500 \times 235 = 587{,}500\ \mathrm{N} \approx 587.5\ \mathrm{kN}
$$

軸剛性は $E=205\,\mathrm{GPa}=205{,}000\,\mathrm{MPa}$ として：

$$
k = \frac{2500 \times 205{,}000}{3500} \approx 146{,}429\ \mathrm{N/mm} \approx 146.4\ \mathrm{kN/mm}
$$

降伏変位は $\delta_y = P_y/k = F_y L/E$ なので：

$$
\delta_y = \frac{235 \times 3500}{205{,}000} \approx 4.01\ \mathrm{mm}
$$

延性率（要求）は $\mu = \delta_{design}/\delta_y = 40/4.01 \approx 9.97$。つまりこの設計では、芯材は降伏変位の約10倍まで塑性変形することを要求されています。BRBはこうした大きな延性に耐えられるからこそ、ダンパーとして使えるのです。

## 履歴ループと消費エネルギー

カオスでも乱流でもない、構造ダンパーの主役は**履歴ループが囲む面積**です。これがブレースが熱に変えて捨てた地震エネルギーそのものを表します。

理想化した完全弾塑性ループでは、1サイクル（$\pm\delta_{design}$ まで1往復）の消費エネルギーは次式で近似できます：

$$
E_{cyc} = 4\,P_y\,(\delta_{design} - \delta_y)
$$

係数の $4$ は、対称な長方形ループの4辺がそれぞれ $P_y \times (\delta_{design}-\delta_y)$ の仕事をすることに対応します。デフォルト値を代入すると：

$$
E_{cyc} = 4 \times 587{,}500 \times (40 - 4.01) \approx 8.46\times10^{7}\ \mathrm{N\cdot mm} \approx 84.6\ \mathrm{kJ}
$$

![対称な履歴ループと、設計層間変形に対する消費エネルギー](/images/buckling-restrained-brace/charts-closeup.png)

左が対称な弾塑性ループ。$P_y$ で頭打ちになる水平な「降伏棚」が上下対称に伸び、その間を弾性勾配がつなぎます。普通の座屈するブレースなら、この圧縮側（左下）が大きく絞られた「ピンチング」形になり、面積＝吸収エネルギーが激減します。右は設計層間変形を横軸にとった $E_{cyc}$ で、$\delta_{design}>\delta_y$ の範囲ではほぼ直線的に増えます。変形を大きく許すほど、たくさんのエネルギーを吸収できるわけです。

## JavaScriptで20行の計算ロジック

このツールの計算はシンプルな代数式だけで完結します。ブラウザ上の実装は次のようになります：

```javascript
function computeBRB(A, Fy, L, E_GPa, drift) {
  const E = E_GPa * 1000;              // GPa -> MPa
  const Py = A * Fy;                   // 降伏耐力 [N]
  const k  = A * E / L;                // 軸剛性 [N/mm]
  const dy = Py / k;                   // 降伏変位 [mm] = Fy*L/E
  const mu = dy > 0 ? drift / dy : 0;  // 延性率（要求）
  // 完全弾塑性ループ1サイクルの消費エネルギー [N*mm]
  const Ecyc   = 4 * Py * Math.max(0, drift - dy);
  const strain = drift / L * 100;      // 芯材ひずみ [%]
  return {
    Py_kN: Py / 1000,
    k_kNmm: k / 1000,
    dy_mm: dy,
    mu: mu,
    Ecyc_kJ: Ecyc / 1e6,
    strain_pct: strain,
  };
}

console.log(computeBRB(2500, 235, 3500, 205, 40));
// { Py_kN: 587.5, k_kNmm: 146.4, dy_mm: 4.01,
//   mu: 9.97, Ecyc_kJ: 84.6, strain_pct: 1.14 }
```

ローレンツ系のような数値積分は不要で、すべて閉じた式です。だからスライダーを動かした瞬間に結果が返ります。

## 設計で最も気をつける「芯材ひずみ」

BRBの性能でいちばん注視すべきなのは、設計地震時に芯材が受ける**ひずみ量**です。これは設計層間変形を芯材の有効長さで割った値で表します：

$$
\varepsilon_{core} = \frac{\delta_{design}}{L} \times 100\ [\%]
$$

デフォルトでは $\varepsilon_{core} = 40/3500 \times 100 \approx 1.14\%$ で、鋼材の延性に十分収まる範囲です。ところが芯材を短くしたり変形を大きくしたりすると、ひずみは一気に増えます。例えば同じ変形で有効長さを $L=1000\,\mathrm{mm}$ にすると $\varepsilon_{core}=4.0\%$、$L=3500\,\mathrm{mm}$ のまま設計層間変形を $105\,\mathrm{mm}$ にしても $\varepsilon_{core}=3.0\%$ に達します。

一般に芯材ひずみが**3%を超える**と、少ない繰り返し回数で芯材が破断する**低サイクル疲労**が問題になります。BRBは数十回規模の繰り返しに耐えることが期待される部材なので、ひずみは余裕をもって計画したいところです。本ツールは芯材ひずみが3%を超えると判定が「ひずみ過大」に切り替わり、有効長さ $L$ を長くするよう促します。なお、これは設計の目安を示すものであり、実際の許容ひずみは採用する芯材鋼種・接合部・適用基準によって異なる点には注意してください。

## ツールで遊ぶ

NovaSolverのツールでは、芯材の寸法・材料・設計変形を変えると、6つの計算結果と3種類のグラフがリアルタイムで更新されます。

![設計層間変形を大きくすると履歴ループが育つ](/images/buckling-restrained-brace/slider-anim.gif)

試してほしい操作：

- **5つのスライダー**（芯材の断面積 $A_{core}$、降伏応力 $F_y$、有効長さ $L$、ヤング率 $E$、設計層間変形）を動かし、降伏耐力・軸剛性・降伏変位・延性率・1サイクル消費エネルギー・芯材ひずみ判定の6つがどう連動するかを見る
- **設計層間変形**を大きくして、履歴ループがどんどん太く育ち、消費エネルギーが増えていく様子を確かめる
- **芯材の有効長さ $L$ を短く**して、芯材ひずみ判定が「ひずみ過大（低サイクル疲労に注意）」へ切り替わる境目を探す
- **降伏応力 $F_y$ を下げる**（低降伏点鋼）と、同じ断面積でも $P_y$ と $\delta_y$ がどう変わるかを比較する
- 中央の**BRB断面アニメーション**で、芯材が引張・圧縮を繰り返しても座屈せず対称に降伏する様子と、右側で同期して描かれる履歴ループのマーカーを観察する
- **履歴ループ**チャートと**消費エネルギー vs 設計層間変形**チャートで、現在の設計点がどこにあるかを確認する

## まとめ

- BRBは「軸力を担う芯材」と「座屈を防ぐ拘束材」に役割を分けた筋かいで、圧縮でも座屈せず対称に降伏する
- 降伏耐力 $P_y = A_{core}F_y$、軸剛性 $k = A_{core}E/L$、降伏変位 $\delta_y = F_yL/E$ という単純な式で主要量が決まる
- デフォルト設定では $P_y=587.5\,\mathrm{kN}$、$k=146.4\,\mathrm{kN/mm}$、$\delta_y=4.01\,\mathrm{mm}$、$\mu\approx9.97$、$E_{cyc}\approx84.6\,\mathrm{kJ}$
- 履歴ループの面積 $E_{cyc}=4P_y(\delta_{design}-\delta_y)$ が吸収する地震エネルギー
- 芯材ひずみ $\varepsilon_{core}=\delta_{design}/L$ が3%を超えると低サイクル疲労に注意

「座屈しない」という一点を工夫しただけで、不公平な筋かいが安定した地震エネルギーの吸収装置に変わる——それがBRBの面白さです。
