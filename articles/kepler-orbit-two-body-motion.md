## 2体問題は「解ける」

[三体問題](https://novasolver.jp/tools/three-body.html)は一般に解けずカオスになりますが、**2 体（太陽と惑星）なら厳密に解けます**。答えは楕円軌道——ケプラーが観測から見抜き、ニュートンが万有引力から導いた、天体力学の出発点です。

ケプラーの 3 法則はこうまとめられます：

1. **第1法則（楕円軌道）**：惑星は太陽を 1 つの焦点とする楕円を描く
2. **第2法則（面積速度一定）**：太陽と惑星を結ぶ線分が等しい時間に等しい面積を掃く
3. **第3法則（調和の法則）**：公転周期の 2 乗は軌道長半径の 3 乗に比例（$T^2 \propto a^3$）

この記事では、これらを数式とコードで確かめます。

📐 **動くデモ**: [ケプラー軌道シミュレーター（NovaSolver）](https://novasolver.jp/tools/kepler-orbit.html)

## 第1法則：楕円の形

軌道長半径 $a$ と離心率 $e$ で楕円が決まります。太陽からの距離は角度 $\theta$（真近点角）の関数：

$$
r(\theta) = \frac{a(1-e^2)}{1 + e\cos\theta}
$$

特別な 2 点が**近日点**（最接近）と**遠日点**（最遠）：

$$
r_{\text{peri}} = a(1-e), \qquad r_{\text{apo}} = a(1+e)
$$

$e=0$ で円、$e\to1$ で細長い楕円。地球は $e=0.017$ でほぼ円、ハレー彗星は $e=0.967$ で極端な楕円です。

## 第2法則：速いところと遅いところ

太陽に近い近日点では速く、遠い遠日点ではゆっくり——その結果、**単位時間に掃く面積が一定**になります。これは角運動量保存の言い換えです。

![等時間で等面積を掃く（ケプラー第2法則）](/images/kepler-orbit/charts-closeup.png)

軌道を**等しい時間間隔**で 8 区間に区切ると、各扇形の面積はすべて等しくなります（数値計算での面積のばらつきは **0.01%**）。図のように、太陽の近くでは「角度は大きいが短い」扇、遠くでは「角度は小さいが長い」扇になり、面積が釣り合います。

速さは **vis-viva（活力）方程式**で与えられます：

$$
v^2 = GM\left(\frac{2}{r} - \frac{1}{a}\right)
$$

近日点と遠日点の速さの比は離心率だけで決まります：

$$
\frac{v_{\text{peri}}}{v_{\text{apo}}} = \frac{1+e}{1-e}
$$

$e=0.5$ なら **ちょうど 3 倍**。$a=1.2\,\text{AU}$ で計算すると、近日点 $r=0.6$ で $v=9.94$、遠日点 $r=1.8$ で $v=3.31$（単位 AU/年）と、確かに比は 3.00 になります。

## 第3法則：周期と大きさ

公転周期 $T$ と長半径 $a$ の関係は：

$$
T^2 = \frac{4\pi^2}{GM}\,a^3
$$

太陽系では年と AU を使うと $T^2 = a^3$ ときれいになります。実際に計算すると：

| 天体 | $a$ [AU] | $T$ [年] | $T^2/a^3$ |
|---|---|---|---|
| 水星 | 0.387 | 0.241 | 1.0000 |
| 地球 | 1.000 | 1.000 | 1.0000 |
| 火星 | 1.524 | 1.881 | 1.0000 |
| ハレー彗星 | 17.8 | 75.1 | 1.0000 |

離心率が違っても $T^2/a^3$ は一定——周期は**長半径だけ**で決まる、というのが第3法則の妙味です。

## JavaScript で軌道を出す

解析解（楕円の式）を描くこともできますが、ニュートンの運動方程式を数値積分すれば 3 法則が「自然に」現れます。近日点から velocity-Verlet で出発させます（$GM=4\pi^2$）：

```javascript
const GM = 4*Math.PI*Math.PI;
let r = a*(1-e);                       // 近日点距離
let pos = [r, 0];
let vel = [0, Math.sqrt(GM*(1+e)/(a*(1-e)))];  // 近日点速度
function acc(p){ const d = Math.hypot(p[0],p[1]); return [-GM*p[0]/d**3, -GM*p[1]/d**3]; }
function step(dt){
  let a0 = acc(pos);
  vel = [vel[0]+a0[0]*dt/2, vel[1]+a0[1]*dt/2];
  pos = [pos[0]+vel[0]*dt, pos[1]+vel[1]*dt];
  let a1 = acc(pos);
  vel = [vel[0]+a1[0]*dt/2, vel[1]+a1[1]*dt/2];
}
```

## ツールで遊ぶ

[ケプラー軌道シミュレーター](https://novasolver.jp/tools/kepler-orbit.html)で試してほしい操作：

- **離心率 e スライダー**を 0 → 0.9 に上げ、円から細長い楕円への変化を見る
- **長半径 a スライダー**を変え、結果表示の **$T^2/a^3$ が一定**であることを確認（第3法則）
- **「等面積表示」**をオンにして、近日点付近で速く・遠日点付近で遅い面積速度一定を観察
- **プリセット**「地球」「火星」「水星」「ハレー彗星」で実際の軌道を比較
- **速度ベクトル**表示で、近日点が最速・遠日点が最遅であることを確認

## まとめ

- 2 体問題は厳密に解け、軌道は太陽を焦点とする楕円（第1法則）
- 面積速度一定（第2法則）＝角運動量保存。等時間の扇は等面積（数値で 0.01%）
- $T^2 = a^3$（第3法則）。周期は長半径だけで決まり、離心率に依らない
- 速さは vis-viva $v^2=GM(2/r-1/a)$、$v_{\text{peri}}/v_{\text{apo}}=(1+e)/(1-e)$

カオスの三体に進む前に、まずは「解ける」二体の美しさを。
