## ローレンツアトラクタとは

**3 本の常微分方程式** から、蝶の形をした無限に複雑な軌道が生まれる。それがローレンツアトラクタです：

$$
\frac{dx}{dt} = \sigma(y - x)
$$
$$
\frac{dy}{dt} = x(\rho - z) - y
$$
$$
\frac{dz}{dt} = xy - \beta z
$$

1963 年、気象学者 Edward Lorenz が大気対流を極端に簡略化したモデルとして導いたものです。たった 3 変数・2 つの非線形項（$xz$ と $xy$）しかないのに、**決定論的なのに長期予測が原理的に不可能**という、カオス理論の象徴になりました。

この記事では：

1. $\sigma, \rho, \beta$ の意味と、カオスが現れる条件
2. RK4（ルンゲ・クッタ 4 次）による 20 行の JavaScript 実装
3. バタフライ効果（初期値鋭敏性）を数値で確かめる

## σ・ρ・β の意味

3 つのパラメータは、もともと流体（大気）の物理量から来ています：

| 記号 | 名前 | 物理的意味 |
|---|---|---|
| $\sigma$ | プラントル数 | 動粘性と熱拡散率の比 |
| $\rho$ | レイリー数（相対値） | 浮力による駆動の強さ |
| $\beta$ | アスペクト比 | 対流ロールの縦横比に関する係数 |

古典的な「蝶」が現れるのは **$\sigma=10,\ \rho=28,\ \beta=8/3$** の組み合わせ。Lorenz 自身が使った値で、いまでも標準パラメータとして使われます。

重要なのは $\rho$ です。$\rho$ が小さいうちは流れは静かで、軌道は一点（固定点）に落ち着きます。ところが、ある臨界値を超えると固定点が不安定になり、軌道はどこにも収束せず蝶の翼の間をさまよい続ける——これがカオスです。

## カオスが始まる臨界点

固定点が不安定化してカオスに突入する $\rho$ の臨界値は、解析的に求められます：

$$
\rho_c = \frac{\sigma(\sigma + \beta + 3)}{\sigma - \beta - 1}
$$

標準パラメータ $\sigma=10,\ \beta=8/3$ を代入すると：

$$
\rho_c = \frac{10(10 + 8/3 + 3)}{10 - 8/3 - 1} = 24.74
$$

つまり $\rho > 24.74$ で持続的なカオスになります。デフォルトの $\rho=28$ はこの少し上にあり、はっきりとカオスが見えるわけです。逆に $\rho$ を 24.74 より下げると、軌道は 2 つの固定点

$$
C_{\pm} = \left(\pm\sqrt{\beta(\rho-1)},\ \pm\sqrt{\beta(\rho-1)},\ \rho-1\right)
$$

のどちらかに巻きついて静止します（$\rho=28$ なら $C_\pm \approx (\pm 8.49,\ \pm 8.49,\ 27)$）。

## RK4 で 20 行の実装

ローレンツ系は解析解を持たないので、数値積分します。精度の高い **ルンゲ・クッタ 4 次（RK4）** が定番です：

```javascript
const sigma = 10, rho = 28, beta = 8 / 3;

// 右辺ベクトル場 f(x,y,z)
function field(x, y, z) {
  return {
    dx: sigma * (y - x),
    dy: x * (rho - z) - y,
    dz: x * y - beta * z,
  };
}

// 1 ステップ進める（dt = 0.01）
function rk4(x, y, z, dt) {
  const k1 = field(x, y, z);
  const k2 = field(x + k1.dx*dt/2, y + k1.dy*dt/2, z + k1.dz*dt/2);
  const k3 = field(x + k2.dx*dt/2, y + k2.dy*dt/2, z + k2.dz*dt/2);
  const k4 = field(x + k3.dx*dt,   y + k3.dy*dt,   z + k3.dz*dt);
  return {
    x: x + (k1.dx + 2*k2.dx + 2*k3.dx + k4.dx) * dt/6,
    y: y + (k1.dy + 2*k2.dy + 2*k3.dy + k4.dy) * dt/6,
    z: z + (k1.dz + 2*k2.dz + 2*k3.dz + k4.dz) * dt/6,
  };
}
```

`(1, 1, 1)` から 5 ステップ回すとこうなります：

```javascript
let s = { x: 1, y: 1, z: 1 };
for (let i = 0; i < 5; i++) {
  console.log(s.x.toFixed(4), s.y.toFixed(4), s.z.toFixed(4));
  s = rk4(s.x, s.y, s.z, 0.01);
}
// 1.0000 1.0000 1.0000
// 1.0126 1.2599 0.9849
// 1.0488 1.5240 0.9731
// 1.1072 1.7983 0.9652
// 1.1869 2.0885 0.9617
```

なぜ RK4 か。オイラー法（1 次）だと $dt=0.01$ でも誤差が蓄積して軌道がアトラクタから滑り落ちますが、RK4 は局所誤差が $O(dt^5)$ と小さく、同じ刻みでも安定して蝶の構造を保ちます。この RK4 は自動車の衝突解析や構造物の地震応答といった CAE の時間積分でも使われる、実務直結の手法です。

## アトラクタを描く

$x, y, z$ の時系列を 3 次元にプロットすると、有名な「蝶」が現れます。NovaSolver のツールでは RK4 をリアルタイムに回し、3D 等角投影で軌道を描いています：

![ローレンツアトラクタの3D軌道](/images/lorenz-attractor/charts-closeup.png)

特徴的な構造：

- **2 枚の翼**：軌道は 2 つの固定点 $C_\pm$ のまわりを回り、不規則なタイミングで翼を乗り換える
- **決して交差しない**：3 次元では軌道が自分自身と交わらない（交われば一意性が破れる）
- **フラクタル次元 ≈ 2.06**：面でも立体でもない、非整数次元の「奇妙なアトラクタ」

## バタフライ効果を数値で確かめる

カオスの核心は **初期値鋭敏性**です。ほぼ同じ点から出発した 2 本の軌道が、指数関数的に離れていきます。

初期値を $(1,1,1)$ と $(1,1,1.00001)$ —— わずか $10^{-5}$ だけずらして両方を積分し、距離 $|a-b|$ を追うと：

```javascript
let a = { x: 1, y: 1, z: 1 };
let b = { x: 1, y: 1, z: 1 + 1e-5 };  // z を 10^-5 だけずらす
const dist = () =>
  Math.hypot(a.x - b.x, a.y - b.y, a.z - b.z);

for (let n = 1; n <= 3000; n++) {
  a = rk4(a.x, a.y, a.z, 0.01);
  b = rk4(b.x, b.y, b.z, 0.01);
}
```

| 時刻 $t$ | 距離 $\lvert a-b\rvert$ |
|---|---|
| 0 | $1.0\times10^{-5}$ |
| 10 | $6.0\times10^{-5}$ |
| 15 | $1.6\times10^{-3}$ |
| 20 | $8.5\times10^{-2}$ |
| 30 | $\approx 36$ |

最初は $10^{-5}$ だった差が、$t\approx30$ にはアトラクタの大きさ（約 40）と同程度まで膨れ上がります。**6 桁の拡大**です。これがバタフライ効果——「ブラジルの蝶の羽ばたきがテキサスに竜巻を起こす」の数学的正体です。

拡大率は **最大リャプノフ指数** $\lambda$ で測ります。$|a-b| \sim e^{\lambda t}$ で離れていき、標準パラメータでは $\lambda \approx 0.9$。$\lambda > 0$ が正であること自体がカオスの定義です。長期予測が不可能なのは、初期条件をどれだけ精密に測っても、わずかな誤差が必ず指数的に拡大するからです。

> 注意：軌道間距離はアトラクタのサイズで頭打ちになるため、$\lambda$ を正しく推定するには「2 本の軌道を一定間隔ごとに再び近づけて、その間の伸び率の対数を平均する（再正規化法）」必要があります。単純に距離の対数を眺めるだけでは飽和して過小評価になります。

## まとめ

- ローレンツ系は $\sigma(y-x),\ x(\rho-z)-y,\ xy-\beta z$ の 3 本の式
- $\rho > 24.74$（標準パラメータ）でカオスに突入し、蝶型のアトラクタが現れる
