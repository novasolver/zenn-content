## ビオ・サバールの法則とは

ビオ・サバールの法則は、定常電流の微小要素 $I\,d\boldsymbol{\ell}$ が空間の各点に作る磁束密度を与える基本則です：

$$
d\boldsymbol{B} = \frac{\mu_0}{4\pi}\,\frac{I\,d\boldsymbol{\ell}\times\hat{\boldsymbol r}}{r^2}
$$

これを電流経路に沿って積分すれば、任意形状の電流が作る磁場が求まります。とはいえ一般には積分が厄介で、解析的に解ける例は限られます。その中で最も美しいのが **半径 $R$ の円電流ループの軸上磁場**。円対称性のおかげで水平成分が打ち消し合い、積分が手で閉じます：

$$
B(z) = \frac{\mu_0\,N\,I\,R^2}{2\,(R^2 + z^2)^{3/2}}
$$

ここで $N$ は巻数、$I$ は電流 [A]、$z$ はループ中心からの軸上距離です。この記事では：

1. 中心磁場 $B(0)$ が **半径に反比例**する意外な性質
2. 半値幅 $z_{1/2}\approx 0.766R$ という設計指標
3. 遠方で磁気双極子（$1/z^3$）に化ける様子

を、実際に数値を計算しながら確かめます。

## 中心磁場と半値幅

$z=0$ を代入すると、ベル型曲線のピークである中心磁場が得られます：

$$
B(0) = \frac{\mu_0\,N\,I}{2R}
$$

注目すべきは、これが **半径 $R$ に反比例**すること。電流を強くすれば磁場は強くなりますが、ループを大きくすると中心磁場はむしろ弱くなります。直感的には、ループを広げると電流の各要素が観測点から遠ざかり、$1/r^2$ でその寄与が薄まるためです。

「磁場が効いている範囲」の目安が半値幅 $z_{1/2}$。$B(z)=B(0)/2$ となる距離で、$(R^2+z^2)^{3/2}=2R^3$ を解くと：

$$
z_{1/2} = R\sqrt{2^{2/3}-1}\approx 0.766\,R
$$

半径だけで決まり、電流や巻数には依存しません。**ピークの高さ（$\propto 1/R$）と広がり（$\propto R$）のトレードオフ**が、ここに集約されています。

## 20行で書く軸上磁場計算

ツールの中核はこの 1 行の式だけです。半径と距離を cm で受け取り、メートルに直して計算します：

```javascript
const MU0 = 4 * Math.PI * 1e-7; // 真空透磁率 T·m/A

// I[A], R_cm[cm], z_cm[cm], N[巻]
function fieldOnAxis(I, R_cm, z_cm, N) {
  const R = R_cm * 0.01, z = z_cm * 0.01; // cm -> m
  const denom = Math.pow(R * R + z * z, 1.5);
  return MU0 * N * I * R * R / (2 * denom);  // B(z) [T]
}

// 中心磁場・B(z)/B(0)・半値幅
function summary(I, R_cm, z_cm, N) {
  const B  = fieldOnAxis(I, R_cm, z_cm, N);
  const B0 = fieldOnAxis(I, R_cm, 0, N);     // = MU0*N*I/(2R)
  const zHalf = R_cm * Math.sqrt(Math.pow(2, 2/3) - 1); // ≈0.766R
  return { B, B0, ratio: B / B0, zHalf };
}
```

既定値 $I=1$ A、$R=5$ cm、$z=0$、$N=1$ を入れると：

```javascript
summary(1, 5, 0, 1);
// B:     1.2566e-5 (T) = 12.566 μT
// B0:    1.2566e-5 (T)  ← z=0 なので B = B(0)
// ratio: 1.000
// zHalf: 3.832 (cm)     ← 0.766 × 5cm
```

中心磁場 12.57 μT。これは $\mu_0 N I/(2R)$ の直接計算（$4\pi\times10^{-7}\times1\times1/(2\times0.05)$）と完全に一致します。半値幅 3.83 cm は確かに $0.766\times5$ です。

## 比は半径の何倍で決まる

$B(z)/B(0)$ は $z$ を半径 $R$ の単位で測った無次元比 $\zeta=z/R$ だけで決まります：

$$
\frac{B(z)}{B(0)} = \frac{1}{(1+\zeta^2)^{3/2}}
$$

数値で見ると、減衰の速さが直感より急なことが分かります：

| $z/R$ | $B(z)/B(0)$ |
|---|---|
| 0 | 1.000 |
| 0.5 | 0.716 |
| 0.766 | 0.500（半値幅） |
| 1 | 0.354 |
| 2 | 0.089 |
| 3 | 0.032 |

$z=2R$ ですでに中心の 9% 弱、$z=3R$ では 3% 強。$z\gg R$ の遠方では $(R^2+z^2)^{3/2}\approx z^3$ となり、

$$
B(z)\approx \frac{\mu_0\,N I R^2}{2z^3} = \frac{\mu_0\,m}{2\pi z^3},\qquad m = N I\pi R^2
$$

という $1/z^3$ 減衰、すなわち磁気モーメント $m$ を持つ **磁気双極子**の磁場に化けます。小さな棒磁石が作る磁場と同じ形です。

## 設計に効く数字

実務的な設定でも確かめられます。素粒子・原子物理の実験では、地磁気（約 50 μT）を打ち消すためにヘルムホルツコイル対を使います。本ツールで $R=30$ cm、$I=1$ A、$N=100$ 巻のループを設定すると：

$$
B(0) = \frac{\mu_0\times100\times1}{2\times0.3} \approx 209\ \mu\text{T}
$$

地磁気を十分上回る一様磁場で打ち消せることが直感できます。巻数 $N$ は中心磁場に線形に効きますが、現実には総線長が伸びて抵抗が増え、インダクタンス $L\propto N^2$ で過渡応答が遅くなるため、無制限には増やせません。

## まとめ

- 円電流ループの軸上磁場は $B(z) = \mu_0 N I R^2 / [2(R^2+z^2)^{3/2}]$ と閉じた形
- 中心磁場 $B(0)=\mu_0 N I/(2R)$ は半径に反比例、巻数・電流に比例
- 半値幅 $z_{1/2}\approx 0.766R$ は半径だけで決まる設計指標
- 既定値で $B(0)=12.57$ μT、$z_{1/2}=3.83$ cm。$z\gg R$ で磁気双極子（$1/z^3$）に
- MRI 主磁場・ヘルムホルツコイル・ワイヤレス充電が、この式の重ね合わせで設計される

「対称性が積分を閉じる」というのは物理計算の醍醐味です。なお本ツールは軸上・定常電流の準静近似に限った閉じた式で、軸外の点は楕円積分を要し、高周波では使えない点に留意してください。
