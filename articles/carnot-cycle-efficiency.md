## なぜエンジンは熱を100%仕事に変えられないのか

ガソリンエンジンも蒸気タービンも、燃やした熱の一部しか仕事に変えられず、残りは捨てられます。これは技術が未熟だからではなく、**熱力学第二法則が定めた根本的な限界**です。1824 年にサディ・カルノーが示した「理想的な熱機関の効率」——**カルノー効率**は、あらゆる熱機関が超えられない上限を与えます。

この記事ではカルノーサイクルの4つの過程をたどり、効率の式を導いて、なぜそれが上限なのかを見ていきます。

♻️ **動くデモ**: [カルノーサイクルシミュレーター（NovaSolver）](https://novasolver.jp/tools/carnot-cycle.html)

## 4つの過程と効率

カルノーサイクルは、高温熱源 $T_H$ と低温熱源 $T_C$ の間で動く**可逆**な4過程からなります。

1. **等温膨張**（$T_H$）：高温源から熱 $Q_H$ を受け取り膨張
2. **断熱膨張**：熱の出入りなく膨張し、$T_C$ まで冷える
3. **等温圧縮**（$T_C$）：低温源へ熱 $Q_C$ を捨てて圧縮
4. **断熱圧縮**：熱の出入りなく圧縮し、$T_H$ へ戻る

このサイクルの効率（仕事 ÷ 受け取った熱）は、驚くべきことに**2つの温度だけ**で決まります。

$$
\eta = \frac{W}{Q_H} = 1 - \frac{T_C}{T_H}
$$

ツールの既定値（$T_H=600\,\mathrm{K}$、$T_C=300\,\mathrm{K}$、$Q_H=2000\,\mathrm{J}$）では

$$
\eta = 1 - \frac{300}{600} = 0.5 = 50\%
$$

仕事 $W=Q_H\eta=1000\,\mathrm{J}$、捨てる熱 $Q_C=Q_H-W=1000\,\mathrm{J}$。受け取った熱の半分しか仕事にならず、残り半分は必ず低温源へ捨てられます。

## P-V図とT-S図が語ること

左の **P-V 線図**では、4つの過程が囲む面積が1サイクルの正味の仕事です。右の **T-S 線図**（温度-エントロピー）では、カルノーサイクルは美しい**長方形**になります。等温過程が水平線（温度一定）、断熱過程が垂直線（エントロピー一定）だからです。この長方形の面積 $(T_H-T_C)\Delta S$ がそのまま仕事 $W$。エントロピー変化は

$$
\Delta S = \frac{Q_H}{T_H} = \frac{Q_C}{T_C}
$$

で、既定値では $\Delta S = 2000/600 = 3.33\,\mathrm{J/K}$。$Q_H/T_H = Q_C/T_C$ が成り立つ（可逆サイクルの全エントロピー変化はゼロ）のがカルノーの核心です。

## なぜこれが「上限」なのか

カルノー効率は、同じ2つの温度で動く**いかなる熱機関も超えられない**——これがカルノーの定理であり、第二法則の一つの表現です。実在のエンジン（オットー・ディーゼル・ランキン）はカルノーより必ず低い効率になります。効率を上げる道は2つだけ：**$T_H$ を上げる**か**$T_C$ を下げる**。発電所が高温・高圧を追い求め、復水器で低温源を確保するのはこのためです。$T_C=0$（絶対零度）でない限り $\eta<1$、つまり**100% は原理的に不可能**です。

## JavaScript 実装

効率と熱・仕事の計算は数行、P-V 図は理想気体の式で描きます。

```javascript
const eta = 1 - TC / TH;       // カルノー効率（温度だけで決まる）
const W = QH * eta;            // 取り出せる仕事
const QC = QH - W;             // 低温源へ捨てる熱
const dS = QH / TH;            // エントロピー変化 (= QC/TC)
// P-V: 等温は P=nRT/V、断熱は PV^γ=const (γ=1.4)
const V2 = V1 * Math.exp(QH / (n*R*TH));          // 等温膨張比
const V3 = V2 * Math.pow(TH/TC, 1/(gamma-1));     // 断熱膨張
```

## ツールで遊ぶ

[カルノーサイクルシミュレーター](https://novasolver.jp/tools/carnot-cycle.html)で試してほしい操作：

- **高温熱源 TH スライダー**を上げ、**カルノー効率 η** が上がる（T-S の長方形が縦に伸びる）のを見る
- **低温熱源 TC スライダー**を下げ、同じく効率が上がることを確認（$T_C\to0$ で $\eta\to1$ だが到達不能）
- **吸収熱量 QH スライダー**を変え、仕事 $W=Q_H\eta$ と排熱 $Q_C$ が比例で変わるのを観察
- **計算結果**で「効率 η」「仕事 W」「排熱 QC」「エントロピー変化 ΔS」を読み、$Q_H/T_H=Q_C/T_C$ を確認
- **P-V 線図**で4過程が囲む面積（仕事）、**T-S 線図**で長方形を見比べる
- **比較グラフ**で、カルノーが実在サイクル（ランキン・ディーゼル・オットー）より高効率であることを確認

## まとめ

- カルノーサイクルは高温 $T_H$・低温 $T_C$ 間の理想可逆サイクル
- 効率は温度だけで決まる：$\eta = 1 - T_C/T_H$（既定値で 50%）
- T-S 線図は長方形、その面積が仕事 $W$。$\Delta S=Q_H/T_H=Q_C/T_C$
- カルノー効率は**あらゆる熱機関の上限**（第二法則）。100% は原理的に不可能

エンジン・発電・冷凍サイクルの効率を考える出発点となるカルノーサイクルを、温度を変えながら体感してみてください。
