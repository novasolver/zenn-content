## ロジスティック写像とは

**たった 1 行の漸化式** から、自然界に普遍的なカオスが生まれる。それがロジスティック写像です：

$$
x_{n+1} = r \cdot x_n (1 - x_n)
$$

- $x_n \in [0, 1]$: 個体数比率（生態学起源）
- $r \in [0, 4]$: 成長率パラメータ

これだけ。掛け算 2 つで「決定論的なのにランダムに見える」奇妙な振る舞いが現れます。

この記事では：

1. $r$ を動かしたときの定常状態の変化
2. 周期倍化分岐とカオスへの遷移
3. ファイゲンバウム定数の話

📐 **動くデモ**: [ロジスティック写像の分岐図（NovaSolver）](https://novasolver.jp/tools/bifurcation-diagram.html)

## $r$ の値によって 4 つの世界

$x_0 = 0.5$ から始めて十分回したあとの定常状態を見ると：

| 領域 | 振る舞い | 例 |
|---|---|---|
| $0 < r < 1$ | $x_n \to 0$（絶滅） | 個体数減少 |
| $1 \leq r < 3$ | $x_n \to 1 - 1/r$（安定平衡） | 一定値 |
| $3 \leq r < 3.449$ | **2 周期**（2 値を交互） | 振動 |
| $3.449 \leq r < 3.544$ | **4 周期** | 倍々増殖 |
| $3.544 \leq r < 3.564$ | **8 周期** | さらに倍 |
| $\dots$ | **周期倍化のカスケード** | 無限に倍々 |
| $\approx 3.57 < r \leq 4$ | **カオス**（周期が消える） | 予測不能 |

## 50 行の JavaScript で実装

ロジスティック写像の反復は **8 行で書ける**：

```javascript
function iterateLogistic(r, x0, n) {
  const out = [x0];
  for (let i = 0; i < n; i++) {
    out.push(r * out[i] * (1 - out[i]));
  }
  return out;
}

// 例: r=3.9 は明確なカオス
console.log(iterateLogistic(3.9, 0.5, 10));
// → [0.5, 0.975, 0.0951, 0.336, 0.870, 0.441, 0.961, 0.146, 0.487, 0.974, 0.0995]
```

数値が **ランダムに見えるが完全に決定論的** です。同じ $r$ と $x_0$ なら何度回しても同じ列が出ます。

## 分岐図を描く

$r$ を横軸、定常状態の $x$ を縦軸にプロットすると、有名な **分岐図** が描けます：

```javascript
function bifurcationData(rMin = 2.5, rMax = 4.0, rSteps = 1000,
                          burnIn = 200, samples = 100) {
  const data = [];
  for (let i = 0; i < rSteps; i++) {
    const r = rMin + (rMax - rMin) * i / (rSteps - 1);
    let x = 0.5;
    // burn-in を捨てる（過渡応答を消す）
    for (let j = 0; j < burnIn; j++) x = r * x * (1 - x);
    // 定常状態をサンプリング
    for (let j = 0; j < samples; j++) {
      x = r * x * (1 - x);
      data.push({ r, x });
    }
  }
  return data;
}
```

`burnIn` で過渡応答を捨てるのがミソ。これを怠ると、分岐図がぼやけます。

## ファイゲンバウム定数

**ここが本記事のクライマックス**。

倍化分岐が起こる $r$ の値を $r_1, r_2, r_3, \dots$ とすると、その間隔の比は **特定の値に収束** します：

$$
\delta = \lim_{n \to \infty} \frac{r_n - r_{n-1}}{r_{n+1} - r_n} = 4.669201609\dots
$$

これが **ファイゲンバウム定数 $\delta$**。

驚くべきことに、この値は **ロジスティック写像に限らず**、放物線のように極大値を持つ任意の写像で **同じ値** が現れます。

> 倍化カスケードは普遍的構造である。物理的詳細によらず、同じ定数が支配する。

これは「相転移における臨界指数の普遍性」と同類で、20 世紀の数理物理における大発見の 1 つです（ファイゲンバウム 1978）。

$r = 3.0$ あたりで初めての分岐、$r \approx 3.57$ でカオス突入、$r \approx 3.83$ で 3 周期の窓——これらの **臨界値を視覚的に体感** できます。

## カオスの「決定論なのに予測不可能」性

カオス領域 $(r > 3.57)$ では、**初期値の微小差が指数関数的に拡大**します（バタフライ効果）。

$x_0 = 0.500$ と $x_0 = 0.500001$ から始めると、20 ステップ後にはまったく違う値になっています：

```javascript
const a = iterateLogistic(3.9, 0.500,    50);
const b = iterateLogistic(3.9, 0.500001, 50);
console.log(a[49], b[49]);  // 全然違う値が出る
```

これは **リアプノフ指数が正** ということです。長期予測が原理的に不可能なシステムのモデルとして、気象、心臓の不整脈、レーザー、生態系などの研究に応用されます。

## まとめ

- ロジスティック写像 $x_{n+1} = r x_n (1 - x_n)$ は 1 行の漸化式
- $r$ を上げると **周期倍化分岐** → **カオス** へ遷移
- 倍化の間隔比は **ファイゲンバウム定数 $\delta \approx 4.669$** に収束（普遍性）
- カオス領域では初期値鋭敏性により長期予測不能

「シンプルさからの複雑さの発生」は数理科学の中心的テーマです。30 行のコードで体感できるのが、ロジスティック写像の魅力。
