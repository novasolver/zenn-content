## 2つのルールが宇宙を動かす

1970 年に数学者ジョン・コンウェイが考案した**ライフゲーム（Game of Life）** は、格子上のセルが「生」か「死」かを、たった2つのルールで更新するだけの**セルオートマトン**です。それなのに、自走する「グライダー」、無限に増殖する「銃」、計算万能（チューリング完全）な構造まで——驚くほど複雑な現象が**創発**します。

この記事ではルールを定義し、JavaScript で実装し、グライダーや銃といった有名パターンの振る舞いを数値で確かめます。

♟️ **動くデモ**: [ライフゲーム シミュレーター（NovaSolver）](https://novasolver.jp/tools/game-of-life.html)

## ルールは B3/S23 だけ

各セルは周囲 8 マス（ムーア近傍）の生存数 $N$ を数え、次の世代を決めます。

- **誕生（Birth）**：死んでいるセルの周囲にちょうど 3 つ生きていれば誕生 → **B3**
- **生存（Survival）**：生きているセルの周囲が 2 または 3 なら生き残る → **S23**
- それ以外は死滅（過疎または過密）

これを **B3/S23** と表記します。式で書けば、生存数 $N_{i,j}=\sum_{(di,dj)\ne(0,0)} s(i+di,j+dj)$ に対して

$$
s_{i,j}(t+1) =
\begin{cases}
1 & N = 3 \\
s_{i,j}(t) & N = 2 \\
0 & \text{それ以外}
\end{cases}
$$

たったこれだけ。盤面の端は反対側につながる**トーラス（周期境界）**として扱います。

## 有名なパターン

ルールが単純でも、初期配置次第で多彩な「生き物」が現れます。

- **ブロック・ブリンカー**：静止物・周期2の振動子（最小の住人）
- **パルサー**：周期 **3** の美しい対称振動子（上図左）
- **ペンタデカスロン**：周期 **15** の振動子
- **グライダー**：周期 **4** ごとに斜めに 1 マス移動する「宇宙船」。実効速度は光速の 1/4（$c/4$）
- **グライダー銃（Gosper gun）**：周期 **30** ごとにグライダーを 1 機ずつ撃ち出す。「有限の初期配置から無限に細胞が増える」ことの証明になった歴史的パターン
- **R-ペントミノ**：たった 5 セルから 1000 世代以上カオス的に暴れ、最終的にグライダーを放出して安定する

![パルサー（周期3）と、ランダム初期からの個体数推移](/images/game-of-life/charts-closeup.png)

右図はランダムに 30% を生きたセルで埋めた初期配置（$80\times80$）の個体数推移です。約 1950 から急速に減り、200 世代後には約 470（密度 7.3%）まで落ちて、静止物と振動子からなる「灰（ash）」に落ち着きます。十分大きな盤面での漸近密度は経験的に **0.0287 前後**と知られています。

## JavaScript 実装

近傍を数えてルールを適用するだけです。端のラップ（トーラス）は剰余で表現します。

```javascript
function countNeighbors(x, y) {
  let n = 0;
  for (let dy = -1; dy <= 1; dy++)
    for (let dx = -1; dx <= 1; dx++) {
      if (dx === 0 && dy === 0) continue;
      const nx = (x + dx + cols) % cols;   // トーラス境界
      const ny = (y + dy + rows) % rows;
      n += grid[ny * cols + nx];
    }
  return n;
}
function step() {
  for (let y = 0; y < rows; y++)
    for (let x = 0; x < cols; x++) {
      const n = countNeighbors(x, y), alive = grid[y*cols + x];
      // B3/S23
      next[y*cols + x] = (alive && (n === 2 || n === 3)) || (!alive && n === 3) ? 1 : 0;
    }
  [grid, next] = [next, grid];            // バッファ入れ替え
}
```

## ツールで遊ぶ

[ライフゲーム シミュレーター](https://novasolver.jp/tools/game-of-life.html)で試してほしい操作：

- **プリセットパターン**「グライダー」「グライダー銃」「パルサー」「ペンタデカスロン」「R-ペントミノ」「LWSS宇宙船」を順に再生
- **グライダー銃**を置いて、周期 30 でグライダーが量産される（個体数が階段状に増える）のを**生存セル数**表示で確認
- **キャンバスをクリック**で自由にセルを描き、自分の初期配置から何が生まれるか実験
- **ランダム密度スライダー**を変えて「ランダム」生成し、密度で寿命がどう変わるか比較
- **1ステップ送り**でグライダーが周期 4 で斜めに 1 マス進むのをコマ送りで確認
- **シミュレーション速度・セルサイズ**を調整し、**世代数・生存率・最大生存数**の推移を観察

## まとめ

- ライフゲームは **B3/S23** という2ルールだけのセルオートマトン
- 単純ルールから振動子・宇宙船・銃・カオスといった複雑なパターンが**創発**する
- グライダーは周期 4 で $c/4$ 移動、Gosper 銃は周期 30 でグライダーを量産（無限増殖の証明）
- ランダム soup は急速に減衰し、静止物・振動子の「灰」に落ち着く（漸近密度 ≈ 0.029）
