## 味噌汁の表面に浮かぶ模様

味噌汁を温めると表面に多角形の模様が浮かび、空には鱗雲が規則正しく並ぶ。これらは下から温められた流体に生まれる**レイリー・ベナール対流**——自然界で最も基本的な「自己組織化」のひとつです。

下を熱し上を冷やすと、温まって軽くなった流体が浮力で上昇し、冷えて重くなった流体が下降します。ただし**温度差が小さいうちは何も起きません**。粘性と熱拡散が浮力を打ち消すからです。温度差がある臨界値を超えた瞬間、突然、整然とした対流ロール（セル）が立ち上がる——この「閾値のある相転移」を支配するのが**レイリー数**です。

## レイリー数と臨界値

対流が起きるかどうかは、**浮力**と**それを抑える粘性・熱拡散**の比で決まります。これを無次元化したのが**レイリー数**です。

$$
\mathrm{Ra} = \frac{g\,\beta\,\Delta T\,L^3}{\nu\,\alpha}
$$

$g$ は重力、$\beta$ は熱膨張率、$\Delta T$ は上下の温度差、$L$ は層の厚さ、$\nu$ は動粘性、$\alpha$ は熱拡散率。$\mathrm{Ra}$ が大きいほど浮力が優勢で、対流が起きやすくなります。

理論が教える臨界値は

$$
\mathrm{Ra}_c \approx 1708
$$

（上下とも自由境界の理想化では $27\pi^4/4\approx657.5$ ですが、剛体境界では約 1708）。これを境に流体の挙動が一変します。

- $\mathrm{Ra} < 1708$：**熱伝導のみ**。流体は静止し、熱は分子拡散で運ばれる
- $\mathrm{Ra} > 1708$：**対流セル**が発生。上昇流と下降流が交互に並ぶロール構造
- さらに $\mathrm{Ra}$ を上げると：**振動対流** → **乱流的対流**へ

## 熱輸送はどれだけ増えるか：ヌッセルト数

対流がどれだけ熱を運ぶかは、**ヌッセルト数** $\mathrm{Nu}$（対流を含む熱伝達 ÷ 伝導だけの熱伝達）で測ります。

$$
\mathrm{Nu} = C\cdot\mathrm{Ra}^{\,n}
$$

$\mathrm{Ra}<\mathrm{Ra}_c$ では流体が動かないので $\mathrm{Nu}=1$（伝導のみ）。臨界を超えると対流が熱を運び始め、$\mathrm{Nu}$ は $\mathrm{Ra}$ とともに増加します（高 $\mathrm{Ra}$ の乱流対流では指数 $n\approx1/3$）。上図右の曲線がこの様子で、$\mathrm{Ra}_c=1708$ を境に $\mathrm{Nu}$ が 1 から立ち上がります。

## JavaScript 実装

ツールは温度場の移流拡散を解き、レイリー数に応じた浮力で流体を駆動します。状態の判定はレイリー数の閾値で行います。

```javascript
let Ra = Math.pow(10, logRa);              // スライダーは log10(Ra)
// 浮力: 温かいセルほど上向きの加速（Boussinesq 近似）
vy[idx] += (T[idx] - Tmean) * buoyScale;   // buoyScale ∝ Ra
// 温度の移流（流れに乗って運ばれる）＋拡散（ならされる）
// 境界: 下端 T=1（高温）, 上端 T=0（低温）
// 状態判定
if      (Ra < 1708)  state = '安定（熱伝導のみ）';
else if (Ra < 5000)  state = '定常対流セル';
else if (Ra < 50000) state = '振動対流';
else                 state = '乱流的対流';
```

## ツールで遊ぶ

[対流セルシミュレーター](https://novasolver.jp/tools/convection-cells.html)で試してほしい操作：

- **レイリー数 Ra スライダー**（対数）を上げ、**対流状態**表示が「安定（伝導）」→「定常対流セル」→「振動対流」→「乱流的対流」へ変わる閾値を体感
- **プリセット**「安定層」「対流セル」「乱流的」を切り替え、$\mathrm{Ra}_c\approx1708$ 前後での劇的な違いを見る
- **アスペクト比スライダー**を変え、容器の幅でロールの数（セルの数）が変わるのを観察
- **「速度ベクトル」「流線オーバーレイ」**をオンにして、上昇流・下降流の循環構造を可視化
- **「ランダム擾乱でリセット」**で、わずかな乱れからセルが自己組織化していく様子を見る
- **計算結果**の「最高温度」「最低温度」「最大流速」で対流の強さを数値で追う

## まとめ

- レイリー・ベナール対流は下から熱した流体に生まれる自己組織化パターン
- **レイリー数** $\mathrm{Ra}=g\beta\Delta T L^3/(\nu\alpha)$ が浮力と散逸の比を表す
- $\mathrm{Ra}_c\approx1708$ を超えると、突然、対流ロール（セル）が立ち上がる（閾値のある相転移）
- 熱輸送は**ヌッセルト数** $\mathrm{Nu}$ で測り、$\mathrm{Ra}<\mathrm{Ra}_c$ では $\mathrm{Nu}=1$（伝導のみ）

マントル対流・大気循環・電子機器の冷却設計まで貫く熱対流の基礎を、レイリー数を動かしながら体感してみてください。
