## マンデルブロ集合とは

複素数の漸化式 **1 本**から、いくらズームしても新しい模様が現れ続ける無限に複雑な図形が生まれます。それがマンデルブロ集合です：

$$
z_{n+1} = z_n^2 + c, \qquad z_0 = 0
$$

複素数 $c$ ごとにこの反復を回し、$z_n$ が**無限大に発散しなければ** $c$ は集合に属します。たったこれだけのルールが、数学で最も有名なフラクタルを描きます。

この記事では：

1. 「発散するか」を判定するエスケープタイム法
2. 縞模様を滑らかにするスムーズ着色
3. 自己相似・ミニブロット・ジュリア集合との関係

## 発散判定：エスケープタイム法

$\lvert z_n \rvert$ が一度 $2$ を超えると、その後は必ず無限大へ発散することが証明できます。そこで「$\lvert z\rvert > 2$ になるまでの反復回数 $n$」を数え、上限 `maxIter` まで超えなければ「集合内」とみなします。

```javascript
function escapeTime(cr, ci, maxIter) {
  let zr = 0, zi = 0;
  for (let n = 0; n < maxIter; n++) {
    const zr2 = zr*zr - zi*zi + cr;   // z^2 + c の実部
    zi = 2*zr*zi + ci;                // 虚部
    zr = zr2;
    if (zr*zr + zi*zi > 4) return n;  // 発散（|z|>2）
  }
  return -1;                          // 集合内
}
```

いくつかの $c$ で試すと（手計算でも追えます）：

| $c$ | 判定 |
|---|---|
| $-0.5 + 0i$（中心の心臓形） | 集合内 |
| $-1.0 + 0i$（周期 2 の球） | 集合内 |
| $0.3 + 0i$（象の谷の縁） | 発散（約 12 反復） |

`maxIter` を上げるほど境界が精密になります。標準ビュー（中心 $-0.5$、ズーム 1）での集合内ピクセル比率は、$\text{maxIter}=50$ で約 17.7%、$200$ で約 17.0%、$1000$ で約 16.8% に収束していきます——境界付近の「判定保留」が反復を増やすほど減るためです。

## 縞をなくすスムーズ着色

反復回数 $n$ は整数なので、そのまま色にすると同心円状の**縞（バンディング）**が出ます。これを連続値に補間するのが**スムーズ着色**です：

$$
\nu = n + 1 - \frac{\log(\log \lvert z \rvert)}{\log 2}
$$

発散した瞬間の $\lvert z \rvert$ の「行き過ぎ具合」で小数部を決めるアイデアです。NovaSolver のツールはこの $\nu$ にカラーマップを当てており、$c = 0.3$ では $\nu \approx 12.35$ という連続値が得られます。これで境界がなめらかなグラデーションになります。

```javascript
if (zr*zr + zi*zi > 4) {
  const mag = Math.hypot(zr, zi);
  return n + 1 - Math.log(Math.log(mag)) / Math.LN2;  // 連続値
}
```

## 無限の自己相似

マンデルブロ集合の主役は**境界**です。境界はフラクタルで、そのハウスドルフ次元は **2**（Shishikura, 1991）——線なのに平面と同じ次元を持つほど複雑、という驚きの結果です。

ズームすると、全体像の縮小コピー（**ミニブロット**）が無限に現れ、渦巻き・稲妻・海馬のような模様が尽きることなく続きます：

![海馬の谷のズーム](/images/mandelbrot/charts-closeup.png)

ピクセル座標 → 複素平面の変換は、ズーム倍率 `zoom` を使って次のようにします（ツールと同じ）：

```javascript
const scale = 3.5 / (zoom * Math.min(W, H));
const cr = centerRe + (px - W/2) * scale;
const ci = centerIm + (py - H/2) * scale;
```

`zoom` を上げて `scale` を小さくするほど、複素平面のごく狭い領域を画面いっぱいに拡大できます。

![ズームしても現れ続けるフラクタル構造](/images/mandelbrot/slider-anim.gif)

## ジュリア集合との関係

同じ漸化式で **$c$ を固定し、$z_0$ を動かす**と、今度は **ジュリア集合**が得られます。マンデルブロ集合は、いわば「どの $c$ が連結なジュリア集合を作るか」の地図になっています。ツールのジュリアモードでは、マウス位置を $c$ として対応するジュリア集合がリアルタイムに変化します。

## まとめ

- マンデルブロ集合は $z_{n+1}=z_n^2+c,\ z_0=0$ が発散しない $c$ の集合
- エスケープタイム法（$\lvert z\rvert>2$ で発散確定）で判定し、スムーズ着色で縞を消す
- 境界はフラクタル次元 2、ミニブロットが無限に現れる自己相似構造
- $c$ 固定・$z_0$ 可変にするとジュリア集合になる

「最小のルールから最大の複雑さ」を最も鮮やかに見せてくれるのがマンデルブロ集合です。
